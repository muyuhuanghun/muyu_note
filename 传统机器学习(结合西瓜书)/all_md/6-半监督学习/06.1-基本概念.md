## 一、半监督学习核心概念

> 如何在只有少量标注数据的情况下，利用大量未标注数据提升模型性能？

半监督学习：让学习器不依赖外界交互、自动利用未标记样本来提升学习性能 -- 就像老师只批改了10份作业，但通过观察剩下90份作业的相似度，推断出他们的成绩

```python
import numpy as np
from sklearn.datasets import make_classification, make_moons
from sklearn.semi_supervised import LabelPropagation, LabelSpreading
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score
import matplotlib.pyplot as plt

# 🌟 半监督学习的核心实验：对比"只用少量有标签"vs"加入海量无标签"的效果
# 设定：总共1000个样本，但只有30个有标签（模拟标注成本高的场景）

# ---- 生成数据集 ----
np.random.seed(42)
X, y = make_classification(n_samples=1000, n_features=2, n_redundant=0,
                           n_clusters_per_class=1, random_state=42)

# 📌 核心操作：把大部分标签"隐藏"成 -1（表示无标签）
# sklearn 中用 -1 表示未标记样本，这是半监督学习的标准约定
rng = np.random.RandomState(42)
n_labeled = 30  # 只保留30个有标签样本
random_unlabeled_points = rng.rand(len(y)) < (1 - n_labeled / len(y))
y_semi = y.copy()
y_semi[random_unlabeled_points] = -1  # ⚠️ -1 = 未标记，sklearn半监督API的标准标记

# ---- 模型1：只用有标签数据（监督学习基线）----
# 模拟的是"只有30个标注，剩下的970个数据直接扔掉"的惨况
X_labeled = X[~random_unlabeled_points]
y_labeled = y[~random_unlabeled_points]

# ---- 模型2：LabelPropagation（图半监督方法）----
# 利用聚类假设：同一个簇里的样本大概率同一类
lp = LabelPropagation(kernel='rbf', gamma=20, n_neighbors=7, max_iter=100)
lp.fit(X, y_semi)  # 同时喂入有标签(-1以外)和无标签(-1)
y_pred_lp = lp.transduction_  # transduction_属性存储对所有训练样本的预测

# ---- 模型3：LabelSpreading（改进版，加入正则化α参数）----
# 利用流形假设：标签在数据流形上平滑变化
ls = LabelSpreading(kernel='rbf', gamma=20, n_neighbors=7, alpha=0.2, max_iter=100)
ls.fit(X, y_semi)
y_pred_ls = ls.transduction_

# ---- 评估：只看无标签样本上的预测准确率 ----
unlabeled_mask = y_semi == -1
acc_lp = accuracy_score(y[unlabeled_mask], y_pred_lp[unlabeled_mask])
acc_ls = accuracy_score(y[unlabeled_mask], y_pred_ls[unlabeled_mask])

print(f"无标签样本上的准确率:")
print(f"  LabelPropagation:  {acc_lp:.4f}")
print(f"  LabelSpreading:    {acc_ls:.4f}")
print(f"💡 只用了 {n_labeled}/{len(y)} ({n_labeled/len(y)*100:.1f}%) 的标签数据！")
```

```python
# ============================================
# 🌟 关键演示：标签量对半监督学习效果的影响
# 你会发现：标签越少，半监督相对监督学习的提升越大
# ============================================

def semi_supervised_benchmark(X, y, labeled_ratios=[0.01, 0.02, 0.05, 0.1, 0.2]):
    """
    测试不同标注比例下半监督学习和监督学习的效果差异
    """
    results = []
    for ratio in labeled_ratios:
        # 随机藏起标签
        rng = np.random.RandomState(42)
        unlabeled_mask = rng.rand(len(y)) > ratio
        y_semi = y.copy()
        y_semi[unlabeled_mask] = -1

        # LabelSpreading
        ls = LabelSpreading(kernel='rbf', gamma=20, n_neighbors=7, alpha=0.2)
        ls.fit(X, y_semi)
        acc_semi = accuracy_score(y[unlabeled_mask], ls.transduction_[unlabeled_mask])

        results.append((ratio, int(ratio * len(y)), acc_semi))
        print(f"  标注 {ratio*100:4.1f}% ({int(ratio*len(y)):3d}张) → 未标注部分准确率: {acc_semi:.4f}")

    return results

print("📌 半监督学习在不同标注比例下的表现:")
print("-" * 50)
semi_supervised_benchmark(X, y)
# 💡 观察：即使只标注 1%（10个样本），半监督也能达到相当不错的准确率
# 这就是"利用无标签数据分布信息"的威力 — 数据本身的聚类结构告诉你答案
```

## 二、两大核心假设：聚类假设 vs 流形假设

> 半监督学习为什么能从未标注数据中获益？

```python
# 🌟 两个假设的核心区别 — 用代码直观感受
# 聚类假设：数据成"团块"，同一团的样本同性
# 流形假设：数据在低维流形上平滑分布，近朱者赤

# ---- 构造两种典型数据分布 ----
# 类型1：团块状数据（适合聚类假设）
X_cluster, y_cluster = make_classification(
    n_samples=300, n_features=2, n_redundant=0,
    n_clusters_per_class=1, n_informative=2, random_state=42
)

# 类型2：月牙形数据（适合流形假设—数据不成团但沿流形分布）
X_moon, y_moon = make_moons(n_samples=300, noise=0.1, random_state=42)

# ⚠️ 月牙形数据中，同一类别的点不聚成"团"，
# 而是像两条弯弯的月牙彼此缠绕 — 这是流形假设擅长的场景

print("聚类假设适用场景: 团块数据 → LabelSpreading(kernel='rbf') 默认行为")
print("流形假设适用场景: 月牙数据 → 需要 k 近邻图来捕捉局部流形结构")
```

```python
# ============================================
# 📌 关键对比：LabelSpreading 中 kernel 参数的选择
# 'rbf': 全连接图，用高斯核衡量全局相似度 → 更偏聚类假设
# 'knn': k近邻图，只连局部邻居 → 更偏流形假设
# ============================================

# 在月牙数据上对比两种kernel
for kernel_name in ['knn', 'rbf']:
    # 隐去90%的标签
    rng = np.random.RandomState(42)
    mask = rng.rand(len(y_moon)) > 0.1
    y_semi = y_moon.copy()
    y_semi[mask] = -1

    ls = LabelSpreading(kernel=kernel_name, n_neighbors=7, alpha=0.2)
    ls.fit(X_moon, y_semi)
    acc = accuracy_score(y_moon[mask], ls.transduction_[mask])
    print(f"  kernel='{kernel_name}' on 月牙数据: 未标注准确率 = {acc:.4f}")
    # 💡 在月牙形这种非团块数据上，knn 通常优于 rbf
    # 因为 knn 只看局部邻居，符合流形假设"近朱者赤"的思想
```

## 三、聚类假设理解

> 为什么"同一簇的样本大概率是同一类"这个假设是合理的？

**核心思想**：**"物以类聚"**。假设数据存在簇结构，同一个簇里的样本极大概率为同一类别。

```python
# 🌟 聚类假设的本质：决策边界应该穿过数据的"低密度区"
# 想象两团棉花糖 — 它们的交界处天然就是最佳的分割线
# 半监督学习就是利用无标签数据来"摸清"棉花糖的形状，
# 从而在没有标签的地方也能画出正确的分界线

# 通俗比喻：
# 你有一堆红苹果和绿苹果，但你只给其中3个贴了标签。
# 你发现所有没贴标签的苹果天然分成两堆（红的聚一堆，绿的聚一堆），
# 那你自然就知道中间那堆是红的，另一堆是绿的 — 这就是聚类假设的威力
```

⚠️ **局限性**：假设类别的形状是比较规整的"团块"。当数据分布复杂（如月牙形）、类别交织在一起时，聚类假设可能失效。

## 四、流形假设理解

> 高维数据为什么可以用低维流形来描述？

**核心思想**：**"近朱者赤"**。高维数据实际上分布在一个低维流形结构上，在流形上相近的样本拥有相似的输出值。

```python
# 🌟 流形假设的比喻：卷起来的春卷皮
# 在三维空间里，春卷皮上两个点可能离得很近（空中直线距离），
# 但它们一个在皮的上边缘，一个在下边缘，其实在"皮表面"这个流形上离得很远
# 流形假设说：不要看三维的直线距离，要看"沿着春卷皮表面走"的距离

# 实际例子：
# 一段视频的每一帧是一张高维图像，但所有帧其实沿着一个
# 一维的时间流形排列 — 相邻帧的内容最相似，标签也应该相似
```

**为什么流形假设适用范围更广？** 聚类假设要求数据成"团"，而流形假设只要求数据在局部是连续和相似的，能处理**更扭曲、更复杂**的数据分布。

## 五、多模态视角下的意义

> 半监督学习在多模态场景中有什么应用价值？

```python
# 🌟 半监督学习在多模态场景（视频+文本+音频）的应用思路
# 
# 流形假设的应用：
#   不同模态（视频和文本）映射到高维空间后，落在同一个复杂流形上
#   可以通过寻找模态间的"邻居"关系，让标签在流形上流动
#   → 你标注了一段"猫的视频"，模型通过流形结构自动推断：
#     哪些没标注的视频也像猫、哪些没标注的文本描述也像猫
# 
# 聚类假设的应用：
#   通过对比学习（Contrastive Learning）把无标签视频聚在一起
#   即使只有极少量标注，也能通过"数据云"的分布找准分类边界
#   → 相当于用无标签数据在特征空间中"画出"了每个类别的轮廓
```

## 六、几种学习方式的区别

> 监督学习、无监督学习、半监督学习的本质区别是什么？

![alt text](image-1.png)

```python
# 📌 三种学习范式的本质区别（通俗版）：
# 
# 监督学习 (Supervised):
#   老师拿着标准答案，逐题教你 → 质量高但答案少（标注成本贵）
#   给你1000道题，但只有100道有正确答案
# 
# 无监督学习 (Unsupervised):
#   没老师，自己找规律 → 只能发现数据的内在结构（聚类、降维）
#   给你1000道题，一道答案都没有，你自己分类
# 
# 半监督学习 (Semi-supervised):
#   老师只给了10道题的答案，剩下990道靠"看邻居"的自己琢磨
#   给你1000道题，只有10道有答案，但你可以利用题目本身的
#   相似度（长得像的题目答案可能一样）来推断其余答案
```
