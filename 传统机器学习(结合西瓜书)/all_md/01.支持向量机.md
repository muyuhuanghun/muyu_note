## 一、为什么需要 SVM？

### 1. 核心问题

```
📌 核心问题：如何找到一个最优的分类边界？

给定两类样本，有无数条线能把它们分开——
但哪条线"最好"？SVM 的答案：间隔最大的那条。

把 SVM 想象成一个帐篷——支持向量就是撑起帐篷的杆子，
非支持向量是帐篷外的石头，移走它们帐篷形状不变。
```

### 2. sklearn 起步

```python
import numpy as np
from sklearn.svm import SVC, SVR, LinearSVC
from sklearn.datasets import make_blobs, make_moons
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import train_test_split, GridSearchCV
from sklearn.metrics import accuracy_score
import matplotlib.pyplot as plt

# 生成线性可分数据
X, y = make_blobs(n_samples=200, centers=2, random_state=42, cluster_std=1.2)

# ⚠️ SVM对特征尺度极度敏感——量纲差异会让某些特征主导距离计算
# 比如一个特征0~1，另一个0~10000，后者会绑架决策边界
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

X_train, X_test, y_train, y_test = train_test_split(X_scaled, y, test_size=0.3, random_state=42)
```

## 二、SVM 的核心原理

### 1. 硬间隔 vs 软间隔：C 惩罚系数的作用

```
📌 C 的物理含义：对"犯规"样本的惩罚力度

C=无穷大 → 硬间隔：强制所有样本满足约束，只在完全线性可分时有效
C极大   → 惩罚极重，模型死记每个点 → 过拟合
C极小   → 惩罚极弱，容忍大量"犯规" → 欠拟合
C趋近无穷大时，软间隔SVM退化为硬间隔SVM
```

```python
# 💡 硬间隔SVM（C=1e10近似无穷大，只有完全线性可分才有效）
# 实际中几乎不用——只要有噪声/异常点就崩
svm_hard = SVC(C=1e10, kernel='linear')
svm_hard.fit(X_train, y_train)
print(f"硬间隔(C=1e10) 训练集准确率: {svm_hard.score(X_train, y_train):.3f}")
print(f"硬间隔(C=1e10) 支持向量数: {sum(svm_hard.n_support_)}")

# 软间隔SVM（C较小，允许部分违反约束，泛化更好）
svm_soft = SVC(C=1.0, kernel='linear')
svm_soft.fit(X_train, y_train)
print(f"软间隔(C=1.0) 训练集准确率: {svm_soft.score(X_train, y_train):.3f}")
print(f"软间隔(C=1.0) 支持向量数: {sum(svm_soft.n_support_)}")

# C从极小到极大的完整对比
for C_val in [0.01, 0.1, 1.0, 10, 100, 10000]:
    svm = SVC(C=C_val, kernel='linear')
    svm.fit(X_train, y_train)
    n_sv = sum(svm.n_support_)
    print(f"C={C_val:6.2f} → 训练集准确率={svm.score(X_train, y_train):.3f}, "
          f"测试集准确率={svm.score(X_test, y_test):.3f}, 支持向量数={n_sv}")
```

### 2. 支持向量与权重公式

```
📌 权重公式：w = Σ α_i y_i x_i

只有 α_i > 0 的样本对超平面有贡献——这就是支持向量。
数学判定标准：拉格朗日乘子非零。
直观理解：触碰/越过间隔边界的样本。
```

```python
# 🌟 从sklearn模型中提取支持向量信息
svm = SVC(C=1.0, kernel='linear')
svm.fit(X_train, y_train)

# 支持向量索引 → 正是 α_i > 0 的样本
sv_indices = svm.support_
# 支持向量的拉格朗日乘子 α
alphas = svm.dual_coef_.ravel()
# 支持向量本身
support_vectors = svm.support_vectors_

print(f"\n总样本数: {len(X_train)}, 支持向量数: {len(sv_indices)} "
      f"(占比 {len(sv_indices)/len(X_train)*100:.1f}%)")
print(f"非零乘子数: {abs(alphas).sum():.1f}, 大部分样本的α_i=0，这就是SVM的稀疏性")

# 💡 验证：移除非支持向量后，模型完全不变
```

### 3. 对偶问题：为什么必要？

```
📌 三个原因：

原因1：原问题变量数=特征维度+1，高维场景成本爆炸；对偶问题变量数=样本数
原因2：对偶解天然符合KKT条件，只有支持向量的乘子非零 → 稀疏性
原因3：对偶问题中只有样本内积，可直接用核函数替换 → 非线性分类
```

### 4. KKT 互补松弛条件

```
📌 KKT 互补松弛条件（理解支持向量的钥匙）：

α_i * [ y_i(w^T x_i + b) - 1 + ξ_i ] = 0

当 α_i > 0 时，括号内必须 = 0，即 y_i(w^T x_i + b) = 1 - ξ_i：
  1. ξ_i = 0     → 样本刚好触碰间隔边界（经典支持向量）
  2. 0 < ξ_i < 1 → 落在间隔带内，分类正确但没到边界
  3. ξ_i > 1     → 分类错误，但也成为支持向量

间隔带外、分类正确的样本 → y_i(w^T x_i + b) > 1 → α_i = 0 → 不是支持向量
```

## 三、核函数：处理非线性数据

### 1. 核技巧的核心思想

```
💡 核技巧：把低维数据映射到高维，无需显式计算高维坐标

核函数本质：隐式计算两个样本在高维特征空间的内积。
合法条件（Mercer定理）：
  1. 函数对称：K(x,z) = K(z,x)
  2. 核矩阵半正定：对任意有限样本，构造的核矩阵必须半正定
```

```python
# 生成线性不可分的数据（月牙形）
X_moon, y_moon = make_moons(n_samples=200, noise=0.15, random_state=42)
X_moon_scaled = StandardScaler().fit_transform(X_moon)

# 💡 常见核函数手写实现（理解内部机制）：
def linear_kernel(x1, x2):
    """线性核：就是最朴素的点积"""
    return np.dot(x1, x2)

def poly_kernel(x1, x2, degree=3, gamma=1.0, coef0=1.0):
    """多项式核：K(x,z) = (γ·x·z + r)^d"""
    return (gamma * np.dot(x1, x2) + coef0) ** degree

def rbf_kernel(x1, x2, gamma=1.0):
    """高斯RBF核：K(x,z) = exp(-γ||x-z||²) —— 最常用的非线性核"""
    dist = np.linalg.norm(x1 - x2) ** 2
    return np.exp(-gamma * dist)
```

### 2. 不同核函数对比

```python
# 💡 核函数选型速查：
#   线性核：高维稀疏数据（如文本分类）上无敌，计算最快
#   多项式核：d=2~3最适合简单非线性边界，d>5严重过拟合
#   高斯RBF核：低维/中小样本量的通用首选

kernels = {
    'linear': SVC(kernel='linear', C=1.0),
    'poly': SVC(kernel='poly', degree=3, C=1.0),
    'rbf': SVC(kernel='rbf', C=1.0, gamma='scale'),
}
for name, model in kernels.items():
    model.fit(X_moon_scaled, y_moon)
    n_sv = sum(model.n_support_)
    print(f"核函数={name:8s} → 准确率={model.score(X_moon_scaled, y_moon):.3f}, 支持向量数={n_sv}")
```

### 3. RBF 核参数 γ 的作用

```
📌 γ 控制高斯核的"宽度"：

γ越大 → 核越窄 → 每个样本影响范围越小 → 容易过拟合
γ越小 → 核越宽 → 模型越平滑 → 容易欠拟合
```

```python
for gamma_val in [0.01, 0.1, 1.0, 10, 100]:
    svm_rbf = SVC(kernel='rbf', C=1.0, gamma=gamma_val)
    svm_rbf.fit(X_moon_scaled, y_moon)
    n_sv = sum(svm_rbf.n_support_)
    print(f"γ={gamma_val:-6.2f} → 支持向量数={n_sv}, "
          f"训练准确率={svm_rbf.score(X_moon_scaled, y_moon):.3f}")
    # ⚠️ γ很大时支持向量数接近总样本数 → 几乎在"背"每个点 → 严重过拟合
```

## 四、调参与实战

### 1. GridSearchCV 网格搜索

```python
# ⚠️ SVM调参前务必先标准化数据！量纲差异直接毁掉距离计算和优化收敛速度
X_moon_scaled = StandardScaler().fit_transform(X_moon)

# 📌 网格搜索：C 和 γ 是RBF核的两大核心超参
param_grid = {
    'C': [0.1, 1, 10, 100],
    'gamma': [0.01, 0.1, 1, 'scale', 'auto'],
}
grid = GridSearchCV(
    SVC(kernel='rbf'), param_grid, cv=5,
    scoring='accuracy', n_jobs=-1
)
grid.fit(X_moon_scaled, y_moon)
print(f"\n最佳参数: {grid.best_params_}")
print(f"最佳交叉验证准确率: {grid.best_score_:.3f}")
```

### 2. 调参实战经验

```
💡 调参步骤：
  1. 先粗调C（对数步长0.1, 1, 10, 100...）
  2. 再细调γ（对照C的较优值附近搜索）
  3. 线性核仅需调C，无核函数专属参数——计算最快、不易过拟合
  4. 多项式核优先设degree=2~3，d>5会严重过拟合
```

## 五、SVR：支持向量回归

### 1. SVR vs SVC 的核心区别

```
📌 核心逻辑完全相反：

SVC：找分隔超平面，让样本尽量落在间隔带之外 → 最大化间隔
SVR：找拟合超平面，让样本尽量落在ε-间隔带之内 → 最小化复杂度+越界损失
```

```python
# 生成回归数据
np.random.seed(42)
X_reg = np.linspace(-5, 5, 100).reshape(-1, 1)
y_reg = np.sin(X_reg).ravel() + np.random.randn(100) * 0.15

X_reg_scaled = StandardScaler().fit_transform(X_reg)
X_train_r, X_test_r, y_train_r, y_test_r = train_test_split(X_reg_scaled, y_reg, test_size=0.3)

# SVR的两个核心参数：
#   ε：容错带宽，偏差<ε不计入损失
#       ε过大 → 容错太宽 → 模型几乎是平线 → 欠拟合
#       ε过小 → 容错太窄 → 每个点都拟合 → 过拟合，支持向量数爆炸
#   C：惩罚系数，和SVC一样的逻辑
for eps_val in [0.05, 0.1, 0.2, 0.5]:
    svr = SVR(kernel='rbf', C=1.0, epsilon=eps_val)
    svr.fit(X_train_r, y_train_r)
    n_sv = len(svr.support_)
    print(f"ε={eps_val:.2f} → 支持向量数={n_sv}, "
          f"训练R²={svr.score(X_train_r, y_train_r):.3f}, "
          f"测试R²={svr.score(X_test_r, y_test_r):.3f}")
```

### 2. SVR 支持向量判定

```
📌 SVR支持向量判定：α̂_i - α_i ≠ 0 的样本

和SVC逻辑一致，权重公式 w = Σ(α̂_i - α_i)x_i
  1. α_i > 0  → 样本低于ε-带下边界（带外），或碰下边界
  2. α̂_i > 0  → 样本高于ε-带上边界（带外），或碰上边界
落在ε-带内部的样本 → α_i = α̂_i = 0 → 对模型无贡献
```

## 六、SVM 的核心优势与选型建议

### 1. 三大优势

```
📌 SVM三大优势：

1. 稀疏性：只依赖少数支持向量，预测时只计算它们的核函数，成本极低
2. 核技巧：隐式高维映射，无需显式计算高维坐标
3. 凸优化：唯一全局最优解，不像神经网络掉进局部最优
```

### 2. 核函数选型速查

```
💡 选型指南：

高维稀疏数据(文本分类) → LinearSVC（不用SVC+linear，LinearSVC底层用LIBLINEAR更快）
样本量 > 100k          → LinearSVC（线性最快）
非线性通用场景         → SVC + RBF（先调C再调γ）
简单多项式边界         → SVC + poly（degree=2~3）
```

### 3. 常见坑

```
⚠️ 常见坑：

1. 忘了标准化 → 决策边界被大数值特征绑架
2. C太大       → 过拟合，泛化崩
3. γ太大       → 每个样本都成支持向量 → 计算爆炸
4. 大数据集    → 不用LinearSVC而用SVC(kernel='linear') → 慢N倍
```
