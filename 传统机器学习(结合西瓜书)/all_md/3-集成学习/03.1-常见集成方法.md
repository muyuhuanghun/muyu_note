## 一、四种集成方法 — 核心代码演示

集成学习如何将多个"弱学习器"组合成一个强学习器？

# 集成学习就像组建一个"专家顾问团"——与其听一个人的意见，
# 不如让多个专家投票，取长补短，减少判断失误
import numpy as np
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.linear_model import LogisticRegression
from sklearn.tree import DecisionTreeClassifier
from sklearn.svm import SVC
from sklearn.ensemble import (
    VotingClassifier, BaggingClassifier, RandomForestClassifier,
    AdaBoostClassifier
)
from sklearn.metrics import accuracy_score

# 造一份二分类数据，模拟"客户是否会流失"场景
X, y = make_classification(n_samples=1000, n_features=20, n_informative=10,
                           n_redundant=5, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

---

### 1. 投票法 (Voting) — 不同算法，同一份数据，各自表态

不同类型模型如何通过投票达成共识？

# 三个不同"性格"的专家：逻辑回归(线性思维)、决策树(规则思维)、SVM(边界思维)
# 它们在同一份训练数据上各自学习，预测时投票表决
clf_lr = LogisticRegression(max_iter=1000, random_state=42)
clf_dt = DecisionTreeClassifier(max_depth=5, random_state=42)
clf_svm = SVC(probability=True, random_state=42)

# 🌟 hard voting: 少数服从多数 — 直接统计票数
vote_hard = VotingClassifier(
    estimators=[('lr', clf_lr), ('dt', clf_dt), ('svm', clf_svm)],
    voting='hard'  # 每个模型投一票，取票数最多的类
)
vote_hard.fit(X_train, y_train)
print(f"📌 硬投票准确率: {vote_hard.score(X_test, y_test):.4f}")

# 💡 soft voting: 加权平均概率 — 每个模型输出概率，取加权平均后选最大
# 当模型能输出靠谱的概率时，soft voting 通常优于 hard voting
vote_soft = VotingClassifier(
    estimators=[('lr', clf_lr), ('dt', clf_dt), ('svm', clf_svm)],
    voting='soft'  # 模型输出概率，取加权平均
)
vote_soft.fit(X_train, y_train)
print(f"📌 软投票准确率: {vote_soft.score(X_test, y_test):.4f}")

# 对比一下三个"专家"各自的表现
for name, clf in [('LR', clf_lr), ('DT', clf_dt), ('SVM', clf_svm)]:
    clf.fit(X_train, y_train)
    print(f"  个体 {name}: {clf.score(X_test, y_test):.4f}")

---

### 2. Bagging — 相同算法，不同数据子集，并行训练

相同模型如何通过数据扰动产生多样性？

# 核心思想：从原始数据中有放回地抽 N 个子集（Bootstrap），
# 在每个子集上训练一个模型，最后投票/平均。像"三个臭皮匠顶个诸葛亮"
# 参考原始数据的80%采样，每个模型看到的数据不一样 → 产生多样性

# 💡 泛型 Bagging：你可以传入任意基学习器
bagging = BaggingClassifier(
    estimator=DecisionTreeClassifier(max_depth=5, random_state=42),
    n_estimators=100,        # 训练100个"臭皮匠"
    max_samples=0.8,         # 每个模型只看80%的数据（Bootstrap采样）
    bootstrap=True,          # 🌟 有放回采样，产生数据差异性
    oob_score=True,          # "袋外样本"自动充当验证集
    random_state=42
)
bagging.fit(X_train, y_train)
print(f"\n📌 通用Bagging准确率: {bagging.score(X_test, y_test):.4f}")
print(f"📌 袋外估计(OOB): {bagging.oob_score_:.4f}")  # OOB ≈ 交叉验证精度

# 🌟 随机森林 — Bagging的"王者皮肤"
# 不仅对样本采样，还对特征列采样（属性扰动），双重随机 → 多样性更强
rf = RandomForestClassifier(
    n_estimators=100,        # 树的数量
    max_depth=5,             # 限制深度防过拟合
    max_features='sqrt',     # 🌟 每棵树随机选 sqrt(n_features) 个特征
    bootstrap=True,          # 样本也Bootstrap
    oob_score=True,
    random_state=42
)
rf.fit(X_train, y_train)
print(f"📌 随机森林准确率:    {rf.score(X_test, y_test):.4f}")
print(f"📌 随机森林OOB:       {rf.oob_score_:.4f}")

### 3. Boosting 快速预览 — 串行"师徒制"

后一个模型如何专门攻克前一个模型的错题？

# 不并行了，而是"徒弟学师父的错题"：后一个模型专门攻克前一个模型做错的样本
# ⚠️ 详细解析见 [[03.2-Boosting]]
ada = AdaBoostClassifier(
    estimator=DecisionTreeClassifier(max_depth=1),  # 决策桩：弱到极点的"徒弟"
    n_estimators=50,           # 串行训练50轮
    learning_rate=0.5,         # 🌟 学习率：控制每轮纠错的激进程度
    random_state=42
)
ada.fit(X_train, y_train)
print(f"\n📌 AdaBoost准确率: {ada.score(X_test, y_test):.4f}")

## 二、四种方法横向对比实验

四种集成方法在同一个擂台上表现如何？

# 把四种集成方法拉到同一个擂台上比一比
models = {
    'Voting(Soft)': vote_soft,
    'Bagging':     bagging,
    'RandomForest':rf,
    'AdaBoost':    ada

print("\n" + "="*50)

for name, model in models.items():
    # 10折交叉验证，看泛化能力
    scores = cross_val_score(model, X, y, cv=10, scoring='accuracy')

## 三、集成方法对比总结

四种方法的本质区别是什么？

#   投票法(Voting):   不同类型模型 → 同一份数据 → 并行投票
#   Bagging:          同一类型模型 → 不同抽样数据 → 并行训练 → 投票/平均
#   Boosting:         同一类型模型 → 串行纠错 → 加权投票
#   Stacking:         不同类型模型 → 交叉验证 → 次级模型学会"谁更可信"
#
# 💡 投票法是"不同模型看同一数据"
# 💡 Bagging是"相同模型看不同子集"
# 💡 Boosting是"徒弟不断学师父的错题"
# 💡 Stacking是"大老板学习各部门经理的历史表现来拍板"
