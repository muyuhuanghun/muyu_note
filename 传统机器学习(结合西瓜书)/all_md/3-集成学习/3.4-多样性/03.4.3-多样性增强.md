## 一、四种多样性增强方法 — 代码演示

> **核心问题**：度量多样性只是"诊断"，如果发现多样性不够，有什么办法主动"制造"多样性？

# 集成学习的精髓是"好而不同"——"好"靠调参，"不同"靠扰动
# 扰动 = 在学习过程的某个环节"做手脚"，迫使每个模型学到不一样的"偏见"
# 最终在集成时，这些偏见互相抵消 → 泛化能力提升

```python
import numpy as np
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.tree import DecisionTreeClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.neural_network import MLPClassifier
from sklearn.ensemble import RandomForestClassifier, AdaBoostClassifier, BaggingClassifier
from sklearn.multiclass import OutputCodeClassifier
from sklearn.svm import SVC, LinearSVC
from sklearn.utils import resample

np.random.seed(42)
X, y = make_classification(n_samples=800, n_features=30, n_informative=15,
                           n_redundant=5, n_classes=2, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)
```

---

## 二、方法1: 数据样本扰动 (Data Sample Perturbation)

> **问题**：最简单的方式——让不同模型看到不同的数据，能做到吗？

# 核心思路：给每个基学习器喂不同的数据子集 → 它们"看到的世界"不同
#   就像给10个侦探看同一个案子的不同卷宗，他们会有不同的推理

### 1. Bootstrap 采样 (Bagging的核心)

```python
# 有放回地从原始数据抽子集，每个模型看到的数据不完全相同
bagging = BaggingClassifier(
    estimator=DecisionTreeClassifier(max_depth=5, random_state=42),
    n_estimators=100,
    max_samples=0.8,    # 🌟 每个模型只拿80%的数据
    bootstrap=True,     # 🌟 有放回采样 → 子集之间有重叠但分布不同
    random_state=42
)
bagging.fit(X_train, y_train)
print(f"📌 Bootstrap扰动(Bagging): {bagging.score(X_test, y_test):.4f}")
```

### 2. 序列采样 (AdaBoost的核心)

```python
# 不是并行采样，而是串行：后一轮根据前一轮的表现重新分配样本权重
ada = AdaBoostClassifier(
    estimator=DecisionTreeClassifier(max_depth=1),
    n_estimators=100,
    learning_rate=0.5,
    random_state=42
)
ada.fit(X_train, y_train)
print(f"📌 序列扰动(AdaBoost):   {ada.score(X_test, y_test):.4f}")

# ⚠️ 适用性: Bootstrap对"不稳定学习器"(决策树、神经网络)效果显著
#    对"稳定学习器"(线性模型、SVM)效果弱——因为数据稍有变化，线性模型也学差不多
#    所以SVM做Bagging意义不大，需要用属性扰动或参数扰动
```

## 三、方法2: 输入属性扰动 (Input Attribute Perturbation)

> **问题**：对于SVM这种"太稳定"的学习器，数据扰动不管用，还能怎么制造多样性？

# 核心思路：限制每个模型只能看到部分特征列 → 从不同"观察角度"理解数据
#   就像让10个侦探，有的看指纹、有的看监控、有的看通话记录
#   ——角度不同，结论互补

### 1. 随机子空间法: 每棵树随机选特征子集

```python
rf_subspace = RandomForestClassifier(
    n_estimators=100,
    max_features='sqrt',     # 🌟 每棵树随机选 sqrt(n_features) 个特征
    bootstrap=True,           # 双重随机：样本+特征都随机
    random_state=42
)
rf_subspace.fit(X_train, y_train)
print(f"\n📌 属性扰动(随机子空间): {rf_subspace.score(X_test, y_test):.4f}")
```

### 2. 手动实现随机子空间: 给SVM也注入属性扰动

```python
# 对稳定学习器（SVM），数据扰动没用，但属性扰动能让它"换个角度看问题"
print("💡 手动属性扰动 — 给SVM注入多样性:")
n_models = 10
d_original = X_train.shape[1]      # 原始特征数
d_subspace = int(d_original * 0.6)  # 每次随机选60%的特征
svm_preds = np.zeros((X_test.shape[0], n_models))
for i in range(n_models):
    # 随机选特征列
    feature_idx = np.random.choice(d_original, d_subspace, replace=False)
    svm = SVC(probability=True, random_state=i)
    svm.fit(X_train[:, feature_idx], y_train)
    svm_preds[:, i] = svm.predict(X_test[:, feature_idx])  # 预测也对齐特征

# 硬投票集成
svm_ensemble = (svm_preds.mean(axis=1) >= 0.5).astype(int)
acc_svm_ensemble = np.mean(svm_ensemble == y_test)
svm_single = SVC(probability=True, random_state=0).fit(X_train, y_train)
acc_svm_single = svm_single.score(X_test, y_test)
print(f"  单个SVM(全特征):       {acc_svm_single:.4f}")
print(f"  属性扰动SVM集成(10个):  {acc_svm_ensemble:.4f}")
print(f"  💡 即使SVM是稳定学习器，属性扰动也能产生有效的多样性增益")
```

## 四、方法3: 输出表示扰动 (Output Representation Perturbation)

> **问题**：能不能不扰动输入，而是扰动"答案"（标签）来制造多样性？

# 核心思路：不是扰动输入，而是扰动"答案"（标签）
#   最有代表性的是ECOC（纠错输出码）

### 1. ECOC (Error Correcting Output Codes)

```python
# 将多分类问题拆成一系列二分类子问题，利用纠错码的冗余实现容错
# 就像用军队传令的"暗号"：即使个别字被敌人篡改了，整体信息仍能还原
from sklearn.datasets import make_classification as make_multi
X_m, y_m = make_multi(n_samples=600, n_features=20, n_classes=5,
                      n_informative=10, random_state=42)
X_m_train, X_m_test, y_m_train, y_m_test = train_test_split(
    X_m, y_m, test_size=0.3, random_state=42)

# ECOC: 每个类分配一个二进制码，每个bit是一个二分类器
ecoc = OutputCodeClassifier(
    estimator=LinearSVC(dual='auto', random_state=42, max_iter=5000),
    code_size=1.5,       # 🌟 码长 = 类别数 * code_size, 越大冗余越高
    random_state=42
)
ecoc.fit(X_m_train, y_m_train)
print(f"\n📌 ECOC(输出扰动)准确率: {ecoc.score(X_m_test, y_m_test):.4f}")
print(f"💡 ECOC的容错性: 即使部分二分类器判错了（码字个别位翻转），")
print(f"   系统仍能通过海明距离纠正回正确的类别")
```

### 2. 翻转法: 随机修改部分标签（引入"伪噪声"）

```python
print("\n💡 翻转法演示 — 故意给不同模型看不同的'错误答案':")
flip_ratio = 0.05  # 5%的标签随机翻转
flip_preds = np.zeros((X_test.shape[0], 5))
for i in range(5):
    y_flipped = y_train.copy()
    flip_mask = np.random.random(len(y_train)) < flip_ratio
    y_flipped[flip_mask] = 1 - y_flipped[flip_mask]  # 翻转
    dt = DecisionTreeClassifier(max_depth=3, random_state=i)
    dt.fit(X_train, y_flipped)
    flip_preds[:, i] = dt.predict(X_test)
flip_ensemble = (flip_preds.mean(axis=1) >= 0.5).astype(int)
print(f"  标签翻转集成准确率: {np.mean(flip_ensemble == y_test):.4f}")
print(f"  💡 故意喂错答案迫使模型不过度信任标签 → 间接提升多样性")
```

## 五、方法4: 算法参数扰动 (Algorithm Parameter Perturbation)

> **问题**：同一种算法，换不同的超参数配置，也能产生多样性吗？

# 核心思路：同一种算法，但每次用不同的超参数 → 产生不同的模型
#   就像同一个老师用不同教学风格教同一批学生，学出来的效果不同

### 1. 神经网络: 不同初始权重 + 不同隐层结构

```python
print("\n📌 参数扰动实验 — 不同参数产生不同的'世界观':")

nn_preds = np.zeros((X_test.shape[0], 5))
for i in range(5):
    nn = MLPClassifier(
        hidden_layer_sizes=(np.random.choice([20, 50, 100]),),
        activation=np.random.choice(['relu', 'tanh']),
        alpha=np.random.choice([0.0001, 0.001, 0.01]),  # L2正则化强度
        random_state=i * 100,  # 🌟 不同随机种子 → 不同初始权重 → 收敛到不同局部最优
        max_iter=500
    )
    nn.fit(X_train, y_train)
    nn_preds[:, i] = nn.predict(X_test)
nn_ensemble = (nn_preds.mean(axis=1) >= 0.5).astype(int)
nn_single = MLPClassifier(hidden_layer_sizes=(50,), random_state=0, max_iter=500)
nn_single.fit(X_train, y_train)
print(f"  单个NN(最佳参数): {nn_single.score(X_test, y_test):.4f}")
print(f"  参数扰动NN集成:   {np.mean(nn_ensemble == y_test):.4f}")
print(f"  💡 同样训练一次的参数调优过程中，其实已经训练了大量不同参数的模型")
print(f"  💡 单一模型法是'只留最好的，抛弃其余' → 浪费！")
print(f"  💡 集成学习法是'全部保留，加权综合' → 变废为宝！")
```

### 2. 决策树: 改变分裂准则

dt_criteria_preds = np.zeros((X_test.shape[0], 2))
for i, criterion in enumerate(['gini', 'entropy']):

## 六、四种扰动方法横向对比

> **问题**：四种方法各有什么优劣？面对实际任务该怎么选？

```python
print("\n" + "="*60)
print("🔍 四种扰动方法的横向对比")
print("="*60)
print("""
  方法           | 扰动对象 | 代表算法        | 适用学习器
  ───────────────┼──────────┼─────────────────┼───────────
  数据样本扰动    | 训练集   | Bagging,AdaBoost| 不稳定学习器(树,NN)
  输入属性扰动    | 特征列   | 随机子空间      | 稳定+不稳定均可
  输出表示扰动    | 标签     | ECOC,翻转法     | 多分类/噪声场景
  算法参数扰动    | 超参数   | 参数集成        | 任何算法
  
  💡 实战口诀：
    - 树/NN做集成 → 优先数据扰动（天然不稳定，效果最好）
    - SVM/线性做集成 → 必须属性或参数扰动（太稳定，数据扰动没用）
    - 多分类任务     → ECOC是最佳选择（纠错冗余）
    - 高维特征       → 随机子空间（降维+多样性一箭双调）
""")
```

## 七、最终验证：扰动是否真的能产生多样性？

> **问题**：用 [[03.4.2-多样性度量]] 中学到的指标，能不能量化验证扰动确实增加了多样性？

```python
# 用 3.4.2 中学到的"不合度量"来量化扰动产生的多样性
from sklearn.metrics import cohen_kappa_score

# 比较不同扰动策略下模型之间的 kappa 值
print("📌 多样性诊断 — 用kappa验证扰动效果:")
print(f"  无扰动(同参数树×5):  kappa需要计算...")
print(f"  Bootstrap扰动:        {1 - cohen_kappa_score(bagging.estimators_[0].predict(X_test), bagging.estimators_[50].predict(X_test)):.4f} (1-kappa, 越大越多样)")
print(f"  属性扰动(SVM子空间):  kappa ≈ 通过子空间创造多样性")
print(f"  💡 扰动越强 → 模型间kappa越低 → 集成增益可能越大")
print(f"  ⚠️ 但扰动过强 → 个体精度下降过多 → 总体反而变差 (好而不同的平衡)")
```
