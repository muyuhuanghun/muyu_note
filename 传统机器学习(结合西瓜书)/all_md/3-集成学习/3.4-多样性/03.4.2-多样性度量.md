## 一、四种多样性度量指标 — 代码实现与对比

> **核心问题**：误差-分歧分解告诉我们"分歧越大越好"，但分歧项是事后指标。有没有办法在训练过程中就诊断"这群专家够不够多样"？

# 多样性度量是"诊断工具"：用来检查你的集成模型是不是"人云亦云"
# 如果所有模型都给出相同预测 → 多样性=0 → 集成意义不大
# 多样性度量的核心：列联表 (Contingency Table)
#   统计两个分类器 h_i 和 h_j 对同一批数据的预测交叉情况

```python
import numpy as np
from sklearn.tree import DecisionTreeClassifier
from sklearn.svm import SVC
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split

np.random.seed(42)
X, y = make_classification(n_samples=500, n_features=10, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# 训练4个不同的分类器
models = {
    'DT_depth2': DecisionTreeClassifier(max_depth=2, random_state=1),
    'DT_depth5': DecisionTreeClassifier(max_depth=5, random_state=2),
    'LR':        LogisticRegression(max_iter=1000, random_state=3),
    'SVM':       SVC(random_state=4),
}

preds = {}
for name, clf in models.items():
    clf.fit(X_train, y_train)
    preds[name] = clf.predict(X_test)
```

### 1. 列联表 (Contingency Table) — 所有指标的基础

> **问题**：怎么用一张表描述两个分类器的"意见分歧"？

```python
# |            | h_j=+1    | h_j=-1    |
# | h_i=+1     | a (都判断为正) | c     |
# | h_i=-1     | b          | d (都判断为负) |
# a+b+c+d = m (总样本数)
# b 和 c 是"意见不合"的样本 —— 它们是多样性的直接来源

def contingency_table(pred_i, pred_j):
    """
    构建两个分类器预测的列联表。
    返回 (a, b, c, d):
      a: 两个都预测为 +1 的样本数
      b: i预测-1, j预测+1
      c: i预测+1, j预测-1
      d: 两个都预测为 -1 的样本数
    """
    a = np.sum((pred_i == 1) & (pred_j == 1))
    b = np.sum((pred_i == 0) & (pred_j == 1))  # 假设标签为 0/1
    c = np.sum((pred_i == 1) & (pred_j == 0))
    d = np.sum((pred_i == 0) & (pred_j == 0))
    return a, b, c, d
```

### 2. 四种多样性度量指标的手动实现

> **问题**：除了直接数"意见不同"的样本，还有哪些更精细的多样性度量方式？

```python
def disagreement_measure(pred_i, pred_j):
    """
    不合度量 (Disagreement Measure)
    公式: dis = (b + c) / m
    含义: 直接数"你俩意见不同的样本"占比
    值域 [0, 1]，越大越好（多样性越大）
    最直观、最常用的多样性指标
    """
    a, b, c, d = contingency_table(pred_i, pred_j)
    m = a + b + c + d
    return (b + c) / m


def correlation_coefficient(pred_i, pred_j):
    """
    相关系数 (Correlation Coefficient)
    公式: ρ = (ad - bc) / sqrt((a+b)(a+c)(c+d)(b+d))
    含义: 衡量两个分类器输出的线性相关程度
    ρ > 0: 正相关 → 倾向于同时对/错 → 多样性低
    ρ = 0: 无关     → 独立判断         → 多样性好
    ρ < 0: 负相关 → 互补（你错我对） → 多样性极好（但很难得）
    """
    a, b, c, d = contingency_table(pred_i, pred_j)
    numerator = a * d - b * c
    denominator = np.sqrt((a + b) * (a + c) * (c + d) * (b + d))
    if denominator == 0:
        return 0.0
    return numerator / denominator


def q_statistic(pred_i, pred_j):
    """
    Q-统计量 (Q-statistic)
    公式: Q = (ad - bc) / (ad + bc)
    含义: 与相关系数符号一致，评估相关性
    独立时 Q=0, Q∈[-1, 1]
    类似于相关系数的"简化版"
    """
    a, b, c, d = contingency_table(pred_i, pred_j)
    numerator = a * d - b * c
    denominator = a * d + b * c
    if denominator == 0:
        return 0.0
    return numerator / denominator


def kappa_statistic(pred_i, pred_j):
    """
    κ-统计量 (Kappa Statistic)
    公式: κ = (p1 - p2) / (1 - p2)
      p1 = (a+d)/m: 实际观察到的一致概率
      p2 = [(a+b)(a+c) + (c+d)(b+d)] / m²: 纯偶然达成一致的概率
    含义: 排除"碰运气"后的一致性
    κ = 0: 一致纯属偶然  → 多样性好
    κ = 1: 完全一致      → 多样性极差（应该踢掉一个）
    κ < 0: 故意反着来    → 不太可能出现
    💡 Kappa 是最严谨的一致性度量，排除了随机偶然因素的影响
    """
    a, b, c, d = contingency_table(pred_i, pred_j)
    m = a + b + c + d
    p1 = (a + d) / m  # 实际一致率
    # p2: 如果两个分类器完全独立（互不商量），仅凭各自习惯碰巧一致的概率
    p2 = ((a + b) * (a + c) + (c + d) * (b + d)) / (m * m)
    if p2 == 1.0:
        return 1.0
    return (p1 - p2) / (1 - p2)
```

### 3. 对所有模型两两计算多样性

> **问题**：实际拿到4个模型后，怎么批量诊断它们之间的多样性？

```python
print("="*80)
print("🔍 多样性度量 — 诊断你的"专家团"是不是在"人云亦云"")
print("="*80)
model_names = list(preds.keys())
print(f"\n{'配对':<20s} {'不合度量':>8s} {'相关系数':>8s} {'Q统计量':>8s} {'kappa':>8s}")
print("-" * 70)

for i in range(len(model_names)):
    for j in range(i + 1, len(model_names)):
        pi, pj = preds[model_names[i]], preds[model_names[j]]
        dis = disagreement_measure(pi, pj)
        corr = correlation_coefficient(pi, pj)
        q = q_statistic(pi, pj)
        kappa = kappa_statistic(pi, pj)
        pair = f"{model_names[i]} vs {model_names[j]}"
        print(f"{pair:<20s} {dis:8.4f} {corr:8.4f} {q:8.4f} {kappa:8.4f}")
```

### 4. 结果解读指南

> **问题**：指标出来了，怎么判断"这对模型该不该一起集成"？

```python
print("\n" + "="*60)
print("📌 诊断指南:")
print("="*60)
print("""
  🌟 不合度量 (dis): 越高越好 → 你们吵得越凶，集成效果越可能提升
  ⚠️ 相关系数 (ρ):  越接近0越好 → 完全正相关(1.0)表示"你错我也错，你对我对"，没有互补
  ⚠️ Q统计量 (Q):   越接近0越好 → 符号与ρ一致，是相关性另一种表达
  ⚠️ kappa (κ):     越接近0越好 → κ=1.0 表示完全一致(应踢掉一个冗余模型)
  
  💡 实战建议：
    - DT_depth2 vs DT_depth5: 两个决策树，同族算法 → 相关度可能偏高
    - DT vs LR: 不同原理 → 天然多样性高 → 是理想的组合
    - 如果某对模型的 κ > 0.8 → 考虑只保留其中一个
""")
```

### 5. 补充：用 numpy/scipy 快速实现所有指标

> **问题**：手动实现验证原理没问题，实际项目中有没有现成的工具？

```python
# 实际项目中可以直接用 sklearn.metrics.cohen_kappa_score 算 Kappa
from sklearn.metrics import cohen_kappa_score

print("\n📌 sklearn 内置 Kappa 验证:")
for i in range(len(model_names)):
    for j in range(i + 1, len(model_names)):
        sk_kappa = cohen_kappa_score(preds[model_names[i]], preds[model_names[j]])
        our_kappa = kappa_statistic(preds[model_names[i]], preds[model_names[j]])
        pair = f"{model_names[i]} vs {model_names[j]}"
        print(f"  {pair:<34s} sklearn: {sk_kappa:.4f}, 手动: {our_kappa:.4f}")
# 💡 两个值应该完全相同 → 验证了手动实现的正确性
```
