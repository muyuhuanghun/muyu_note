## 一、问题引入：维数灾难与密采样困境

![alt text](image-1.png)

维数灾难的核心矛盾：归一化后范围在 [0,1]，要满足密采样，每个维度上都要隔 0.001 放一个点，所需样本量呈指数增长 —— 实际样本量远远不够，高维稀疏问题由此而来。

## 二、MDS 代码演示：从距离矩阵还原低维坐标

```python
import numpy as np
from sklearn.manifold import MDS
from sklearn.datasets import make_blobs
import matplotlib.pyplot as plt

# ============================================
# 📌 Step 1: 生成高维数据 + 手动MDS流程演示
# ============================================
# 生成 100 个样本，每个 10 维（高维），但真实结构可能只需要 2-3 维就能表达
X_high, _ = make_blobs(n_samples=100, n_features=10, centers=3, random_state=42)

# ============================================
# 📌 Step 2: 手动实现 MDS 核心流程（理解原理）
# ============================================
# MDS的精髓：仅通过样本间的距离，就能用线性代数（中心化 + 特征值分解）
# 还原出它们在低维空间中的绝对坐标 —— 就像只知道城市间距离就能画出地图

def manual_mds(dist_matrix, n_components=2):
    """
    🌟 手动实现经典MDS
    输入：距离矩阵 D (m x m)
    输出：低维坐标 Z (n_components x m)

    核心推导链：
    1. 距离平方 dist²_ij = b_ii + b_jj - 2b_ij （距离与内积的关系）
    2. 中心化约束 ∑z_i = 0（固定坐标系，消除平移自由度）
    3. 双中心化（Double Centering）→ 仅用距离就算出内积矩阵 B
    4. 对 B 特征分解 → 取前 d' 个最大特征值 → 得到低维坐标
    """
    m = dist_matrix.shape[0]

    # --- 双中心化：把距离矩阵变成内积矩阵 ---
    # 这就像是把"城市间里程表"翻译成"城市坐标"
    D_sq = dist_matrix ** 2  # 距离平方矩阵

    # 行均值、列均值、全局均值（"·" 标记的那些符号）
    row_mean = D_sq.mean(axis=1, keepdims=True)   # dist²_i·
    col_mean = D_sq.mean(axis=0, keepdims=True)   # dist²_·j
    total_mean = D_sq.mean()                       # dist²_··

    # 🌟 双中心化公式：B = -1/2 * (I - 11^T/m) * D² * (I - 11^T/m)
    # 本质上就是：B_ij = -1/2 * (dist²_ij - dist²_i· - dist²_·j + dist²_··)
    H = np.eye(m) - np.ones((m, m)) / m  # 中心化矩阵
    B = -0.5 * H @ D_sq @ H              # 内积矩阵（m x m）

    # --- 特征分解 ---
    # 📌 B 的特征值就是各维度的"能量"，特征向量就是坐标方向
    eigenvalues, eigenvectors = np.linalg.eigh(B)

    # 从大到小排序（eigh 返回的是升序）
    idx = np.argsort(eigenvalues)[::-1]
    eigenvalues = eigenvalues[idx]
    eigenvectors = eigenvectors[:, idx]

    # 💡 只取非零特征值，扔掉负值（数值误差）
    positive_idx = eigenvalues > 1e-8
    eigenvalues = eigenvalues[positive_idx]
    eigenvectors = eigenvectors[:, positive_idx]

    # 取前 n_components 维：Z = Λ^{1/2} * V^T
    # 想象：特征值的平方根是"拉伸程度"，特征向量是"方向"
    Z = np.diag(np.sqrt(eigenvalues[:n_components])) @ eigenvectors[:, :n_components].T

    return Z  # shape: (n_components, m)

# 计算原始距离矩阵，喂给手动MDS
from sklearn.metrics import pairwise_distances
D = pairwise_distances(X_high, metric='euclidean')
Z_manual = manual_mds(D, n_components=2).T  # 转置成 (m, n_components)

# ============================================
# 📌 Step 3: 对比 sklearn 的 MDS（验证手动实现）
# ============================================
mds_sklearn = MDS(n_components=2, dissimilarity='precomputed', random_state=42)
Z_sklearn = mds_sklearn.fit_transform(D)

print("手动MDS前5个样本的低维坐标:")
print(Z_manual[:5])
print("\nsklearn MDS前5个样本的低维坐标:")
print(Z_sklearn[:5])
# 💡 两者应该非常接近（可能差一个旋转/翻转，因为特征向量符号可以相反）
```

## 三、降维的现实意义：为什么需要 MDS？

```python
# ============================================
# A. 缓解维数灾难 —— 距离在高维空间失效
# ============================================
# 想象 20 维空间里要维持密采样需要 10^60 个样本，宇宙中的原子都没这么多
# MDS 把数据压到低维流形上，让距离度量重新变得有意义

# ============================================
# B. 提升泛化能力 —— 降维 = 去噪
# ============================================
# 过高的维度让模型容易捕捉噪声（过拟合）
# 降维本质是提取主要特征、剔除冗余，让模型在测试集上更稳健

# ============================================
# C. 数据可视化 —— 降到 2D/3D 就能用眼睛看
# ============================================
# 高维数据人眼看不了，降到 2 维后聚类趋势、离群点一目了然
```

## 四、非零特征值 vs 最大特征值：数学精确 vs 工程近似

![alt text](image-2.png)

```python
# 📌 这个区别是理解降维"度"的关键：
#
# 非零特征值 Λ_* (d* 个):
#   - 数学上完美还原所有距离，严格相等
#   - 但 d* 可能 = d（比如 1000 维数据有 1000 个非零特征值）
#   - 根本没有"降"维 —— 只是换了个坐标系
#
# 最大特征值 Λ_tilde (d' 个，d' << d*):
#   - 主动丢弃小特征值（贡献低的维度 = 噪声/次要信息）
#   - 允许距离有误差，换取更低的计算维度和更好的泛化
#   - 🌟 这才是真正有效的降维操作

# 可视化特征值的衰减（"碎石图"）
# 特征值衰减越快，说明数据越"低秩"，降维效果越好
eigenvalues_sorted = np.sort(np.linalg.eigvalsh(np.cov(X_high.T)))[::-1]
print("协方差矩阵特征值（从大到小）:")
for i, val in enumerate(eigenvalues_sorted[:5]):
    bar = '█' * int(val / eigenvalues_sorted[0] * 40)
    print(f"  维度{i+1}: {val:8.3f} {bar}")

# 💡 通常前几个特征值占了大部分能量，后面的可以安全丢弃
# 这就是 d' 选取的依据：保留前 d' 个特征值，它们的能量占比达到阈值（如 95%）
cumsum_ratio = np.cumsum(eigenvalues_sorted) / np.sum(eigenvalues_sorted)
d_prime = np.searchsorted(cumsum_ratio, 0.95) + 1
print(f"\n保留 {d_prime} 维即可解释 95% 的方差")
```

## 五、总结

MDS 的精妙之处：只要拥有样本间的相对距离（距离矩阵），
就能通过中心化 + 特征值分解还原出绝对坐标。
这就像手头只有一张城市间里程表，就能在白纸上画出各城市的相对位置。
MDS 是理解 Isomap 等流形学习方法的数学基石。
