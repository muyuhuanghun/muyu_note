## 一、PCA 核心代码演示：协方差矩阵 + 特征分解

PCA 的直观理解：**最小重构误差**。就像把一团歪着的烟雾旋转摆正，然后只保留最长的几个轴，扔掉短的（噪音），从而实现降维。

```python
import numpy as np
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler
from sklearn.datasets import load_iris
import matplotlib.pyplot as plt

# ============================================
# 📌 Step 1: 加载数据 + 中心化（PCA 的前提）
# ============================================
iris = load_iris()
X = iris.data  # 150 个样本，4 个特征（花萼长宽、花瓣长宽）
y = iris.target

# 🌟 中心化：让数据以原点为"重心"，这是 PCA 公式推导的前提
# 中心化后 ∑x_i = 0，协方差矩阵就是 ∑x_i x_i^T
X_centered = X - X.mean(axis=0)

# ============================================
# 📌 Step 2: 手动实现 PCA（理解核心原理）
# ============================================
def manual_pca(X, n_components=2):
    """
    🌟 手动 PCA 实现
    核心三步走：
    1. 算协方差矩阵（描述数据在各个方向上的"伸展程度"）
    2. 特征分解（找出"长轴"和"短轴"）
    3. 取前 d' 个最大特征值对应的特征向量组成投影矩阵
    """
    m = X.shape[0]

    # --- 协方差矩阵 ---
    # 📌 协方差矩阵 = 1/m * X^T X（数据已中心化）
    # 对角线 = 每个特征的方差（"拉得多长"）
    # 非对角线 = 特征间的协方差（"倾斜方向"）
    # 几何直觉：数据在高维空间形成了一个"超椭球"，协方差矩阵描述了它的形状
    cov_matrix = (X.T @ X) / m

    # --- 特征值分解 ---
    # 🌟 特征向量 = 椭球的主轴方向，特征值 = 沿该轴的"伸展长度"
    eigenvalues, eigenvectors = np.linalg.eigh(cov_matrix)

    # 从大到小排序
    idx = np.argsort(eigenvalues)[::-1]
    eigenvalues = eigenvalues[idx]
    eigenvectors = eigenvectors[:, idx]

    # --- 取前 d' 个主成分 ---
    # 投影矩阵 W: d x d'，每一列是一个主成分方向（基向量）
    W = eigenvectors[:, :n_components]  # shape: (d, d')

    # 投影：Z = X W（高维 → 低维）
    Z = X @ W  # shape: (m, d')

    # 重构：X_hat = Z W^T（低维 → 高维还原）
    # 由于丢掉了部分维度，重构会有误差 —— 这就是"重构误差"
    X_reconstructed = Z @ W.T

    return Z, W, eigenvalues, X_reconstructed

Z_manual, W_manual, eigenvals, X_recon = manual_pca(X_centered, n_components=2)

# ============================================
# 📌 Step 3: 对比 sklearn 的 PCA
# ============================================
pca = PCA(n_components=2)
Z_sklearn = pca.fit_transform(X)

print("手动PCA前5个样本:")
print(Z_manual[:5])
print("\nsklearn PCA前5个样本:")
print(Z_sklearn[:5])

# 解释方差比例（每个主成分的"能量占比"）
print(f"\n各主成分解释方差比例: {pca.explained_variance_ratio_}")
print(f"累计解释方差: {pca.explained_variance_ratio_.sum():.3f}")
# 💡 对于 iris 数据，前 2 维就解释了 97.7% 的方差，效果非常好
```

## 二、为什么协方差矩阵的最大特征值 = 方差最大的方向？

```python
# ============================================
# 🌟 核心数学直觉：Rayleigh 商
# ============================================
# 投影后方差 = w^T S w（S 是协方差矩阵，w 是投影方向）
# 在 ||w||=1 约束下，w^T S w 的最大值 = S 的最大特征值
# 取得最大值时的 w = 该特征值对应的特征向量
#
# 💡 通俗比喻：协方差矩阵定义了数据的"椭球形状"
# 特征分解 = 找出这个椭球的长轴（最大特征值方向）和短轴
# PCA = 保留长轴（核心特征），丢弃短轴（噪声/次要信息）

# 验证一下：随机方向 vs 最大特征向量方向的投影方差
np.random.seed(42)
random_w = np.random.randn(4)
random_w = random_w / np.linalg.norm(random_w)  # 归一化

var_random = np.var(X_centered @ random_w)
var_pc1 = eigenvals[0]  # 第一主成分方向上的方差 = 最大特征值

print(f"随机方向的投影方差: {var_random:.3f}")
print(f"第一主成分方向的投影方差（= λ_max）: {var_pc1:.3f}")
# 💡 第一主成分的方差显著大于随机方向 —— 验证了 PCA 确实找到了最优投影方向
```

## 三、d' 值的选取：保留多少信息？

![alt text](image-6.png)

```python
# ============================================
# 🌟 三种 d' 选取策略
# ============================================

# 方法1: 保留 95% 的方差（最常用）
pca_95 = PCA(n_components=0.95)  # 自动选取最小的 d' 使累计方差 >= 95%
Z_95 = pca_95.fit_transform(X)
print(f"保留95%方差需要 d' = {pca_95.n_components_} 维")

# 方法2: 看"碎石图"找拐点（Elbow Method）
pca_full = PCA().fit(X)
import matplotlib.pyplot as plt
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 4))

ax1.plot(range(1, 5), pca_full.explained_variance_ratio_, 'o-', linewidth=2)
ax1.set_xlabel('主成分编号'), ax1.set_ylabel('解释方差比例')
ax1.set_title('碎石图 (Scree Plot)')

ax2.plot(range(1, 5), np.cumsum(pca_full.explained_variance_ratio_), 's-', linewidth=2)
ax2.axhline(0.95, color='r', linestyle='--', label='95% 阈值')
ax2.set_xlabel('主成分编号'), ax2.set_ylabel('累计解释方差')
ax2.set_title('累计方差图'), ax2.legend()

# 💡 拐点 = "肘部"的位置，之后再加维度收益很小

# 方法3: 降维后再做分类，看准确率变化
from sklearn.neighbors import KNeighborsClassifier
from sklearn.model_selection import cross_val_score

for d_prime in range(1, 5):
    pca_d = PCA(n_components=d_prime)
    X_reduced = pca_d.fit_transform(X)
    knn = KNeighborsClassifier(n_neighbors=5)
    score = cross_val_score(knn, X_reduced, y, cv=5).mean()
    print(f"d'={d_prime}, KNN准确率={score:.3f}")
# 💡 维度太高太低都不好，找到一个平衡点 —— 这是 d' 选取的实用指南
```

## 四、PCA 重构误差演示

```python
# 🌟 PCA 就像用"素描"代替"照片"：保留主要轮廓，丢失细节纹理
# 重构误差 = ||X - X_reconstructed||²，d' 越小误差越大

# 用不同维度重构，看误差变化
from sklearn.decomposition import PCA as PCA_sk

for d_prime in [1, 2, 3]:
    pca_d = PCA_sk(n_components=d_prime)
    Z = pca_d.fit_transform(X)
    X_recon = pca_d.inverse_transform(Z)
    mse = np.mean((X - X_recon) ** 2)
    print(f"d'={d_prime}, 重构MSE={mse:.4f}")

# 💡 随着 d' 增加，重构误差递减 —— 保留的信息越多，素描越接近原图
# 但 d'=d 时误差为零（没有降维，只是换了个坐标系）
```

## 五、总结

PCA 的本质三步：
1. 协方差矩阵 ∑x_i x_i^T → 描述数据的"椭球形状"
2. 特征分解 → 找出长轴（主成分方向）和短轴（噪声方向）
3. 取前 d' 个长轴 → 投影得到低维坐标

最小化重构误差 等价于 最大化投影方差
PCA 是线性方法，对弯曲的数据（如 S 形曲面）会失败 → 需要 KPCA 和流形学习
