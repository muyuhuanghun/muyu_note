## 一、问题引入：线性 PCA 的局限性

![alt text](image-1.png)

**KPCA 的动机**：在二维平面上采样的点，通过一个非线性函数卷成 S 形曲面嵌入三维空间。直接对三维数据做线性 PCA 会得到一团乱麻 —— 因为 PCA 只会"直着切"，而数据是"弯的"。我们必须把数据先映射到高维空间，让弯曲的结构变直，再执行 PCA。

## 二、KPCA 代码演示：核技巧让 PCA 处理非线性数据

```python
import numpy as np
from sklearn.decomposition import PCA, KernelPCA
from sklearn.datasets import make_swiss_roll, make_circles
import matplotlib.pyplot as plt

# ============================================
# 📌 Step 1: 构造非线性数据（瑞士卷 + 同心圆）
# ============================================
# 瑞士卷：二维平面被卷进三维空间 —— 线性 PCA 的噩梦
X_swiss, color_swiss = make_swiss_roll(n_samples=1000, noise=0.1, random_state=42)
# color_swiss 是沿卷轴的位置，用来着色观察效果

# 同心圆：两类点在二维平面上形成同心圆 —— 线性不可分
X_circles, y_circles = make_circles(n_samples=500, noise=0.05, factor=0.3, random_state=42)

# ============================================
# 📌 Step 2: 线性 PCA vs 核 PCA —— 直观对比
# ============================================

# --- 对比瑞士卷数据 ---
# 瑞士卷就像一块被卷起来的瑞士卷蛋糕皮（二维面），蜷缩在三维空间里
# 线性 PCA 会"一刀切"投影，把卷层混在一起；KPCA 能识别非线性结构，把卷展开
pca_swiss = PCA(n_components=2)
kpca_swiss = KernelPCA(n_components=2, kernel='rbf', gamma=0.1)

Z_pca_swiss = pca_swiss.fit_transform(X_swiss)
Z_kpca_swiss = kpca_swiss.fit_transform(X_swiss)

print("=== 瑞士卷降维对比 ===")
print(f"PCA 解释方差: {pca_swiss.explained_variance_ratio_}")
# 💡 KPCA 没有 explained_variance_ratio_，因为它在核空间操作

# --- 对比同心圆数据 ---
# 同心圆在二维空间无法用直线分开（线性不可分），但径向方向可以
# KPCA 通过高斯核把它们"拉"到高维，在那里同心圆变得可以线性分离
pca_circles = PCA(n_components=2)
kpca_circles = KernelPCA(n_components=2, kernel='rbf', gamma=2.0)

Z_pca_circles = pca_circles.fit_transform(X_circles)
Z_kpca_circles = kpca_circles.fit_transform(X_circles)
```

## 三、手动实现 KPCA 核心流程（理解原理）

```python
from scipy.spatial.distance import pdist, squareform

def manual_kpca(X, kernel='rbf', gamma=1.0, n_components=2):
    """
    🌟 手动实现核 PCA
    核心思路：在原始空间算核矩阵 K，然后对 K 做特征分解
    —— 这相当于在无穷维特征空间里执行了线性 PCA，但完全不需要显式映射

    推导链：
    1. 特征空间中 PCA: (∑φ(x_i)φ(x_i)^T) W = λ W
    2. W 可表示为映射样本的线性组合: W = ∑φ(x_j)α_j
    3. 代入方程 → 两边左乘 φ(x_k)^T → 引入核函数 κ(x_i, x_j) = φ(x_i)^T φ(x_j)
    4. 化简得: K²A = λKA → KA = λA（约掉一个 K）
    """
    m = X.shape[0]

    # --- Step 1: 计算核矩阵 K (m x m) ---
    # 🌟 核矩阵的每一个元素 K_ij = κ(x_i, x_j) = φ(x_i)^T φ(x_j)
    # 这就是"核技巧"的核心：不显式计算 φ，直接算内积
    if kernel == 'rbf':
        # 高斯核/RBF: κ(x_i, x_j) = exp(-γ ||x_i - x_j||²)
        dist_sq = squareform(pdist(X, 'sqeuclidean'))
        K = np.exp(-gamma * dist_sq)
    elif kernel == 'poly':
        # 多项式核: κ(x_i, x_j) = (x_i^T x_j + 1)^d
        d = 3  # degree
        K = (X @ X.T + 1) ** d
    elif kernel == 'linear':
        # 线性核: κ(x_i, x_j) = x_i^T x_j（退化为普通 PCA）
        K = X @ X.T
    else:
        raise ValueError(f"Unknown kernel: {kernel}")

    # --- Step 2: 中心化核矩阵 ---
    # 📌 特征空间中的数据也需要中心化（∑φ(x_i) = 0）
    # 对核矩阵中心化等价于在特征空间中心化映射后的数据
    one_n = np.ones((m, m)) / m
    K_centered = K - one_n @ K - K @ one_n + one_n @ K @ one_n

    # --- Step 3: 特征值分解 ---
    eigenvalues, eigenvectors = np.linalg.eigh(K_centered)

    # 从大到小排序
    idx = np.argsort(eigenvalues)[::-1]
    eigenvalues = eigenvalues[idx]
    eigenvectors = eigenvectors[:, idx]

    # 取前 d' 个
    alphas = eigenvectors[:, :n_components]  # 系数矩阵 A (m x d')
    lambdas = eigenvalues[:n_components]

    # --- Step 4: 计算投影坐标 ---
    # 🌟 新样本投影: z_j = ∑α_i^j κ(x_i, x)
    # 对于训练样本（已有的核矩阵），就是: Z = K_centered @ A
    # 每个特征向量还差一个 1/√λ 的缩放
    Z = K_centered @ alphas
    # 归一化使投影坐标的方差 = 特征值
    Z = Z / np.sqrt(lambdas)

    return Z, alphas, lambdas, K_centered

# 验证手动实现
Z_manual, alphas, lambdas, K_centered = manual_kpca(X_circles, kernel='rbf', gamma=2.0, n_components=2)
Z_sklearn = KernelPCA(n_components=2, kernel='rbf', gamma=2.0).fit_transform(X_circles)

print("\n=== 手动 KPCA vs sklearn KPCA ===")
print("手动 KPCA 前3个样本:")
print(Z_manual[:3])
print("\nsklearn KPCA 前3个样本:")
print(Z_sklearn[:3])
# 💡 两者应该非常接近（可能差一个符号翻转）
```

## 四、核函数选择实战：哪种核适合什么数据？

```python
# ============================================
# 📌 不同核函数在同心圆数据上的表现
# ============================================
kernels = {
    'rbf':    {'kernel': 'rbf',    'gamma': 2.0},
    'poly':   {'kernel': 'poly',   'degree': 3, 'gamma': 1.0},
    'sigmoid':{'kernel': 'sigmoid','gamma': 0.5},
    'cosine': {'kernel': 'cosine'},
}

for name, params in kernels.items():
    kpca = KernelPCA(n_components=2, **params)
    Z = kpca.fit_transform(X_circles)
    # 看降维后两类点的分离程度
    sep = np.linalg.norm(Z[y_circles==0].mean(0) - Z[y_circles==1].mean(0))
    print(f"核={name:8s}, 类间距离={sep:.3f}")
# 💡 RBF 核通常在非线性问题上表现最好
# 因为高斯核把数据映射到无穷维，几乎任何分布在高维都线性可分
```

## 五、KPCA 为什么能提取非线性结构？

```python
# 🌟 核心直觉：三步曲
#
# Step 1: 非线性映射 φ —— 把弯曲的数据"拉直"
#   想象一根弯铁丝（原始空间），通过 φ 映射到高维，铁丝变直了
#   根据"盖尔范德-奈马克定理"的直觉：维度足够高时，非线性结构会线性化
#
# Step 2: 核技巧 —— 不显式做映射，只算内积
#   κ(x_i, x_j) = φ(x_i)^T φ(x_j)
#   就像你不需要知道魔术师的把戏，只需要知道魔术效果
#
# Step 3: 在特征空间执行线性 PCA
#   对核矩阵 K 做特征分解，等价于在特征空间做 PCA
#   KA = λA —— 一个 m x m 的特征值问题，完全避开了无穷维 φ

# ============================================
# ⚠️ KPCA 的代价：对新样本预测很慢
# ============================================
# 线性 PCA: 训练出 W 后，预测只需 z = W^T x（一次矩阵乘法）
# KPCA: 每预测一个新样本，需要和所有 m 个训练样本算核函数
#        z_j = ∑ α_i^j κ(x_i, x)  →  O(m * d) vs O(d * d')
#
# 💡 如果训练集有 100 万样本，每个新样本要算 100 万次核函数
# 这就是 KPCA 在大规模数据上的致命弱点
```

## 六、KPCA vs PCA 速查表

| 对比维度 | 线性 PCA | 核 PCA (KPCA) |
| --- | --- | --- |
| **映射方式** | 直接线性投影 | 先映射到高维特征空间，再做线性投影 |
| **处理能力** | 只能提取线性结构 | 能提取非线性结构（S形曲面、同心圆等） |
| **计算对象** | 协方差矩阵 XX^T (d x d) | 核矩阵 K (m x m) |
| **新样本预测** | 乘投影矩阵 W，O(d*d') | 与所有训练样本算核函数，O(m*d) |
| **参数选择** | 只需选 d' | 选 d' + 核函数类型 + 核参数（调参量大） |
| **训练开销** | O(d³) 特征分解 | O(m³) 特征分解 |

## 七、总结

KPCA 的核心思路：既然数据在原始空间是弯的，那就把它"抬"到更高维空间
在高维空间它会变直（线性化），然后执行标准 PCA。
通过核技巧，这一切都不需要显式地计算高维映射 φ。

代价也很明确：预测时依赖所有训练样本，大规模数据上会非常慢。
