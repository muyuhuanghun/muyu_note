## 一、KNN核心概念代码演示

> KNN (K-Nearest Neighbors) 的核心思想："物以类聚，人以群分" —— 看一个样本的 k 个邻居是谁，由它们投票决定新来者的身份。
> KNN 属于**惰性学习（Lazy Learning）**，训练阶段几乎不做计算，只是把数据存起来，所有计算都在预测阶段发生。

```python
import numpy as np
from sklearn.neighbors import KNeighborsClassifier
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import cross_val_score, train_test_split
from sklearn.datasets import make_classification

# ============================================
# 📌 Step 1: 生成模拟数据 + 标准化（距离计算必须标准化！）
# ============================================
X, y = make_classification(
    n_samples=500, n_features=10, n_informative=5,
    n_redundant=2, n_classes=3, random_state=42
)

# ⚠️ KNN靠距离吃饭，不同量纲的特征（如身高1.8m vs 收入10000元）
# 会让大数值特征主导距离计算，必须标准化！
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

X_train, X_test, y_train, y_test = train_test_split(
    X_scaled, y, test_size=0.2, random_state=42
)

# ============================================
# 📌 Step 2: 用交叉验证寻找最优 k 值
# ============================================
# 💡 k 是 KNN 的灵魂超参数：
#   - k 太小（如 k=1）：决策边界破碎，噪声点说了算 → 过拟合
#   - k 太大：模型只看大趋势，局部细节全丢 → 欠拟合
#   - 极端情况 k=样本总数：永远预测最多的那一类，模型废了

best_k, best_score = 1, 0
for k in range(1, 31):
    knn_temp = KNeighborsClassifier(n_neighbors=k)
    scores = cross_val_score(knn_temp, X_train, y_train, cv=5)
    if scores.mean() > best_score:
        best_k, best_score = k, scores.mean()

print(f"最优 k = {best_k}, 交叉验证准确率 = {best_score:.4f}")

# ============================================
# 📌 Step 3: 训练最终模型 + 多种距离度量对比
# ============================================
# 🌟 距离度量决定"近"的定义：
#   - p=2: 欧氏距离 (Euclidean) —— 直线距离，最常用
#   - p=1: 曼哈顿距离 (Manhattan) —— 城市街区走法
#   - p=1 到 p=2 之间：闵可夫斯基距离 (Minkowski) 的广义形式

for p_val, name in [(1, "曼哈顿"), (2, "欧氏"), (3, "闵可夫斯基p=3")]:
    knn = KNeighborsClassifier(n_neighbors=best_k, p=p_val)
    knn.fit(X_train, y_train)
    acc = knn.score(X_test, y_test)
    print(f"{name}距离 (p={p_val}) 测试准确率: {acc:.4f}")
```

## 二、进阶优化：加权KNN + 空间索引加速

```python
from sklearn.neighbors import KNeighborsClassifier

# ============================================
# 🌟 加权 KNN：距离更近的邻居话语权更大
# ============================================
# 默认是"一人一票"的民主投票，weights='distance' 改成"按距离加权"的资历投票
# 权重通常 w = 1/d，距离越近权重越大
knn_weighted = KNeighborsClassifier(
    n_neighbors=best_k,
    weights='distance'  # 💡 距离近的邻居投票权重更高
)
knn_weighted.fit(X_train, y_train)
print(f"加权KNN测试准确率: {knn_weighted.score(X_test, y_test):.4f}")

# ============================================
# 🚀 空间索引加速：KD-Tree / Ball-Tree
# ============================================
# 暴力搜索 O(N*D)，KD-Tree 把搜索复杂度降到 O(log N)
# 想象成在图书馆找书：暴力=逐本翻阅，KD-Tree=按书架分类快速定位
knn_fast = KNeighborsClassifier(
    n_neighbors=best_k,
    algorithm='kd_tree',  # 📌 切换到 KD-Tree 加速近邻搜索
    weights='distance'
)
knn_fast.fit(X_train, y_train)
print(f"KD-Tree加速KNN测试准确率: {knn_fast.score(X_test, y_test):.4f}")
```

## 三、KNN 优缺点速查

| 优点 | 缺点 |
| --- | --- |
| **简单有效**：易于理解和实现 | **计算开销大**：每次预测遍历全量数据 O(N*D) |
| **无需训练**：没有显式训练过程 | **内存消耗高**：需要存储所有训练数据 |
| **天然多分类**：投票机制天然支持 | **维数灾难**：高维空间"最近"概念失效 |
| **对异常值不敏感**（k 取值合适时） | **样本不平衡**：大类样本投票占绝对优势 |

## 四、KNN 面临的核心问题：维数灾难

KNN 在高维空间下为什么会失效？下面模拟一下：

```python
# 📌 模拟"维数灾难"：随着维度增加，最近邻和最远邻的距离趋于相同
np.random.seed(42)

def distance_contrast_ratio(n_dims, n_samples=1000):
    """计算随机点集中最近邻/最远邻距离比，越高维这个比值越接近1"""
    points = np.random.uniform(0, 1, (n_samples, n_dims))
    # 随机挑一个点，算它到所有其他点的距离
    query = np.random.uniform(0, 1, (1, n_dims))
    dists = np.sqrt(np.sum((points - query) ** 2, axis=1))
    return np.min(dists) / np.max(dists)

for dim in [2, 10, 50, 100, 500]:
    ratio = distance_contrast_ratio(dim)
    print(f"维度={dim:3d}, 最近/最远距离比={ratio:.4f}")

# 💡 输出会显示：维度越高，最近邻和最远邻距离越来越接近
# 这意味着"近"和"远"的区分在高维空间消失了——这就是维数灾难
# 🌟 解决方法：降维！这就是后续 PCA、MDS、流形学习等方法的动机
```

## 五、总结

KNN 是"简单但强大"的基线模型（Baseline），适合小规模、低维、分布清晰的数据。
它的维数灾难问题是整个降维章节的出发点：既然高维空间距离不可靠，
我们就需要把数据压缩到低维流形上，让距离重新变得有意义。
