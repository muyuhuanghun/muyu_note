## 一、核心对比：三种降维方法对新样本的处理方式

> 这三种方法降维后，来了新样本怎么办？哪些能"即插即用"，哪些要"从头再来"？

```python
import numpy as np
from sklearn.decomposition import PCA
from sklearn.manifold import MDS
from sklearn.decomposition import KernelPCA
from sklearn.datasets import make_blobs

# ============================================
# 📌 准备数据和模型训练
# ============================================
X_train, _ = make_blobs(n_samples=200, n_features=10, centers=3, random_state=42)
X_new = np.random.randn(5, 10)  # 5 个新样本，模拟实际部署中的新数据

# ============================================
# 📌 方法1: PCA —— 归纳式，产生投影矩阵，新样本直接乘
# ============================================
pca = PCA(n_components=3).fit(X_train)

# 🌟 PCA 的"训练"本质：找到了一个从高维到低维的"转换器" W (d x d')
# 一旦训练完成，W 就固化了，像一把固定的"尺子"
Z_train_pca = pca.transform(X_train)     # Z = X @ W
Z_new_pca = pca.transform(X_new)         # 新样本直接乘，O(d * d')
print(f"PCA 投影矩阵形状: {pca.components_.shape}")  # (3, 10)
print(f"PCA 新样本降维结果:\n{Z_new_pca}")

# 💡 PCA 训练完后，可以扔掉原始训练数据，只保留投影矩阵 W
# 这就是"归纳式"的魅力：学到一个通用映射函数

# ============================================
# 📌 方法2: MDS —— 转导式，不产生投影矩阵，新样本无法直接降维
# ============================================
from sklearn.metrics import pairwise_distances
D_train = pairwise_distances(X_train)
mds = MDS(n_components=3, dissimilarity='precomputed', random_state=42)
Z_train_mds = mds.fit_transform(D_train)

# ⚠️ MDS 只能给训练样本产出坐标 Z = Λ^{1/2} V^T
# 它不产生映射函数 f: x → z，所以新样本来了没法直接降维
# 要处理新样本，通常需要：
#   - 重新跑一遍 MDS（把新样本加入距离矩阵），计算量巨大
#   - 或用插值法近似（不精确）
print(f"MDS 降维结果形状: {Z_train_mds.shape}")  # (200, 3)

# 💡 MDS 就像给你一张"城市地图"（训练样本坐标），但没给"导航公式"
# 来了一个新城（新样本），你不知道它在图上的位置

# ============================================
# 📌 方法3: KPCA —— 依赖核矩阵，新样本需与所有训练样本算核函数
# ============================================
kpca = KernelPCA(n_components=3, kernel='rbf', gamma=0.1)
Z_train_kpca = kpca.fit_transform(X_train)

# 🌟 KPCA 能处理新样本，但代价很大：
# z_j = ∑ α_i^j κ(x_i, x_new)  ← 每个新样本都要跟所有训练样本算一遍核函数
Z_new_kpca = kpca.transform(X_new)  # O(m * d)，m=训练样本数
print(f"KPCA 新样本降维结果:\n{Z_new_kpca}")
# ⚠️ m=200 时很快，但 m=100万 时每个新样本要做 100 万次核计算 —— 生产环境噩梦
```

## 二、转导式 vs 归纳式：降维方法的分水岭

> 什么叫"转导式"和"归纳式"？这是区分降维方法能否处理新样本的关键分水岭。

| 算法 | 是否产生通用映射 | 新样本处理方式 | 核心公式支撑 |
| --- | --- | --- | --- |
| **MDS** | 否（转导式） | 需重新计算或插值 | Z = Λ^{1/2} V^T |
| **PCA** | 是（归纳式） | 直接乘投影矩阵 W | Z = W^T X |
| **KPCA** | 半（依赖核矩阵） | 与全体训练样本算核值 | z_j = ∑ α_i^j κ(x_i, x) |
| **Isomap** | 否（转导式） | 需重新构建近邻图+MDS | MDS(测地线距离矩阵) |
| **LLE** | 否（转导式） | 需重新算权重+特征分解 | Z = M 的次小特征向量 |

## 三、全方法对比代码：同数据、不同方法、统一评估

> 同一份数据上，五种降维方法的速度和效果差距有多大？

```python
from sklearn.manifold import MDS, Isomap, LocallyLinearEmbedding
from sklearn.decomposition import PCA, KernelPCA
from sklearn.datasets import make_swiss_roll
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier
import time

# ============================================
# 📌 构造非线性数据 + 降维后分类评估
# ============================================
X, y_continuous = make_swiss_roll(n_samples=800, noise=0.1, random_state=42)
# 将瑞士卷切成 3 段作为分类标签
y = np.digitize(y_continuous, bins=np.percentile(y_continuous, [33, 67]))

X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, random_state=42)

# ============================================
# 📌 各降维方法大比拼
# ============================================
methods = {
    'PCA':     PCA(n_components=2),
    'KPCA':    KernelPCA(n_components=2, kernel='rbf', gamma=0.1),
    'MDS':     MDS(n_components=2, random_state=42),
    'Isomap':  Isomap(n_neighbors=10, n_components=2),
    'LLE':     LocallyLinearEmbedding(n_neighbors=10, n_components=2),
}

print(f"{'方法':<10} {'训练时间':>10} {'KNN准确率':>10} {'新样本支持'}")
print("-" * 55)

for name, method in methods.items():
    t0 = time.time()

    # 训练 + 降维
    if name == 'MDS':
        Z_tr = method.fit_transform(X_tr)  # MDS 是转导式，fit_transform 是合一的
    else:
        Z_tr = method.fit_transform(X_tr)

    train_time = time.time() - t0

    # KNN 评估降维效果
    knn = KNeighborsClassifier(n_neighbors=10)
    knn.fit(Z_tr, y_tr)

    # ⚠️ MDS/Isomap/LLE 是转导式，新样本无法直接 transform
    try:
        Z_te = method.transform(X_te)
        acc = knn.score(Z_te, y_te)
        new_sample = "✅ 支持"
    except:
        acc = knn.score(Z_tr, y_tr)  # 只能用训练集评估
        new_sample = "❌ 不支持"

    print(f"{name:<10} {train_time:9.3f}s {acc:9.3f} {new_sample}")

# 💡 典型输出解读：
#   - PCA: 最快，支持新样本，但非线性数据上效果差
#   - KPCA: 较快，支持新样本（代价大），非线性效果好
#   - MDS: 中等速度，不支持新样本
#   - Isomap: 较慢（最短路径计算），不支持新样本，非线性效果最好
#   - LLE: 中等速度，不支持新样本
```

## 四、选型指南：什么时候用什么？

> 面对五种降维方法，实际项目中该如何选择？

```python
# ============================================
# 📌 决策树（写在代码注释里比画图更直观）
# ============================================
def choose_dimensionality_reduction(data_is_nonlinear, need_new_samples,
                                     n_samples, n_features):
    """
    降维方法选型决策函数

    Parameters:
    - data_is_nonlinear: 数据是否有非线性结构（如弯曲、卷绕）
    - need_new_samples: 是否需要处理部署后的新样本
    - n_samples: 训练样本数
    - n_features: 特征维度
    """

    # --- 场景1: 线性数据（或不确定）+ 需要新样本支持 ---
    if not data_is_nonlinear and need_new_samples:
        return "🌟 PCA: 最快、最简单、支持新样本，首选"

    # --- 场景2: 非线性数据 + 必须支持新样本 ---
    if data_is_nonlinear and need_new_samples:
        if n_samples > 10000:
            return ("⚠️ KPCA 预测会很慢（O(n_samples) per sample），"
                    "考虑先采样或用神经网络（AutoEncoder）")
        return ("KPCA: 支持新样本但预测开销大（需与所有训练样本算核函数），"
                "小数据集首选")

    # --- 场景3: 非线性数据 + 只需降维可视化（不需新样本） ---
    if data_is_nonlinear and not need_new_samples:
        if n_samples < 5000:
            return "Isomap: 全局结构保持最好，适合可视化"
        return "LLE: 比 Isomap 快（只需邻居级别的计算），适合中等规模"

    # --- 场景4: 需要保持距离的精确结构 ---
    return "MDS: 保留原始距离最精确，但计算代价高（O(n³)），适合小数据集"

# 💡 使用示例
print(choose_dimensionality_reduction(
    data_is_nonlinear=True, need_new_samples=False,
    n_samples=500, n_features=100
))
```

## 五、总结：五种方法一张表

> 最终速查：五种方法的核心属性一览。

| 属性 | PCA | KPCA | MDS | Isomap | LLE |
| --- | --- | --- | --- | --- | --- |
| **线性/非线性** | 线性 | 非线性 | 线性距离保持 | 非线性(测地线) | 非线性(局部) |
| **核心矩阵** | XX^T (d x d) | K (m x m) | D距离→B内积 | 测地线距离 | W权重→M代价 |
| **新样本** | ✅ W^T x | ✅ ∑α·κ(x_i,x) | ❌ 需重算 | ❌ 需重算 | ❌ 需重算 |
| **时间复杂度** | O(d³) | O(m³) | O(m³) | O(m²log m) | O(m³) |
| **是否归纳式** | 是 | 半 | 否(转导式) | 否(转导式) | 否(转导式) |
| **比喻** | 旋转坐标系找长轴 | 高维拉直再找长轴 | 按里程表画地图 | 沿山路量距离再铺平 | 按邻居关系排座位 |
