## 二、 智能体的功能简介
本实验设计并实现了一个面向数字教育场景的智能化教学辅助系统——“数学 assistant”。该智能体旨在改变传统大模型“直白、生硬地直接吐出答案”的单向灌输模式，而是通过图形化工作流技术，将科学的教学法引入到人工智能的对话逻辑中，扮演一位具备共情能力、因材施教的“虚拟数学导师”。

本系统的核心功能主要涵盖以下五个教学维度：
1. **学生学业意图的动态识别**：系统能够对学生输入的自然语言进行深层语义分析，精准判断学生当前的实际诉求。例如：学生是在请求讲解基础概念、需要具体题目的解题步骤，还是在反馈自己的错题，亦或是在倾诉学业压力和焦虑。
2. **多通道分支导训（因材施教）**：系统改变了“一问一答”的死板结构，利用前置的分支判断路由器，针对不同类型的学生问题提供完全不同的讲解风格和教学路径，从而实现真正的个性化教学。
3. **数形结合的图形绘制单元（核心特色）**：为了突破传统 AI 只能聊文字的限制，系统内置了初步的图形解析与绘制尝试功能。当学生输入一个具体的二次函数解析式时，智能体会在后台计算关键坐标点（如顶点、与坐标轴的交点），并尝试为学生渲染或生成直观的抛物线函数图像，帮助学生通过“看图”来理解抽象的代数问题。
4. **联网知识检索增强（保障权威）**：当学生提到教材以外的拓展定理、或需要极其严谨的官方数学定义时，智能体自动触发搜索模块，提取互联网上的公开高质量教学资料进行补充，从根本上杜绝人工智能常有的知识偏差现象。
5. **错题摘要与逻辑漏洞反思**：当学生处于错题反馈分支时，智能体不仅会指出正确答案，还能自动捕捉学生话语里的“病因”（如符号看错、移项未变号、公式套错等），将这些错误特征提取为结构化的改进摘要，引导学生进行二次反思。

## 三、 智能体的搜索单元逻辑图、功能演示

### 3.1 搜索单元设计思路
在数学教学过程中，知识的准确性和严谨性是第一位的。大语言模型虽然知识面广，但在面对一些细分数学定理或复杂公式的推导背景时，容易产生知识模糊。为了让智能体说出的每一句话、每一个公式都有据可查，本系统引入了搜索单元（Web Search Tool）：
* **教学背景的有机融合**：大模型可以将联网搜索到的权威公开教材解析、标准公式释义作为“参考上下文”。
* **消灭大模型幻觉**：确保给学生输出的内容百分之百符合教学大纲与规范，提供安全、可靠的学术级答疑。

### 3.2 搜索单元逻辑流程
搜索单元在系统内部扮演着“开卷参考”的角色。当学生提出需要背景补充的问题时，数据的流转逻辑如下：

【 学生输入复杂数学问题 】 
          │
          ▼
【 系统提取教学核心关键词 】
          │
          ▼
【 搜索单元：网络检索公开教学资料 】
          │
          ▼
【 返回权威、准确的知识摘要 】
          │
          ▼
【 大模型：结合公开资料组织教学语言 】
          │
          ▼
【 输出给学生清晰、无误的讲解 】

### 3.3 搜索单元功能演示
* **示例输入**：请问二次函数 y = ax² + bx + c 的顶点公式是怎么推导出来的？
* **系统内部流转**：智能体通过核心词提取，发现需要提供严谨的公式证明，于是触发搜索单元，调取关于“配方法推导二次函数顶点”的公开规范教学大纲资料，随后交由输出节点进行多步骤拆解。
* **示例输出**：
  “同学们好！二次函数的顶点公式主要是通过配方法推导出来的。我们一起来看详细的变形步骤，这能帮我们加深对代数式恒等变形的理解：
  
  步骤一：提取二次项系数 a
  我们把含有未知数 x 的项提取出 a，常数项 c 留在外面：
  y = a(x² + b/a x) + c
  
  步骤二：括号内配成完全平方式
  加上一次项系数 b/a 一半的平方，也就是 (b/2a)²，为了保持等式平衡，加完后再立刻减去它：
  y = a[x² + b/a x + (b/2a)² - (b/2a)²] + c
  
  步骤三：化简与组合
  将完全平方部分打包，并把减去的项乘以外面的 a 移出来通分：
  y = a(x + b/2a)² - b²/4a + c
  y = a(x + b/2a)² + (4ac - b²)/4a
  
  教学总结：由此我们可以清晰地看到，抛物线的顶点坐标公式就是 (-b/2a, (4ac - b²)/4a)。这意味着只要知道了 a、b、c 的值，我们连图都不用画，就能直接锁定图像的最值位置了！”

## 四、 智能体变量及分支单元逻辑图、功能演示

### 4.1 变量单元设计思路
为了让智能体具备“听懂学生意图”的能力，系统在工作流前置部分引入了变量提取技术。当学生输入一段话时，大模型会像漏斗一样，从中抽离出核心的教学标签变量：
* **问题标签（动态变量）**：其取值由前置意图判断模型决定，可选范围包括“学科问答”、“问题反馈”、“生活日常”。该变量是后续流程能够产生分流的唯一钥匙。

### 4.2 分支单元设计思路
分支逻辑单元（即工作流中的“分支判断_001”）是实现数字化因材施教的核心部件。它就像学校里的“分流向导”，根据上一步提取出的“问题标签”变量，动态决定本次会话将进入哪一个教学车间：
1. **分支路径一：【学科问答】** -> 引导至专注于公式、定理、解题步骤以及函数图像尝试绘制的专业答疑节点。
2. **分支路径二：【问题反馈】** -> 引导至错题摘要与分析节点，不急于给出正确答案，先帮学生诊断逻辑盲区，并把错题特征记录到系统中。
3. **分支路径三：【生活日常】** -> 引导至情感关怀与导师对话节点，加载班主任“郭老师”的人设立场，对学生的焦虑进行安抚，提供宏观的学习方法指导。

### 4.4 分支单元功能演示一：学科问答分支
* **学生输入**：解方程 x² - 5x + 6 = 0
* **系统变量提取**：`问题标签` = `学科问答`
* **智能体输出示例**：
  “这是一道典型的一元二次方程求解题。除了求根公式外，老师更推荐你掌握十字相乘法（因式分解），这能极大地锻炼你的数感：
  1. 寻找常数拆分：我们需要找到两个数字，它们的乘积等于常数项 6，而它们的和等于一次项系数 -5。
  2. 锁定数字：经过观察，-2 和 -3 刚好满足条件（因为 (-2) × (-3) = 6，且 (-2) + (-3) = -5）。
  3. 因式分解变形：因此，原方程左边可以写成：(x - 2)(x - 3) = 0
  4. 求出最终根：最终解得：x1 = 2, x2 = 3。”

### 4.5 分支单元功能演示二：错题反思分支
* **学生输入**：老师，方程 x² - 5x + 6 = 0，我算出来的答案是 x = -2 和 x = -3，为什么不对呀？
* **系统变量提取**：`问题标签` = `问题反馈`
* **智能体输出示例**：
  “看到你主动作出尝试，老师非常高兴！你找出的 -2 和 -3 这两个数字是完全准确的，这说明你的因式分解拆分能力很棒。
  
  不过，你掉进了一个非常经典的‘符号陷阱’里：
  在你的草稿本上，方程其实已经被成功变形为了 (x - 2)(x - 3) = 0。
  接下来的逻辑是：我们要让 (x - 2) = 0 成立，此时把 -2 移到等号的右边，根据移项变号的规则，它应该变成正 2（即 x = 2）。你直接把括号里的数字连带符号当成了最终答案，忽略了最后一步的移项变号。下次做完题，试着把 -2 代入原方程验算一下，就会及时发现符号问题啦！”

## 五、 整个系统的功能演示

### 5.1 系统整体流程
整个系统依托于工作流平台的底层链条，各节点环环相扣，实现了一套完整的教研辅助流程：
1. **感知与捕获**：系统捕获用户话语，将其作为源数据输入工作流。
2. **加工与特征抽取**：通过前置模型，把大段的聊天文本压缩提炼成带有教学属性的变量。
3. **逻辑流转导航**：分支判断节点作为核心大脑，根据变量将流量科学分配。
4. **数形结合尝试**：如果属于函数题目，尝试在后台调取绘图逻辑。
5. **融汇生成与输出**：由专业提示词调校过的大模型产出符合教学心理学的文字和图形，最终呈现给学生。

### 5.2 综合多轮连续教学演示案例（数形结合功能展示）
* **交互第一轮（触发生活日常分支）**：
  * **学生**：郭老师，最近数学课进度好快，上周讲一元二次方程，这周又跟二次函数图像结合起来了。我觉得好抽象，题根本不会做，心里有点烦。
  * **智能体（流转至生活日常分支）**：“同学们在刚接触函数和图像的结合时，普遍都会产生这种挫败感，这非常正常。数学从单纯的‘算数’进入到‘数形结合’，是一次思维的跳跃。别烦作，咱们不用一口气把所有的难题都做完。今天我们可以先不看复杂的题目，只从最基础的函数开口方向聊起，老师陪着你一步一步来。”
* **交互第二轮（无缝切换至学科核心答疑分支，并触发绘图功能）**：
  * **学生**：谢谢老师，那我听您的。您能帮我分析一下二次函数 y = x² - 4x + 3 的图像长什么样吗？
  * **智能体（流转至学科问答分支）**：
    “没问题！既然你想知道这个函数的长相，老师先在后台帮你计算并尝试绘制出了它的抛物线图像结构：
    
    【智能体数形结合分析面板】
    * 开口方向：二次项系数 a = 1 > 0，所以图像开口向上。
    * 顶点坐标：通过公式 x = -b/2a = 2，代入算得 y = -1，顶点为 (2, -1)。
    * 与 Y 轴交点：令 x=0，得 (0, 3)。
    * 与 X 轴交点：解方程 x² - 4x + 3 = 0，得 (1, 0) 和 (3, 0)。
    
    【图像初步绘制输出】
    （智能体在下方尝试渲染并展示出一条以 (2, -1) 为最低点、对称轴为 x=2、开口朝上的抛物线图像草图）
    
    老师讲解：你看，有了这张图，我们是不是就能一眼看出：当 x=2 时，函数有最小值 -1？而且在 x<2 的时候，随着 x 变大，图像是往下走的（单调递减）。现在结合老师画的图，你再看看是不是觉得函数没那么抽象了？”

## 六、 公开资料与数据收集说明
本实验在智能体的研发与测试过程中，紧密结合了公开的教育教研资料，使系统的行为举止更像一个真正的数字化工具：
1. **基础教材规范收集**：收集并参考了主流数学教材中关于函数、方程、代数变形的标准术语和推导符号，确保智能体输出的公式与学生的课本完全一致。
2. **启发式教学法引入**：融合了教育心理学中常用的“微步教学”与“数形结合”理念。系统在多轮交互中尝试将代数解析式直接转化为几何图像，打破学生的思维壁垒。
3. **教育信息化编排思维**：借助公开的数字化智能体组装方法，成功将“意图拆解”、“逻辑判断”和“可视化绘图反馈”三者有条不紊地串联在同一个应用中。

## 七、 自我迭代过程
在实验开发周期内，本智能体经历了从粗糙到精致的五次重大版本自我迭代：
* **第一代：单一式Prompt对话** ── 最早的版本面对学生的提问，只会长篇大论直接把文字答案贴出来，无法提供图形支持。
* **第二代：结构化变量提炼** ── 增加了变量提取机制，让智能体能够把学生的提问转化为“数字化标签”，使系统能从全局看懂学生的真实意图。
* **第三代：多通道分支路由** ── 引入了多路 If-Else 分支判断节点。这一举措分流了流量，让“纯学术推导”、“错题诊断分析”和“生活日常关怀”拥有了各自独立运作的逻辑模块。
* **第四代：数形结合绘图功能的尝试引入** ── 为了让数学教学活起来，我们在学科回答分支中加入了根据题目自动解析坐标并尝试绘制图像的节点。虽然目前图像的精细度和动态交互还不完全，但成功实现了“从无到有”的跨越。
* **第五代：联网搜索联动** ── 在最后的优化中，将学科问答分支与搜索单元绑定，确保查阅网络公开权威数据，大幅度提升了数字化教学的严谨性与确定性。

## 八、 实验总结与展望
本实验圆满完成了“数学 assistant”智能体的开发与编排。通过可视化工作流将搜索单元、变量单元和分支逻辑单元进行了深度的融合与协同，各项功能完全运行正常，满足并达到了实验预期的全部指标。

**系统的局限性与后续升级展望**：
正如在实验中发现的，目前系统内置的“根据题目绘制图像”功能还不够完全。它虽然能够准确计算出坐标点并生成基础的静态草图，但在图像的精细度（如标注精细网格线、多函数对比）以及动态交互性上依然存在局限，无法让学生通过鼠标拖动抛物线来实时观察系数的变化。

在后续的 2.0 版本升级规划中，我们期望重点完善这一绘图单元。通过引入更强大的动态数学函数绘图插件，让智能体不仅能生成完美的动态函数图像，还能支持学生“在线拖动抛物线、改变 a、b、c 的值并实时看到图像缩放和移动”的交互。此外，还将引入“图片识别”功能（学生直接拍摄手写几何图形上传，AI 在图上标记漏洞），从而打造一个真正立体、全面的数形结合数字化教学辅助智能体。
