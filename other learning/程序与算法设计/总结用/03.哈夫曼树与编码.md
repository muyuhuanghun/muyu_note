## 一、哈夫曼树是什么？

```
💡 核心问题：如何用最少的二进制位表示出现频率不同的字符？

场景：一段文本中各字符出现频率
  A: 5次  B: 9次  C: 12次  D: 13次  E: 16次  F: 45次

等长编码（3位）：A=000, B=001, C=010, D=011, E=100, F=101
  总位数 = (5+9+12+13+16+45) × 3 = 300

哈夫曼编码（变长）：F=0, C=100, D=101, A=1100, B=1101, E=111
  总位数 = 45×1 + 12×3 + 13×3 + 5×4 + 9×4 + 16×3 = 224

节省了 25% 的空间！
```

📌 哈夫曼树 = **带权路径长度（WPL）最小**的二叉树。频率高的字符路径短，频率低的字符路径长。

## 二、数据结构定义

```c
typedef struct huffnode {
    char data;       // 字符
    int weight;      // 权值（出现频率）
    int parent;      // 父节点下标（-1表示无父节点）
    int lchild;      // 左孩子下标（-1表示无）
    int rchild;      // 右孩子下标（-1表示无）
} HuffNode;
```

📌 用**数组**而非链表存储，因为哈夫曼树是完全二叉树结构，总节点数固定为 `2n-1`（n 个叶子节点）。

## 三、构建算法（贪心）

### 1. 核心思路

```
🌟 贪心策略：每次选权值最小的两个节点合并

步骤：
1. 初始化 2n-1 个节点，前 n 个是叶子（已知权值）
2. 从第 n 个开始，每轮：
   a. 在未合并节点中找权值最小的两个 (min1, min2)
   b. 合并为新节点，权值 = min1 + min2
   c. 标记两个子节点已被合并（parent ≠ -1）
3. 重复直到所有节点都有父节点
```

### 2. 实现代码

```c
static void creatht(HuffNode ht[], int n)
{
    int i, k, lnode, rnode;
    double min1, min2;

    // 🚀 Step 1: 初始化所有节点
    for(i = 0; i < 2*n-1; i++)
    {
        ht[i].parent = -1;   // -1 表示尚未被合并
        ht[i].lchild = -1;
        ht[i].rchild = -1;
    }

    // 🌟 Step 2: 从第 n 个节点开始，逐步构建非叶子节点
    for(i = n; i < 2*n-1; i++)
    {
        min1 = min2 = 32767;  // 初始化为极大值
        lnode = rnode = -1;

        // 在 [0, i-1] 范围内找两个 parent==-1 的最小权值节点
        for(k = 0; k < i; k++)
        {
            if(ht[k].parent == -1)  // 只在"未合并"节点中选
            {
                if(ht[k].weight < min1)
                {
                    // 📌 当前最小值下沉为第二小
                    min2 = min1;
                    rnode = lnode;

                    // 更新最小值
                    min1 = ht[k].weight;
                    lnode = k;
                }
                else if(ht[k].weight < min2)
                {
                    // 更新第二小值
                    min2 = ht[k].weight;
                    rnode = k;
                }
            }
        }

        // 🌟 Step 3: 合并两个最小节点
        ht[i].weight = ht[lnode].weight + ht[rnode].weight;
        ht[i].lchild = lnode;
        ht[i].rchild = rnode;

        // 标记子节点已被合并
        ht[lnode].parent = i;
        ht[rnode].parent = i;
    }
}
```

### 3. 图解过程

```
初始叶子：A(5) B(9) C(12) D(13) E(16) F(45)

第1轮：选 A(5) + B(9) → 节点6(14)
第2轮：选 C(12) + D(13) → 节点7(25)
第3轮：选 节点6(14) + E(16) → 节点8(30)
第4轮：选 节点7(25) + 节点8(30) → 节点9(55)
第5轮：选 F(45) + 节点9(55) → 节点10(100) ← 根节点

最终树结构：
            100
           /    \
         F(45)  55
               /   \
             25    30
            / \   / \
          C12 D13 14 E16
                  / \
                A5  B9
```

### 4. 复杂度分析

| 指标 | 复杂度 | 说明 |
|:---|:---:|:---|
| 时间 | O(n²) | n-1 轮，每轮遍历找最小值 O(n) |
| 空间 | O(n) | 数组大小 2n-1 |

💡 优化：用**最小堆**找最小值，可将时间复杂度降到 O(n log n)。

## 四、哈夫曼编码

### 1. 编码规则

```
从叶子到根回溯路径：
- 左分支 → '0'
- 右分支 → '1'
- 路径上的字符序列反转即为编码

例：A 的路径为 根→右→右→左→左
    编码为 "0110"（从叶子读起：左=0, 左=0, 右=1, 右=1 → 反转 → 1100）
```

### 2. 实现代码

```c
static void encoding(HuffNode ht[], Tcode book[], int n)
{
    char *str = (char *)malloc(n+1);
    str[n] = '\0';

    for(int i = 0; i < n; i++)  // 对每个叶子节点
    {
        book[i].ch = ht[i].data;
        int idx = i;
        int j = n;  // 从字符串末尾开始填充

        // 🌟 从叶子向上回溯到根
        while((p = ht[idx].parent) > 0)
        {
            if(ht[p].lchild == idx)
                str[--j] = '0';   // 左孩子 → 编码 0
            else
                str[--j] = '1';   // 右孩子 → 编码 1
            idx = p;              // 向上移动
        }
        strcpy(book[i].code, &str[j]);  // 从有效位置复制
        book[i].lenth = n - j;           // 编码长度
    }
    free(str);
}
```
