## 解题思路

- 经典的**双指针归并**算法，与第 160 题（合并顺序表）思路相同
- 用指针 `i` 扫描数组 a，`j` 扫描数组 b，`k` 指向数组 c 的写入位置
- 每次比较 `a[i]` 和 `b[j]`，将较小者写入 `c[k]` 并推进对应指针
- 当某一数组耗尽后，将另一数组的剩余元素全部追加到 c
- 注意：a 和 b 的参数用 `const` 修饰，表示函数不会修改源数组

## 参考解答

```c
/*
 * merge_2in1 - 将两个有序数组合并到第三个数组中
 *
 * 核心思想：双指针归并
 *   - i 扫描数组 a，j 扫描数组 b，k 指向数组 c 的写入位置
 *   - 每次比较 a[i] 和 b[j]，取较小者写入 c[k]
 *   - 某一数组耗尽后，将另一数组的剩余元素全部追加
 *
 * 与第 160 题（合并顺序表）的区别：
 *   - 本题使用裸指针 + 长度参数，而非顺序表结构体
 *   - 源数组标记为 const，保证不会被意外修改
 *
 * 时间复杂度：O(lena + lenb)
 * 空间复杂度：O(1)（数组 c 由调用者提供）
 *
 * @param a    源数组1，已升序排序（const，不可修改）
 * @param lena 数组 a 的长度
 * @param b    源数组2，已升序排序（const，不可修改）
 * @param lenb 数组 b 的长度
 * @param c    目标数组，存放合并后的有序结果（需保证足够大）
 */
void merge_2in1(const int *a, int lena, const int *b, int lenb, int *c) {
    int i = 0;  /* 数组 a 的扫描指针，从下标 0 开始 */
    int j = 0;  /* 数组 b 的扫描指针，从下标 0 开始 */
    int k = 0;  /* 数组 c 的写入指针，从下标 0 开始 */

    /* 阶段1：两个数组都未耗尽时，逐一比较取较小值 */
    while (i < lena && j < lenb) {
        if (a[i] <= b[j]) {
            c[k] = a[i];  /* a 的当前元素较小（或相等），写入 c */
            i++;           /* 推进 a 的指针 */
        } else {
            c[k] = b[j];  /* b 的当前元素较小，写入 c */
            j++;           /* 推进 b 的指针 */
        }
        k++;  /* 无论取自哪个数组，c 的写入指针都要前进 */
    }

    /* 阶段2：若数组 a 有剩余，全部追加到 c */
    while (i < lena) {
        c[k++] = a[i++];
    }

    /* 阶段3：若数组 b 有剩余，全部追加到 c */
    while (j < lenb) {
        c[k++] = b[j++];
    }
}
```
