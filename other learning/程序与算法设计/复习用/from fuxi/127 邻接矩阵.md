# 127 邻接矩阵基本操作

> 题目编号：127

## 题目

试在邻接矩阵存储结构上实现图的基本操作 `matrix_insert_vertex` 和 `matrix_insert_arc`，相关定义如下：

### 数据结构定义

```c
typedef int VertexType;    // 顶点数据类型，此处为整型

typedef enum {
    DG,     // 有向图 Directed Graph
    UDG     // 无向图 Undirected Graph
} GraphType;

#define MAX_VERTEX_NUM 20  // 最大顶点数

typedef struct {
    VertexType vertex[MAX_VERTEX_NUM];       // 顶点向量，存储所有顶点的数据
    int arcs[MAX_VERTEX_NUM][MAX_VERTEX_NUM]; // 邻接矩阵，arcs[i][j]表示顶点i到顶点j是否有弧
    int vexnum, arcnum;  // 图的当前顶点数和弧数
    GraphType type;      // 图的种类标志（有向图/无向图）
} MatrixGraph;

// 已有函数声明：返回顶点v在vertex数组中的下标，如果v不存在返回-1
int matrix_locate_vertex(MatrixGraph *MG, VertexType vex);

// 需要实现的两个操作
bool matrix_insert_vertex(MatrixGraph *G, VertexType v);
bool matrix_insert_arc(MatrixGraph *G, VertexType v, VertexType w);
```

当成功插入顶点或边时，函数返回 `true`，否则（如顶点或边已存在、插入边时顶点v或w不存在）返回 `false`。

## 解题思路

**`matrix_insert_vertex` 插入顶点：**

- **检查容量**：当前顶点数 `vexnum` 是否已达到 `MAX_VERTEX_NUM`，若是则插入失败
- **检查重复**：遍历 `vertex` 数组，若已存在相同值的顶点则插入失败
- **执行插入**：将新顶点追加到 `vertex` 数组末尾，`vexnum` 自增

**`matrix_insert_arc` 插入弧：**

- **定位顶点**：调用 `matrix_locate_vertex` 分别找到 v 和 w 在数组中的下标
- **检查存在性**：若任一顶点不存在（返回-1），则插入失败
- **检查重复**：若邻接矩阵中对应位置已非零，说明弧已存在，返回失败
- **设置弧**：将 `arcs[vIndex][wIndex]` 置为 1，`arcnum` 自增
- **无向图对称处理**：若图为无向图（`UDG`），还需将 `arcs[wIndex][vIndex]` 同样置为 1

## 参考解答

```c
bool matrix_insert_vertex(MatrixGraph *G, VertexType v) {
    // 第一步：检查顶点数是否已达上限
    if (G->vexnum >= MAX_VERTEX_NUM)
        return false;

    // 第二步：遍历已有顶点，检查是否重复
    for (int i = 0; i < G->vexnum; i++) {
        if (G->vertex[i] == v)
            return false;  // 顶点已存在，插入失败
    }

    // 第三步：将新顶点放入顶点向量末尾，顶点计数加1
    G->vertex[G->vexnum] = v;
    G->vexnum++;
    return true;
}

bool matrix_insert_arc(MatrixGraph *G, VertexType v, VertexType w) {
    // 第一步：定位两个顶点在顶点向量中的下标
    int vIndex = matrix_locate_vertex(G, v);
    int wIndex = matrix_locate_vertex(G, w);

    // 第二步：若任一顶点不存在，插入失败
    if (vIndex < 0 || wIndex < 0)
        return false;

    // 第三步：检查弧是否已存在（邻接矩阵中对应位置非零）
    if (G->arcs[vIndex][wIndex] != 0)
        return false;

    // 第四步：设置弧，arcnum计数加1
    G->arcs[vIndex][wIndex] = 1;
    G->arcnum++;

    // 第五步：若为无向图，需要对称设置（v->w 和 w->v 都要有）
    if (G->type == UDG)
        G->arcs[wIndex][vIndex] = 1;

    return true;
}
```
