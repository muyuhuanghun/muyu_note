# 非递归先序遍历（char 标签版本）

> 题目编号：198

## 题目

已知二叉树的存储结构和栈操作接口如下：

```c
#include "exam202306.h"

typedef struct bitnode {
    char tag;                   // 结点的字符标签
    struct bitnode *left, *right;  // 左子树和右子树
} bitnode, *bitree;
```

可用的栈操作接口：

```c
void stack_init(stack_ptr *S);       // 栈初始化
bool stack_empty(stack_ptr *S);      // 判空，返回栈是否为空
void stack_push(stack_ptr *S, bitree item);  // 入栈
bitree stack_pop(stack_ptr *S);      // 出栈，返回栈顶元素
```

已有的外部声明：

```c
extern void visit(char);    // 访问结点的函数，参数是结点的字符标签
extern stack *S;            // 已初始化的外部栈，直接使用即可
```

请实现函数：

```c
/*
 * @brief   不用递归，实现二叉树的先序遍历
 * @param   tree：指向二叉树根结点的指针（注意：可能是空树）
 * @return  void
 */
void preorder(bitree tree) {
    // 你的代码写在这里
}
```

## 解题思路

- 本题与第 120 题本质相同，都是**非递归先序遍历**，区别在于：
  - 结点标签类型为 `char`（而非 `int`）
  - 栈操作接口不同（`stack_pop` 直接返回元素，而非通过指针参数传出）
  - 使用外部已声明的栈 `S`，无需自行分配
- 算法步骤：
  1. 处理空树：如果 `tree` 为 NULL，直接返回
  2. 将根结点入栈
  3. 循环：弹出栈顶 -> 访问结点 -> 先压右子树再压左子树
- **关键**：先压右再压左，利用栈的 LIFO 特性保证左子树先被访问

## 参考解答

```c
void preorder(bitree tree) {
    if (!tree) return;          // 空树直接返回，无需遍历

    stack_init(S);              // 初始化栈（使用外部已声明的栈 S）
    stack_push(S, tree);        // 根结点入栈

    while (!stack_empty(S)) {   // 栈不为空时持续循环
        bitnode node = stack_pop(S);   // 弹出栈顶结点
        visit(node.tag);               // 访问该结点（先序：先访问根）

        // 注意压栈顺序：先右后左
        // 栈是后进先出（LIFO），先压入右子树，后压入左子树
        // 出栈时左子树先被弹出，保证了"根->左->右"的先序顺序
        if (node.right) stack_push(S, node.right);  // 右子树先入栈
        if (node.left)  stack_push(S, node.left);   // 左子树后入栈
    }
}
```
