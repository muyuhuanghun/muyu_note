# 181 图的焊接

> 题目编号：181

## 题目

### 一、已知条件

设有两张有向图 G1 和 G2，二者有一些**字符标签相同**的顶点（例如 B 和 D）。

现定义两张**图的焊接（weld）**是将二者的标签相同的顶点合并，融合成一张图，其余顶点和边不变。

（原题附有两张图的示意图：G1 和 G2 中标签相同的顶点 B、D 在焊接后合并为同一顶点，其余顶点和边保持不变。）

有向图用**邻接表**表示，结构如下：

### 数据结构定义

```c
#define MAX_VERTEX_NUM 20   // 最大顶点数量

// 弧结点（邻接表中的边结点）
typedef struct _arc_node {
    int adjvex;               // 该弧指向的顶点在顶点向量中的序号
    struct _arc_node *nextarc; // 指向同一弧链表中下一条弧的指针
} arc_node;

// 顶点结点
typedef struct vertex_node {
    char tag;                 // 顶点字符标签（如 'A', 'B' 等）
    arc_node *firstarc;       // 指向该顶点第一条出弧的指针
} vertex_node;

// 邻接表表示的图
typedef struct Graph {
    vertex_node vertex[MAX_VERTEX_NUM]; // 顶点向量，下标从0开始
    int vexnum, arcnum;                 // 图的当前顶点数和弧数
} adjlist;
```

另有根据顶点字符标签 `v` 定位该顶点在图G顶点向量中序号的函数：

```c
// 已有函数：根据字符标签查找顶点下标，例如 locate_vertex(G2, 'F') 返回 3
int locate_vertex(adjlist* G, char v);
```

### 二、任务描述

焊接算法分为几个子算法，其中除了合并边（弧）的子算法，其余都已经完成。现请设计一个算法，实现焊接算法的子算法：**合并两张图的边（弧）**。

### 三、编码要求

1. 算法函数原型：`void merge_arcs(adjlist *G1, adjlist *G2);`
   - **功能**：将图G2的边（弧）合并到G1中，即将G2中所有的边复制到G1中；G2保持不变
   - **空图处理**：如果两张图中只要有一张为空图（即顶点数为0），那么算法不做任何操作，即G1和G2保持不变
   - **参数**：G1和G2都是指向图的指针
   - **返回值**：无
   - **注意**：请采用**头插法**处理链表的插入
2. 编码约束
   - 时间复杂度：无特别要求
   - 空间复杂度：无特别要求

## 解题思路

**核心思路：遍历G2的每条弧，在G1中找到对应顶点，然后用头插法插入弧结点。**

具体步骤如下：

1. **空图检查**：若G1或G2的顶点数为0，直接返回
2. **遍历G2的所有顶点**：对G2中的每个顶点 G2->vertex[i]：
   - 用 `locate_vertex` 在G1中查找该顶点标签对应的下标 `pos1`
   - 若G1中不存在该顶点（pos1为-1），说明这是G2独有的顶点，跳过其所有弧（因为焊接只合并公共顶点，非公共顶点应已由其他子算法处理）
   - 若G1中存在，继续遍历该顶点的弧链表
3. **遍历G2当前顶点的每条出弧**：对弧结点 `p`（指向G2中的某个顶点 j）：
   - 用 `locate_vertex` 在G1中找到弧头顶点 G2->vertex[p->adjvex].tag 对应的下标 `pos2`
   - 若G1中不存在弧头顶点，跳过该弧
   - **检查重复**：遍历G1中 pos1 的弧链表，看是否已存在指向 pos2 的弧，若已存在则跳过
   - **头插法插入**：创建新的弧结点，插入到G1中 pos1 的弧链表头部
4. **更新弧数**：每成功插入一条弧，G1->arcnum 自增

**难点说明：**

本题的复杂之处在于：
- 需要通过字符标签在两个图之间建立映射关系
- 需要检查弧是否重复，避免多次合并时产生冗余边
- 头插法要求修改弧链表的头指针

## 参考解答

```c
void merge_arcs(adjlist *G1, adjlist *G2) {
    // ========== 第一步：空图检查 ==========
    // 如果任一图为空（顶点数为0），不做任何操作
    if (G1->vexnum == 0 || G2->vexnum == 0)
        return;

    // ========== 第二步：遍历G2中的每一个顶点 ==========
    for (int i = 0; i < G2->vexnum; i++) {
        // 在G1中查找与G2当前顶点标签相同的顶点下标
        int pos1 = locate_vertex(G1, G2->vertex[i].tag);

        // 如果G1中不存在该标签的顶点，跳过该顶点的所有弧
        // （这种情况在焊接的完整流程中，不应出现，
        //   因为顶点合并子算法已将公共顶点合并到G1中）
        if (pos1 == -1)
            continue;

        // ========== 第三步：遍历G2当前顶点的所有出弧 ==========
        arc_node *p = G2->vertex[i].firstarc;
        while (p != NULL) {
            // 获取弧头顶点在G2中的标签
            char targetTag = G2->vertex[p->adjvex].tag;

            // 在G1中查找弧头顶点的下标
            int pos2 = locate_vertex(G1, targetTag);

            // 如果G1中不存在该弧头顶点，跳过这条弧
            if (pos2 == -1) {
                p = p->nextarc;
                continue;
            }

            // ========== 第四步：检查G1中是否已存在该弧（去重） ==========
            // 遍历G1中 pos1 顶点的弧链表，检查是否已有指向 pos2 的弧
            int duplicate = 0;  // 重复标志，0表示不重复
            arc_node *q = G1->vertex[pos1].firstarc;
            while (q != NULL) {
                if (q->adjvex == pos2) {
                    duplicate = 1;  // 发现重复弧
                    break;
                }
                q = q->nextarc;
            }

            // 如果弧已存在，跳过，继续处理下一条弧
            if (duplicate) {
                p = p->nextarc;
                continue;
            }

            // ========== 第五步：用头插法将新弧插入G1的弧链表 ==========
            // 创建新的弧结点
            arc_node *newArc = (arc_node *)malloc(sizeof(arc_node));
            newArc->adjvex = pos2;           // 弧头在G1中的下标

            // 头插法：新结点的 next 指向原链表头，然后更新头指针
            newArc->nextarc = G1->vertex[pos1].firstarc;
            G1->vertex[pos1].firstarc = newArc;

            // 弧数加1
            G1->arcnum++;

            // 继续处理G2中当前顶点的下一条弧
            p = p->nextarc;
        }
    }
}
```

**算法要点总结：**

- **标签映射**：通过 `locate_vertex` 函数，用字符标签在G1和G2之间建立顶点对应关系
- **头插法**：新弧结点插入链表头部，时间复杂度 O(1)，但会改变弧的相对顺序
- **去重检查**：每条弧插入前都需遍历目标链表检查是否重复，避免多次调用 `merge_arcs` 时产生冗余边
- **整体时间复杂度**：O(G2的顶点数 * G2的最大出度 * G1的最大出度)，因去重检查需要遍历链表
