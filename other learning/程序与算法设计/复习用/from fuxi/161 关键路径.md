# 161 关键路径

> 题目编号：161

## 题目

已知有6个顶点（顶点编号为0~5）的带权有向图G，其邻接矩阵数组A如下：

```c
// 邻接矩阵，∞ 表示无弧（用 INT_MAX 或一个极大值表示）
int a[6][6] = {
    {∞, 4, 6, ∞, ∞, ∞},   // 顶点0: 0->1(权4), 0->2(权6)
    {∞, ∞, 5, ∞, ∞, ∞},   // 顶点1: 1->2(权5)
    {∞, ∞, ∞, 4, 3, ∞},   // 顶点2: 2->3(权4), 2->4(权3)
    {∞, ∞, ∞, ∞, ∞, 3},   // 顶点3: 3->5(权3)
    {∞, ∞, ∞, ∞, ∞, 3},   // 顶点4: 4->5(权3)
    {∞, ∞, ∞, ∞, ∞, ∞}    // 顶点5: 无出弧（汇点）
};
```

实现函数：

```c
// 将图G的关键路径顶点编号保存到path数组中，返回该关键路径的长度
int check_key_path(int* path);
```

## 解题思路

本题考查 **AOE网（Activity On Edge Network）** 中关键路径的求解。AOE网中，顶点表示事件，带权弧表示活动，权值表示活动持续时间。关键路径是从源点到汇点的最长路径，决定了工程的最短完成时间。

**AOE网关键路径的核心算法分为三步：**

**1. 正向求最早发生时间 `ve[]`（Forward Pass）：**

- 从源点出发，`ve[0] = 0`
- 对每个顶点 j，`ve[j] = max{ ve[i] + w(i,j) }`，其中 i 是 j 的所有前驱
- 含义：所有前驱活动都完成后，事件才能发生，取最大值

**2. 逆向求最迟发生时间 `vl[]`（Backward Pass）：**

- 从汇点出发，`vl[5] = ve[5]`（汇点的最迟时间等于最早时间）
- 对每个顶点 i，`vl[i] = min{ vl[j] - w(i,j) }`，其中 j 是 i 的所有后继
- 含义：不影响工期的前提下，事件最迟什么时候必须发生

**3. 求关键活动并提取关键路径：**

- 对每条弧（活动）<i, j>，计算：
  - `e(i,j) = ve[i]`（活动最早开始时间）
  - `l(i,j) = vl[j] - w(i,j)`（活动最迟开始时间）
- 若 `e(i,j) == l(i,j)`，则该活动是**关键活动**
- 由关键活动构成的从源点到汇点的路径即为**关键路径**

**本题中图的结构分析：**

```
源点(0) --> 1 --(5)--> 2 --(4)--> 3 --(3)--> 5(汇点)
  |                                      ^
  +---(6)--------> 2 --(3)--> 4 --(3)---+
       (4)
```

- 源点：0（入度为0）
- 汇点：5（出度为0）

## 参考解答

```c
#include <limits.h>  // 提供 INT_MAX，用于表示无穷大

// 辅助函数：返回两个整数中的较大值
int max(int a, int b) {
    return a > b ? a : b;
}

// 辅助函数：返回两个整数中的较小值
int min(int a, int b) {
    return a < b ? a : b;
}

int check_key_path(int* path) {
    int n = 6;  // 顶点数量

    // 用 INT_MAX 表示无穷大（无弧）
    int arcs[6][6] = {
        {INT_MAX, 4, 6, INT_MAX, INT_MAX, INT_MAX},
        {INT_MAX, INT_MAX, 5, INT_MAX, INT_MAX, INT_MAX},
        {INT_MAX, INT_MAX, INT_MAX, 4, 3, INT_MAX},
        {INT_MAX, INT_MAX, INT_MAX, INT_MAX, INT_MAX, 3},
        {INT_MAX, INT_MAX, INT_MAX, INT_MAX, INT_MAX, 3},
        {INT_MAX, INT_MAX, INT_MAX, INT_MAX, INT_MAX, INT_MAX}
    };

    // ========== 第一步：正向计算各顶点的最早发生时间 ve[] ==========
    // ve[j] = max{ ve[i] + w(i,j) } 对所有指向j的弧<i,j>
    int ve[6];
    for (int i = 0; i < n; i++)
        ve[i] = 0;  // 初始化为0

    // 按拓扑序遍历（此处矩阵天然满足下标递增的拓扑序）
    for (int j = 0; j < n; j++) {
        for (int i = 0; i < j; i++) {
            // 如果存在弧 i->j，尝试更新 ve[j]
            if (arcs[i][j] != INT_MAX) {
                ve[j] = max(ve[j], ve[i] + arcs[i][j]);
            }
        }
    }

    // ========== 第二步：逆向计算各顶点的最迟发生时间 vl[] ==========
    // vl[i] = min{ vl[j] - w(i,j) } 对所有从i出发的弧<i,j>
    int vl[6];
    for (int i = 0; i < n; i++)
        vl[i] = ve[n - 1];  // 初始化为汇点的最早时间（工程总工期）

    // 逆拓扑序遍历（从汇点往源点方向）
    for (int i = n - 2; i >= 0; i--) {
        for (int j = i + 1; j < n; j++) {
            // 如果存在弧 i->j，尝试用 vl[j] 反推更新 vl[i]
            if (arcs[i][j] != INT_MAX) {
                vl[i] = min(vl[i], vl[j] - arcs[i][j]);
            }
        }
    }

    // ========== 第三步：找关键活动，提取关键路径 ==========
    // 关键活动满足：e(i,j) == l(i,j)
    // 其中 e(i,j) = ve[i]，l(i,j) = vl[j] - w(i,j)
    int pathLen = 0;       // 关键路径上的顶点数
    int visited[6] = {0};  // 标记顶点是否已加入路径，避免重复

    // 从源点开始，沿关键活动构建关键路径
    int curr = 0;  // 当前顶点，从源点0开始
    path[pathLen++] = curr;
    visited[curr] = 1;

    while (curr != n - 1) {
        // 在当前顶点的所有出弧中，寻找关键活动
        for (int j = curr + 1; j < n; j++) {
            if (arcs[curr][j] != INT_MAX) {
                // 计算活动的最早开始时间和最迟开始时间
                int e = ve[curr];               // 最早开始 = 弧尾顶点的最早发生时间
                int l = vl[j] - arcs[curr][j];  // 最迟开始 = 弧头顶点最迟发生时间 - 活动持续时间

                if (e == l && !visited[j]) {
                    // 找到关键活动，将弧头顶点加入路径
                    path[pathLen++] = j;
                    visited[j] = 1;
                    curr = j;  // 前进到下一个顶点
                    break;
                }
            }
        }
    }

    // ========== 计算关键路径的总长度 ==========
    // 即汇点的最早发生时间 = 工程最短工期
    int pathLength = ve[n - 1];

    return pathLength;
}
```

**手动验证（正向 ve[] 计算过程）：**

| 顶点 | 前驱弧 | ve[] 计算 | ve[] 结果 |
|:---:|:---|:---|:---:|
| 0 | 无（源点） | ve[0] = 0 | 0 |
| 1 | 0->1(4) | ve[1] = ve[0]+4 = 4 | 4 |
| 2 | 0->2(6), 1->2(5) | max(0+6, 4+5) = max(6,9) = 9 | 9 |
| 3 | 2->3(4) | ve[3] = ve[2]+4 = 13 | 13 |
| 4 | 2->4(3) | ve[4] = ve[2]+3 = 12 | 12 |
| 5 | 3->5(3), 4->5(3) | max(13+3, 12+3) = max(16,15) = 16 | 16 |

**手动验证（逆向 vl[] 计算过程）：**

| 顶点 | 后继弧 | vl[] 计算 | vl[] 结果 |
|:---:|:---|:---|:---:|
| 5 | 无（汇点） | vl[5] = ve[5] = 16 | 16 |
| 4 | 4->5(3) | vl[4] = vl[5]-3 = 13 | 13 |
| 3 | 3->5(3) | vl[3] = vl[5]-3 = 13 | 13 |
| 2 | 2->3(4), 2->4(3) | min(13-4, 13-3) = min(9,10) = 9 | 9 |
| 1 | 1->2(5) | vl[1] = vl[2]-5 = 4 | 4 |
| 0 | 0->1(4), 0->2(6) | min(4-4, 9-6) = min(0,3) = 0 | 0 |

**关键活动判定：**

| 弧 | 权重 | e=ve[i] | l=vl[j]-w | e==l? |
|:---:|:---:|:---:|:---:|:---:|
| 0->1 | 4 | 0 | 4-4=0 | **是** |
| 0->2 | 6 | 0 | 9-6=3 | 否 |
| 1->2 | 5 | 4 | 9-5=4 | **是** |
| 2->3 | 4 | 9 | 13-4=9 | **是** |
| 2->4 | 3 | 9 | 13-3=10 | 否 |
| 3->5 | 3 | 13 | 16-3=13 | **是** |
| 4->5 | 3 | 12 | 16-3=13 | 否 |

**关键路径：0 -> 1 -> 2 -> 3 -> 5，路径长度 = 16**
