# 树的层序遍历（BST 构建 + BFS）

> 题目编号：162

## 题目

已知树的定义如下：

```c
typedef struct node {
    int data;               // 结点存储的关键字
    struct node *left;      // 指向左子树的指针
    struct node *right;     // 指向右子树的指针
} node, *tree;
```

实现函数：

`void check_tree_level_visit(int keys[], int n);`

功能要求：
- 根据 `keys` 中输入的顺序，生成一棵**二叉排序树**（BST）
- 再按**层次遍历**方式访问，将访问所得的关键字按顺序保存至 `keys` 数组中
- `n` 为 `keys` 数组的长度（1 <= n <= 100）
- 可以有辅助函数

样例输入：`[36, 53, 28, 68, 9, 33]`
样例输出：`[36, 28, 53, 9, 33, 68]`

## 解题思路

本题分为两个步骤：

**第一步：构建二叉排序树（BST）**
- 取 `keys[0]` 作为根结点
- 依次将 `keys[1]` 到 `keys[n-1]` 插入 BST
- BST 插入规则：比当前结点小的往左子树走，比当前结点大的往右子树走，递归直到找到空位

**第二步：层序遍历（BFS）**
- 使用**数组模拟队列**（`head` 和 `tail` 两个指针）
- 根结点入队，循环执行：出队 -> 访问 -> 左子结点入队 -> 右子结点入队
- 队列为空时遍历结束

## 参考解答

```c
#include <stdlib.h>

typedef struct node {
    int data;               // 结点存储的关键字
    struct node *left;      // 指向左子树的指针
    struct node *right;     // 指向右子树的指针
} node, *tree;

/*
 * 初始化一个新结点
 * 将 data 字段设为给定值，左右子树指针设为 NULL
 */
void init_node(node *node, int data) {
    node->data = data;      // 设置结点的关键字
    node->left = NULL;      // 左子树为空
    node->right = NULL;     // 右子树为空
}

/*
 * 向二叉排序树中插入一个值
 * 规则：value > root->data 则插入右子树，否则插入左子树
 * 递归查找直到找到空位，然后创建新结点挂上去
 */
void bst_insert(node *root, int value) {
    if (value > root->data) {               // 比当前结点大，走右子树
        if (!root->right) {                 // 右子树为空，直接插入
            node *newNode = (node *) malloc(sizeof(node));
            init_node(newNode, value);
            root->right = newNode;          // 新结点成为右孩子
        } else {
            bst_insert(root->right, value); // 右子树不空，递归继续
        }
    } else {                                // 比当前结点小（或相等），走左子树
        if (!root->left) {                  // 左子树为空，直接插入
            node *newNode = (node *) malloc(sizeof(node));
            init_node(newNode, value);
            root->left = newNode;           // 新结点成为左孩子
        } else {
            bst_insert(root->left, value);  // 左子树不空，递归继续
        }
    }
}

/*
 * 主函数：构建 BST 并进行层序遍历
 * 步骤1：用 keys[0] 初始化根结点，将剩余元素依次插入 BST
 * 步骤2：用数组模拟队列进行 BFS 层序遍历，结果写回 keys 数组
 */
void check_tree_level_visit(int keys[], int n) {
    // ========= 第一步：构建二叉排序树 =========
    node *root = (node *) malloc(sizeof(node));
    init_node(root, keys[0]);               // keys[0] 作为根结点

    for (int i = 1; i < n; ++i) {
        bst_insert(root, keys[i]);          // 依次插入剩余元素
    }

    // ========= 第二步：层序遍历（BFS） =========
    node *nodes[100] = {0};                 // 用数组模拟队列
    int head = 0;                           // 队头指针（出队端）
    int tail = 0;                           // 队尾指针（入队端）
    int index = 0;                          // 写回 keys 数组的索引

    nodes[tail++] = root;                   // 根结点入队

    while (head < tail) {                   // 队列不为空
        node *current = nodes[head++];      // 出队：取出队头结点
        keys[index++] = current->data;      // 访问：将结点值写入 keys

        // 按照层序规则，先左后右入队
        if (current->left)  nodes[tail++] = current->left;   // 左孩子入队
        if (current->right) nodes[tail++] = current->right;  // 右孩子入队
    }
}
```
