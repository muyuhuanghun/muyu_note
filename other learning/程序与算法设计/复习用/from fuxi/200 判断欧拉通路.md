# 200 判断欧拉通路

> 题目编号：200

## 题目

判断有向图中是否存在欧拉通路。

函数原型：

```c
 * @brief   判断有向图中是否存在欧拉通路
 * @param   G: 邻接矩阵表示的有向图
 * @return  bool: 欧拉通路存在返回 true，否则返回 false
 */
bool if_eulerpath(adjmatrix *G);
```

## 解题思路

**欧拉通路（Euler Path）**的定义：经过图中**每条边恰好一次**的路径（不要求回到起点）。

**有向图存在欧拉通路的充要条件（出入度判定法）：**

1. **连通性**：图的底图（忽略方向）是连通的（本题假设图已连通，考试中通常不做连通性检查）
2. **出入度条件**：
   - **情况一**：所有顶点的入度等于出度（此时存在欧拉**回路**，自然也是欧拉通路）
   - **情况二**：恰好有两个顶点出入度不相等——其中一个**出度比入度多1**（起点），另一个**入度比出度多1**（终点），其余所有顶点入度等于出度
3. **违反条件的情况**：若有顶点的 `|入度 - 出度| > 1`，或出入度不等的顶点数既不是0也不是2，则不存在欧拉通路

**算法步骤：**

1. 遍历邻接矩阵，统计每个顶点的入度和出度
2. 计算每个顶点的 `diff = indegree - outdegree`
3. 若任何顶点的 `|diff| > 1`，返回 false
4. 统计 `diff != 0` 的顶点个数 `diff_count`
5. 若 `diff_count == 0`（全相等）或 `diff_count == 2`（一进一出），返回 true；否则返回 false

## 参考解答

```c
bool if_eulerpath(adjmatrix *G) {
    int n = G->vexnum;  // 图中顶点的个数

    // ========== 第一步：统计每个顶点的入度和出度 ==========
    // 动态分配数组，存储每个顶点的入度和出度
    int *indegree  = (int *)malloc(n * sizeof(int));
    int *outdegree = (int *)malloc(n * sizeof(int));

    // 初始化为0
    for (int i = 0; i < n; i++) {
        indegree[i]  = 0;
        outdegree[i] = 0;
    }

    // 遍历邻接矩阵：若 arcs[i][j] != 0，说明存在弧 i->j
    // 则顶点i的出度+1，顶点j的入度+1
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            if (G->arcs[i][j] != 0) {
                outdegree[i]++;  // i 是弧尾，出度增加
                indegree[j]++;   // j 是弧头，入度增加
            }
        }
    }

    // ========== 第二步：检查出入度条件 ==========
    int diff_count = 0;  // 记录入度与出度不相等的顶点个数

    for (int i = 0; i < n; i++) {
        int diff = indegree[i] - outdegree[i];

        // 条件1：任何顶点的 |入度-出度| 不能超过1
        // 否则该顶点要么有太多入边无法走完，要么有太多出边无法全走
        if (diff > 1 || diff < -1) {
            free(indegree);
            free(outdegree);
            return false;  // 不满足欧拉通路条件
        }

        // 统计出入度不等的顶点数
        if (diff == 1 || diff == -1)
            diff_count++;
    }

    // ========== 第三步：根据不等顶点数判断 ==========
    // 欧拉通路存在的两种情况：
    //   (1) diff_count == 0: 所有顶点入度等于出度，存在欧拉回路
    //   (2) diff_count == 2: 恰好一个顶点出度多1（起点），一个顶点入度多1（终点）
    // 其他情况（diff_count为奇数，或diff_count > 2）均不存在欧拉通路
    if (diff_count != 0 && diff_count != 2) {
        free(indegree);
        free(outdegree);
        return false;
    }

    // 释放动态分配的内存，避免内存泄漏
    free(indegree);
    free(outdegree);
    return true;  // 满足条件，存在欧拉通路
}
```

**核心判定逻辑总结：**

| diff_count | 含义 | 结果 |
|:---:|:---|:---:|
| 0 | 所有顶点入度=出度（存在欧拉回路） | true |
| 2 | 恰好1个出度多1（起点），1个入度多1（终点） | true |
| 其他 | 不满足欧拉通路条件 | false |

**注意**：本题使用 `malloc` 动态分配内存，函数返回前必须 `free` 释放，否则会造成内存泄漏。
