# 镜像二叉树

> 题目编号：179

## 题目

设有两棵二叉树 t1 和 t2。如果 t2 是 t1 左右翻转得到的，那么称二叉树 t1 和 t2 互为**镜像**。

二叉树的存储结构如下：

```c
typedef struct _btree_node {
    char tag;                           // 二叉树结点的字符标签
    struct _btree_node *left, *right;   // 左子树和右子树
} btree_node, *btree;
```

请设计一个算法，实现一棵二叉树的镜像翻转。

算法函数原型：

`btree mirror(btree tree);`

功能：生成二叉树 tree 的镜像二叉树，返回镜像二叉树的根结点指针。

参数：tree 是指向源二叉树根结点的指针。

返回值：指向二叉树 tree 的镜像二叉树根结点的指针。

## 解题思路

- 镜像翻转的本质是：**将每个结点的左右子树互换**
- 采用**递归**方式实现，思路清晰简洁
- 递归终止条件：当结点为 NULL 时，返回 NULL
- 递归过程：
  1. 分配一个新结点
  2. 复制原结点的 tag 值到新结点
  3. 新结点的左子树 = 原结点右子树的镜像（递归调用）
  4. 新结点的右子树 = 原结点左子树的镜像（递归调用）
- **注意**：本题是生成一棵新的镜像树，不是原地翻转

## 参考解答

```c
/*
 * 递归生成二叉树的镜像
 * 思路：分配新结点，复制 tag，左右子树互换后递归构建
 * 递归终止：遇到 NULL 结点，直接返回 NULL
 */
btree mirror(btree tree) {
    if (!tree) return NULL;  // 递归终止：空树的镜像还是空树

    // 分配一个新结点
    btree t = (btree) malloc(sizeof(btree_node));

    t->tag = tree->tag;                 // 复制原结点的标签

    // 核心操作：左右子树互换
    t->left  = mirror(tree->right);     // 新树的左子树 = 原树右子树的镜像
    t->right = mirror(tree->left);      // 新树的右子树 = 原树左子树的镜像

    return t;  // 返回新构建的镜像树根结点
}
```
