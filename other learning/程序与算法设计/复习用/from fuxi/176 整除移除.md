# 176 整除移除

> 题目编号：176

## 题目

### 数据结构定义

```c
#define MAXLEN 128  /* 线性表最大容量 */

/* ========== 顺序表结构体定义 ========== */
typedef struct {
    int elem[MAXLEN];  /* 存储数据的数组，下标从 0 开始 */
    unsigned len;      /* 数组中有效数据的个数 */
} list;
```

### 编码要求

请设计一个算法，其功能是：在一个给定的线性表中，**移除所有能被指定正整数整除的元素**。操作完成后的线性表中保留的元素呈连续存储的状态。

**函数原型：**

```c
void remove_elem(list *L, unsigned f);
```

**功能**：在线性表 L 中移除所有能被 f 整除的元素。

**参数**：
- `L`：指向线性表的指针，线性表可能为空
- `f`：整除因子，测试用例保证 f 不小于 2

**返回值**：无

**复杂度约束**：
- 时间复杂度：`O(L->len)`
- 空间复杂度：`O(1)`

---

## 解题思路

- 采用**双指针法**（快慢指针），在原数组上原地筛选，无需额外空间
- **慢指针 j**：指向下一个"保留元素"应当写入的位置
- **快指针 i**：遍历整个数组，逐一检查每个元素
- 遍历时，若 `elem[i]` 不能被 f 整除，则将其复制到 `elem[j]` 并推进 j；若能被整除则跳过
- 遍历结束后，`j` 即为保留元素的个数，更新 `L->len = j`

---

## 参考解答

```c
/*
 * remove_elem - 移除线性表中所有能被 f 整除的元素
 *
 * 算法：双指针原地筛选（类似 LeetCode Remove Element）
 *   - i 是快指针，扫描整个数组
 *   - j 是慢指针，指向下一个保留元素的写入位置
 *   - 当 elem[i] 不能被 f 整除时，将其复制到 elem[j]，j 前进
 *   - 当 elem[i] 能被 f 整除时，直接跳过（不复制）
 *   - 遍历结束后，j 就是保留元素的个数
 *
 * 时间复杂度：O(n)，只遍历一次
 * 空间复杂度：O(1)，原地操作
 *
 * @param L 指向线性表的指针
 * @param f 整除因子（f >= 2）
 */
void remove_elem(list *L, unsigned f) {
    int i = 0;  /* 快指针：遍历整个数组 */
    int j = 0;  /* 慢指针：指向下一个保留元素的写入位置 */

    while (i < L->len) {                /* 遍历数组中的每一个元素 */
        if (L->elem[i] % f != 0) {      /* 当前元素不能被 f 整除 -> 保留 */
            L->elem[j] = L->elem[i];    /* 将元素复制到慢指针位置 */
            j++;                         /* 慢指针前进，准备下一个写入位 */
        }
        /* 若 elem[i] % f == 0，直接跳过，不复制 */
        i++;  /* 快指针始终前进 */
    }

    L->len = j;  /* 更新线性表长度为保留元素的个数 */
}
```
