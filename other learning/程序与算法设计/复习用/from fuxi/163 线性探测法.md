# 线性探测法

> 题目编号：163

## 题目

线性哈希是一种简单的哈希方法，其中哈希函数为 `H(key) = key mod m`，其中 m 是哈希表的长度。当发生冲突时，线性探测法会寻找下一个空闲位置来存储关键字。具体来说，如果位置 H(key) 被占用，则检查 H(key) + 1，然后是 H(key) + 2，依此类推，直到找到一个空位。

函数 `void print_hash_array(int arr[], int n);` 应该实现以下功能：

1. 创建一个大小为 13 的哈希表（保证输入数据为 13 个）。
2. 遍历给定的关键字数组，对每个关键字应用哈希函数。
3. 如果哈希位置已被占用，则使用线性探测法找到下一个空闲位置。
4. 在找到的位置存储关键字。
5. 打印哈希表的内容，以验证关键字是否正确存储。

### 样例

```text
输入：[1, 5, 21, 26, 39, 14, 15, 16, 17, 18, 19, 20, 111]
输出：[26, 1, 39, 14, 15, 5, 16, 17, 21, 18, 19, 20, 111]
```

### 数据结构定义

```c
#define SIZE 13  /* 哈希表大小，与题目要求一致 */
```

## 解题思路

- **哈希函数**：`H(key) = key % 13`，取模后得到的值即为该关键字在哈希表中的理想存放位置。
- **冲突处理**：若目标位置已被占用（值非零），则从该位置开始向后逐个探测，使用取模运算实现环形查找：`key = (key + 1) % SIZE`。
- **空位判断**：哈希表使用 `calloc` 初始化为全零，因此值为 0 的槽位表示空闲，值非零表示已被占用。
- **核心循环**：`while (hashTable[key])` 不断向后探测，直到找到空位为止，然后将关键字存入该位置。
- **时间复杂度**：最坏情况下每次插入需要遍历整个表，即 O(n)，平均情况下接近 O(1)。

## 参考解答

```c
#include <stdio.h>
#include <stdlib.h>

#define SIZE 13  /* 哈希表大小，与题目要求的 13 个关键字对应 */

/*
 * print_hash_array - 使用线性探测法构建哈希表并打印结果
 *
 * 工作流程：
 *   1. 分配并初始化一个大小为 SIZE 的哈希表（calloc 保证初始值为 0）
 *   2. 对每个关键字计算哈希值 key % SIZE
 *   3. 若该位置非空（发生冲突），则线性向后探测直到找到空位
 *   4. 将关键字存入空位
 *   5. 遍历打印哈希表的每个槽位
 *
 * @param arr: 待散列的关键字数组，长度必须为 SIZE
 */
void print_hash_array(int arr[]) {
    /* 使用 calloc 分配哈希表，所有元素初始化为 0，0 表示空槽位 */
    int *hashTable = (int *)calloc(SIZE, sizeof(int));

    /* 内存分配失败检查 */
    if (hashTable == NULL) {
        fprintf(stderr, "Memory allocation failed\n");
        return;
    }

    /* 逐一将关键字插入哈希表 */
    for (int i = 0; i < SIZE; i++) {
        /* 第一步：计算初始哈希位置 */
        int key = arr[i] % SIZE;

        /* 第二步：线性探测 —— 若当前位置已被占用，则向后移动一位
         * 利用取模运算 (key + 1) % SIZE 实现环形查找，
         * 即到达表尾后自动回到表头继续探测 */
        while (hashTable[key]) {
            key = (key + 1) % SIZE;
        }

        /* 第三步：找到空位，存入关键字 */
        hashTable[key] = arr[i];
    }

    /* 打印哈希表的全部槽位，验证插入结果 */
    for (int i = 0; i < SIZE; ++i) {
        printf("%d ", hashTable[i]);
    }

    /* 释放动态分配的哈希表内存 */
    free(hashTable);
}
```
