# 178. 反转字符串

> 题目编号：178

## 题目

### 已知条件

有一个递归函数如下：

```c
void reverse() {
    char c = getchar();       // 从标准输入读取一个字符
    if (c == '.') return;     // 遇到 '.' 结束符则停止递归

    reverse();                // 递归调用：先处理后续字符
    putchar(c);               // 递归返回后才输出当前字符（后进先出）
}
```

其功能是将输入的字符序列（以 `'.'` 结尾）**倒序输出**（不包括 `'.'`）。

示例：
- 输入：`abc123.`
- 输出：`321cba`

另有可用的栈接口函数如下：

```c
void push(stack *S, char x);    // 将字符 x 压入栈 S，S 是指向栈的指针
char pop(stack *S);             // 弹栈，返回栈 S 的栈顶数据
bool empty(stack *S);           // 测试栈 S 是否为空，如果为空返回 true，否则返回 false
```

### 任务描述

请设计一个算法，利用栈消除 `reverse()` 中的递归，但功能不变。

### 编码约束

1. 算法函数原型：`void reverse(stack *S);`
   - 功能：将输入的字符序列倒序输出，输入以 `'.'` 结尾
   - 参数：`S` 是指向栈的指针，栈 `S` 已经初始化
   - 返回值：无
2. 时间复杂度：无特别要求
3. 空间复杂度：O(1)（不计栈空间）
4. **提示**：常量空间复杂度意味着，除了使用栈和单个变量，不能定义数组等辅助存储

## 解题思路

**核心观察**：递归函数中，`putchar(c)` 位于递归调用 `reverse()` 之后，这意味着字符的输出顺序与读取顺序恰好相反。这本质上是一个**后进先出（LIFO）**的行为，天然适合用栈模拟。

**递归 vs 栈的对应关系**：
- 递归的"压栈"阶段 = `while` 循环中逐个读取字符并 `push` 入栈
- 递归的"回溯"阶段 = `while` 循环中逐个 `pop` 并输出

**算法步骤**：
1. **入栈阶段**：循环读取字符，直到遇到 `'.'` 为止，每读一个字符就 `push` 入栈
2. **出栈阶段**：循环检查栈是否为空，非空则 `pop` 栈顶元素并用 `putchar` 输出
3. 由于栈是 LIFO 结构，先入栈的字符后出栈，输出顺序自然就是输入的倒序

**时间复杂度**：O(n)，其中 n 是输入字符的个数（不含 `'.'`）。每个字符恰好入栈一次、出栈一次。

**空间复杂度**：O(1)（不计栈空间），只使用了一个 `char` 类型的变量 `c`。

## 参考解答

```c
/**
 * 利栈消除递归，实现字符串反转输出
 *
 * 原理：递归的本质是利用函数调用栈实现 LIFO，
 *       此处用显式的栈数据结构替代隐式的调用栈，
 *       将"读取时压栈、回溯时输出"的两阶段分离为两个 while 循环。
 *
 * @param S 指向已初始化的栈的指针
 */
void reverse(stack *S) {
    char c = getchar();  // 读取第一个字符

    // 阶段一：入栈（对应递归的"递进"过程）
    // 持续读取字符，直到遇到结束符 '.'
    // 每读到一个字符就压入栈中
    while (c != '.') {
        push(S, c);       // 将当前字符压入栈
        c = getchar();    // 读取下一个字符
    }
    // 此时，栈中从底到顶依次是：第一个字符、第二个字符、...、最后一个字符

    // 阶段二：出栈（对应递归的"回溯"过程）
    // 栈顶是最后读入的字符，弹出顺序与读入顺序相反，实现倒序输出
    while (!empty(S)) {
        putchar(pop(S));  // 弹出栈顶字符并输出
    }
    // 输出结果即为输入字符序列的倒序（不含结束符 '.'）
}
```
