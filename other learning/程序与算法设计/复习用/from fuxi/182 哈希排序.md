# 哈希排序（计数排序）

> 题目编号：182

## 题目

### 已知条件

有一个乱序的正整数数组，其长度为 n，其中元素值在 1 ~ m 之间。已知：

- n 和 m 都不太大
- n 小于 m
- 元素没有重复值，即数组中没有两个数是相同的
- 数组下标从 0 开始

### 任务描述

请设计一个算法，对上述数组进行从小到大升序排序。

**限制条件**：

1. 不能用基数排序（radix sort）
2. 不能为 m 预估一个预设值

### 编码要求

1. 算法函数原型：`void xsort(unsigned *a, unsigned n);`

   - **功能**：将指定数组进行从小到大升序排序。如果数组长度为 0，则函数什么都不做。
   - **参数**：
     - `a`：待排序数组
     - `n`：数组长度（注意：长度可能为 0）
   - **返回值**：无

2. 编码约束

   - 时间复杂度：O(m)
   - 空间复杂度：无特别要求

> **提示**：利用数组中无重复值的特点，将数据散列到一个长度为 m 的一维数组中（这里 hash(K) = K），然后再依次收集到原数组中。注意：m 的值未知，须编码求得。

## 解题思路

- **核心思想**：利用哈希的思想，将每个元素的值直接作为计数数组的下标（即 hash(K) = K），实现 O(1) 的"插入"。
- **求最大值 m**：首先遍历数组，找出元素的最大值 m，以此确定计数数组的大小为 m + 1。
- **计数阶段**：遍历原数组，对每个元素 a[i] 执行 `count[a[i]]++`，在计数数组中对应位置标记。
- **收集阶段**：从小到大遍历计数数组（下标 1 到 m），将值非零的下标依次写回原数组。由于题目保证无重复值，每个 count[i] 最多为 1。
- **边界处理**：若 n == 0，直接返回，不做任何操作。
- **时间复杂度**：遍历原数组 O(n) + 遍历计数数组 O(m)，总计 O(n + m)。因 n < m，简记为 O(m)。
- **空间复杂度**：额外分配了一个大小为 m + 1 的计数数组，即 O(m)。

## 参考解答

```c
#include <stdlib.h>

/*
 * xsort - 基于计数（哈希）思想的排序算法
 *
 * 原理：利用 hash(K) = K 的哈希函数，将每个元素的值直接映射到
 *       计数数组的对应下标，然后从小到大收集即可完成排序。
 *       题目保证元素无重复值，因此每个计数位置最多为 1。
 *
 * @param a: 待排序的正整数数组（元素范围 1 ~ m，无重复）
 * @param n: 数组长度（可能为 0）
 *
 * 时间复杂度：O(n + m)，因 n < m，简记为 O(m)
 * 空间复杂度：O(m)，用于分配计数数组
 */
void xsort(unsigned *a, unsigned n) {
    /* 边界条件：数组长度为 0，无需排序，直接返回 */
    if (n == 0) {
        return;
    }

    /* ============================================================
     * 第一步：遍历数组，求出最大值 m
     * m 用于确定计数数组的大小，题目不允许预设固定值，
     * 因此必须在运行时动态求得 */
    unsigned m = 0;
    for (unsigned i = 0; i < n; ++i) {
        if (a[i] > m) {
            m = a[i];
        }
    }

    /* ============================================================
     * 第二步：分配计数数组，大小为 m + 1（下标 0 ~ m）
     * 使用 calloc 初始化为全零，count[i] = 0 表示值 i 未出现 */
    unsigned *count = (unsigned *)calloc(m + 1, sizeof(unsigned));

    /* ============================================================
     * 第三步：计数 —— 遍历原数组，将每个元素的值作为下标，
     * 在 count 中标记出现（hash(K) = K） */
    for (unsigned i = 0; i < n; ++i) {
        count[a[i]]++;  /* 值 a[i] 出现，对应计数 +1 */
    }

    /* ============================================================
     * 第四步：收集 —— 从小到大遍历计数数组，
     * 将出现过的值（count[i] > 0）依次写回原数组
     * 由于无重复值，count[i] 最多为 1，while 循环最多执行一次 */
    unsigned index = 0;         /* 写回原数组的当前位置 */
    for (unsigned i = 1; i <= m; ++i) {
        while (count[i] > 0) {
            a[index++] = i;     /* 将值 i 写入原数组 */
            count[i]--;         /* 对应计数减 1 */
        }
    }

    /* 第五步：释放计数数组的动态内存 */
    free(count);
}
```
