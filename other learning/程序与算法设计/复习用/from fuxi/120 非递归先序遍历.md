# 非递归先序遍历

> 题目编号：120

## 题目

已知二叉树按照二叉链表方式存储，利用栈的基本操作写出先序遍历非递归形式的算法：

`void pre_order(BiTree root);`

在遍历过程中，`pre_order` 函数需要调用 `visit_node` 函数来实现对结点的访问，该函数声明如下：

`void visit_node(BiTNode *node);`

二叉树的相关定义如下：

```c
typedef int DataType;

typedef struct Node {
    DataType data;          // 结点存储的数据
    struct Node* left;      // 指向左子树的指针
    struct Node* right;     // 指向右子树的指针
} BiTNode, *BiTree;
```

遍历所使用栈的相关操作如下：

```c
#define Stack_Size 50
typedef BiTNode* ElemType;  // 栈中元素类型为二叉树结点指针

typedef struct {
    ElemType elem[Stack_Size];  // 栈空间数组
    int top;                    // 栈顶指针
} Stack;

void init_stack(Stack *S);                        // 初始化栈
bool push(Stack* S, ElemType x);                  // x 入栈
bool pop(Stack* S, ElemType *px);                 // 出栈，元素保存到 px 所指的单元，函数返回 true，栈为空时返回 false
bool top(Stack* S, ElemType *px);                 // 获取栈顶元素，将其保存到 px 所指的单元，函数返回 true，栈满时返回 false
bool is_empty(Stack* S);                          // 栈为空时返回 true，否则返回 false
```

## 解题思路

- 先序遍历的顺序是 **根 -> 左 -> 右**，非递归实现的核心工具是**栈**
- 将根结点入栈，然后循环执行：弹出栈顶 -> 访问结点 -> 先压右子树再压左子树
- **关键技巧**：栈是 LIFO（后进先出），所以必须**先压右再压左**，这样才能保证左子树先被弹出访问
- 循环终止条件是栈为空，此时所有结点都已访问完毕

## 参考解答

```c
#include <stdlib.h>

void pre_order(BiTree root) {
    Stack *S;
    init_stack(S);              // 初始化栈
    push(S, root);              // 先将根结点入栈

    while (!is_empty(S)) {      // 栈不为空时持续循环
        BiTNode *node;
        pop(S, &node);          // 弹出栈顶结点
        visit_node(node);       // 访问该结点（先序：先访问根）

        // 注意压栈顺序：先右后左
        // 因为栈是后进先出（LIFO），先压入右子树，后压入左子树
        // 这样出栈时左子树先被弹出，保证了先序遍历"根->左->右"的顺序
        if (node->right) push(S, node->right);  // 右子树先入栈
        if (node->left)  push(S, node->left);   // 左子树后入栈
    }

    free(S);  // 释放栈的内存
}
```
