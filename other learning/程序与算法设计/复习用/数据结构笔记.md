## 第一章 绪论

### 1.1 数据结构基本概念

**数据结构**是相互之间存在一种或多种特定关系的数据元素的集合。

#### 逻辑结构
| 结构类型 | 描述 | 示例 |
|---------|------|------|
| 集合结构 | 数据元素同属一个集合 | 无关系 |
| 线性结构 | 一对一关系 | 线性表、栈、队列 |
| 树形结构 | 一对多关系 | 二叉树、B树 |
| 图结构 | 多对多关系 | 有向图、无向图 |

#### 存储结构
| 存储方式 | 特点 |
|---------|------|
| 顺序存储 | 连续内存，支持随机访问 |
| 链式存储 | 离散内存，指针连接 |
| 索引存储 | 建立索引表加速查找 |
| 散列存储 | 关键字直接映射地址 |

### 1.2 算法复杂度

#### 时间复杂度
表示算法执行时间与问题规模n的增长关系，记作 T(n) = O(f(n))

常见时间复杂度排序：
```
O(1) < O(logn) < O(n) < O(nlogn) < O(n²) < O(n³) < O(2ⁿ) < O(n!)
```

**分析规则：**
- 只考虑最高阶项
- 去除常数系数
- 一般考虑最坏或平均时间复杂度

#### 空间复杂度
表示算法所需存储空间与问题规模n的关系，记作 S(n) = O(g(n))

```c
#include <stdio.h>

// 时间复杂度示例

// O(1) - 常数时间
int constant_time(int n) {
    return n * n;
}

// O(n) - 线性时间
int linear_time(int n) {
    int total = 0;
    for (int i = 0; i < n; i++) {
        total += i;
    }
    return total;
}

// O(n²) - 平方时间
int quadratic_time(int n) {
    int total = 0;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            total += i * j;
        }
    }
    return total;
}

// O(logn) - 对数时间
int logarithmic_time(int n) {
    int count = 0;
    int i = 1;
    while (i < n) {
        i *= 2;
        count++;
    }
    return count;
}

int main() {
    printf("时间复杂度示例\n");
    printf("O(1): constant_time(10) = %d\n", constant_time(10));
    printf("O(n): linear_time(10) = %d\n", linear_time(10));
    printf("O(n²): quadratic_time(10) = %d\n", quadratic_time(10));
    printf("O(logn): logarithmic_time(100) = %d\n", logarithmic_time(100));
    return 0;
}
```

## 第二章 线性表

### 2.1 顺序表

**定义**：用一段连续的存储单元依次存储线性表中的数据元素。

**特点**：
- 支持随机访问，时间复杂度O(1)
- 存储密度高
- 插入删除需要移动元素，时间复杂度O(n)

#### 传递方式对比
| 写法 | 传递方式 | 是否拷贝 | 能否修改原变量 | 开销 |
|------|---------|---------|--------------|------|
| SqList L | 值传递 | 是 | 否 | 大 |
| SqList &L | 引用传递 | 否 | 是 | 小 |
| SqList *L | 指针传递 | 否 | 是 | 小 |

```c
#include <stdio.h>
#include <stdbool.h>

#define MaxSize 100

typedef int ElemType;

// 顺序表定义
typedef struct {
    ElemType data[MaxSize];
    int length;
} SqList;

// 初始化顺序表
void InitList(SqList *L) {
    L->length = 0;
}

// 在位序i处插入元素e,位序为i的索引下标为i-1
bool ListInsert(SqList *L, int i, ElemType e) {
    if (i < 1 || i > L->length + 1) return false; //length + 1表示可以追加到末尾
    if (L->length >= MaxSize) return false;

    // 从后往前移动元素
    for (int j = L->length; j >= i; j--) {
        L->data[j] = L->data[j - 1];
    }
    L->data[i - 1] = e;
    L->length++;
    return true;
}

// 删除位序i处的元素
bool ListDelete(SqList *L, int i, ElemType *e) {
    if (i < 1 || i > L->length) return false;

    *e = L->data[i - 1];
    // 从前往后移动元素
    for (int j = i; j < L->length; j++) {
        L->data[j - 1] = L->data[j];
    }
    L->length--;
    return true;
}

// 按值查找，返回位序
int LocateElem(SqList L, ElemType e) {
    for (int i = 0; i < L.length; i++) {
        if (L.data[i] == e) return i + 1;
    } // 没找到的标记
}

// 按位序查找，返回元素
bool GetElem(SqList L, int i, ElemType *e) {
    if (i < 1 || i > L.length) return false;
    *e = L.data[i - 1];
    return true;
}

// 打印顺序表
void PrintList(SqList L) {
    for (int i = 0; i < L.length; i++) {
        printf("%d ", L.data[i]);
    }
    printf("\n");
}

int main() {
    SqList L;
    InitList(&L);

    ListInsert(&L, 1, 10);
    ListInsert(&L, 2, 20);
    ListInsert(&L, 3, 30);
    printf("顺序表: ");
    PrintList(L);
    printf("长度: %d\n", L.length);

    ElemType e;
    ListDelete(&L, 2, &e);
    printf("删除位序2的元素: %d\n", e);
    printf("删除后: ");
    PrintList(L);

    printf("元素30的位序: %d\n", LocateElem(L, 30));

    return 0;
}
```

### 2.2 单链表

**定义**：每个节点包含数据域和指针域，指针指向下一个节点。

**关键概念**：
- **LNode**：强调"节点"的概念，用于定义单个节点
- **LinkList**：强调"链表"的概念，用于定义头指针
- 头节点不存储数据，初始化时指针域设为空

**操作复杂度**：
| 操作 | 时间复杂度 |
|------|----------|
| 按位查找 | O(n) |
| 按值查找 | O(n) |
| 插入(已知指针) | O(1) |
| 删除(已知指针) | O(1) |

```c
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

typedef int ElemType;

// 节点定义
typedef struct LNode {
    ElemType data;
    struct LNode *next;
} LNode, *LinkList;

// 初始化链表（带头节点）
bool InitList(LinkList *L) { // 我们要给 L 本身赋予一个新的地址，因此这里时使用到了二级指针
    *L = (LNode *)malloc(sizeof(LNode));
    if (*L == NULL) return false;
    (*L)->next = NULL;
    return true;
}

// 在位序i处插入元素e
bool ListInsert(LinkList L, int i, ElemType e) {
    if (i < 1) return false;

    LNode *p = L;
    int j = 0;
    // 找到第i-1个节点
    while (p != NULL && j < i - 1) {
        p = p->next;
        j++;
    }
    if (p == NULL) return false;

    // 创建新节点并插入
    LNode *s = (LNode *)malloc(sizeof(LNode));
    if (s == NULL) return false;
    s->data = e;
    s->next = p->next;
    p->next = s;
    return true;
}

// 删除位序i处的元素
bool ListDelete(LinkList L, int i, ElemType *e) {
    if (i < 1) return false;

    LNode *p = L;
    int j = 0;
    // 找到第i-1个节点
    while (p->next != NULL && j < i - 1) {
        p = p->next;
        j++;
    }
    if (p->next == NULL) return false;

    // 删除节点
    LNode *q = p->next;
    *e = q->data;
    p->next = q->next;
    free(q);
    return true;
}

// 按位序查找
LNode* GetElem(LinkList L, int i) {
    LNode *p = L->next;
    int j = 1;
    while (p != NULL && j < i) {
        p = p->next;
        j++;
    }
    return p;
}

// 按值查找
LNode* LocateElem(LinkList L, ElemType e) {
    LNode *p = L->next;
    while (p != NULL && p->data != e) {
        p = p->next;
    }
    return p;
}

// 头插法建立链表
void HeadInsert(LinkList L, ElemType e) {
    LNode *s = (LNode *)malloc(sizeof(LNode));
    s->data = e;
    s->next = L->next;
    L->next = s;
}

// 尾插法建立链表
void TailInsert(LinkList L, LNode **r, ElemType e) { // r表示尾指针
    LNode *s = (LNode *)malloc(sizeof(LNode));
    s->data = e;
    s->next = NULL;
    (*r)->next = s;
    *r = s;
}

// 打印链表
void PrintList(LinkList L) {
    LNode *p = L->next;
    while (p != NULL) {
        printf("%d", p->data);
        if (p->next != NULL) printf(" -> ");
        p = p->next;
    }
    printf("\n");
}

// 求表长
int Length(LinkList L) {
    int len = 0;
    LNode *p = L->next;
    while (p != NULL) {
        len++;
        p = p->next;
    }
    return len;
}

// 销毁链表
void DestroyList(LinkList *L) {
    LNode *p = *L;
    while (p != NULL) {
        LNode *temp = p;
        p = p->next;
        free(temp);
    }
    *L = NULL;
}

int main() {
    LinkList L;
    InitList(&L);

    // 尾插法建立链表
    LNode *r = L; // 尾指针
    TailInsert(L, &r, 10);
    TailInsert(L, &r, 20);
    TailInsert(L, &r, 30);
    printf("尾插法建立链表: ");
    PrintList(L);

    // 头插法（会逆序）
    HeadInsert(L, 5);
    printf("头插法插入5: ");
    PrintList(L);

    // 按位序查找
    LNode *p = GetElem(L, 2);
    if (p) printf("位序2的元素: %d\n", p->data);

    // 按值查找
    p = LocateElem(L, 20);
    if (p) printf("元素20找到\n");

    // 删除
    ElemType e;
    ListDelete(L, 2, &e);
    printf("删除位序2的元素: %d\n", e);
    printf("删除后: ");
    PrintList(L);

    printf("表长: %d\n", Length(L));

    DestroyList(&L);
    return 0;
}
```

### 💡 总结：链表操作中的指针级别选择

**核心原则：要修改谁，就传谁的地址。**

| 函数 | 操作内容 | 是否修改指针本身 | 几级指针 |
|------|---------|----------------|----------|
| `InitList(LinkList *L)` | `*L = malloc(...)` | ✅ 让L指向新分配的头节点 | 二级 |
| `TailInsert(L, LNode **r)` | `*r = s` | ✅ 让尾指针r指向新插入的节点 | 二级 |
| `ListInsert(LinkList L, ...)` | `p->next = s` | ❌ L始终指向头节点，只是通过L操作链表内部 | 一级 |
| `ListDelete(LinkList L, ...)` | `p->next = q->next` | ❌ 同上，L本身没变 | 一级 |
| `GetElem / LocateElem` | `p = p->next` 遍历 | ❌ 只是读取，不修改任何指针 | 一级 |

简单记忆：
- **初始化** (`InitList`) -> 要给头指针分配新地址 -> 二级指针
- **尾插法** (`TailInsert`) -> 要不断更新尾指针的位置 -> 二级指针
- **插入/删除/查找** -> 头指针L不动，只通过它访问链表内部 -> 一级指针

### 2.3 双链表

**特点**：每个节点有前驱和后继两个指针，支持双向遍历。

### 2.4 循环链表

**特点**：
- 循环单链表：表尾节点next指向头节点
- 循环双链表：表尾next指向头，头prior指向表尾
- **优越性**：给定任意节点，可找到所有节点

### 2.5 静态链表

**特点**：
- 用数组实现链表
- 存储的是下一个节点的下标（游标）而非地址
- 内存连续

### 2.6 顺序表 vs 链表

| 对比项 | 顺序表 | 链表 |
|-------|-------|------|
| 存储方式 | 连续 | 离散 |
| 随机访问 | 支持O(1) | 不支持O(n) |
| 存储密度 | 高 | 低 |
| 插入删除 | O(n) | O(1)已知位置 |
| 扩容 | 困难 | 容易 |

## 第三章 栈和队列

### 3.1 栈

**定义**：后进先出(LIFO)的线性表，只允许在栈顶操作。

**基本操作**：
- Push(S, x)：进栈
- Pop(S, &x)：出栈
- GetTop(S, &x)：读栈顶元素

#### 顺序栈
- 栈顶指针指向栈顶元素
- 进栈：先自增，再赋值
- 出栈：先取值，再自减

#### 共享栈
- 两个栈共享同一数组
- 栈1从前往后增长，栈2从后往前增长
- 栈满条件：top1 + 1 == top2

```c
#include <stdio.h>
#include <stdbool.h>

#define MaxSize 100

typedef int ElemType;

// 顺序栈定义
typedef struct {
    ElemType data[MaxSize];
    int top;  // 栈顶指针
} SqStack;

// 初始化栈
void InitStack(SqStack *S) {
    S->top = -1;  // 初始为空栈
}

// 判断栈空
bool StackEmpty(SqStack S) {
    return S.top == -1;
}

// 进栈
bool Push(SqStack *S, ElemType x) {
    if (S->top >= MaxSize - 1) return false;  // 栈满
    S->top++;
    S->data[S->top] = x;
    return true;
}

// 出栈
bool Pop(SqStack *S, ElemType *x) {
    if (S->top == -1) return false;  // 栈空
    *x = S->data[S->top];
    S->top--;
    return true;
}

// 读栈顶元素
bool GetTop(SqStack S, ElemType *x) {
    if (S.top == -1) return false;
    *x = S.data[S.top];
    return true;
}

int main() {
    SqStack S;
    InitStack(&S);

    Push(&S, 1);
    Push(&S, 2);
    Push(&S, 3);

    ElemType x;
    GetTop(S, &x);
    printf("栈顶元素: %d\n", x);

    Pop(&S, &x);
    printf("出栈: %d\n", x);
    Pop(&S, &x);
    printf("出栈: %d\n", x);

    GetTop(S, &x);
    printf("栈顶元素: %d\n", x);

    return 0;
}
```

### 3.2 队列

**定义**：先进先出(FIFO)的线性表，队尾入队，队头出队。

#### 循环队列

**判满方案**：
1. 牺牲一个存储单元：`(rear + 1) % MaxSize == front`
2. 增加size变量记录元素个数
3. 增加flag标记最后一次操作是插入还是删除

**重要公式**：
- 队列长度：`(rear - front + MaxSize) % MaxSize`
- 入队：`rear = (rear + 1) % MaxSize`
- 出队：`front = (front + 1) % MaxSize`

```c
#include <stdio.h>
#include <stdbool.h>

#define MaxSize 100

typedef int ElemType;

// 循环队列定义
typedef struct {
    ElemType data[MaxSize];
    int front;  // 队头指针
    int rear;   // 队尾指针（指向下一个可插入位置）
} SqQueue;

// 初始化队列
void InitQueue(SqQueue *Q) {
    Q->front = 0;
    Q->rear = 0;
}

// 判断队空
bool QueueEmpty(SqQueue Q) {
    return Q.front == Q.rear;
}

// 入队
bool EnQueue(SqQueue *Q, ElemType x) {
    if ((Q->rear + 1) % MaxSize == Q->front) return false;  // 队满
    Q->data[Q->rear] = x;
    Q->rear = (Q->rear + 1) % MaxSize;
    return true;
}

// 出队
bool DeQueue(SqQueue *Q, ElemType *x) {
    if (Q->front == Q->rear) return false;  // 队空
    *x = Q->data[Q->front];
    Q->front = (Q->front + 1) % MaxSize;
    return true;
}

// 获取队头元素
bool GetHead(SqQueue Q, ElemType *x) {
    if (Q.front == Q.rear) return false;
    *x = Q.data[Q.front];
    return true;
}

// 求队列长度
int QueueLength(SqQueue Q) {
    return (Q.rear - Q.front + MaxSize) % MaxSize;
}

int main() {
    SqQueue Q;
    InitQueue(&Q);

    EnQueue(&Q, 1);
    EnQueue(&Q, 2);
    EnQueue(&Q, 3);

    printf("队列长度: %d\n", QueueLength(Q));

    ElemType x;
    GetHead(Q, &x);
    printf("队头元素: %d\n", x);

    DeQueue(&Q, &x);
    printf("出队: %d\n", x);
    DeQueue(&Q, &x);
    printf("出队: %d\n", x);

    printf("队列长度: %d\n", QueueLength(Q));

    return 0;
}
```

### 3.3 栈的应用

#### 括号匹配
算法：遇到左括号入栈，遇到右括号出栈并匹配。

#### 表达式求值
- **中缀转后缀**：运算符栈，按优先级入栈出栈
- **后缀表达式计算**：操作数栈，遇运算符弹出两个操作数

#### 递归
栈用于保存递归调用的现场（参数、局部变量、返回地址）

```c
// 括号匹配
bool bracket_match(const char *expr) {
    CharStack S;
    InitStack(&S);

    for (int i = 0; expr[i] != '\0'; i++) {
        char c = expr[i];
        if (c == '(' || c == '[' || c == '{') {
            Push(&S, c);
        } else if (c == ')' || c == ']' || c == '}') {
            if (StackEmpty(S)) return false;
            char top;
            Pop(&S, &top);
            // 检查匹配
            if (c == ')' && top != '(') return false;
            if (c == ']' && top != '[') return false;
            if (c == '}' && top != '{') return false;
        }
    }
    return StackEmpty(S);
}

// 后缀表达式计算
// 输入格式：数字和运算符用空格分隔，如 "1 2 + 3 *"
int eval_postfix(const char *expr) {
    IntStack S;
    InitStack(&S);

    int i = 0;
    while (expr[i] != '\0') {
        // 跳过空格
        while (expr[i] == ' ') i++;
        if (expr[i] == '\0') break;

        if (isdigit(expr[i]) || (expr[i] == '-' && isdigit(expr[i+1]))) {
            // 读取数字
            int num = 0;
            int sign = 1;
            if (expr[i] == '-') { sign = -1; i++; }
            while (isdigit(expr[i])) {
                num = num * 10 + (expr[i] - '0');
                i++;
            }
            Push(&S, sign * num);
        } else {
            // 运算符
            int b, a;
            Pop(&S, &b);  // 右操作数先出栈
            Pop(&S, &a);  // 左操作数
            switch (expr[i]) {
                case '+': Push(&S, a + b); break;
                case '-': Push(&S, a - b); break;
                case '*': Push(&S, a * b); break;
                case '/': Push(&S, a / b); break;
            }
            i++;
        }
    }

    int result;
    Pop(&S, &result);
    return result;
}
```

## 第四章 串

### 4.1 基本概念

**串**：由零个或多个字符组成的有限序列。

#### 存储方式
| 方式 | 特点 |
|------|------|
| 定长顺序存储 | 静态数组，长度受限 |
| 堆分配存储 | 动态分配，灵活 |
| 链式存储 | 存储密度低，每节点存多个字符 |

### 4.2 模式匹配

#### 朴素模式匹配(Brute-Force)
- 时间复杂度：O(nm)，n为主串长度，m为模式串长度
- 最坏情况：每次比较到模式串最后一位才发现不匹配

#### KMP算法
- 核心思想：利用已匹配信息，主串指针i不回溯
- **next数组**：当j位置失配时，j应该回退到的位置
- next数组只与模式串有关，与主串无关
- 时间复杂度：O(n+m)

```c
// 朴素模式匹配算法
int brute_force(const char *S, const char *T) {
    int i = 0, j = 0;
    int n = strlen(S), m = strlen(T);

    while (i < n && j < m) {
        if (S[i] == T[j]) {
            i++; j++;
        } else {
            i = i - j + 1;  // i回溯
            j = 0;
        }
    }

    if (j >= m) return i - m;  // 匹配成功
    return -1;  // 匹配失败
}

// 求next数组
void get_next(const char *T, int *next) {
    int m = strlen(T);
    next[0] = -1;
    int i = 0, j = -1;

    while (i < m - 1) {
        if (j == -1 || T[i] == T[j]) {
            i++; j++;
            next[i] = j;
        } else {
            j = next[j];
        }
    }
}

// KMP算法
int kmp(const char *S, const char *T) {
    int n = strlen(S), m = strlen(T);
    int next[m];
    get_next(T, next);

    int i = 0, j = 0;
    while (i < n && j < m) {
        if (j == -1 || S[i] == T[j]) {
            i++; j++;
        } else {
            j = next[j];  // j回退，i不回溯
        }
    }

    if (j >= m) return i - m;
    return -1;
}
```

## 第五章 树

### 5.1 基本概念

**树**：n个节点的有限集合。

**重要术语**：
- **度**：节点的子树数量
- **深度**：从根到该节点的层数
- **高度**：从该节点到最远叶子的层数

**性质**：
- 树中节点数 = 所有节点度数之和 + 1
- 度为m的树，第i层最多有 m^(i-1) 个节点

### 5.2 二叉树

**定义**：每个节点最多有两个子树的有序树。

**特殊二叉树**：
- **满二叉树**：每层节点数都达到最大
- **完全二叉树**：只有最后几层可能不满，且从左到右排列
- **二叉排序树**：左子树 < 根 < 右子树
- **平衡二叉树**：任意节点左右子树高度差不超过1

**重要性质**：
1. 叶子节点数 = 度为2的节点数 + 1，即 n₀ = n₂ + 1
2. 完全二叉树中，节点i的父节点为 ⌊i/2⌋，左子为2i，右子为2i+1
3. n个节点的完全二叉树高度为 ⌈log₂(n+1)⌉

```c
#include <stdio.h>
#include <stdlib.h>

typedef char ElemType;

// 二叉树节点定义
typedef struct BiTNode {
    ElemType data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;

// 创建新节点
BiTNode* CreateNode(ElemType data) {
    BiTNode *node = (BiTNode *)malloc(sizeof(BiTNode));
    node->data = data;
    node->lchild = NULL;
    node->rchild = NULL;
    return node;
}

// 先序遍历
void PreOrder(BiTree T) {
    if (T == NULL) return;
    printf("%c ", T->data);
    PreOrder(T->lchild);
    PreOrder(T->rchild);
}

// 中序遍历
void InOrder(BiTree T) {
    if (T == NULL) return;
    InOrder(T->lchild);
    printf("%c ", T->data);
    InOrder(T->rchild);
}

// 后序遍历
void PostOrder(BiTree T) {
    if (T == NULL) return;
    PostOrder(T->lchild);
    PostOrder(T->rchild);
    printf("%c ", T->data);
}

// 求树的深度
int TreeDepth(BiTree T) {
    if (T == NULL) return 0;
    // 基准条件（Base Case）：这是递归的出口。如果当前节点为空（说明已经越过了叶子节点，
    // 或者原本就是一棵空树），那么它的深度自然是 0。
    int l = TreeDepth(T->lchild);
    // 递归向左：向左伸展，把当前节点的左孩子作为新的根节点传给 TreeDepth。
    // 程序会一路向左死磕，直到触发 T == NULL 才会开始返回。最终得到的 l 代表左子树的最大深度。
    int r = TreeDepth(T->rchild);
    return (l > r ? l : r) + 1;
}

// 求节点个数
int NodeCount(BiTree T) {
    if (T == NULL) return 0;

    int leftCount = NodeCount(T->lchild);  // 先去把左子树的节点数算出来，记在账本上
    int rightCount = NodeCount(T->rchild); // 再去把右子树的节点数算出来，记在账本上

    return leftCount + rightCount + 1;     // 最后：左边 + 右边 + 我自己(1)，上报给上一层
}

// 求叶子节点个数
int LeafCount(BiTree T) {
    if (T == NULL) return 0;
    if (T->lchild == NULL && T->rchild == NULL) return 1;

    int leftLeaf = LeafCount(T->lchild);   // 去把左子树的叶子节点数算出来，记在账本上
    int rightLeaf = LeafCount(T->rchild); // 再去把右子树的叶子节点数算出来，记在账本上

    // 最后汇总：把我左边的叶子和右边的叶子加起来，上报给上一层
    return leftLeaf + rightLeaf;
}

// 层次遍历（需要队列）
#define MaxSize 100

// 队列节点（存储树节点指针）
typedef struct {
    BiTNode *data[MaxSize]; // 数组中的每个元素也是指针
    int front, rear;
} Queue;

void InitQueue(Queue *Q) { Q->front = 0; Q->rear = 0; }
bool IsEmpty(Queue Q) { return Q.front == Q.rear; }

bool EnQueue(Queue *Q, BiTNode *node) {
    if ((Q->rear + 1) % MaxSize == Q->front) return false;
    // 检查队列是否满了，这里为了区分队空和队满的情况，于是在判断队满的时候牺牲最后一个位置
    // 什么也不放(这里rear表示下一个可以插入的位置)
    Q->data[Q->rear] = node;
    Q->rear = (Q->rear + 1) % MaxSize;
    return true;
}
bool DeQueue(Queue *Q, BiTNode **node) {
    if (Q->front == Q->rear) return false; // 判断队列是否为空
    *node = Q->data[Q->front];
    // C 语言是值传递，为了在函数内部修改主函数中指针变量的值，必须传递该指针的地址（即二级指针）。
    // 通过 *node = ... 就能把队列里的节点地址成功带回给调用者。
    Q->front = (Q->front + 1) % MaxSize;
    return true;
}

void LevelOrder(BiTree T) {
    if (T == NULL) return;
    Queue Q;
    InitQueue(&Q);
    EnQueue(&Q, T); // 将二叉树的根节点（第一层）加入队列

    while (!IsEmpty(Q)) {
        // 只要队列中还有节点，就一直遍历
        // 父母在前面出队，孩子在后面排队
        BiTNode *node;
        DeQueue(&Q, &node); // 注意这里传入了指针的指针，也就是二级指针
        printf("%c ", node->data);
        if (node->lchild != NULL) EnQueue(&Q, node->lchild);
        if (node->rchild != NULL) EnQueue(&Q, node->rchild);
    }
}

// 销毁二叉树
void DestroyTree(BiTree T) {
    if (T == NULL) return;
    DestroyTree(T->lchild);
    DestroyTree(T->rchild);
    free(T);
}
```

### 补充：如何非递归实现先中后序遍历

递归的本质是**利用系统栈来保存信息**。因此，想要非递归实现先中后序遍历，核心思路就是**由我们自己在代码里手动维护一个栈（Stack）**。

### 1. 先序遍历（根 -> 左 -> 右）

先序遍历最简单。因为一碰上根节点就要立刻访问它，然后再去访问左右孩子。

#### 💡 核心逻辑

1. 把根节点入栈。
2. 只要栈不空，就弹出一个节点并**立刻访问/打印**它。
3. **关键点**：把该节点的**右孩子先入栈，左孩子后入栈**。
   - 为什么右孩子先入栈？因为栈是先进后出（LIFO）。为了让左孩子先出队被访问，必须让左孩子后压入栈顶。

```c
void PreOrderIterative(BiTree T) {
    if (T == NULL) return;
    Stack S;
    InitStack(&S);
    BiNode *p;

    Push(&S, T); // 根节点先入栈
    while (!IsEmpty(S)) {
        Pop(&S, &p);          // 弹出栈顶节点
        printf("%c ", p->data); // 立刻访问

        // 注意顺序：先压右，后压左
        if (p->rchild != NULL) Push(&S, p->rchild);
        if (p->lchild != NULL) Push(&S, p->lchild);
    }
}
```

### 2. 中序遍历（左 -> 根 -> 右）

中序遍历要求先访问完左子树，才能访问根节点。所以我们不能一碰到节点就打印，得先把它"憋"在栈里。

#### 💡 核心逻辑

1. 指针 `p` 顺着左孩子一路向左狂奔，把沿途遇见的节点**全压入栈中**，直到撞到 `NULL`。
2. 走不动了，说明最左底层的左子树处理完了。从栈中**弹出一个节点并访问**（此时访问的就是"根"）。
3. 既然它的左和根都处理完了，指针 `p` 转向该节点的**右孩子**（`p = p->rchild`），重复步骤 1。

```c
void InOrderIterative(BiTree T) {
    Stack S;
    InitStack(&S);
    BiNode *p = T; // p 为工作指针

    while (p != NULL || !IsEmpty(S)) {
        if (p != NULL) {
            Push(&S, p);  // 一路向左，沿途节点全部入栈"憋着"
            p = p->lchild;
        } else {          // 左边走到头了
            Pop(&S, &p);  // 弹出一个当前能访问的"最左/根"节点
            printf("%c ", p->data); // 访问它
            p = p->rchild; // 转向它的右孩子
        }
    }
}
```

### 3. 后序遍历（左 -> 右 -> 根）—— 考场大难点

后序遍历是非递归里最复杂的，因为根节点要在左、右子树都访问完后才能访问。也就是说，**一个节点会在栈顶出现两次**，你必须区分哪一次才能真正弹出并访问它。

#### 💡 核心逻辑

我们引入一个**辅助指针 `r`**，用来记录**上一个刚刚被访问并打印的节点**。

1. 同样一路向左，把节点全部压入栈，直到走不动。
2. 看一眼栈顶节点（先别弹出）：
   - 如果它**有右孩子**，并且这个右孩子**还没有被访问过**（即 `p->rchild != r`），那现在就不能访问根，指针 `p` 转向右孩子，继续去压栈。
   - 如果它**没有右孩子**，或者它的右孩子**刚刚才被访问完**（即 `p->rchild == r`），说明左右子树都搞定了！终于轮到它自己了，**安全弹出并访问**。访问后用 `r` 标记它，并把 `p` 置为 `NULL`（迫使下一轮循环直接去读新的栈顶）。

```c
void PostOrderIterative(BiTree T) {
    Stack S;
    InitStack(&S);
    BiNode *p = T;
    BiNode *r = NULL; // 记录最近刚访问过的节点

    while (p != NULL || !IsEmpty(S)) {
        if (p != NULL) {
            Push(&S, p);   // 一路向左入栈
            p = p->lchild;
        } else {
            GetTop(&S, &p); // 仅仅读取栈顶，先不弹出！

            // 如果右子树存在，且还没被访问过，先去伺候右子树
            if (p->rchild != NULL && p->rchild != r) {
                p = p->rchild;
            } else {
                // 否则（无右孩子或右孩子已访问完），现在可以安全弹出并访问根了
                Pop(&S, &p);
                printf("%c ", p->data);
                r = p;       // 账本更新：记录我刚刚访问了 p
                p = NULL;    // 节点访问完后，将 p 置空，强制下一轮去取栈顶
            }
        }
    }
}
```

#### ⚡ 考场记忆口诀与避坑指南

- **中序和后序的框架高度相似**：都是一个 `while (p || !IsEmpty)` 循环。里面套一个 `if (p) { ... 一路向左 ... } else { ... }` 的结构。
- **后序的特殊之处**：在 `else` 分支里，中序是直接 `Pop`，而后序是先 `GetTop` 看一眼，直到确认右边安全了才敢真正的 `Pop`。
- **考场救命大招（针对后序）**：如果考场上实在忘了后序的 `r` 指针怎么写，有一个作弊改法：
  > 先序遍历是：`根 -> 左 -> 右`。如果你把先序代码改成先压左后压右，它就会变成：`根 -> 右 -> 左`。
  > 这时候，你只要用一个辅助数组把这个结果存起来，最后**逆序输出**，它就神奇地变成了：`左 -> 右 -> 根`（后序遍历）！虽然这不是正统的原地算法，但 OJ 机考拿满分是完全没问题的。

### 5.5 哈夫曼树

**定义**：带权路径长度(WPL)最小的二叉树。

**构造算法**：
1. 将n个权值作为n棵只有根节点的树
2. 选取权值最小的两棵树合并
3. 新树权值为两子树权值之和
4. 重复直到只剩一棵树

**性质**：
- 没有度为1的节点
- n个叶子节点共有2n-1个节点

**哈夫曼编码**：
- 左分支为0，右分支为1
- 从根到叶子的路径即为该字符的编码
- 是前缀编码，任意编码不是其他编码的前缀

### 5.6 并查集

**定义**：用于处理不相交集合的合并和查询问题。

**操作**：
- **Find(x)**：查找x所属集合（找根节点）
- **Union(x, y)**：合并x和y所属集合

**优化**：
1. 按秩合并：小树合并到大树
2. 路径压缩：查找时直接指向根节点

```c
// 初始化
void InitUF(UnionFind *uf, int n) {
    uf->size = n;
    for (int i = 0; i < n; i++) {
        uf->parent[i] = i;  // 初始时每个元素是自己的父节点
        uf->rank[i] = 0;
    }
}

// 查找（带路径压缩）
int Find(UnionFind *uf, int x) {
    if (uf->parent[x] != x) {
        uf->parent[x] = Find(uf, uf->parent[x]);  // 路径压缩
    }
    return uf->parent[x];
}

// 合并（按秩合并）
bool Union(UnionFind *uf, int x, int y) {
    int root_x = Find(uf, x);
    int root_y = Find(uf, y);

    if (root_x == root_y) return false;  // 已在同一集合

    // 按秩合并
    if (uf->rank[root_x] < uf->rank[root_y]) {
        uf->parent[root_x] = root_y;
    } else if (uf->rank[root_x] > uf->rank[root_y]) {
        uf->parent[root_y] = root_x;
    } else {
        uf->parent[root_y] = root_x;
        uf->rank[root_x]++;
    }
    return true;
}
```

- 数组+链表

### 6.3 图的遍历

#### 广度优先搜索(BFS)
- 类似树的层次遍历
- 使用队列
- 时间复杂度：邻接矩阵O(n²)，邻接表O(n+e)

#### 深度优先搜索(DFS)
- 类似树的先序遍历
- 使用递归或栈
- 时间复杂度：邻接矩阵O(n²)，邻接表O(n+e)

```c
// 广度优先搜索
void BFS(Graph G, int start) {
    bool visited[MAX_VERTEX] = {false};
    Queue Q;
    InitQueue(&Q);

    printf("BFS: ");
    visited[start] = true;
    EnQueue(&Q, start);

    while (!IsEmpty(Q)) {
        int v = DeQueue(&Q);
        printf("%d ", v);

        ArcNode *p = G.vertices[v].first;
        while (p != NULL) {
            if (!visited[p->adjvex]) {
                visited[p->adjvex] = true;
                EnQueue(&Q, p->adjvex);
            }
            p = p->next;
        }
    }
    printf("\n");
}

// 深度优先搜索（递归）
void DFS(Graph G, int v, bool *visited) {
    visited[v] = true;
    printf("%d ", v);

    ArcNode *p = G.vertices[v].first;
    while (p != NULL) {
        if (!visited[p->adjvex]) {
            DFS(G, p->adjvex, visited);
        }
        p = p->next;
    }
}
```

### 6.6 拓扑排序

**定义**：对有向无环图(DAG)的顶点进行线性排序，使得对于边<u,v>，u排在v前面。

**算法**：

### 8.1 插入排序

```c
// 直接插入排序
void InsertSort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}

// 希尔排序
void ShellSort(int arr[], int n) {
    for (int gap = n / 2; gap > 0; gap /= 2) {
        for (int i = gap; i < n; i++) {
            int key = arr[i];
            int j = i - gap;
            while (j >= 0 && arr[j] > key) {
                arr[j + gap] = arr[j];
                j -= gap;
            }
            arr[j + gap] = key;
        }
    }
}
```

### 8.2 交换排序

#### 冒泡排序
- 时间复杂度：O(n²)
- 空间复杂度：O(1)
- 稳定排序

#### 快速排序
- 分治思想
- 平均时间复杂度：O(nlogn)
- 最坏时间复杂度：O(n²)
- 不稳定排序
- 通常被认为是同数量级中最快的排序

```c
// 冒泡排序
void BubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = true;
            }
        }
        if (!swapped) break;  // 优化：无交换说明已有序
    }
}

// 快速排序分区函数
int Partition(int arr[], int low, int high) {
    int pivot = arr[low];  // 选择第一个元素作为基准

    while (low < high) {
        while (low < high && arr[high] >= pivot) high--;
        arr[low] = arr[high];
        while (low < high && arr[low] <= pivot) low++;
        arr[high] = arr[low];
    }
    arr[low] = pivot;
    return low;
}

// 快速排序
void QuickSort(int arr[], int low, int high) {
    if (low < high) {
        int pivot = Partition(arr, low, high);
        QuickSort(arr, low, pivot - 1);
        QuickSort(arr, pivot + 1, high);
    }
}
```

### 8.3 选择排序

#### 简单选择排序
- 时间复杂度：O(n²)
- 不稳定排序

#### 堆排序
- 利用堆数据结构
- 时间复杂度：O(nlogn)
- 不稳定排序

```c
// 调整堆
void Heapify(int arr[], int n, int i) {
    int largest = i;
    int left = 2 * i + 1;
    int right = 2 * i + 2;

    if (left < n && arr[left] > arr[largest])
        largest = left;
    if (right < n && arr[right] > arr[largest])
        largest = right;

    if (largest != i) {
        swap(&arr[i], &arr[largest]);
        Heapify(arr, n, largest);
    }
}

// 堆排序
void HeapSort(int arr[], int n) {
    // 构建最大堆
    for (int i = n / 2 - 1; i >= 0; i--)
        Heapify(arr, n, i);

    // 逐个提取元素
    for (int i = n - 1; i > 0; i--) {
        swap(&arr[0], &arr[i]);
        Heapify(arr, i, 0);
    }
}

// 简单选择排序
void SelectSort(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIdx])
                minIdx = j;
        }
        swap(&arr[i], &arr[minIdx]);
    }
}
```

### 8.4 归并排序

- 分治思想
- 时间复杂度：O(nlogn)
- 空间复杂度：O(n)
- 稳定排序

```c
// 合并两个有序数组
void Merge(int arr[], int temp[], int left, int mid, int right) {
    int i = left, j = mid + 1, k = left;

    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j])
            temp[k++] = arr[i++];
        else
            temp[k++] = arr[j++];
    }

    while (i <= mid) temp[k++] = arr[i++];
    while (j <= right) temp[k++] = arr[j++];

    for (i = left; i <= right; i++)
        arr[i] = temp[i];
}

// 归并排序
void MergeSort(int arr[], int temp[], int left, int right) {
    if (left < right) {
        int mid = (left + right) / 2;
        MergeSort(arr, temp, left, mid);
        MergeSort(arr, temp, mid + 1, right);
        Merge(arr, temp, left, mid, right);
    }
}
```

## 附录：常用技巧与易错点

### 1. 复杂度分析
- 嵌套循环通常是O(n²)
- 二分思想通常是O(logn)
- 递归分析用主定理

### 2. 链表操作
- 头插法可实现链表逆置
- 删除节点要注意释放内存
- 双指针技巧（快慢指针）

### 3. 栈和队列
- 中缀转后缀：运算符栈
- 括号匹配：左括号入栈
- 循环队列：牺牲一个存储单元

### 4. 树
- n₀ = n₂ + 1（二叉树）
- 完全二叉树用数组存储
- 哈夫曼编码是前缀编码

### 5. 图
- BFS用队列，DFS用栈/递归
- Dijkstra不能处理负权边
- 拓扑排序可检测有向环

### 6. 排序
- 快速排序平均最快
- 归并排序稳定且O(nlogn)
- 堆排序空间最优O(1)
