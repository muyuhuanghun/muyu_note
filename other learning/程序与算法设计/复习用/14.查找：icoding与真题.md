## 一、BST 查找与 AVL 树

BST 的核心性质：左子树所有结点 < 根 < 右子树所有结点，中序遍历自动有序。查找时每次比较排除一半子树，平均 O(log n)，但若按有序数据插入会退化为链表 O(n)。AVL 树通过旋转保证任意结点的平衡因子（左高 - 右高）绝对值不超过 1。

### AVL 四种旋转

```c
// 右旋（LL 型）：左子树的左子树太高
AVLNode* rotate_right(AVLNode *y) {
    AVLNode *x = y->left;
    y->left = x->right;
    x->right = y;
    // 更新高度（先 y 后 x，因为 y 现在是子结点）
    y->height = 1 + max(height(y->left), height(y->right));
    x->height = 1 + max(height(x->left), height(x->right));
    return x;
}

// 左旋（RR 型）：右子树的右子树太高
AVLNode* rotate_left(AVLNode *x) {
    AVLNode *y = x->right;
    x->right = y->left;
    y->left = x;
    x->height = 1 + max(height(x->left), height(x->right));
    y->height = 1 + max(height(y->left), height(y->right));
    return y;
}
```

**旋转判断口诀**：
- LL（左子树的左子树太高）-> 右旋
- RR（右子树的右子树太高）-> 左旋
- LR（左子树的右子树太高）-> 先左旋再右旋
- RL（右子树的左子树太高）-> 先右旋再左旋

**icoding 练习**: AVL 树插入操作——先标准 BST 插入，再更新高度，最后检查平衡因子选择旋转方式。

## 二、哈希表

哈希表的核心思想：通过哈希函数 H(key) 直接算出存储地址，平均 O(1) 查找。当不同关键字映射到同一地址时产生冲突，需要冲突处理。

### 哈希函数：除留余数法

```c
int hash_func(int key, int size) {
    return key % size;  // size 通常取素数，减少冲突
}
```

### 冲突处理方法对比

| 方法 | 原理 | 优点 | 缺点 |
|:---|:---|:---|:---|
| **链地址法** | 每个桶挂一个链表 | 无聚集，删除简单 | 需要额外指针空间 |
| **线性探测法** | 冲突后向后逐个探测 | 实现简单 | 容易产生聚集现象 |
| **二次探测法** | 按 1^2, -1^2, 2^2, -2^2... 探测 | 减少聚集 | 可能找不到空位 |

**icoding 练习**:
- 哈希表创建与初始化（calloc 分配桶数组）
- 哈希表插入（除留余数法 + 链地址法头插）
- 哈希表查找（遍历桶内链表）

## 三、真题精选

### 真题 163：线性探测法

> 题目编号：163 | 来源：21级期末

解题思路:
- 哈希函数：`H(key) = key % 13`，表长为 13（题目给定 13 个关键字）
- 冲突处理：当前位置被占则向后探测，用取模实现环形查找 `(key + 1) % SIZE`
- 空位判断：calloc 初始化为 0，值为 0 表示空闲
- 核心循环：`while (hashTable[key])` 不断向后探测直到找到空位

```c
#define SIZE 13

void print_hash_array(int arr[]) {
    int *hashTable = (int *)calloc(SIZE, sizeof(int));

    for (int i = 0; i < SIZE; i++) {
        int key = arr[i] % SIZE;
        while (hashTable[key])              // 冲突：向后探测
            key = (key + 1) % SIZE;         // 取模实现环形
        hashTable[key] = arr[i];
    }

    for (int i = 0; i < SIZE; i++)
        printf("%d ", hashTable[i]);
    free(hashTable);
}
```

### 真题 199：哈希冲突（拉链法）

> 题目编号：199 | 来源：22级期末

解题思路:
- 哈希函数：`hashval = keys[i] % P`，P 为桶数（素数）
- 链地址法：每个桶维护一条单链表，冲突元素挂在同一链表上
- 头插法：新结点的 next 指向原桶头，桶指针更新为新结点
- 空桶处理：桶为 NULL 时直接赋值

```c
void hashing(hashnode *ht[], int *keys, int n) {
    for (int i = 0; i < n; i++) {
        hashnode *newnode = (hashnode *)malloc(sizeof(hashnode));
        newnode->key = keys[i];
        newnode->next = NULL;

        int hashval = keys[i] % P;

        if (ht[hashval] == NULL) {
            ht[hashval] = newnode;          // 空桶，直接赋值
        } else {
            newnode->next = ht[hashval];    // 头插法
            ht[hashval] = newnode;
        }
    }
}
```

### 真题 182：哈希排序（计数排序）

> 题目编号：182 | 来源：22级期末

解题思路:
- 核心思想：利用哈希，hash(K) = K，将元素值直接作为计数数组下标
- 三步走：遍历数组求最大值 m -> 分配计数数组 count[m+1] -> 遍历原数组标记出现 -> 从小到大收集
- 由于无重复值，每个 count[i] 最多为 1
- 时间 O(n + m)，因 n < m 简记为 O(m)；空间 O(m)

```c
void xsort(unsigned *a, unsigned n) {
    if (n == 0) return;

    // 求最大值 m
    unsigned m = 0;
    for (unsigned i = 0; i < n; i++)
        if (a[i] > m) m = a[i];

    // 计数数组：hash(K) = K
    unsigned *count = (unsigned *)calloc(m + 1, sizeof(unsigned));
    for (unsigned i = 0; i < n; i++)
        count[a[i]]++;

    // 收集：按顺序写回原数组
    unsigned index = 0;
    for (unsigned i = 1; i <= m; i++)
        while (count[i] > 0) {
            a[index++] = i;
            count[i]--;
        }
    free(count);
}
```

## 解题套路总结

查找的四大考法：

1. **BST 查找/插入**
   - 左小右大，递归/迭代
   - 最坏 O(n)，平均 O(log n)

2. **AVL 树旋转**
   - 平衡因子 = 左高 - 右高，绝对值不超过 1
   - 四种旋转：LL -> 右旋，RR -> 左旋，LR -> 先左后右，RL -> 先右后左
   - 判断方法：看破坏平衡的插入发生在哪棵子树

3. **哈希表**
   - 哈希函数：除留余数法（key % p，p 选素数）
   - 冲突处理：链地址法（头插法）、线性探测法（环形探测）、二次探测法
   - ASL（平均查找长度）衡量效率

4. **计数排序（哈希思想）**
   - 值做下标，计数后顺序输出
   - O(n + m)，非负整数且范围小时最快
