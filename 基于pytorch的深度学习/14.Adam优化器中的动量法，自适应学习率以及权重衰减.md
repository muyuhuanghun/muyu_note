# Adam优化器中的动量法，自适应学习率以及权重衰减

> 作为深度学习优化器的“标配”，Adam = **Adaptive Moment Estimation**（自适应矩估计），核心是融合了**动量法**（解决**梯度震荡、加速收敛**）和**自适应学习率**（为**不同参数定制学习率**）两大核心思想。
> 

## 一、两个核心基础

**在讲Adam之前，先拆解它的两个核心组件——这是理解Adam的前提。**

### 1. 动量法（Momentum）：给梯度加“惯性”

### 核心问题：普通 **$SGD$** 的痛点：

普通随机梯度下降（$SGD$）的更新公式是： $\theta = \theta - \eta \cdot g_t$ 

（ $\theta$ =参数， $\eta$ =学习率， $g_t$ =t时刻梯度）

- 问题1：梯度**震荡**（比如鞍点、局部波动），**收敛慢**；
- 问题2：只看当前梯度，**忽略历史梯度的“趋势”**。

### 动量法的解决思路：

模拟物理中的“惯性”：参数更新不仅依赖**当前梯度**，还依赖**历史梯度的累积**（可理解为**“下坡时顺着惯性滑得更快，上坡时惯性抵消部分阻力”**）。

> 在统计学里：
**一阶矩 = 均值，描述数据的中心趋势(这里可理解为长期趋势)
二阶矩 = 平方的均值**
> 

### 数学公式（标准动量法）：

1. 计算动量（历史梯度的**加权平均**）：
    
     $v_t = \beta_1 \cdot v_{t-1} + (1 - \beta_1) \cdot g_t$  
    
    - $v_t$ ：t时刻的动量（一阶矩，**梯度的均值**）；
    - $v_{t-1}$ ：t-1时刻的动量（初始为0）；
    - $\beta_1$ ：**动量衰减系数**（Adam默认0.9），**控制历史梯度的权重**；
    - $g_t$ ：t时刻的梯度，这里**时间步可理解为迭代次数**
2. 参数更新：
    
     $\theta = \theta - \eta \cdot v_t$ 
    

### 直观理解：

- 若连续多步梯度方向**相同**（比如下坡）：动量 $v_t$ 会**不断累积，参数更新步长变大，收敛更快；**
- 若梯度方向频繁变化（震荡）：动量会**抵消部分反向梯度**，减少震荡，让更新更平滑。

### 2. 自适应学习率（Adaptive Learning Rate）：为参数“定制”学习率

### 核心问题：统一学习率的痛点：

传统梯度下降使用**全局学习率 $\eta$** ，但模型中不同参数的“需求”不同：

- 比如：**高频更新的参数**（如文本任务的词嵌入）需要**小学习率；**更新频繁、**影响全局、噪声大**，小学习率能**避免震荡和过拟合**，保证底层特征稳定；
    - **低频参数**（如最后一层全连接）需要**大学习率**；更新少、影响局部、噪声小，大学习率能**加速收敛，快速适配任务目标**；
- 若用统一学习率，容易出现**“部分参数更新过度，部分更新不足”**。

### 自适应学习率的解决思路：

为**每个参数维护一个“学习率缩放因子”**，根据该参数的**历史梯度平方**（二阶矩）调整学习率：

### 数学公式（$RMSprop$为代表）

1. 计算**梯度平方的累积**（二阶矩）：
    
     $s_t = \beta_2 \cdot s_{t-1} + (1 - \beta_2) \cdot g_t^2$ 
    
    - $s_t$ ：t时刻的二阶矩（梯度**平方的均值**）；
    - $s_{t-1}$ ：t-1时刻的二阶矩（初始为0）；
    - $\beta_2$ ：二阶矩衰减系数（Adam默认0.999）；
    - $g_t^2$ ：t时刻梯度的逐元素平方。
2. 参数更新（加入**防止除0**的小常数 $\epsilon$ ，Adam默认 $10^{-8}$ ）：
    
     $\theta = \theta - \eta \cdot \frac{g_t}{\sqrt{s_t} + \epsilon}$ 
    

### Q：为什么梯度平方可以衡量每个**参数的更新频繁度**

1. 梯度平方 $g^2$ 是**非负数**（任何数的平方≥0），因此：**梯度出现的次数越多（更新越频繁）**，$g^2$ 的**累积和就越大**
2. 除了 **“更新频繁度”**，梯度平方还能衡量 **“更新强度”**：
    - 即使更新**频率相同**，**单次梯度绝对值大的参数**（比如g=10），其梯度平方（100）远大于梯度绝对值小的参数（g=0.1，平方0.01）；
    - 这意味着：二阶矩不仅能区分 **“更新多少次”**，还能区分 **“每次更新有多剧烈”**—— 这也是自适应学习率需要的关键信息**（单次更新步长大的参数需要更小的学习率）。**

## 二、Adam优化器：动量法 + 自适应学习率的融合

> Adam把“动量法的一阶矩”和“自适应学习率的二阶矩”结合，还加入了**偏差修正（解决初始时刻累积值偏小的问题）**，最终成为“既快又稳”的优化器。
> 

### 1. Adam完整公式

#### 步骤1：初始化

- 所有参数的一阶矩 $v_0 = 0$ ，二阶矩 $s_0 = 0$ ；
- 超参数： $\beta_1=0.9$ ， $\beta_2=0.999$ ， $\epsilon=10^{-8}$ ，学习率 $\eta=0.001$ **（Adam默认值）**。

#### 步骤2：t时刻计算梯度 $g_t$

 $g_t = \nabla_\theta J(\theta_t)$ （ $J(\theta)$ 为损失函数）

#### 步骤3：更新一阶矩（动量）

 $v_t = \beta_1 \cdot v_{t-1} + (1 - \beta_1) \cdot g_t$ 

#### 步骤4：更新二阶矩（自适应学习率）

 $s_t = \beta_2 \cdot s_{t-1} + (1 - \beta_2) \cdot g_t^2$ 

#### 步骤5：偏差修正（核心！Adam的关键改进）

由于初始 $v_0=s_0=0$ ，前几步的 $v_t与s_t$ 会**偏小，需修正**：

 $\hat{v}_t = \frac{v_t}{1 - \beta_1^t}$ 

 $\hat{s}_t = \frac{s_t}{1 - \beta_2^t}$ 

### 步骤6：参数更新

$\theta_{t+1} = \theta_t - \eta \cdot \frac{\hat{v}_t}{\sqrt{\hat{s}_t} + \epsilon}$ 

### Q：为什么修正分母是 $1-\beta_1^t$ ？

> 核心原因是：**修正的是「指数移动平均（$EMA$）本身的系统性偏差」，而非“梯度是否变化”**。

#### 一、明确核心：修正的是“$EMA$的偏差”，不是“梯度的偏差”

**首先区分两个概念：**

- 梯度变化 → 影响 $v_t$ 的**具体数值**；
- $EMA$的初始值为0 → 导致 $v_t$ 相对于「梯度的真实加权均值」存在**系统性低估**，这个低估的“比例”只**和 $\beta_1$、$t$ 有关，和梯度具体值无关**。

#### 二、通用数学推导

用**任意梯度序列 $g_1,g_2,...,g_t$** **推导证明**：
$\mathbb{E}[\hat{v}_t] = \mathbb{E}\left[\frac{v_t}{1-\beta_1^t}\right] = \mathbb{E}\left[\frac{(1-\beta_1)\sum_{k=1}^t \beta_1^{t-k}g_k}{1-\beta_1^t}\right] = \mathbb{E}[\bar{g}_t]$
（$\bar{g}_t$ 是梯度的“$EMA$**等效均值**”，即梯度的**真实加权平均**）

##### 步骤1：展开任意梯度下的 $v_t$

对任意梯度序列，$v_t$ 的展开式依然成立**（和梯度值无关）**：
$v_t = \beta_1 v_{t-1} + (1-\beta_1)g_t = (1-\beta_1)\sum_{k=1}^t \beta_1^{t-k}g_k$
这个展开式是$EMA$的数学性质，**仅依赖递推规则，不依赖梯度是否变化。**

##### 步骤2：定义“梯度的真实$EMA$均值”

$EMA$的本质是**对历史梯度做加权平均**，**权重为** $\omega_k = \frac{(1-\beta_1)\beta_1^{t-k}}{\sum_{i=1}^t (1-\beta_1)\beta_1^{t-i}} = \frac{\beta_1^{t-k}}{1-\beta_1^t}$

###### 2.1.   第一步：所有权重加起来等于多少？

权重是：$β_1^{t−1}, β_1^{t−2}, …,β_1^0$

这是一个**等比数列求和**：$S=1+β_1+β_1^{2}+⋯+β_1^{t−1}=\frac{1−β_1^t}{1-β_1}$

**即所有权重的总和**。

###### 2.2.   **真正的 “加权平均”** 长什么样？

**真正的加权平均，必须满足：权重加起来 = 1**

所以第 k 步梯度 $g_k$ 的**真实权重**应该是：$真实权重=\frac{原来的权重}{权重总和}$

原来的权重是：$β_1^{t−k}$ 权重总和是：$\frac{1-β_1^t}{1-β_1}$所以：$ω_k=\frac{β_1^{t−k}}{\frac{1-β_1^t}{1-β_1}}$=$\frac{(1-β_1)β_1^{t−k}}{1-β_1^t}$

因此，梯度的真实$EMA$均值为：
$\bar{g}_t = \sum_{k=1}^t \omega_k g_k = \frac{(1-\beta_1)\sum_{k=1}^t \beta_1^{t-k}g_k}{1-\beta_1^t}$

##### 步骤3：对比 $v_t$ 和 $\bar{g}_t$

把 $v_t = (1-\beta_1)\sum_{k=1}^t \beta_1^{t-k}g_k$ 代入上式：
$\bar{g}_t = \frac{v_t}{1-\beta_1^t} = \hat{v}_t$

**修正的核心对象：$EMA$本身的“权重和未归一化”问题，而非梯度是否变化**

### 2. 手动计算演示

**（计算一二阶矩时用的是未修正的数据，参数更新时用的是修正后的数据）**

### 已知条件：

- 单参数 $\theta_0 = 10$ （初始值）；
- 超参数： $\beta_1=0.9$ ， $\beta_2=0.999$ ， $\eta=0.001$ ， $\epsilon=10^{-8}$ ；
- 梯度序列（模拟3步训练的梯度）： $g_1=2$ ， $g_2=1$ ， $g_3=0.5$ 。

#### 第1步（t=1）

1. 一阶矩： $v_1 = 0.9×0 + 0.1×2 = 0.2$ 
2. 二阶矩： $s_1 = 0.999×0 + 0.001×(2^2) = 0.004$ 
3. 偏差修正：
 $\hat{v}_1 = 0.2 / (1 - 0.9^1) = 0.2 / 0.1 = 2$ 
 $\hat{s}_1 = 0.004 / (1 - 0.999^1) = 0.004 / 0.001 = 4$ 
4. 参数更新：
 $\theta_1 = 10 - 0.001 × (2 / (\sqrt{4} + 10^{-8})) = 10 - 0.001×(2/2) = 9.999$ 

#### 第2步（t=2）

1. 一阶矩： $v_2 = 0.9×0.2 + 0.1×1 = 0.18 + 0.1 = 0.28$ 
2. 二阶矩： $s_2 = 0.999×0.004 + 0.001×(1^2) = 0.003996 + 0.001 = 0.004996$ 
3. 偏差修正：
 $\hat{v}_2 = 0.28 / (1 - 0.9^2) = 0.28 / 0.19 ≈ 1.4737$ 
 $\hat{s}_2 = 0.004996 / (1 - 0.999^2) = 0.004996 / 0.001999 ≈ 2.4992$ 
4. 参数更新：
 $\theta_2 = 9.999 - 0.001 × (1.4737 / (\sqrt{2.4992} + 10^{-8})) ≈ 9.999 - 0.001×(1.4737/1.5809) ≈ 9.99809$ 

#### 第3步（t=3）

1. 一阶矩： $v_3 = 0.9×0.28 + 0.1×0.5 = 0.252 + 0.05 = 0.302$ 
2. 二阶矩： $s_3 = 0.999×0.004996 + 0.001×(0.5^2) ≈ 0.004991 + 0.00025 = 0.005241$ 
3. 偏差修正：
 $\hat{v}_3 = 0.302 / (1 - 0.9^3) = 0.302 / 0.271 ≈ 1.1144$ 
 $\hat{s}_3 = 0.005241 / (1 - 0.999^3) ≈ 0.005241 / 0.002997 ≈ 1.7487$ 
4. 参数更新：
 $\theta_3 ≈ 9.99809 - 0.001 × (1.1144 / \sqrt{1.7487}) ≈ 9.99809 - 0.001×0.843 ≈ 9.99725$

## 三、实战例子：PyTorch中使用Adam优化器

用一个简单的线性回归任务，演示Adam的使用，对比$SGD$和$Adam$的收敛效果。

### 1. 代码实现

```python
import torch
import torch.nn as nn
import matplotlib.pyplot as plt

# 1. 生成模拟数据：y = 2x + 3 + 噪声
torch.manual_seed(42)  # 固定随机种子
#让代码中所有基于 PyTorch 生成的随机数 “可复现”—— 即让每次运行代码，**随机数的结果都完全一样**

x = torch.randn(1000, 1)
# 形状是(N, 1)，**N为样本数，1就是每个样本的特征维度**
y = 2 * x + 3 + 0.1 * torch.randn_like(x)
#加入噪声：创建一个和输入张量 x **完全同形状、同数据类型、同设备（CPU/GPU）**的新张量，且新张量的元素服从标准正态分布（均值 = 0，标准差 = 1）。

# 2. 定义线性回归模型
class LinearModel(nn.Module):
    def __init__(self):
        super().__init__()
        # 创建一个全连接层
        self.linear = nn.Linear(1, 1) 
    def forward(self, x):
        return self.linear(x)
```

<aside>
💡

- `nn.Linear` 是`nn.Module` 的子类，而 `nn.Module` **重写了 __call__ 魔法方法**，这个方法让**实例可以像函数一样被调用**；当你执行 `self.linear(x)` 时，本质是调用 `self.linear.__call__(x)`，从而进行一些像**记录梯度、切换训练 / 推理模式**的操作等等

</aside>

```python
# 3. 初始化模型和损失函数
model_adam = LinearModel()
model_sgd = LinearModel()  # 对比SGD
criterion = nn.MSELoss()
# 使用**均方误差损失**，计算"模型预测值"和"真实标签值"之间**差值的平方的平均值**
```

> `nn.MSELoss()` 有一个核心可选参数 **`reduction`**，决定**损失的输出形式**：
> 

| 参数值 | 含义 | 输出形状 | 例子（上面的模拟数据） |
| --- | --- | --- | --- |
| `'mean'`（默认） | 计算所有样本的**平均损失** | 标量（单个数值） | 0.03 |
| `'sum'` | 计算所有样本的**误差平方和** | 标量 | 0.09 |
| `'none'` | 不归约，**保留每个样本的损失** | 和输入同形状（3,1） | `[[0.04], [0.04], [0.01]]` |

```python
# 4.定义优化器：Adam vs SGD
# Adam用0.01学习率
optimizer_adam = torch.optim.Adam(model_adam.parameters(), lr=0.01) 
# SGD用相同学习率 
optimizer_sgd = torch.optim.SGD(model_sgd.parameters(), lr=0.01)  
```

```python
# 一些可选参数
optimizer_adam = torch.optim.Adam(
model_adam.parameters(), # 告诉 Adam 优化器**"需要优化的参数是哪些"**
lr=0.01,                 # 学习率
betas=(0.9, 0.999),      # 一阶矩（动量）和二阶矩的**指数衰减系数**
eps=1e-08,               # **避免分母为 0**（对应 Adam 公式中的 ϵ）
weight_decay=1e-4        # **权重衰减，防止过拟合**
)
```

```python
# 5. 训练过程
epochs = 100
loss_adam = []
loss_sgd = []

# 训练Adam模型
for epoch in range(epochs):
    # 前向传播
    y_pred = model_adam(x)
    loss = criterion(y_pred, y)
    loss_adam.append(loss.item())

    # 反向传播 + 更新
    optimizer_adam.zero_grad()  # **清空上一轮迭代中累积的梯度值，避免梯度叠加**导致参数更新错误。
    loss.backward()
    optimizer_adam.step()       # Adam参数更新

# 训练SGD模型（相同步骤）
for epoch in range(epochs):
    y_pred = model_sgd(x)
    loss = criterion(y_pred, y)
    loss_sgd.append(loss.item())

    optimizer_sgd.zero_grad()
    loss.backward()
    optimizer_sgd.step()

```

### 补充一：唯一不需要清零的场景：梯度累积（梯度累加）

梯度累积是**小批量训练**的技巧（比如显存不足时），核心是 **「多轮前向传播累积梯度，一次更新参数」**，此时**不手动清零**，让梯度自然累加：

```python
accumulation_steps = 4  # 累积4轮梯度再更新
for epoch in range(epochs):
    for i, (x_batch, y_batch) in enumerate(dataloader):
        # 前向传播
        y_pred = model_adam(x_batch)
        loss = criterion(y_pred, y_batch)
        loss = loss / accumulation_steps  **# 损失归一化**
        
        # 反向传播：**梯度累加（不清零）**
        loss.backward()
        
        # 每累积4轮，更新一次参数并清零
        if (i+1) % accumulation_steps == 0:
            optimizer_adam.step()
            optimizer_adam.zero_grad()  # 仅此时清零
```

### 补充二：损失归一化（Loss Normalization）

#### 1. 为什么需要损失归一化？

深度学习训练中，**损失的量级**会因**任务、模型结构、数据规模、批次大小**等因素剧烈变化，直接带来问题：

- 损失值过大：梯度值也会过大，导致参数更新**步长失控，模型震荡甚至无法收敛**；
- 损失值过小：梯度值趋近于 0，出现**梯度消失，模型参数几乎不更新**，训练停滞；
- 不同任务损失量级差异：分类任务交叉熵损失、回归任务 $MSE$ **损失量级不同**，**直接对比 / 训练会不公平。**

#### 2. 最常见的损失归一化方式（结合训练场景）

在深度学习训练中，**最核心、最常用的归一化是「按批次大小（Batch Size）归一化损失」**，也是你后续会高频遇到的形式，具体解释：

1. **原始损失计算**：模型对一个批次（batch）的所有样本计算损失时，会得到**每个样本的损失**，再求和得到**批次总损失（sum loss）。**
2. **归一化操作**：将批次总损失**除以批次大小（batch size）**，**得到平均损失（mean loss）**，这就是最典型的损失归一化。
    - 公式：`归一化损失 = 批次总损失 / batch_size`

<aside>
💡
补充：其他归一化形式

- **$L2$ 归一化**：对损失向量做 $L2$ 范数缩放，**让损失的模长为 1**，用于**对抗训练、特征学习**等场景；
- **动态归一化**：**根据训练阶段、损失分布动态调整**缩放系数，用于**复杂任务**（如多任务学习、大模型训练）；
- **相对归一化**：将损失除以**当前批次的损失均值 / 方差**，适配**非平稳损失分布。**
<aside>

#### 3. 关键意义

归一化后的损失（平均损失）是训练日志中最常显示的指标，它能**公平反映单个样本的损失水平**，同时让优化器的**学习率（learning rate）设置更通用，无需根据批次大小频繁调整。**
