## 一、为什么需要迁移学习？

### 1. 从头训练的困境

```
📌 核心问题：从头训练一个大模型需要海量数据和计算资源

问题：
- ImageNet 有 1400 万张图像，训练 ResNet-50 需要几天到几周
- 医疗影像、小众领域可能只有几百张图
- 从头训练会导致严重过拟合

现实：
- 大公司用海量数据训练大模型（如 ResNet、BERT）
- 小团队用迁移学习，在特定任务上微调
- 迁移学习是深度学习落地的关键技术
```

### 2. 迁移学习的核心思想

```
💡 核心直觉：把在大数据集上学到的"知识"迁移到小数据集

迁移学习的前提：
- 深度网络的低层特征（边缘、纹理）是通用的
- 深度网络的高层特征（语义、类别）是任务相关的
- 低层特征可以迁移到新任务

迁移学习的做法：
- 用预训练模型的权重初始化新模型
- 冻结低层（不更新参数），只训练高层
- 或者用很小的学习率微调整个网络
```

## 二、迁移学习的方法

### 1. 特征提取 (Feature Extraction)

```python
# 🌟 方法 1：冻结整个 backbone，只训练分类头

import torch
import torch.nn as nn
import torchvision.models as models

# 加载预训练的 ResNet-50
model = models.resnet50(pretrained=True)

# 冻结所有参数
for param in model.parameters():
    param.requires_grad = False

# 替换最后的全连接层（分类头）
num_classes = 10  # 新任务的类别数
model.fc = nn.Linear(model.fc.in_features, num_classes)

# 只有新的分类头会被训练
print("可训练参数:")
for name, param in model.named_parameters():
    if param.requires_grad:
        print(f"  {name}: {param.shape}")

# 训练时，只有 fc 层的参数会更新
optimizer = torch.optim.Adam(model.fc.parameters(), lr=1e-3)
```

**适用场景**：
- 数据量很小（< 1000）
- 新任务与预训练任务相似
- 快速原型验证

### 2. 微调 (Fine-tuning)

```python
# 🌟 方法 2：解冻部分层，用小学习率微调

# 加载预训练模型
model = models.resnet50(pretrained=True)

# 冻结前面的层，解冻后面的层
# 假设我们只微调 layer4 和 fc
for name, param in model.named_parameters():
    if 'layer4' in name or 'fc' in name:
        param.requires_grad = True  # 解冻
    else:
        param.requires_grad = False  # 冻结

# 使用差异化学习率
# 前面的层用更小的学习率，后面的层用更大的学习率
optimizer = torch.optim.Adam([
    {'params': model.layer4.parameters(), 'lr': 1e-4},
    {'params': model.fc.parameters(), 'lr': 1e-3},
])

# 或者统一用小学习率
optimizer = torch.optim.Adam(filter(lambda p: p.requires_grad, model.parameters()), lr=1e-4)
```

**适用场景**：
- 数据量中等（1000 - 10000）
- 新任务与预训练任务有一定差异
- 希望模型适应新任务的特定特征

### 3. 差异化学习率 (Discriminative Learning Rates)

```python
# 🌟 方法 3：不同层使用不同学习率

# 原则：越靠近输入的层，学习率越小
# 因为低层特征更通用，需要保留
# 高层特征更任务相关，需要更多调整

model = models.resnet50(pretrained=True)

# 定义不同层的学习率
optimizer = torch.optim.Adam([
    {'params': model.layer1.parameters(), 'lr': 1e-5},  # 最低层，学习率最小
    {'params': model.layer2.parameters(), 'lr': 1e-5},
    {'params': model.layer3.parameters(), 'lr': 1e-4},
    {'params': model.layer4.parameters(), 'lr': 1e-4},
    {'params': model.fc.parameters(), 'lr': 1e-3},      # 最高层，学习率最大
])

# 或者用学习率衰减
# 假设总学习率为 lr，第 i 层的学习率为 lr * (decay_factor ** i)
```

### 4. 逐步解冻 (Gradual Unfreezing)

```python
# 🌟 方法 4：训练过程中逐步解冻层

# 阶段 1：只训练分类头
for param in model.parameters():
    param.requires_grad = False
for param in model.fc.parameters():
    param.requires_grad = True

train(model, epochs=5)

# 阶段 2：解冻 layer4
for param in model.layer4.parameters():
    param.requires_grad = True

train(model, epochs=5)

# 阶段 3：解冻 layer3
for param in model.layer3.parameters():
    param.requires_grad = True

train(model, epochs=5)

# 阶段 4：解冻所有层
for param in model.parameters():
    param.requires_grad = True

train(model, epochs=10, lr=1e-5)  # 用小学习率
```

**适用场景**：
- 数据量中等到大
- 需要精细控制迁移学习的过程
- NLP 中的 ULMFiT 方法

## 三、迁移学习的策略选择

### 1. 按数据量和相似度选择

```
┌─────────────────────────────────────────────────────────────┐
│  数据量    与预训练任务相似度    推荐策略                      │
├─────────────────────────────────────────────────────────────┤
│  小        高                  特征提取（冻结全部）            │
│  小        低                  特征提取 + 数据增强            │
│  中        高                  微调（解冻后面几层）            │
│  中        低                  差异化学习率                   │
│  大        高                  微调（解冻全部，小学习率）      │
│  大        低                  从头训练                       │
└─────────────────────────────────────────────────────────────┘
```

### 2. 医疗影像迁移学习的特殊考虑

```
📌 医疗影像迁移学习的挑战：

问题：
- ImageNet 是自然图像（猫、狗、车）
- 医疗影像（X 光、CT、MRI）与自然图像差异大
- 低层特征（边缘、纹理）可能仍有用
- 高层特征（语义）可能完全不同

解决方案：
1. 用 ImageNet 预训练模型初始化
2. 用较大的学习率微调（因为差异大）
3. 或者用医疗影像数据集预训练（如 CheXpert）
4. 考虑自监督预训练
```

## 五、迁移学习的最佳实践

### 1. 数据预处理的一致性

```python
# 🌟 使用与预训练时相同的预处理

# ImageNet 预训练模型的标准预处理
transform = transforms.Compose([
    transforms.Resize(256),
    transforms.CenterCrop(224),
    transforms.ToTensor(),
    transforms.Normalize(
        mean=[0.485, 0.456, 0.406],  # ImageNet 的均值
        std=[0.229, 0.224, 0.225]    # ImageNet 的标准差
    ),
])

# 为什么？
# 预训练模型是在特定预处理下训练的
# 如果预处理不一致，模型输入分布不同，效果会变差
```

### 2. 学习率的选择

```python
# 🌟 迁移学习的学习率选择原则

# 特征提取（冻结全部）：
# 可以用较大的学习率（如 1e-3）
# 因为只训练分类头，参数少

# 微调（解冻部分）：
# 必须用较小的学习率（如 1e-4 或 1e-5）
# 因为预训练权重已经很好，大的更新会破坏它们

# 差异化学习率：
# 低层：1e-5
# 中层：1e-4
# 高层：1e-3
```

### 3. 冻结层的 BatchNorm

```python
# 🌟 冻结层时，BatchNorm 需要特殊处理

# 问题：
# 即使冻结了 BN 层的参数（weight, bias）
# BN 在训练模式下仍会用当前 batch 的统计量
# 这会改变预训练的特征分布

# 解决方案：
# 冻结的层设置为 eval 模式
model.eval()

# 或者手动设置
for module in model.modules():
    if isinstance(module, nn.BatchNorm2d):
        module.eval()  # 使用 running_mean 和 running_var
```

```

3. 冻结/解冻特定层
4. 用小学习率微调
5. 保存微调后的模型
6. 在新任务上评估
```

```python
import torch.optim as optim

model = models.resnet50(pretrained=True)

for param in model.parameters():
    param.requires_grad = False

num_classes = 10
model.fc = nn.Linear(model.fc.in_features, num_classes)

optimizer = optim.Adam(model.fc.parameters(), lr=1e-3)
criterion = nn.CrossEntropyLoss()

# 5. 数据预处理（与预训练一致）
transform = transforms.Compose([
    transforms.Resize(256),
    transforms.CenterCrop(224),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]),
])

# 6. 训练
for epoch in range(10):
    model.train()
    for images, labels in train_loader:
        outputs = model(images)
        loss = criterion(outputs, labels)
        
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
    
    # 验证

    correct = 0

            correct += (predicted == labels).sum().item()
    
    print(f"Epoch {epoch+1}, Accuracy: {correct/total:.4f}")

# 7. 解冻更多层，继续微调
for param in model.layer4.parameters():
    param.requires_grad = True

optimizer = optim.Adam([
    {'params': model.layer4.parameters(), 'lr': 1e-5},
    {'params': model.fc.parameters(), 'lr': 1e-4},
])

# 继续训练...
```
