## 一、为什么需要学习率调度器？

### 1. 固定学习率的困境

```
📌 核心矛盾：大学习率 vs 小学习率

大学习率 (如 0.1)：
✅ 训练初期快速收敛
❌ 训练后期在最优解附近震荡
❌ 可能跳过最优解

小学习率 (如 0.0001)：
✅ 训练后期精细调整
❌ 训练初期收敛太慢
❌ 可能陷入局部最优

理想情况：
- 训练初期用大学习率（快速接近最优解）
- 训练后期用小学习率（精细调整）
- 这就是学习率调度器的核心思想！
```

### 2. 学习率调度器的作用

```
💡 核心直觉：让学习率随训练过程动态变化

作用：
- 加速收敛：初期用大步长快速接近最优解
- 提升精度：后期用小步长精细调整
- 避免震荡：在最优解附近减小学习率
- 逃离局部最优：偶尔增大学习率跳出局部最优
```

## 二、常见的学习率调度策略

### 1. StepLR —— 阶梯式衰减

```python
# 🌟 最简单的调度策略：每隔 N 个 epoch，学习率乘以 γ

import torch.optim as optim

optimizer = optim.SGD(model.parameters(), lr=0.1)
scheduler = optim.lr_scheduler.StepLR(optimizer, step_size=30, gamma=0.1)

# 学习率变化：
# epoch 0-29:  lr = 0.1
# epoch 30-59: lr = 0.01
# epoch 60-89: lr = 0.001
# ...

for epoch in range(100):
    train(...)
    scheduler.step()  # 每个 epoch 结束后更新学习率
```

**适用场景**：训练初期快速收敛，后期精细调整

### 2. MultiStepLR —— 多阶段衰减

```python
# 🌟 在指定的 epoch 衰减学习率

scheduler = optim.lr_scheduler.MultiStepLR(
    optimizer, 
    milestones=[30, 80],  # 在第 30 和 80 个 epoch 衰减
    gamma=0.1
)

# 学习率变化：
# epoch 0-29:  lr = 0.1
# epoch 30-79: lr = 0.01
# epoch 80+:   lr = 0.001
```

**适用场景**：需要精确控制学习率变化时机

### 3. ExponentialLR —— 指数衰减

```python
# 🌟 每个 epoch 学习率乘以 γ

scheduler = optim.lr_scheduler.ExponentialLR(optimizer, gamma=0.95)

# 学习率变化：
# epoch 0: lr = 0.1
# epoch 1: lr = 0.1 * 0.95 = 0.095
# epoch 2: lr = 0.095 * 0.95 = 0.09025
# ...指数衰减
```

**适用场景**：需要平滑衰减，不希望阶梯式跳变

### 4. CosineAnnealingLR —— 余弦退火（最常用）

```python
# 🌟 学习率按余弦函数从初始值衰减到最小值

scheduler = optim.lr_scheduler.CosineAnnealingLR(
    optimizer, 
    T_max=100,      # 一个周期的 epoch 数
    eta_min=1e-6    # 最小学习率
)

# 学习率变化：
# lr = η_min + 0.5 * (η_max - η_min) * (1 + cos(π * t / T_max))
# 像余弦函数一样从高到低平滑变化
```

**适用场景**：最常用的调度策略，效果通常优于阶梯式

### 5. CosineAnnealingWarmRestarts —— 带热重启的余弦退火

```python
# 🌟 每隔 T_0 个 epoch 重新开始余弦退火

scheduler = optim.lr_scheduler.CosineAnnealingWarmRestarts(
    optimizer, 
    T_0=10,        # 第一个周期的 epoch 数
    T_mult=2       # 每次重启后周期翻倍
)

# 学习率变化：
# epoch 0-9:   余弦退火 (T=10)
# epoch 10-29: 余弦退火 (T=20)
# epoch 30-69: 余弦退火 (T=40)
# ...
```

**适用场景**：避免陷入局部最优，让网络有"重新探索"的机会

### 6. ReduceLROnPlateau —— 自适应衰减

```python
# 🌟 当验证集指标停止改善时，自动降低学习率

scheduler = optim.lr_scheduler.ReduceLROnPlateau(
    optimizer, 
    mode='min',       # 监控指标是越小越好 (如 loss)
    factor=0.1,       # 衰减倍数
    patience=10,      # 容忍多少个 epoch 不改善
    verbose=True
)

for epoch in range(100):
    train(...)
    val_loss = validate(...)
    scheduler.step(val_loss)  # 根据验证损失调整学习率
```

**适用场景**：不需要预设衰减时机，让网络自己决定何时衰减

### 7. Warmup + Cosine Decay —— 预热 + 余弦衰减（Transformer 标配）

```python
# 🌟 训练初期线性增大学习率（warmup），然后余弦衰减

from torch.optim.lr_scheduler import LambdaLR

def warmup_cosine_schedule(optimizer, warmup_steps, total_steps):
    def lr_lambda(current_step):
        # Warmup 阶段：线性增大
        if current_step < warmup_steps:
            return current_step / warmup_steps
        # 余弦衰减阶段
        progress = (current_step - warmup_steps) / (total_steps - warmup_steps)
        return max(0.0, 0.5 * (1.0 + math.cos(math.pi * progress)))
    
    return LambdaLR(optimizer, lr_lambda)

# 学习率变化：
# 阶段 1 (warmup): lr 从 0 线性增大到初始学习率
# 阶段 2 (decay):  lr 按余弦函数衰减到接近 0
```

**适用场景**：Transformer、大模型训练的标配，避免初期梯度不稳定

## 三、学习率调度器的选择策略

### 1. 按任务类型选择

```
┌─────────────────────────────────────────────────────────────┐
│  任务类型              推荐调度器                             │
├─────────────────────────────────────────────────────────────┤
│  CNN 图像分类          CosineAnnealingLR / StepLR           │
│  目标检测 (YOLO)       CosineAnnealingLR + Warmup           │
│  语义分割 (UNet)       PolyLR (余弦变体)                     │
│  Transformer           Warmup + Cosine Decay                │
│  不确定 / 快速实验      ReduceLROnPlateau (傻瓜式)           │
└─────────────────────────────────────────────────────────────┘
```

### 2. 按训练阶段选择

```
📌 训练初期 (0-30% epochs):
- 用 Warmup 或较大学习率
- 目标：快速收敛到损失较低的区域

📌 训练中期 (30-80% epochs):
- 用 CosineAnnealing 或 StepLR
- 目标：稳定收敛，避免震荡

📌 训练后期 (80-100% epochs):
- 用较小学习率
- 目标：精细调整，逼近最优解
```

## 四、学习率调度器的使用技巧

### 1. 调度器的调用顺序

```python
# 🌟 标准训练循环中的调用顺序

for epoch in range(num_epochs):
    # 1. 训练
    for batch in train_loader:
        optimizer.zero_grad()
        loss = model(batch)
        loss.backward()
        optimizer.step()
    
    # 2. 更新学习率 (在 epoch 结束后)
    scheduler.step()
    
    # 3. 验证
    val_loss = validate(...)
```

### 2. 与 Checkpoint 配合

```python
# 🌟 保存和加载调度器状态

# 保存
torch.save({
    'epoch': epoch,
    'model_state_dict': model.state_dict(),
    'optimizer_state_dict': optimizer.state_dict(),
    'scheduler_state_dict': scheduler.state_dict(),  # 保存调度器状态
}, 'checkpoint.pth')

# 加载
checkpoint = torch.load('checkpoint.pth')
model.load_state_dict(checkpoint['model_state_dict'])
optimizer.load_state_dict(checkpoint['optimizer_state_dict'])
scheduler.load_state_dict(checkpoint['scheduler_state_dict'])  # 恢复调度器状态
```

### 3. 学习率范围测试 (LR Range Test)

```python
# 🌟 找到最佳初始学习率

def lr_range_test(model, train_loader, optimizer, criterion, 
                  start_lr=1e-7, end_lr=10, num_iter=100):
    """
    从很小的学习率开始，逐渐增大，记录每个学习率对应的损失
    找到损失下降最快的学习率作为初始学习率
    """
    lr_schedule = np.geomspace(start_lr, end_lr, num_iter)
    losses = []
    
    for i, lr in enumerate(lr_schedule):
        # 设置学习率
        for param_group in optimizer.param_groups:
            param_group['lr'] = lr
        
        # 训练一个 batch
        batch = next(iter(train_loader))
        loss = train_one_batch(model, batch, optimizer, criterion)
        losses.append(loss)
    
    # 找到损失下降最快的学习率
    best_lr = lr_schedule[np.argmin(losses)]
    return best_lr
```

## 五、对整体学习路线的影响

### 1. 在后续任务中的应用

| 任务 | 推荐的学习率调度策略 |
|------|---------------------|
| **UNet** | CosineAnnealingLR，初始 lr=1e-3 |
| **YOLO** | Warmup + Cosine Decay，初始 lr=1e-2 |
| **FaceNet** | StepLR 或 CosineAnnealingLR |
| **Transformer** | Warmup + Cosine Decay (必须) |

### 2. 与优化器的配合

```
📌 Adam 优化器 + 学习率调度器

Adam 自带自适应学习率，但仍需要调度器：
- Adam 的初始学习率通常为 1e-3 ~ 1e-4
- 配合 CosineAnnealingLR 可以进一步提升效果
- 配合 ReduceLROnPlateau 可以自动调整

📌 SGD 优化器 + 学习率调度器

SGD 没有自适应学习率，调度器更重要：
- SGD 的初始学习率通常为 0.01 ~ 0.1
- 必须配合 Momentum (0.9)
- 通常用 StepLR 或 CosineAnnealingLR
```

## 六、代码验证（完整训练循环）

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.optim.lr_scheduler import CosineAnnealingLR

# 模型、优化器、调度器
model = nn.Linear(10, 2)
optimizer = optim.Adam(model.parameters(), lr=1e-3)
scheduler = CosineAnnealingLR(optimizer, T_max=100, eta_min=1e-6)

# 训练循环
for epoch in range(100):
    # 训练
    for batch in train_loader:
        optimizer.zero_grad()
        loss = criterion(model(batch.x), batch.y)
        loss.backward()
        optimizer.step()
    
    # 更新学习率
    scheduler.step()
    
    # 打印当前学习率
    current_lr = scheduler.get_last_lr()[0]
    if epoch % 10 == 0:
        print(f"Epoch {epoch}, LR: {current_lr:.6f}")
```
