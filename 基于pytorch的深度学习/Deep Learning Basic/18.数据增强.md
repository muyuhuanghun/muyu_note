## 一、为什么需要数据增强？

### 1. 数据稀缺的困境

```
📌 核心问题：深度学习是"数据饥渴型"算法

问题：
- 深度学习模型参数量巨大（如 ResNet-50 有 2500 万参数）
- 参数越多，需要的训练数据越多
- 医疗影像、小众领域的数据往往很少

后果：
- 数据不足 → 过拟合 → 泛化能力差
- 收集数据成本高、周期长
- 某些数据根本无法大量获取（如罕见疾病影像）
```

### 2. 数据增强的核心思想

```
💡 核心直觉：在不改变标签的前提下，创造"新"数据

原理：
- 对原始图像做随机变换（旋转、翻转、裁剪...）
- 变换后的图像仍然属于同一类别
- 模型需要学习到"旋转的猫仍然是猫"
- 等于用少量数据生成无限多的训练样本
```

## 二、常见的数据增强方法

### 1. 几何变换

```python
import torchvision.transforms as T

# 🌟 基础几何变换
transform = T.Compose([
    # 随机水平翻转 (概率 0.5)
    T.RandomHorizontalFlip(p=0.5),
    
    # 随机垂直翻转 (概率 0.5，某些任务不适用)
    T.RandomVerticalFlip(p=0.5),
    
    # 随机旋转 (±15度)
    T.RandomRotation(degrees=15),
    
    # 随机仿射变换
    T.RandomAffine(
        degrees=0,           # 旋转角度
        translate=(0.1, 0.1), # 平移范围 (宽度, 高度) 的比例
        scale=(0.9, 1.1),    # 缩放范围
        shear=10             # 剪切角度
    ),
    
    # 随机裁剪并缩放回原大小
    T.RandomResizedCrop(
        size=224,
        scale=(0.8, 1.0),   # 裁剪面积占比范围
        ratio=(0.9, 1.1)    # 宽高比范围
    ),
])
```

### 2. 颜色变换

```python
# 🌟 颜色/亮度/对比度变换
transform = T.Compose([
    # 随机调整亮度、对比度、饱和度、色调
    T.ColorJitter(
        brightness=0.2,  # 亮度变化范围
        contrast=0.2,    # 对比度变化范围
        saturation=0.2,  # 饱和度变化范围
        hue=0.1          # 色调变化范围
    ),
    
    # 随机转换为灰度图 (概率 0.1)

    # 随机高斯模糊
    T.GaussianBlur(
        kernel_size=3,
        sigma=(0.1, 2.0)
    ),
])
```

### 3. 随机擦除 (Random Erasing)

```python
# 🌟 随机遮挡图像的一部分，强迫模型关注全局特征

transform = T.Compose([
    T.ToTensor(),
    T.RandomErasing(
        p=0.5,           # 执行概率
        scale=(0.02, 0.33), # 遮挡面积占比范围
        ratio=(0.3, 3.3),   # 遮挡区域的宽高比
        value='random'      # 遮挡填充值：随机、0、均值
    ),
])
```

**直觉理解**：就像给模型戴上了"眼罩"，强迫它从局部特征推断整体

### 4. Mixup —— 样本混合

```python
# 🌟 将两张图像按比例混合，标签也按比例混合

def mixup_data(x, y, alpha=0.2):
    """
    x: 图像 tensor [batch, channels, h, w]
    y: 标签 tensor [batch]
    alpha: 混合参数 (越大混合越激进)
    """
    if alpha > 0:
        lam = np.random.beta(alpha, alpha)  # Beta 分布采样混合比例
    else:
        lam = 1
    
    batch_size = x.size(0)
    index = torch.randperm(batch_size)  # 随机打乱索引
    
    # 混合图像
    mixed_x = lam * x + (1 - lam) * x[index, :]
    
    # 混合标签 (用于计算损失)
    y_a, y_b = y, y[index]
    return mixed_x, y_a, y_b, lam

def mixup_criterion(criterion, pred, y_a, y_b, lam):
    """混合损失"""
    return lam * criterion(pred, y_a) + (1 - lam) * criterion(pred, y_b)
```

**直觉理解**：把"猫"和"狗"的图像按 7:3 混合，标签也变成 70% 猫 + 30% 狗

### 5. CutMix —— 区域替换

```python
# 🌟 将一张图像的某个区域替换为另一张图像

def cutmix_data(x, y, alpha=1.0):
    """
    比 Mixup 更好：保留了局部特征的完整性
    """
    lam = np.random.beta(alpha, alpha)
    batch_size = x.size(0)
    index = torch.randperm(batch_size)
    
    # 生成随机裁剪区域
    _, _, H, W = x.shape
    cut_ratio = np.sqrt(1 - lam)
    cut_h = int(H * cut_ratio)
    cut_w = int(W * cut_ratio)
    
    # 随机中心点
    cx = np.random.randint(W)
    cy = np.random.randint(H)
    
    # 裁剪区域边界
    x1 = np.clip(cx - cut_w // 2, 0, W)
    x2 = np.clip(cx + cut_w // 2, 0, W)
    y1 = np.clip(cy - cut_h // 2, 0, H)
    y2 = np.clip(cy + cut_h // 2, 0, H)
    
    # 替换区域
    x[:, :, y1:y2, x1:x2] = x[index, :, y1:y2, x1:x2]
    
    # 调整混合比例
    lam = 1 - ((x2 - x1) * (y2 - y1) / (W * H))
    
    return x, y, y[index], lam
```

**直觉理解**：把另一只狗的头部区域贴到当前图像上，标签按面积比例混合

## 三、医疗影像数据增强的特殊考虑

### 1. 医疗影像的特点

```
📌 医疗影像的特殊性：
- 数据稀缺（罕见疾病可能只有几十例）
- 标注成本高（需要专业医生）
- 类别不均衡（正常样本多，病灶样本少）
- 图像质量参差不齐（不同设备、不同参数）
```

### 2. 医疗影像增强策略

```python
# 🌟 医疗影像增强的推荐配置

medical_transform = T.Compose([
    # ✅ 推荐使用的增强
    T.RandomHorizontalFlip(p=0.5),    # 水平翻转 (大多数解剖结构左右对称)
    T.RandomVerticalFlip(p=0.5),      # 垂直翻转 (某些任务适用)
    T.RandomRotation(degrees=15),     # 小角度旋转
    T.RandomAffine(degrees=0, translate=(0.1, 0.1)),  # 轻微平移
    
    # ⚠️ 谨慎使用的增强
    T.ColorJitter(brightness=0.1, contrast=0.1),  # 轻微颜色变化
    # 注意：医疗影像的颜色往往有诊断意义，不能过度变化
    
    # ❌ 通常不使用的增强
    # T.RandomHorizontalFlip(p=0.5)  # 某些器官不对称，不能翻转
    # T.RandomResizedCrop(...)       # 可能裁掉关键病灶
])
```

### 3. 分割任务的数据增强

```python
# 🌟 分割任务需要同步增强图像和标签

class SegmentationTransform:
    def __init__(self):
        self.image_transform = T.Compose([
            T.RandomHorizontalFlip(p=0.5),
            T.RandomRotation(degrees=15),
            T.ColorJitter(brightness=0.1, contrast=0.1),
        ])
        self.mask_transform = T.Compose([
            T.RandomHorizontalFlip(p=0.5),
            T.RandomRotation(degrees=15),
            # 注意：mask 不能做颜色变换！
        ])
    
    def __call__(self, image, mask):
        # 使用相同的随机种子
        seed = np.random.randint(2147483647)
        
        torch.manual_seed(seed)
        image = self.image_transform(image)
        
        torch.manual_seed(seed)  # 相同的随机种子
        mask = self.mask_transform(mask)
        
        return image, mask
```

## 四、数据增强的使用技巧

### 1. 训练时 vs 推理时

```python
# 🌟 数据增强只在训练时使用！

# 训练时
train_transform = T.Compose([
    T.RandomHorizontalFlip(p=0.5),
    T.RandomRotation(degrees=15),
    T.ToTensor(),
    T.Normalize(mean=[0.485, 0.456, 0.406], 
                std=[0.229, 0.224, 0.225]),
])

# 推理时（不做随机增强）
val_transform = T.Compose([
    T.ToTensor(),
    T.Normalize(mean=[0.485, 0.456, 0.406], 
                std=[0.229, 0.224, 0.225]),
])

# 在 DataLoader 中使用
train_dataset = datasets.ImageFolder('train/', transform=train_transform)
val_dataset = datasets.ImageFolder('val/', transform=val_transform)
```

### 2. 增强强度的选择

```
📌 增强强度的选择原则：

数据量小 (< 1000 张)：
- 增强强度要大
- 多种增强方法组合
- 目标：大幅增加数据多样性

数据量中等 (1000-10000 张)：
- 增强强度适中
- 选择与任务相关的增强方法
- 目标：适度增加多样性

数据量大 (> 10000 张)：
- 增强强度可以小
- 只用基础增强（翻转、旋转）
- 目标：防止过拟合
```

### 3. 在线增强 vs 离线增强

```
📌 在线增强 (On-the-fly)：
- 每个 batch 加载时实时做增强
- 优点：无限数据多样性，不占存储
- 缺点：增加训练时间

📌 离线增强 (Offline)：
- 提前生成增强后的图像保存到磁盘
- 优点：训练时不增加计算量
- 缺点：存储空间大，多样性有限

推荐：通常用在线增强，除非数据量极大或增强计算很重
```

## 五、对整体学习路线的影响

### 1. 在后续任务中的应用

| 任务 | 数据增强策略 |
|------|-------------|
| **UNet** | 几何变换为主，颜色变换谨慎，同步增强 mask |
| **YOLO** | Mosaic 增强（拼接 4 张图）、MixUp、随机裁剪 |
| **FaceNet** | 人脸对齐、光照变化、轻微遮挡 |
| **Transformer** | RandAugment（自动搜索增强策略） |

### 2. 与其他技术的配合

```
数据增强 + Batch Normalization：
- BN 对 batch 的统计量敏感
- 数据增强增加了 batch 内的多样性
- BN 的效果更好

数据增强 + Dropout：
- 两者都是正则化手段
- 数据增强从数据层面增加多样性
- Dropout 从模型层面增加随机性
- 通常可以同时使用

数据增强 + 学习率调度：
- 数据增强相当于增加了训练难度
- 初期可能需要更小的学习率
- 后期可以适当增大学习率
```

import torch
from torchvision import transforms as T
from torchvision import datasets
from torch.utils.data import DataLoader

# 定义增强策略
train_transform = T.Compose([
    T.RandomHorizontalFlip(p=0.5),
    T.RandomRotation(degrees=15),
    T.RandomResizedCrop(224, scale=(0.8, 1.0)),
    T.ColorJitter(brightness=0.2, contrast=0.2, saturation=0.2),
    T.ToTensor(),
    T.Normalize(mean=[0.485, 0.456, 0.406], 
                std=[0.229, 0.224, 0.225]),
    T.RandomErasing(p=0.5, scale=(0.02, 0.33)),
])

val_transform = T.Compose([
    T.Resize(256),
    T.CenterCrop(224),
    T.ToTensor(),
    T.Normalize(mean=[0.485, 0.456, 0.406], 
                std=[0.229, 0.224, 0.225]),
])

# 创建数据集
train_dataset = datasets.ImageFolder('data/train/', transform=train_transform)
val_dataset = datasets.ImageFolder('data/val/', transform=val_transform)

# 创建 DataLoader
train_loader = DataLoader(train_dataset, batch_size=32, shuffle=True)
val_loader = DataLoader(val_dataset, batch_size=32, shuffle=False)

print(f"训练集大小: {len(train_dataset)}")
print(f"验证集大小: {len(val_dataset)}")
print(f"每个 epoch 的 batch 数: {len(train_loader)}")
