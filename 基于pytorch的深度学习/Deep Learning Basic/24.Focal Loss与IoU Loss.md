## 一、Focal Loss

### 1. 为什么需要 Focal Loss？

```
📌 核心问题：类别不均衡时，简单样本主导损失

场景：目标检测中，背景占 99%，目标占 1%

问题：
- 大量简单背景样本的损失很小，但数量多
- 少量困难目标样本的损失大，但数量少
- 总损失被简单背景主导
- 模型学不到如何检测困难目标

交叉熵损失的局限：
- CE = -log(p_t)
- 对于简单样本 (p_t = 0.9)：CE = 0.1
- 对于困难样本 (p_t = 0.1)：CE = 1.0
- 简单样本虽然损失小，但数量是困难样本的 99 倍！
```

### 2. Focal Loss 的核心思想

```
💡 核心直觉：给简单样本降权，让模型聚焦于困难样本

Focal Loss 的设计：
FL = -α_t * (1 - p_t)^γ * log(p_t)

关键因子：(1 - p_t)^γ
- 对于简单样本 (p_t 接近 1)：(1-p_t)^γ ≈ 0，损失被大幅降低
- 对于困难样本 (p_t 接近 0)：(1-p_t)^γ ≈ 1，损失几乎不变
- γ (gamma) 是聚焦参数，越大对简单样本的惩罚越轻
```

### 3. Focal Loss 的公式

```python
# 🌟 Focal Loss 的完整公式

# 标准 Focal Loss
FL(p_t) = -α_t * (1 - p_t)^γ * log(p_t)

# 其中：
# p_t = 模型预测正确类别的概率
# γ (gamma) = 聚焦参数，通常取 2.0
# α_t = 类别权重，用于平衡正负样本

# 对于二分类：
# p_t = p (如果标签=1)
# p_t = 1-p (如果标签=0)

# α_t 的选择：
# 正样本 (目标)：α = 0.25
# 负样本 (背景)：α = 0.75
# 或者根据类别频率动态调整
```

### 4. PyTorch 实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class FocalLoss(nn.Module):
    def __init__(self, alpha=0.25, gamma=2.0, reduction='mean'):
        """
        alpha: 正样本权重
        gamma: 聚焦参数
        reduction: 'mean' | 'sum' | 'none'
        """
        super(FocalLoss, self).__init__()
        self.alpha = alpha
        self.gamma = gamma
        self.reduction = reduction
    
    def forward(self, pred, target):
        """
        pred: 模型输出 (logits)，形状 [batch, num_classes]
        target: 真实标签 (类别索引)，形状 [batch]
        """
        # 计算交叉熵损失
        ce_loss = F.cross_entropy(pred, target, reduction='none')
        
        # 计算 p_t
        p_t = torch.exp(-ce_loss)  # p_t = exp(-CE) = 模型预测正确类别的概率
        
        # 计算 alpha_t
        alpha_t = torch.where(target == 1, self.alpha, 1 - self.alpha)
        
        # 计算 Focal Loss
        focal_loss = alpha_t * (1 - p_t) ** self.gamma * ce_loss
        
        if self.reduction == 'mean':
            return focal_loss.mean()
        elif self.reduction == 'sum':
            return focal_loss.sum()
        else:
            return focal_loss

# 多类别 Focal Loss
class MultiClassFocalLoss(nn.Module):
    def __init__(self, alpha=None, gamma=2.0, reduction='mean'):
        """
        alpha: 每个类别的权重，形状 [num_classes]
        gamma: 聚焦参数
        """
        super(MultiClassFocalLoss, self).__init__()
        if alpha is None:
            self.alpha = torch.ones(num_classes)
        else:
            self.alpha = alpha
        self.gamma = gamma
        self.reduction = reduction
    
    def forward(self, pred, target):
        """
        pred: [batch, num_classes] (logits)
        target: [batch] (类别索引)
        """
        ce_loss = F.cross_entropy(pred, target, reduction='none')
        p_t = torch.exp(-ce_loss)
        
        # 获取每个样本对应类别的 alpha
        alpha_t = self.alpha[target]
        
        focal_loss = alpha_t * (1 - p_t) ** self.gamma * ce_loss
        
        if self.reduction == 'mean':
            return focal_loss.mean()
        elif self.reduction == 'sum':
            return focal_loss.sum()
        else:
            return focal_loss
```

## 二、IoU Loss

### 1. 为什么需要 IoU Loss？

```
📌 核心问题：L1/L2 Loss 不能反映"重合度"

场景：目标检测中的边界框回归

问题：
- L1 Loss：衡量坐标差的绝对值
- L2 Loss：衡量坐标差的平方
- 但这两个指标不能反映预测框和真实框的重合程度

例子：
假设真实框是 [100, 100, 200, 200]

预测框 A：[110, 110, 210, 210]
- L1 Loss = |110-100| + |110-100| + |210-200| + |210-200| = 40
- IoU = 0.73

预测框 B：[100, 100, 150, 150]
- L1 Loss = |100-100| + |100-100| + |150-200| + |150-200| = 100
- IoU = 0.25

L1 Loss 认为 B 更差，但 IoU 认为 A 更好！
IoU 更符合我们对"检测质量"的直觉
```

### 2. IoU (Intersection over Union) 的定义

```python
# 🌟 IoU 的计算

def compute_iou(box1, box2):
    """
    box1, box2: [x1, y1, x2, y2] 格式
    返回：IoU 值
    """
    # 计算交集区域
    x1 = max(box1[0], box2[0])
    y1 = max(box1[1], box2[1])
    x2 = min(box1[2], box2[2])
    y2 = min(box1[3], box2[3])
    
    intersection = max(0, x2 - x1) * max(0, y2 - y1)
    
    # 计算并集区域
    area1 = (box1[2] - box1[0]) * (box1[3] - box1[1])
    area2 = (box2[2] - box2[0]) * (box2[3] - box2[1])
    union = area1 + area2 - intersection
    
    # 计算 IoU
    iou = intersection / (union + 1e-8)  # 防止除 0
    
    return iou
```

### 3. IoU Loss

```python
# 🌟 IoU Loss = 1 - IoU

class IoULoss(nn.Module):
    def __init__(self, reduction='mean'):
        super(IoULoss, self).__init__()
        self.reduction = reduction
    
    def forward(self, pred, target):
        """
        pred: [batch, 4] (x1, y1, x2, y2)
        target: [batch, 4] (x1, y1, x2, y2)
        """
        # 计算交集
        x1 = torch.max(pred[:, 0], target[:, 0])
        y1 = torch.max(pred[:, 1], target[:, 1])
        x2 = torch.min(pred[:, 2], target[:, 2])
        y2 = torch.min(pred[:, 3], target[:, 3])
        
        intersection = torch.clamp(x2 - x1, min=0) * torch.clamp(y2 - y1, min=0)
        
        # 计算并集
        area_pred = (pred[:, 2] - pred[:, 0]) * (pred[:, 3] - pred[:, 1])
        area_target = (target[:, 2] - target[:, 0]) * (target[:, 3] - target[:, 1])
        union = area_pred + area_target - intersection
        
        # 计算 IoU
        iou = intersection / (union + 1e-8)
        
        # IoU Loss
        loss = 1 - iou
        
        if self.reduction == 'mean':
            return loss.mean()
        elif self.reduction == 'sum':
            return loss.sum()
        else:
            return loss
```

## 三、IoU Loss 的变体

### 1. GIoU (Generalized IoU)

```python
# 🌟 GIoU：解决 IoU 的两个问题

# 问题 1：当 IoU = 0 时，梯度为 0，无法优化
# 问题 2：IoU 不能反映两个框的距离关系

# GIoU 的改进：
# GIoU = IoU - (C - |A∪B|) / |C|
# 其中 C 是两个框的最小外接矩形

class GIoULoss(nn.Module):
    def __init__(self, reduction='mean'):
        super(GIoULoss, self).__init__()
        self.reduction = reduction
    
    def forward(self, pred, target):
        """
        pred: [batch, 4] (x1, y1, x2, y2)
        target: [batch, 4] (x1, y1, x2, y2)
        """
        # 计算 IoU
        x1 = torch.max(pred[:, 0], target[:, 0])
        y1 = torch.max(pred[:, 1], target[:, 1])
        x2 = torch.min(pred[:, 2], target[:, 2])
        y2 = torch.min(pred[:, 3], target[:, 3])
        
        intersection = torch.clamp(x2 - x1, min=0) * torch.clamp(y2 - y1, min=0)
        
        area_pred = (pred[:, 2] - pred[:, 0]) * (pred[:, 3] - pred[:, 1])
        area_target = (target[:, 2] - target[:, 0]) * (target[:, 3] - target[:, 1])
        union = area_pred + area_target - intersection
        
        iou = intersection / (union + 1e-8)
        
        # 计算外接矩形 C
        c_x1 = torch.min(pred[:, 0], target[:, 0])
        c_y1 = torch.min(pred[:, 1], target[:, 1])
        c_x2 = torch.max(pred[:, 2], target[:, 2])
        c_y2 = torch.max(pred[:, 3], target[:, 3])
        
        area_c = (c_x2 - c_x1) * (c_y2 - c_y1)
        
        # 计算 GIoU
        giou = iou - (area_c - union) / (area_c + 1e-8)
        
        # GIoU Loss
        loss = 1 - giou
        
        if self.reduction == 'mean':
            return loss.mean()
        elif self.reduction == 'sum':
            return loss.sum()
        else:
            return loss
```

### 2. DIoU (Distance IoU)

```python
# 🌟 DIoU：同时考虑重叠面积和中心点距离

# DIoU = IoU - ρ²(b, b_gt) / c²
# 其中：
# ρ²(b, b_gt) = 两个框中心点的欧氏距离平方
# c² = 外接矩形对角线长度的平方

class DIoULoss(nn.Module):
    def __init__(self, reduction='mean'):
        super(DIoULoss, self).__init__()
        self.reduction = reduction
    
    def forward(self, pred, target):
        # 计算 IoU（同上）
        ...
        
        # 计算中心点
        pred_center_x = (pred[:, 0] + pred[:, 2]) / 2
        pred_center_y = (pred[:, 1] + pred[:, 3]) / 2
        target_center_x = (target[:, 0] + target[:, 2]) / 2
        target_center_y = (target[:, 1] + target[:, 3]) / 2
        
        # 中心点距离平方
        center_distance = (pred_center_x - target_center_x) ** 2 + \
                         (pred_center_y - target_center_y) ** 2
        
        # 外接矩形对角线平方
        c_x1 = torch.min(pred[:, 0], target[:, 0])
        c_y1 = torch.min(pred[:, 1], target[:, 1])
        c_x2 = torch.max(pred[:, 2], target[:, 2])
        c_y2 = torch.max(pred[:, 3], target[:, 3])
        
        diagonal_distance = (c_x2 - c_x1) ** 2 + (c_y2 - c_y1) ** 2
        
        # DIoU
        diou = iou - center_distance / (diagonal_distance + 1e-8)
        
        # DIoU Loss
        loss = 1 - diou
        
        if self.reduction == 'mean':
            return loss.mean()
        elif self.reduction == 'sum':
            return loss.sum()
        else:
            return loss
```

### 3. CIoU (Complete IoU)

```python
# 🌟 CIoU：在 DIoU 基础上加入宽高比

# CIoU = IoU - ρ²(b, b_gt) / c² - α * v
# 其中：
# v = 4/π² * (arctan(w_gt/h_gt) - arctan(w/h))²  # 宽高比一致性
# α = v / ((1 - IoU) + v)  # 权重因子

class CIoULoss(nn.Module):
    def __init__(self, reduction='mean'):
        super(CIoULoss, self).__init__()
        self.reduction = reduction
    
    def forward(self, pred, target):
        # 计算 IoU（同上）
        ...
        
        # 计算 DIoU（同上）
        ...
        
        # 计算宽高比
        pred_w = pred[:, 2] - pred[:, 0]
        pred_h = pred[:, 3] - pred[:, 1]
        target_w = target[:, 2] - target[:, 0]
        target_h = target[:, 3] - target[:, 1]
        
        v = (4 / (torch.pi ** 2)) * \
            (torch.atan(target_w / (target_h + 1e-8)) - \
             torch.atan(pred_w / (pred_h + 1e-8))) ** 2
        
        alpha = v / (1 - iou + v + 1e-8)
        
        # CIoU
        ciou = diou - alpha * v
        
        # CIoU Loss
        loss = 1 - ciou
        
        if self.reduction == 'mean':
            return loss.mean()
        elif self.reduction == 'sum':
            return loss.sum()
        else:
            return loss
```

## 四、IoU Loss 变体的对比

```
┌─────────────────────────────────────────────────────────────────────────┐
│  Loss     考虑因素                         优点                         │
├─────────────────────────────────────────────────────────────────────────┤
│  IoU      重叠面积                         最简单，直接优化 IoU          │
│  GIoU     重叠面积 + 外接矩形               解决 IoU=0 时梯度为 0 的问题 │
│  DIoU     重叠面积 + 中心点距离             收敛更快，对位置更敏感        │
│  CIoU     重叠面积 + 中心点距离 + 宽高比     最全面，YOLOv5/v8 使用      │
└─────────────────────────────────────────────────────────────────────────┘

📌 选择建议：
- 简单任务：IoU Loss 或 GIoU Loss
- 目标检测：CIoU Loss（YOLOv5/v8 的默认选择）
- 实时检测：DIoU Loss（计算更快）
```

## 五、对整体学习路线的影响

### 1. 在后续任务中的应用

| 任务 | 使用的损失函数 |
|------|---------------|
| **UNet** | Dice Loss + CrossEntropy |
| **YOLO** | CIoU Loss + BCE Loss (置信度) + CrossEntropy (分类) |
| **FaceNet** | Triplet Loss 或 ArcFace Loss |

### 2. 与评估指标的关系

```
📌 Focal Loss 和 IoU Loss 都是"指标对齐"的损失函数：

Focal Loss：
- 优化目标：让模型关注困难样本
- 评估指标：通常与分类指标 (F1, AUC) 相关

IoU Loss：
- 优化目标：直接优化 IoU
- 评估指标：mAP@0.5, mAP@0.5:0.95 都基于 IoU

使用这些损失函数，训练目标和评估目标一致，效果更好
```
