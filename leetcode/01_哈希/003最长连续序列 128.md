```cpp
#include <vector>
#include <unordered_set>
using namespace std;

class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        unordered_set<int> st(nums.begin(), nums.end());
        int maxLen = 0;

        for(int x : st)
        {
            // x-1不在集合，说明x是序列起点
            if(!st.count(x - 1))
            {
                int cur = x;
                int len = 1;
                while(st.count(cur + 1))
                {
                    cur++;
                    len++;
                }
                maxLen = max(maxLen, len);
            }
        }
        return maxLen;
    }
};
```

## 关键数据结构 `unordered_set<int>`

- 底层哈希表，插入、`count()`查找平均时间 \(O(1)\)
- 会**自动去重**，重复数字只会存一份，避免重复计算
- `st.count(val)`：存在返回 1，不存在返回 0

## 核心逻辑：只从序列起点开始遍历

> 示例数组：`[100,4,200,1,3,2]`，集合 {100,4,200,1,3,2}

判断条件：`if(!st.count(x-1))`

- x=100：`99`不在集合 → **起点**，向后找 101，没有，长度 = 1
- x=4：`3`存在，不是起点，直接跳过，**不进入 while 循环**
- x=200：`199`不在集合 →起点，长度 = 1
- x=1：`0`不在集合 →起点；进入 while 循环：找 2、3、4，len 累加到 4
- x=3：`2`存在，跳过
- x=2：`1`存在，跳过

> 为什么整体复杂度是 \(O(n)\)？ 每个数字只会被 while 循环访问一次。比如序列`1,2,3,4`：只有 x=1 进入 while，2、3、4 直接被外层 for 跳过，不会重复循环。

### 变量说明

1. `maxLen`：记录全局最长连续序列长度，初始 0；空集合直接返回 0。
2. `cur`：当前向后探测到的数字。
3. `len`：当前这一段连续序列的长度。

## 边界情况

1. `nums = []` 空数组：`st`为空，for 循环不执行，返回`maxLen=0`
2. `nums = [0]`：返回 1
3. 大量重复：`[2,2,2]`，集合只有 {2}，返回 1。

# 原题

给定一个未排序的整数数组 `nums` ，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

**示例 1：**

**输入：**nums = [100,4,200,1,3,2]
**输出：**4
**解释：**最长数字连续序列是 [1, 2, 3, 4]。它的长度为 4。

**示例 2：**

**输入：**nums = [0,3,7,2,5,8,4,6,0,1]
**输出：**9

**示例 3：**

**输入：**nums = [1,0,1,2]
**输出：**3
