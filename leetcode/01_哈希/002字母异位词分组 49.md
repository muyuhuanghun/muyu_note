```cpp
#include <vector>
#include <string>
#include <unordered_map>
#include <algorithm>

using namespace std;

class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        unordered_map<string, vector<string>> mp;
        for (const string& s : strs) {
            string key = s;          // 拷贝原串，避免修改输入
            sort(key.begin(), key.end()); // 排序生成key
            mp[key].push_back(s);    // 原串归入对应分组
        }
        vector<vector<string>> ans;
        for (auto& pair : mp) {
            ans.push_back(pair.second);
        }
        return ans;
    }
};
```

lambda自定义排序，二维数组
```cpp
vector<pair<int,int>> vec = {{2,3},{1,5},{1,2}};
// 第一key升序；key相等，第二key降序
sort(vec.begin(), vec.end(), [](const pair<int,int>& x, const pair<int,int>& y){
    if(x.first != y.first)
        return x.first < y.first;
    return x.second > y.second;
});
```

sort可对结构体中的数字排序

```cpp
#include <vector>
#include <algorithm>
#include <string>
using namespace std;

struct Student
{
    string name;
    int score;
};
int main()
{
    vector<Student> stus = {
        {"zhangsan", 80},
        {"lisi", 60},
        {"wangwu", 90}
    };
    // lambda比较器，const&避免拷贝
    sort(stus.begin(), stus.end(), [](const Student& a, const Student& b)
    {
        return a.score < b.score;    // a.score更小，a放前面 → 升序
    });
    return 0;
}
```


# 原题

给你一个字符串数组，请你将 字母异位词 组合在一起。可以按任意顺序返回结果列表。

**示例 1:**

**输入:** strs = [ "eat", "tea", "tan", "ate", "nat", "bat"]

**输出:** [["bat"],["nat","tan"],["ate","eat","tea"]]

**解释：**

- 在 strs 中没有字符串可以通过重新排列来形成 `"bat"`。
- 字符串 `"nat"` 和 `"tan"` 是字母异位词，因为它们可以重新排列以形成彼此。
- 字符串 `"ate"` ，`"eat"` 和 `"tea"` 是字母异位词，因为它们可以重新排列以形成彼此。

**示例 2:**

**输入:** strs = [""]

**输出:** [[""]]

**示例 3:**

**输入:** strs = ["a"]

**输出:** [["a"]]
