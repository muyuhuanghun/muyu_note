```
#include <vector>
#include <string>
using namespace std;

class Solution {
public:
    vector<int> findAnagrams(string s, string p) {
        vector<int> res;
        int cntP[26] = {0};
        int cntS[26] = {0};
        int lenP = p.size();
        int lenS = s.size();
        if(lenS < lenP) return res;

        //初始化p的计数，s的第一个窗口
        for(int i = 0; i < lenP; i++)
        {
            cntP[p[i]-'a']++;
            cntS[s[i]-'a']++;
        }

        //判断第一个窗口是否匹配
        bool ok = true;
        for(int i = 0; i < 26; i++)
        {
            if(cntS[i] != cntP[i]){
                ok = false;
                break;
            }
        }
        if(ok) res.push_back(0);

        //滑动窗口向右移动
        for(int right = lenP; right < lenS; right++)
        {
            //移出窗口左边字符
            int leftOut = s[right - lenP] - 'a';
            cntS[leftOut]--;
            //加入新的右边字符
            int newIn = s[right] - 'a';
            cntS[newIn]++;

            //对比26个字母计数
            ok = true;
            for(int i = 0; i < 26; i++)
            {
                if(cntS[i] != cntP[i])
                {
                    ok = false;
                    break;
                }
            }
            if(ok)
            {
                res.push_back(right - lenP + 1);
            }
        }
        return res;
    }
};
```

- `ntP`统计模式串`p`每个字母出现多少次
- `cntS`统计 s 当前窗口内每个字母出现多少次 窗口匹配条件：**26 个位置，cntS [i] == cntP [i] 全部成立**，代表窗口是异位词。

## 方法二：diff 差异计数优化（最优，不用每次循环 26 次）

只维护**一个 cnt 数组**：`cnt[i] = 窗口内字符i次数 − p中字符i次数`

- `cnt[i]==0`：该字符两边次数相等
- `diff`变量：记录有多少个字母`cnt[i]≠0`（不匹配的字符数量）
- 当`diff == 0`：代表全部字符匹配，当前窗口就是异位词。

> 核心：窗口移动时，只修改进出的两个字符，动态更新 diff，**不需要遍历全部 26 个字母**。

```
class Solution {
public:
    vector<int> findAnagrams(string s, string p) {
        vector<int> res;
        int cnt[26] = {0};
        int lenS = s.size(), lenP = p.size();
        if(lenS < lenP) return res;

        //初始化窗口
        for(int i = 0; i < lenP; ++i)
        {
            cnt[p[i]-'a']--;   //p的字符减1
            cnt[s[i]-'a']++;   //s窗口字符加1
        }
        //统计初始diff：不等于0的字符数量
        int diff = 0;
        for(int i = 0; i < 26; i++)
        {
            if(cnt[i] != 0) diff++;
        }
        if(diff == 0) res.push_back(0);

        for(int right = lenP; right < lenS; right++)
        {
            //【移出窗口的字符 out】
            int out = s[right - lenP] - 'a';
            if(cnt[out] == 1) diff--; //原来不匹配，删掉之后变匹配，diff减少
            cnt[out]--;
            if(cnt[out] == 0) diff++; //修改后变成匹配，diff增加

            //【移入窗口的字符 in】
            int in = s[right] - 'a';
            if(cnt[in] == 0) diff--;
            cnt[in]++;
            if(cnt[in] == 1) diff++;

            //diff等于0，完全匹配
            if(diff == 0)
            {
                res.push_back(right - lenP + 1);
            }
        }
        return res;
    }
};
```

### diff 逻辑详解（重点）

以移出字符`out`举例：

1. 修改前，如果`cnt[out]==1`：说明这个字符之前是不匹配的；我们对它`cnt--`之后就变成 0，匹配了 →`diff -=1`
2. 执行`cnt[out]--`
3. 修改完成后，如果`cnt[out]==0`：说明修改后变成不匹配，→`diff +=1`

移入字符`in`逻辑同理。

> 只处理进出的两个字符，其余字符完全不管。

# 原题
给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的 **异位词** 的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

**示例 1:**

**输入:** s = "cbaebabacd", p = "abc"
**输出:** [0,6]
**解释:**
起始索引等于 0 的子串是 "cba", 它是 "abc" 的异位词。
起始索引等于 6 的子串是 "bac", 它是 "abc" 的异位词。

 **示例 2:**

**输入:** s = "abab", p = "ab"
**输出:** [0,1,2]
**解释:**
起始索引等于 0 的子串是 "ab", 它是 "ab" 的异位词。
起始索引等于 1 的子串是 "ba", 它是 "ab" 的异位词。
起始索引等于 2 的子串是 "ab", 它是 "ab" 的异位词。
