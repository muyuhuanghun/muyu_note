```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        vector<vector<int>> res;
        sort(nums.begin(),nums.end());
        int n = nums.size();
        for(int i = 0 ;i < n ;i++)
        {
            if(i>0&&nums[i]==nums[i-1])
            {
                continue;
            }
            int left = i + 1;
            int right = n - 1;
            while(left < right)
            {
                int sum = nums[i] + nums[left] + nums[right];
                if(sum == 0)
                {
                    res.push_back({nums[i],nums[left],nums[right]});
                    while(left<right && nums[left]==nums[left+1])
                    {
                        left++;
                    }
                    while(left<right && nums[right]==nums[right-1])
                    {
                        right--;
                    }
                    left++;
                    right--;
                }
                else if(sum<0)
                {
                    left++;
                }
                else
                {
                    right--;
                }
            }
        }
        return res;
    }
};
```

排序先行，转化为一个数固定的两数之和，维护左/右指针，判断sum与0的关系，决定指针移动

判重需要两次，外部针对非0的重复，内部二次判重筛选出大量0的重复

先把数组排序，外层循环固定第一个数，跳过重复值。内部用左右双指针在 i 右侧找另外两个数，计算三数之和；等于 0 保存答案，同时跳过左右指针重复元素，和偏小左移，偏大右移。

### 三处重复判定

1. **i 层去重（第一个数）**`if(i>0 && nums[i]==nums[i-1]) continue;` i 和前一个数相同，跳过，避免相同的第一个数生成重复三元组。
2. **left 去重（第二个数）** 找到解后：`while(left<right && nums[left]==nums[left+1]) left++;` 跳过 left 后面相等的数，防止第二个数重复。
3. **right 去重（第三个数）** 找到解后：`while(left<right && nums[right]==nums[right-1]) right--;` 跳过 right 前面相等的数，防止第三个数重复。

> 只在**找到一组答案之后**执行 left、right 的去重，之后再`left++、right--`。

# 原题

给你一个整数数组 `nums` ，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k` ，同时还满足 `nums[i] + nums[j] + nums[k] == 0` 。请你返回所有和为 `0` 且不重复的三元组。

**注意：**答案中不可以包含重复的三元组。

**示例 1：**

**输入：**nums = [-1,0,1,2,-1,-4]
**输出：**[[-1,-1,2],[-1,0,1]]
**解释：**
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0 。
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0 。
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0 。
不同的三元组是 [-1,0,1] 和 [-1,-1,2] 。
注意，输出的顺序和三元组的顺序并不重要。

**示例 2：**

**输入：**nums = [0,1,1]
**输出：**[]
**解释：**唯一可能的三元组和不为 0 。

**示例 3：**

**输入：**nums = [0,0,0]
**输出：**[[0,0,0]]
**解释：**唯一可能的三元组和为 0 。
