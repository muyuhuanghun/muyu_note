## 核心思路：单调队列

题目要求每个长度为 `k` 的窗口中的最大值。

暴力做法是每个窗口遍历一遍找最大值，时间复杂度是：

```
O(n * k)
```

会超时。

更好的方法是维护一个 **单调递减队列**。

队列中存的是 **数组下标**，并且这些下标对应的值从队首到队尾是递减的。

也就是说：

```
nums[deque[0]] >= nums[deque[1]] >= nums[deque[2]] ...
```

这样队首元素永远是当前窗口的最大值。

---

## C++ 代码

```
#include <vector>
#include <deque>
using namespace std;

class Solution {
public:
    vector<int> maxSlidingWindow(vector<int>& nums, int k) {
        deque<int> q;          // 存下标，不直接存值
        vector<int> ans;

        for (int i = 0; i < nums.size(); i++) {
            // 1. 删除已经滑出窗口的下标
            // 当前窗口范围是 [i - k + 1, i]
            // 如果队首下标 <= i - k，说明它已经不在窗口内
            while (!q.empty() && q.front() <= i - k) {
                q.pop_front();
            }

            // 2. 维护单调递减队列
            // 如果当前元素 nums[i] >= 队尾元素 nums[q.back()]
            // 那么队尾元素不可能再成为后续窗口最大值
            while (!q.empty() && nums[q.back()] <= nums[i]) {
                q.pop_back();
            }

            // 3. 当前下标入队
            q.push_back(i);

            // 4. 当窗口形成后，队首就是当前窗口最大值
            if (i >= k - 1) {
                ans.push_back(nums[q.front()]);
            }
        }

        return ans;
    }
};
```

---

## 为什么队列里存下标，而不是存值？

因为我们需要判断一个元素是否已经滑出窗口。

例如当前遍历到下标 `i`，窗口长度是 `k`，那么当前窗口范围是：

```
[i - k + 1, i]
```

如果队首下标：

```
q.front() <= i - k
```

说明它已经在窗口左边之外了，需要弹出。

如果只存值，就没办法知道它的位置。

---

## 维护单调递减队列的原因

假设当前元素是 `nums[i]`，队尾元素是 `nums[q.back()]`。

如果：

```
nums[q.back()] <= nums[i]
```

那么队尾元素可以直接删除。

原因是：

1. `nums[i]` 比它大或者相等；
2. `i` 的位置比它靠后；
3. 在未来窗口中，只要它还存在，`nums[i]` 一定也还存在得更久；
4. 所以队尾元素永远不可能再成为最大值。

因此可以放心删除队尾较小的元素。

# 原题

给你一个整数数组 `nums`，有一个大小为 `k` 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 `k` 个数字。滑动窗口每次只向右移动一位。

返回 _滑动窗口中的最大值_ 。

**示例 1：**

**输入：**nums = [1,3,-1,-3,5,3,6,7], k = 3
**输出：**[3,3,5,5,6,7]
**解释：**
滑动窗口的位置                最大值
---------------               -----
[1  3  -1] -3  5  3  6  7       **3**
 1 [3  -1  -3] 5  3  6  7       **3**
 1  3 [-1  -3  5] 3  6  7      **5**
 1  3  -1 [-3  5  3] 6  7       **5**
 1  3  -1  -3 [5  3  6] 7       **6**
 1  3  -1  -3  5 [3  6  7]      **7**

**示例 2：**

**输入：**nums = [1], k = 1
**输出**[1]

**提示：**

- `1 <= nums.length <= 105`
- `-104 <= nums[i] <= 104`
- `1 <= k <= nums.length`
