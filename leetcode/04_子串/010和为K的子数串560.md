```
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        unordered_map<int , int > mp;
        mp[0] = 1;
        int presum = 0 ;
        int ans = 0;
        for(int x : nums)
        {
            presum += x;
            if(mp.count(presum - k))
            {
                ans +=mp[presum - k];
            }
            mp[presum]++;
        }
        return ans;
    }
};
```

## 题目复述

给定整数数组 `nums` 和整数 `k`，求**连续子数组**，子数组总和等于 `k` 的总个数。

> 子数组：元素必须在原数组中连续；数组可以包含**负数、0**。 子数组不同起点 / 终点就算不同，哪怕数值一样。

示例：`nums = [1,1,1], k=2` 满足条件：`[0,1]`、`[1,2]` → 答案 = 2

---

## 为什么不能用滑动窗口（双指针）

滑动窗口（左右指针伸缩）成立前提：**窗口增加元素，总和单调变化**。 本题有负数：窗口扩大，总和可能变小；窗口缩小，总和可能变大。 单调性消失，双指针无法正确收缩，**不能用**。

> 暴力思路：枚举左端点 i，不断向右累加，统计 sum == k。O (n²)，大数据超时。 需要 O (n) 算法：**前缀和 + 哈希表计数**

## 核心：前缀和

定义前缀和数组： `preSum[i]` = 数组前 i 项之和，也就是 `nums[0] ~ nums[i-1]` 的总和。

$$

\begin{aligned}
preSum[0] &= 0 \\
preSum[1] &= nums[0] \\
preSum[2] &= nums[0]+nums[1] \\
preSum[i] &= \sum_{t=0}^{i-1} nums[t]
\end{aligned}
$$

子数组 `[j, i-1]`（从下标 j 到 i-1，包含两端）的和：

$$
\boldsymbol{sum = preSum[i] - preSum[j]}
$$

我们想要 `sum = k`

$$
\boldsymbol {preSum[i] - preSum[j] = k}
$$

移项：

$$
\boldsymbol{preSum[j] = preSum[i] - k}
$$

### 这句话最重要

> 遍历到 i 位置时，**前面有多少个 j 满足前缀和等于 `preSum[i]−k`，就代表以 i-1 结尾，有多少个符合条件的子数组**。

例子： `preSum[i]=3，k=2` → 去找前面有几个`preSum[j]=1`，每一个 j 对应一段子数组和为 2。

## 哈希表作用

`unordered_map<int, int> mp`

- key：前缀和的值
- value：这个前缀和**出现过多少次**

初始化：`mp[0]=1`

> 含义：前缀和 = 0 预先出现 1 次。 用来处理这种场景：`preSum[i] == k`，此时`preSum[j]=0`，代表从数组开头到 i-1 的子数组直接满足条件。

## 遍历流程（边算前缀和，边查哈希表）

1. 初始：`preSum=0, ans=0, mp={0:1}`
2. 逐个读取数组元素，更新`preSum += x`
3. 查询：`mp.count(preSum - k)`，如果存在，ans 加上`mp[preSum−k]`
4. **查询完成之后**，再把当前 preSum 存入哈希表，计数 + 1

> ⚠️顺序不能颠倒！必须**先查询，再插入**，避免把当前 preSum 算进本次查询（j 必须在 i 前面）
