# 工具集总览

📌 从本科到研究生阶段高频使用的脚本与工具集合，按场景分门别类。

# ==========================================
# 📁 目录结构
# ==========================================

```
工具集/
├── 00.工具集总览.md              ← 本文件
├── 01.文件管理/                  ← 批量重命名、文件整理、重复文件查找
├── 02.学习辅助/                  ← Anki卡片生成、番茄钟、Deadline追踪
├── 03.科研工具/                  ← 论文管理、实验数据处理、BibTeX、arXiv
├── 04.编程辅助/                  ← 代码模板生成、自动测试、项目脚手架
├── 05.Git与版本控制/             ← Git批量操作、仓库分析
├── 06.服务器与环境/              ← 开发环境配置、SLURM任务提交
├── 07.笔记与知识管理/            ← Obsidian链接检查、笔记统计
├── 08.网络与安全/                ← 端口扫描、HTTP服务器、网络信息、密码工具
├── 09.文本与数据处理/            ← JSON/CSV转换、文本对比、编码转换、批量替换
├── 10.图片处理/                  ← 图片批量处理、EXIF管理（需Pillow）
├── 11.系统工具/                  ← 系统信息收集、磁盘分析、进程监控
├── 12.数据库工具/                ← SQLite查看器、CSV导入、结构对比
└── 13.自动化与通知/              ← 定时任务、消息通知、工作流编排
```

# ==========================================
# 🚀 快速使用
# ==========================================

所有 Python 脚本均为独立运行，无需额外安装依赖（仅使用标准库）。
科研工具中的部分脚本需要安装第三方库，详见各目录 README。

```bash
# 示例：运行文件整理脚本
python 工具集/01.文件管理/file_organizer.py /path/to/messy/folder

# 示例：生成 Anki 卡片
python 工具集/02.学习辅助/anki_card_generator.py 笔记文件.md -o 输出卡片.txt
```

# ==========================================
# 💡 使用建议
# ==========================================

1. **先读 README**：每个目录下都有 README.md，说明用途和参数
2. **先 dry-run**：涉及文件操作的脚本都支持 `--dry-run` 模式，先预览再执行
3. **按需修改**：脚本中的阈值、路径、格式等都可以按自己的习惯调整
4. **版本迭代**：随着使用场景变化，持续优化脚本逻辑
