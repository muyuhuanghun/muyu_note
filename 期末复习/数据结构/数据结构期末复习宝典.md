# 第一章 绪论

## 核心概念

- **Data_Structure = (D, R)**：D 是数据元素集合，R 是 D 上关系的集合
- **逻辑结构**：线性结构 → 树形结构 → 图形结构（表是树的特例，树是图的特例）
- **存储结构**：顺序存储 | 链式存储 | 散列存储

| 存储方式 | 原理 | 优点 | 缺点 |
|---------|------|------|------|
| 顺序存储 | 相对位置表示逻辑关系 | 随机存取，无额外空间 | 插删需移动元素，静态分配 |
| 链式存储 | 指针表示逻辑关系 | 动态分配，插删 O(1) | 不可随机存取，存储密度 < 1 |
| 散列存储 | 关键字直接计算地址 | 查找 O(1) | 冲突处理复杂 |

**ADT 三元组**：(D, R, O) — 数据对象、结构关系、基本操作
**ADT 三大特征**：信息隐蔽、数据封装、使用与实现分离

## 算法评价

**算法五大特性**：有穷性、确定性、可行性、输入、输出

### 时间复杂度

- 大 O 记号：T(n) = O(f(n))，取最高阶，忽略常数系数
- 常用阶（低→高）：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ)

```c
// 矩阵相乘示例 — 语句频度分析
for (i=0; i<n; i++)           // n+1
  for (j=0; j<n; j++) {       // n(n+1)
    c[i][j] = 0;              // n²
    for (k=0; k<n; k++)       // n²(n+1)
      c[i][j] += a[i][k]*b[k][j]; // n³
  }
// T(n) = 2n³ + 3n² + 2n + 1 → O(n³)
```

### 空间复杂度

```c
// 数组逆序 — 两种方案对比
// 方案1: 辅助数组 b[] → S(n) = O(n)
for (i=0; i<n; i++) b[i] = a[n-i-1];
for (i=0; i<n; i++) a[i] = b[i];

// 方案2: 原地交换 → S(n) = O(1)
for (i=0; i<n/2; i++) {
    t = a[i]; a[i] = a[n-i-1]; a[n-i-1] = t;
}
```

> ⚠️ **防坑**：时间复杂度以**最坏情况**计算；时间和空间往往此消彼长，需综合考量。

# 第二章 线性表

## 概念与物理存储

- **定义**：n(n≥0) 个类型相同的有限序列，一对一关系
- **三特性**：同一性（同类元素）、有穷性（有限个）、有序性（序偶关系）

### 顺序表（SeqList）

```c
#define MAXSIZE 100
typedef struct {
    ElemType elem[MAXSIZE];
    int last;  // 最后一个元素的下标，空表为 -1
} SeqList;
// 注意：元素序号 i 对应下标 i-1
```

### 单链表（LinkList）

```c
typedef struct Node {
    ElemType data;
    struct Node *next;
} Node, *LinkList;
// LinkList 用作头指针变量，Node * 用作结点指针
```

> ⚠️ **带头结点**：空表判断为 `L->next == NULL`；不带头结点：`L == NULL`

## 核心操作与算法

### 顺序表操作

| 操作 | 时间复杂度 | 要点 |
|------|-----------|------|
| 按序号查找 | O(1) | `L.elem[i-1]` |
| 按值查找 | O(n) | 顺序扫描 |
| 插入 | O(n) | 元素后移，平均移动 n/2 个 |
| 删除 | O(n) | 元素前移，平均移动 (n-1)/2 个 |

```c
// Time: O(n) | Space: O(1)
int InsList(SeqList *L, int i, ElemType e) {
    if (i<1 || i>L->last+2) return ERROR;  // 位置合法
    if (L->last >= MAXSIZE-1) return ERROR; // 表满
    for (int k=L->last; k>=i-1; k--)       // 后移
        L->elem[k+1] = L->elem[k];
    L->elem[i-1] = e;
    L->last++;
    return OK;
}
```

```c
// Time: O(n) | Space: O(1)
int DelList(SeqList *L, int i, ElemType *e) {
    if (i<1 || i>L->last+1) return ERROR;
    *e = L->elem[i-1];
    for (int k=i; k<=L->last; k++)          // 前移
        L->elem[k-1] = L->elem[k];
    L->last--;
    return OK;
}
```

### 单链表操作

| 操作 | 时间复杂度 | 说明 |
|------|-----------|------|
| 按序号查找 | O(n) | 从头扫描 |
| 按值查找 | O(n) | 从头扫描 |
| 头插法建表 | O(n) | 结点顺序与逻辑**相反** |
| 尾插法建表 | O(n) | 结点顺序与逻辑**相同** |
| 插入 | O(n) | 找前驱 + 改指针 |
| 删除 | O(n) | 找前驱 + 改指针 + free |

```c
// Time: O(n) | Space: O(1) — 单链表插入
int InsList(LinkList L, int i, ElemType e) {
    Node *pre = L; int k = 0;
    while (pre!=NULL && k<i-1) { pre=pre->next; k++; } // 找第 i-1 个
    if (pre==NULL) return ERROR;
    Node *s = (Node*)malloc(sizeof(Node));
    s->data = e;
    s->next = pre->next;  // 先接后继
    pre->next = s;         // 再接前驱
    return OK;
}
```

```c
// Time: O(n) | Space: O(1) — 单链表删除
int DelList(LinkList L, int i, ElemType *e) {
    Node *pre = L; int k = 0;
    while (pre->next!=NULL && k<i-1) { pre=pre->next; k++; }
    if (pre->next==NULL) return ERROR;
    Node *r = pre->next;
    pre->next = r->next;   // 跳过被删结点
    *e = r->data;
    free(r);
    return OK;
}
```

```c
// Time: O(n) | Space: O(1) — 带头结点单链表就地逆置
void ReverseList(LinkList L) {
    Node *p = L->next, *q;
    L->next = NULL;           // 逆置表初始为空
    while (p != NULL) {
        q = p->next;          // 保存后继
        p->next = L->next;    // 头插法
        L->next = p;
        p = q;
    }
}
```

### 顺序表合并（二路归并）

```c
// Time: O(n+m) | Space: O(n+m)
void merge(SeqList *LA, SeqList *LB, SeqList *LC) {
    int i=0, j=0, k=0;
    while (i<=LA->last && j<=LB->last)
        if (LA->elem[i] <= LB->elem[j])
            LC->elem[k++] = LA->elem[i++];
        else
            LC->elem[k++] = LB->elem[j++];
    while (i<=LA->last) LC->elem[k++] = LA->elem[i++];
    while (j<=LB->last) LC->elem[k++] = LB->elem[j++];
    LC->last = k - 1;
}
```

### 循环链表

- 无空指针域，尾结点条件：`p->next == L`
- **尾指针合并 O(1)**：`RA->next = RB->next->next; RB->next = p;`

### 双向链表

```c
typedef struct DNode {
    ElemType data;
    struct DNode *prior, *next;
} DNode, *DoubleList;
```

**前插操作（4 步）**：
```
s->prior = p->prior;
p->prior->next = s;
s->next = p;
p->prior = s;
```

**后插操作（4 步）**：
```
s->next = p->next;
p->next->prior = s;
s->prior = p;
p->next = s;
```

**删除操作（2 步 + free）**：
```
p->prior->next = p->next;
p->next->prior = p->prior;
free(p);
```

### 真题与解题套路

**顺序表三大核心模式**：
1. **双指针**（快慢指针）：顺序表删除、筛选、去重 → O(n) 原地
2. **归并**：两个有序表合并 → 双指针逐一比较
3. **求差+对齐**：链表交汇点 → 长链表先走差值步

**典型真题**：
| 编号 | 题目 | 考点 |
|:---:|:---|:---|
| 160 | 合并顺序表 | 双指针归并 |
| 176 | 整除移除 | 双指针筛选 |
| 177 | 共享结点 | 求差对齐找交汇点 |
| 197 | 保留偶数 | 双指针筛选（同 176） |
| 201 | 合并有序数组 | 归并（裸指针版） |

**解题模板**：
```c
// 顺序表双指针筛选（保留满足条件的元素）
int j = 0;
for (int i = 0; i <= L->last; i++) {
    if (满足保留条件) L->elem[j++] = L->elem[i];
}
L->last = j - 1;

// 链表共享结点：求差对齐
int lenA = getLength(LA), lenB = getLength(LB);
while (lenA > lenB) { LA = LA->next; lenA--; }
while (lenB > lenA) { LB = LB->next; lenB--; }
while (LA != LB) { LA = LA->next; LB = LB->next; }
```

## 横向对比与期末防坑

| 对比项 | 顺序表 | 单链表 | 双向链表 | 循环链表 |
|--------|--------|--------|---------|---------|
| 存储密度 | 1 (100%) | < 1 | < 1（更小） | < 1 |
| 随机存取 | ✅ O(1) | ❌ O(n) | ❌ O(n) | ❌ O(n) |
| 插删效率 | O(n) | O(1)* | O(1)* | O(1)* |
| 找前驱 | O(1) | ❌ 不可 | O(1) | ❌ 不可 |
| 空表判断 | last==-1 | L->next==NULL | 同左 | p->next==L |

*已知位置时

> ⚠️ **防坑**：
> 1. 单链表插入必须**先接后继再改前驱**，顺序反了会丢链
> 2. 头插法建表结果是**逆序**的
> 3. 删除 `free(r)` 之前必须先保存数据
> 4. 循环链表判空：带头结点 `p->next == L`，不带头结点 `p == NULL`

# 第三章 栈和队列

## 概念与物理存储

- **栈**：后进先出 (LIFO)，只在栈顶操作
- **队列**：先进先出 (FIFO)，队尾入、队头出

### 顺序栈

```c
#define MAXSIZE 100
typedef struct {
    ElemType elem[MAXSIZE];
    int top;  // 栈顶下标，空栈为 -1
} SeqStack;
```

### 链栈

```c
typedef struct StackNode {
    ElemType data;
    struct StackNode *next;
} StackNode, *LinkStack;
// top == NULL 为空栈，入/出栈均在链头操作
```

### 两栈共享

```c
typedef struct {
    ElemType elem[MAXSIZE];
    int top1, top2;  // 栈1从左增，栈2从右减
} DblStack;
// 栈满条件：top1 + 1 == top2
```

### 队列

```c
// 链队列
typedef struct QNode {
    ElemType data;
    struct QNode *next;
} QNode;
typedef struct {
    QNode *front, *rear;
} LinkQueue;
```

```c
// 循环队列
#define MAXSIZE 100
typedef struct {
    ElemType elem[MAXSIZE];
    int front, rear;
} CirQueue;
```

## 核心操作与算法

### 栈操作

```c
// Time: O(1) | Space: O(1)
void Push(SeqStack *S, ElemType e) {
    if (S->top == MAXSIZE-1) { printf("栈满"); return; }
    S->elem[++S->top] = e;
}
ElemType Pop(SeqStack *S) {
    if (S->top == -1) { printf("栈空"); return ERROR; }
    return S->elem[S->top--];
}
```

### 循环队列操作

```
入队：Q.rear = (Q.rear + 1) % MAXSIZE
出队：Q.front = (Q.front + 1) % MAXSIZE
判空：Q.front == Q.rear
判满：(Q.rear + 1) % MAXSIZE == Q.front  （牺牲一个空间）
队列长度：(Q.rear - Q.front + MAXSIZE) % MAXSIZE
```

### 带标志域循环队列

```c
typedef struct {
    ElemType elem[MAXSIZE];
    int front, rear;
    int flag;  // 最近操作：0=删除，1=插入
} FlagQueue;
// 判空：front==rear && flag==0
// 判满：front==rear && flag==1
```

## 栈的经典应用

### 表达式求值（中缀→后缀→计算）

**中缀转后缀规则**：
1. 操作数直接输出
2. `(` 入栈
3. `)` 弹栈直到遇到 `(`
4. 运算符：弹出所有优先级 ≥ 当前的运算符，再将当前入栈

**后缀表达式计算**：操作数入栈，遇运算符弹两个操作数计算后压回

### 括号匹配

遇 `(` 入栈，遇 `)` 弹栈，最终栈空则匹配

### 真题与解题套路

**三大考法**：
1. **栈模拟递归**：非递归先序/中序遍历，递归转非递归（栈的 LIFO = 递归的回溯）
2. **表达式求值**：后缀表达式数字入栈，遇运算符弹两个算（先弹的是右操作数）
3. **队列实现**：循环链表队列，判空条件 `next == 自身`

**典型真题**：
| 编号 | 题目 | 考点 |
|:---:|:---|:---|
| 113 | 循环链表表示队列 | 循环链表队列实现 |
| 120/198 | 非递归先序遍历 | 栈模拟，**高频必考** |
| 178 | 反转字符串 | 递归转栈 |

**非递归先序遍历模板（最高频编程题）**：
```c
void preorder(BiTree root) {
    Stack S; init_stack(&S);
    push(&S, root);
    while (!is_empty(&S)) {
        BiTNode *node;
        pop(&S, &node);
        visit(node);
        if (node->right) push(&S, node->right);  // 右先入
        if (node->left) push(&S, node->left);    // 左后入 -> 左先出
    }
}
```

## 横向对比与期末防坑

| 对比项 | 栈 | 队列 |
|--------|-----|------|
| 特性 | LIFO | FIFO |
| 入口/出口 | 同端（栈顶） | 异端（队尾入、队头出） |
| 典型应用 | 表达式、括号匹配、递归 | BFS、任务调度 |
| 判空 | top==-1 (顺序) / top==NULL (链) | front==rear |
| 判满 | top==MAXSIZE-1 | (rear+1)%MAX==front |

> ⚠️ **防坑**：
> 1. 循环队列**牺牲一个空间**来区分队满和队空
> 2. 栈和队列的 `top`/`front`/`rear` 初值要搞清（`-1` 还是 `0`）
> 3. 中缀转后缀时，**同级运算符也要弹出**（左结合）
> 4. 表达式求值计算顺序：先弹出的是**右操作数**

# 第四章 串

## 概念与物理存储

- **串**：零个或多个字符组成的有限序列
- **存储**：顺序存储（定长/堆分配）、链式存储（块链）

```c
// 定长顺序串
typedef struct {
    char ch[MAXSIZE + 1];  // ch[0] 不用或存长度
    int length;
} SString;
```

## 核心操作与算法

### 朴素模式匹配（Brute-Force）

```c
// Time: O(n*m) 最坏 | Space: O(1)
int Index(SString S, SString T, int pos) {
    int i = pos, j = 1;
    while (i <= S.length && j <= T.length) {
        if (S.ch[i] == T.ch[j]) { i++; j++; }
        else { i = i - j + 2; j = 1; }  // 回溯
    }
    if (j > T.length) return i - T.length;
    return 0;
}
```

### KMP 算法

**核心思想**：利用已匹配信息，主串指针不回溯

```c
// Time: O(n+m) | Space: O(m) — next 数组计算
void get_next(SString T, int next[]) {
    next[1] = 0;
    int i = 1, j = 0;
    while (i < T.length) {
        if (j == 0 || T.ch[i] == T.ch[j]) {
            i++; j++;
            next[i] = j;
        } else
            j = next[j];
    }
}
```

```c
// Time: O(n+m) | Space: O(1) — KMP 匹配
int Index_KMP(SString S, SString T, int pos, int next[]) {
    int i = pos, j = 1;
    while (i <= S.length && j <= T.length) {
        if (j == 0 || S.ch[i] == T.ch[j]) { i++; j++; }
        else j = next[j];  // 不回溯 i
    }
    if (j > T.length) return i - T.length;
    return 0;
}
```

**next 数组手算方法**：
- `next[1] = 0`
- `next[j]` = 模式串 `T[1..j-1]` 中**最长相等前后缀长度 + 1**

| j | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|
| T | a | b | a | a | b | c | a |
| next | 0 | 1 | 1 | 2 | 2 | 3 | 1 |

### 改进 KMP（nextval）

```c
void get_nextval(SString T, int nextval[]) {
    nextval[1] = 0;
    int i = 1, j = 0;
    while (i < T.length) {
        if (j == 0 || T.ch[i] == T.ch[j]) {
            i++; j++;
            if (T.ch[i] != T.ch[j]) nextval[i] = j;
            else nextval[i] = nextval[j];
        } else
            j = nextval[j];
    }
}
```

## 横向对比

| 算法 | 时间复杂度 | 主串指针回溯 | 适用场景 |
|------|-----------|------------|---------|
| Brute-Force | O(n×m) | ✅ 回溯 | 短串匹配 |
| KMP | O(n+m) | ❌ 不回溯 | 长串/多次匹配 |
| KMP 改进 | O(n+m) | ❌ 不回溯 | 避免多余比较 |

### 真题与解题套路

**三大考法**：
1. **串操作**：比较、替换、匹配，核心是逐字符遍历
2. **KMP 手算**：next 数组计算是高频手算题
3. **块链串**：每个结点存多个字符，减少指针开销

**串替换模板**：
```c
// 在主串中将所有 pattern 替换为 replacement
while (mi < mlen) {
    if (strncmp(main_str + mi, pattern, plen) == 0) {
        for (int i = 0; i < rlen; i++) result[ri++] = replacement[i];
        mi += plen;  // 跳过已匹配
    } else {
        result[ri++] = main_str[mi++];
    }
}
```

> ⚠️ **防坑**：
> 1. next 数组下标从 **1** 开始，`next[1] = 0` 是标志
> 2. 手算 next 时，找的是**最长相等前后缀**，不是最长公共子串
> 3. KMP 当 `j == 0` 时，`i` 和 `j` **都要++**

# 第五章 数组与广义表

## 概念与物理存储

### 数组顺序存储

**行优先**（C 语言）：`LOC(a[i][j]) = a + (i*n + j) * sizeof(元素)`

**列优先**（Fortran）：`LOC(a[i][j]) = a + (j*m + i) * sizeof(元素)`

### 特殊矩阵压缩

**对称矩阵**：只存下三角，`k = i*(i-1)/2 + j - 1`（i ≥ j）

**三角矩阵**：类似对称，额外存一个常数 c

**三对角矩阵**：`k = 2i + j - 3`

### 稀疏矩阵

**三元组表示**：

```c
typedef struct {
    int row, col;
    ElemType value;
} Triple;
typedef struct {
    Triple data[MAXSIZE + 1];  // data[0] 存行数、列数、非零元素个数
    int rows, cols, nums;
} TSMatrix;
```

**快速转置算法**：

```c
// Time: O(n + cols) | Space: O(cols)
// 核心：先统计每列非零元素个数 → 计算每列起始位置 → 一趟扫描填充
```

步骤：
1. 统计 M 中每列非零元素个数 `num[col]`
2. 计算每列第一个非零元素在转置后的位置 `cpot[1]=1, cpot[col]=cpot[col-1]+num[col-1]`
3. 扫描 M，将每个元素放到 T 的对应位置

### 广义表

- **表头** head(L) = 第一个元素
- **表尾** tail(L) = 除第一个元素外的子表
- **长度** = 最外层元素个数
- **深度** = 括号最大嵌套层数

### 真题与解题套路

# 第六章 树与二叉树

## 概念与物理存储

### 基本术语

| 术语 | 含义 |
|------|------|
| 度 | 结点的子树个数 |
| 叶子结点 | 度为 0 的结点 |
| 层次 | 根为第 1 层 |
| 深度/高度 | 最大层次 |
| 森林 | m 棵互不相交的树的集合 |

### 二叉树性质（必背）

1. 第 i 层最多 **2^(i-1)** 个结点
2. 深度为 k 的二叉树最多 **2^k - 1** 个结点
3. **n₀ = n₂ + 1**（叶子结点数 = 度为 2 的结点数 + 1）
4. **完全二叉树** n 个结点，深度为 **⌊log₂n⌋ + 1**
5. 完全二叉树中，结点 i 的左孩子 **2i**，右孩子 **2i+1**，父结点 **⌊i/2⌋**

### 存储结构

```c

// 链式存储
typedef struct BiTNode {
    ElemType data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;
```

### 线索二叉树

```c
typedef struct BiThrNode {

    int LTag, RTag;  // 0=孩子线索，1=前驱/后继线索
```

## 核心操作与算法

### 三种遍历（递归）

```c
// Time: O(n) | Space: O(h) h为树高
void PreOrder(BiTree T) {   // 前序：根左右
    if (T) { visit(T); PreOrder(T->lchild); PreOrder(T->rchild); }
}
void InOrder(BiTree T) {    // 中序：左根右
    if (T) { InOrder(T->lchild); visit(T); InOrder(T->rchild); }
}
void PostOrder(BiTree T) {  // 后序：左右根
    if (T) { PostOrder(T->lchild); PostOrder(T->rchild); visit(T); }
}
```

### 中序遍历（非递归，栈）

```c
// Time: O(n) | Space: O(h)
void InOrder_NonRec(BiTree T) {
    InitStack(S); BiTree p = T;
    while (p || !IsEmpty(S)) {
        if (p) { Push(S, p); p = p->lchild; }  // 左到底
        else { Pop(S, p); visit(p); p = p->rchild; }
    }
}
```

### 层序遍历（队列）

```c
// Time: O(n) | Space: O(w) w为最大宽度
void LevelOrder(BiTree T) {
    InitQueue(Q); EnQueue(Q, T);
    while (!IsEmpty(Q)) {
        DeQueue(Q, p); visit(p);
        if (p->lchild) EnQueue(Q, p->lchild);
        if (p->rchild) EnQueue(Q, p->rchild);
    }
}
```

### 由遍历序列构造二叉树

**关键**：必须有**中序** + (前序或后序) 才能唯一确定

- 前序/后序 → 确定根
- 中序 → 确定左右子树

### 树和森林的遍历

| 树 | 森林 | 二叉树 |
|----|------|--------|
| 先根遍历 | 先序遍历 | 先序遍历 |
| 后根遍历 | 中序遍历 | 中序遍历 |

**树↔二叉树转换**：左孩子右兄弟（第一个孩子变左子树，兄弟变右子树）

## 哈夫曼树与编码

### 构造步骤

1. 将 n 个权值作为 n 棵只有根结点的树集合 F
2. 从 F 中选权值**最小的两棵**合并，新根权值 = 两子之和，放回 F
3. 重复直到 F 中只剩一棵树

**WPL（带权路径长度）**= Σ(wᵢ × lᵢ)，wᵢ 为权值，lᵢ 为路径长度

### 哈夫曼编码

- 左分支编码 0，右分支编码 1
- 从根到叶子的路径即为该字符的编码
- **前缀编码**：任何编码都不是其他编码的前缀 → 无歧义解码

## 横向对比与期末防坑

| 遍历方式 | 序列特征 | 用途 |
|---------|---------|------|
| 前序 | 根在最前 | 复制树 |
| 中序 | 根在中间 | BST 有序输出 |
| 后序 | 根在最后 | 释放内存、计算表达式 |
| 层序 | 逐层从左到右 | 求树宽、最短路径 |

### 真题与解题套路

**五大考法**：
1. **遍历**（必考）：递归一行代码，非递归用栈，层序用队列
2. **建树**：BST 逐个插入，前序+中序重建
3. **结点关系**：LCA（p/q 分居左右时当前结点即答案）
4. **树的变换**：镜像翻转（递归交换左右子树）
5. **计数统计**：叶子数（左右都空）、树高（max 左右高 + 1）

**典型真题**：
| 编号 | 题目 | 考点 |
|:---:|:---|:---|
| 120/198 | 非递归先序遍历 | 栈模拟，**最高频** |
| 162/180 | 层序遍历 | 队列 BFS |
| 179 | 镜像二叉树 | 递归交换左右子树 |
| 25-2 | 非递归找双子结点 | 先序变形 |

**LCA（最近公共祖先）递归模板**：
```c
BiTree LCA(BiTree root, BiTree p, BiTree q) {
    if (!root || root == p || root == q) return root;
    BiTree left = LCA(root->lchild, p, q);
    BiTree right = LCA(root->rchild, p, q);
    if (left && right) return root;   // p/q 分居左右
    return left ? left : right;       // 都在同一侧
}
```

> ⚠️ **防坑**：
> 1. **n₀ = n₂ + 1** 是最常考的性质，选择题必出
> 2. 完全二叉树编号从 **1** 开始，i 的左孩子是 **2i**（不是 2i+1）
> 3. 只有前序+后序**无法**唯一确定二叉树
> 4. 哈夫曼编码中，**权值最小的两个**要合并，注意相同权值时的选取顺序
> 5. 线索化后，中序遍历第一个结点的前驱为 NULL，最后一个结点的后继为 NULL

## 核心操作与算法

### 深度优先搜索（DFS）

```c
// Time: O(n²) 邻接矩阵 / O(n+e) 邻接表 | Space: O(n)
int visited[MAXVEX];
void DFS(MGraph G, int i) {
    visited[i] = 1; visit(G.vexs[i]);
    for (int j=0; j<G.numVertexes; j++)
        if (G.arc[i][j]==1 && !visited[j])
            DFS(G, j);
}
void DFSTraverse(MGraph G) {
    memset(visited, 0, sizeof(visited));
    for (int i=0; i<G.numVertexes; i++)
        if (!visited[i]) DFS(G, i);  // 处理非连通图
}
```

### 广度优先搜索（BFS）

```c
// Time: O(n²) 邻接矩阵 / O(n+e) 邻接表 | Space: O(n)
void BFS(MGraph G, int i) {
    InitQueue(Q);
    visited[i] = 1; visit(G.vexs[i]); EnQueue(Q, i);
    while (!IsEmpty(Q)) {
        DeQueue(Q, i);
        for (int j=0; j<G.numVertexes; j++)
            if (G.arc[i][j]==1 && !visited[j]) {
                visited[j] = 1; visit(G.vexs[j]); EnQueue(Q, j);
            }
    }
}
```

### 最短路径

#### Dijkstra（单源最短路径）

```c

// 维护 dist[] 和 path[] 数组，每次选未访问中 dist 最小的点
```

**手动推导步骤**：
1. 初始化 `dist[]` = 源点到各点的直接距离，不可达为 ∞
2. 选 dist 最小的未访问点 v，标记已访问
3. 对 v 的每个邻接点 w：若 `dist[v] + G[v][w] < dist[w]`，更新
4. 重复直到所有点已访问

#### Floyd（多源最短路径）

```c
// Time: O(n³) | Space: O(n²) | 可处理负权（无负环）
for (k=0; k<n; k++)
  for (i=0; i<n; i++)
    for (j=0; j<n; j++)
      if (D[i][k]+D[k][j] < D[i][j])
        D[i][j] = D[i][k]+D[k][j];
```

### 拓扑排序

- **条件**：有向无环图 (DAG)
- **步骤**：选入度为 0 的顶点输出，删除其所有出弧，重复
- **用途**：判断有向图是否有环、确定工程可行性顺序

### 关键路径（AOE 网）

- **关键活动**：`etv[i] == ltv[i]` 的顶点在关键路径上
- **关键路径** = 从源点到汇点的**最长路径**

```
etv（最早发生时间）：正向计算，取所有前驱的最大值
ltv（最晚发生时间）：逆向计算，取所有后继的最小值
ete（活动最早开始）：弧尾顶点的 etv
lte（活动最晚开始）：弧头顶点的 ltv - 弧权值
关键活动：ete == lte
```

2. **遍历**：DFS（递归/栈）、BFS（队列），非连通图需遍历所有顶点
3. **最短路径**：Dijkstra（单源、无负权）、Floyd（多源）
4. **最小生成树**：Prim（从点出发、稠密图）、Kruskal（从边出发、稀疏图）
5. **拓扑排序/关键路径**：AOE 网关键路径 = 最长路径 = 工程最短工期

**欧拉通路判定**：
```
遍历邻接矩阵统计每个顶点的入度和出度
diff = indegree - outdegree
判定：
  任何顶点 |diff| > 1 → 不存在
  diff != 0 的顶点数为 0 → 欧拉回路
  diff != 0 的顶点数为 2 → 欧拉通路（一进一出）
  其他 → 不存在
```

**入度/出度计算**：

```c
// 入度：第 j 列的非零元素个数
for (i=0; i<G->vexnum; i++) if (G->arcs[i][v]!=0) count++;
// 出度：第 i 行的非零元素个数

```

# 第八章 查找

## 核心操作与算法

### 顺序查找

```c
// Time: O(n) | ASL = (n+1)/2
int SeqSearch(int A[], int n, int key) {
    for (int i=0; i<n; i++)
        if (A[i] == key) return i;
    return -1;
}
```

### 折半查找（二分查找）

```c
// Time: O(log n) | 要求有序表 + 顺序存储
int BinSearch(int A[], int n, int key) {
    int low=0, high=n-1, mid;
    while (low <= high) {
        mid = (low + high) / 2;
        if (A[mid] == key) return mid;
        else if (A[mid] < key) low = mid + 1;
        else high = mid - 1;
    }
    return -1;
}
```

**ASL 成功** = Σ(比较次数 × 该层结点数) / n

### 分块查找

- 块间有序（第 i 块最大值 < 第 i+1 块最小值），块内无序
- 先在索引表中确定块（顺序或折半），再在块内顺序查找

### 二叉排序树（BST）

```c
// Time: O(log n) 平均 / O(n) 最坏 | Space: O(n)
BiTree SearchBST(BiTree T, int key) {
    if (!T || T->data == key) return T;
    if (key < T->data) return SearchBST(T->lchild, key);
    else return SearchBST(T->rchild, key);
}
```

**中序遍历 BST → 有序序列**

### 平衡二叉树（AVL）

**平衡因子** BF = 左子树高度 - 右子树高度，|BF| ≤ 1

| 失衡类型 | 旋转方式 | 条件 |
|---------|---------|------|
| LL | 右旋 | BF > 1 且左子 BF ≥ 0 |
| RR | 左旋 | BF < -1 且右子 BF ≤ 0 |
| LR | 先左旋再右旋 | BF > 1 且左子 BF < 0 |
| RL | 先右旋再左旋 | BF < -1 且右子 BF > 0 |

**LL 右旋**：将失衡结点的左孩子提升为根，原根变为右孩子
**RR 左旋**：将失衡结点的右孩子提升为根，原根变为左孩子

### 哈希表

**常用哈希函数**：
- 除留余数法：`H(key) = key % p`（p 为 ≤ 表长的素数）
- 直接定址法：`H(key) = a*key + b`

**冲突处理**：

| 方法 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| 开放定址法（线性探测） | 逐个探测下一个空位 | 简单 | 容易聚集 |
| 链地址法 | 同义词链成链表 | 无聚集，删除方便 | 指针开销 |

**装填因子** α = 表中记录数 / 表长

**ASL**：成功 = 每个元素比较次数之和 / 元素个数；失败 = 每个位置探测到空位的次数之和 / 哈希函数模数

## 横向对比

| 查找方式 | 时间 | 要求 | 适用 |
|---------|------|------|------|
| 顺序查找 | O(n) | 无 | 小表 |
| 折半查找 | O(log n) | 有序+顺序 | 静态表 |
| BST | O(log n) 平均 | 无 | 动态插入 |
| AVL | O(log n) | 平衡 | 频繁插入删除 |
| 哈希 | O(1) 平均 | 哈希函数 | 快速查找 |

### 真题与解题套路

**四大考法**：
1. **BST 查找/插入**：左小右大，递归/迭代
2. **AVL 旋转**：LL→右旋，RR→左旋，LR→先左后右，RL→先右后左
3. **哈希表**：除留余数法 + 链地址法/线性探测法
4. **计数排序**：hash(K)=K，值做下标，计数后顺序输出 → O(n+m)

**典型真题**：
| 编号 | 题目 | 考点 |
|:---:|:---|:---|
| 163 | 线性探测法 | 哈希冲突处理 |
| 182 | 哈希排序 | 计数排序 |
| 199 | 哈希冲突 | 拉链法插入 |

**线性探测哈希模板**：
```c
int idx = key % SIZE;
while (hashTable[idx])              // 冲突：向后探测
    idx = (idx + 1) % SIZE;         // 取模实现环形
hashTable[idx] = key;
```

**拉链法哈希模板**：
```c
int idx = key % P;
HashNode *node = malloc(sizeof(HashNode));
node->key = key;
node->next = table[idx];            // 头插法
table[idx] = node;
```

> ⚠️ **防坑**：
> 1. 折半查找**只能用于顺序存储**的有序表，链表不行
> 2. BST 最坏情况退化为 O(n)（有序插入时变成单链表）
> 3. AVL 旋转：**LR 和 RL 是双旋转**，先处理子树再处理根
> 4. 哈希线性探测的**聚集问题**：冲突集中在某区域
> 5. 哈希失败 ASL 的计算：对每个可能的哈希值位置，探测到空位的次数

## 精简代码实现

### 直接插入排序

```c
// Time: O(n²) | Space: O(1) | Stable
void InsertSort(int A[], int n) {
    for (int i=1; i<n; i++) {
        int temp = A[i], j;
        for (j=i-1; j>=0 && A[j]>temp; j--)
            A[j+1] = A[j];  // 后移
        A[j+1] = temp;       // 插入
    }
}
```

### 冒泡排序

```c
// Time: O(n²) best O(n) | Space: O(1) | Stable
void BubbleSort(int A[], int n) {
    for (int i=0; i<n-1; i++) {
        int flag = 0;
        for (int j=n-1; j>i; j--)
            if (A[j-1] > A[j]) {
                swap(A[j-1], A[j]);
                flag = 1;
            }
        if (!flag) break;  // 无交换则已有序
    }
}
```

### 快速排序

```c
// Time: O(n log n) avg, O(n²) worst | Space: O(log n) | Unstable
int Partition(int A[], int low, int high) {
    int pivot = A[low];
    while (low < high) {
        while (low<high && A[high]>=pivot) high--;
        A[low] = A[high];
        while (low<high && A[low]<=pivot) low++;
        A[high] = A[low];
    }
    A[low] = pivot;
    return low;
}
void QuickSort(int A[], int low, int high) {
    if (low < high) {
        int pivotpos = Partition(A, low, high);
        QuickSort(A, low, pivotpos-1);
        QuickSort(A, pivotpos+1, high);
    }
}
```

### 简单选择排序

```c
// Time: O(n²) | Space: O(1) | Unstable
void SelectSort(int A[], int n) {
    for (int i=0; i<n-1; i++) {
        int min = i;
        for (int j=i+1; j<n; j++)
            if (A[j] < A[min]) min = j;
        if (min != i) swap(A[i], A[min]);
    }
}
```

### 堆排序

```c
// Time: O(n log n) | Space: O(1) | Unstable
// 大根堆：A[i] >= A[2i] && A[i] >= A[2i+1]
// 小根堆：A[i] <= A[2i] && A[i] <= A[2i+1]

void HeapAdjust(int A[], int i, int n) {  // 筛选法调整堆
    int temp = A[i];
    for (int j=2*i; j<=n; j*=2) {
        if (j<n && A[j]<A[j+1]) j++;  // 选较大子
        if (temp >= A[j]) break;
        A[i] = A[j]; i = j;
    }
    A[i] = temp;
}
void HeapSort(int A[], int n) {
    for (int i=n/2; i>=1; i--)  // 建堆
        HeapAdjust(A, i, n);
    for (int i=n; i>1; i--) {   // 排序
        swap(A[1], A[i]);
        HeapAdjust(A, 1, i-1);
    }
}
```

### 归并排序

```c
// Time: O(n log n) | Space: O(n) | Stable
void Merge(int A[], int low, int mid, int high) {
    int *B = (int*)malloc((high-low+1)*sizeof(int));
    int i=low, j=mid+1, k=0;
    while (i<=mid && j<=high)
        B[k++] = (A[i]<=A[j]) ? A[i++] : A[j++];
    while (i<=mid) B[k++] = A[i++];
    while (j<=high) B[k++] = A[j++];
    for (k=0; k<high-low+1; k++) A[low+k] = B[k];
    free(B);
}
void MergeSort(int A[], int low, int high) {
    if (low < high) {
        int mid = (low+high)/2;
        MergeSort(A, low, mid);
        MergeSort(A, mid+1, high);
        Merge(A, low, mid, high);
    }
}
```

**三大考法**：

2. **排序过程手算**：给定数组，写出第一趟排序结果
3. **排序选择**：根据场景选择合适的排序算法

**手算第一趟结果**（数组 `[49, 38, 65, 97, 76, 13, 27, 49]`）：

| 排序算法 | 第一趟结果 | 说明 |
|:---|:---|:---|

**堆操作补充（向上调整）**：
```c
// 插入新元素到堆末尾，向上调整
void heapify_up(int arr[], int i) {
    while (i > 0) {
        int parent = (i - 1) / 2;
        if (arr[i] < arr[parent]) {     // 小顶堆：子 < 父就交换
            swap(&arr[i], &arr[parent]);
            i = parent;
        } else break;
    }
}
```

**排序选择速查**：
- 小规模 → 插入排序
- 通用 → 快排
- 不允许最坏 → 堆排序
- 需要稳定 → 归并排序
- 非负整数且范围小 → 计数排序

> ⚠️ **防坑**：
> 1. 快排**最坏 O(n²)**：已有序序列 + 取第一个为 pivot
> 2. **堆排序空间 O(1)** 是它的最大优势，但不稳定
> 3. 希尔排序的增量序列选择影响性能，最后一个增量必须为 **1**
> 4. 稳定排序只有：直接插入、折半插入、冒泡、归并、基数排序
> 5. 冒泡排序加 `flag` 优化后，最好情况 O(n)
> 6. 建堆从 **n/2** 开始向下调整，不是从 n 开始
> 7. 快排的 Partition 是**高频手写题**，务必掌握
