## 📋 项目概述

### 1.1 项目背景

当前 Obsidian 仓库采用 Git + GitHub 方案进行同步，存在以下痛点：

- **同步延迟**：分钟级同步，无法满足实时协作需求
- **操作繁琐**：需要手动 commit/pull，容易遗忘
- **冲突风险**：多设备同时编辑时冲突处理复杂
- **移动端体验差**：Git 操作在移动端不便

### 1.2 需求分析

#### 功能需求

| 需求项 | 优先级 | 说明 |
|:---|:---|:---|
| 实时同步 | P0 | 设备间秒级同步延迟 |
| 多端支持 | P0 | Windows/macOS/iOS/Android |
| 冲突处理 | P1 | 自动合并或友好提示 |
| 离线支持 | P1 | 断网后可继续编辑 |
| 版本历史 | P2 | 支持历史版本回溯 |
| 选择性同步 | P2 | 可指定同步文件夹 |

#### 非功能需求

| 需求项 | 指标 |
|:---|:---|
| 同步延迟 | < 3 秒（正常网络） |
| 并发设备数 | ≥ 5 台 |
| 数据可靠性 | 99.99% |
| 服务可用性 | 99.9% |
| 单文件大小 | 支持 50MB |
| 总存储空间 | 可扩展至 100GB+ |

## 🔧 技术选型

### 3.1 核心组件选型

#### 数据库：CouchDB 3.x

**选择理由**：

| 特性 | 说明 |
|:---|:---|
| 原生同步协议 | 内置 Replication Protocol，专为同步设计 |
| 变更流 | Changes Feed 支持实时监听文档变更 |
| 冲突处理 | MVCC 机制，自动检测冲突 |
| HTTP API | RESTful 接口，易于集成 |
| 多主复制 | 支持多节点双向同步 |
| 文档模型 | JSON 文档，适合存储 Markdown 元数据 |

**版本选择**：

```yaml
推荐版本: CouchDB 3.3.x
原因:
  - 稳定性好
  - 性能优化
  - 安全特性完善
  - 社区活跃
```

**选择理由**：

```yaml
功能:
  - SSL/TLS 终止
  - WebSocket 代理（LiveSync 依赖）
  - 请求限流

优势:
  - 高性能
```

#### 容器化：Docker + Docker Compose

**选择理由**：

```yaml
优势:
```

```bash
#!/bin/bash
# 📌 系统初始化脚本

set -e

# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装基础工具
sudo apt install -y \
  curl \
  wget \
  git \
  vim \
  htop \
  net-tools \
  ufw

# 设置时区
sudo timedatectl set-timezone Asia/Shanghai

# 配置 Swap（内存不足时）
if [ ! -f /swapfile ]; then
  sudo fallocate -l 2G /swapfile
  sudo chmod 600 /swapfile
  sudo mkswap /swapfile
  sudo swapon /swapfile
  echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
fi

# 优化内核参数
sudo tee -a /etc/sysctl.conf << 'EOF'
# 网络优化
net.core.somaxconn = 65535
net.ipv4.tcp_max_syn_backlog = 65535
net.ipv4.ip_local_port_range = 1024 65535

# 文件描述符
fs.file-max = 655350
fs.inotify.max_user_watches = 524288

# 虚拟内存
vm.swappiness = 10
vm.overcommit_memory = 1
EOF

sudo sysctl -p

# 配置文件描述符限制
sudo tee /etc/security/limits.d/obsidian.conf << 'EOF'
* soft nofile 65535
* hard nofile 65535
* soft nproc 65535
* hard nproc 65535
EOF

echo "✅ 系统初始化完成"
```

#### 初始化脚本 (scripts/init.sh)

```bash
#!/bin/bash
# 📌 CouchDB 初始化脚本

set -e

source ../.env

COUCHDB_URL="http://localhost:5984"
AUTH="-u ${COUCHDB_USER}:${COUCHDB_PASSWORD}"

echo "🚀 开始初始化 CouchDB..."

# 等待 CouchDB 启动
echo "⏳ 等待 CouchDB 启动..."
until curl -s ${COUCHDB_URL}/_up > /dev/null 2>&1; do
  sleep 1
done
echo "✅ CouchDB 已启动"

# 创建主数据库
echo "📦 创建主数据库: ${DB_NAME}"
curl -X PUT ${AUTH} ${COUCHDB_URL}/${DB_NAME}

# 创建配置数据库
echo "📦 创建配置数据库: ${CONFIG_DB_NAME}"
curl -X PUT ${AUTH} ${COUCHDB_URL}/${CONFIG_DB_NAME}

# 设置安全规则
echo "🔒 设置数据库安全规则"
curl -X PUT ${AUTH} ${COUCHDB_URL}/${DB_NAME}/_security \
  -H "Content-Type: application/json" \
  -d '{"admins":{"names":[],"roles":[]},"members":{"names":["'${COUCHDB_USER}'"],"roles":[]}}'

curl -X PUT ${AUTH} ${COUCHDB_URL}/${CONFIG_DB_NAME}/_security \
  -H "Content-Type: application/json" \
  -d '{"admins":{"names":[],"roles":[]},"members":{"names":["'${COUCHDB_USER}'"],"roles":[]}}'

# 创建索引（优化查询性能）
echo "📊 创建索引"
curl -X POST ${AUTH} ${COUCHDB_URL}/${DB_NAME}/index \
  -H "Content-Type: application/json" \
  -d '{"index":{"fields":["type"]},"name":"type-index"}'

curl -X POST ${AUTH} ${COUCHDB_URL}/${DB_NAME}/index \
  -H "Content-Type: application/json" \
  -d '{"index":{"fields":["_deleted"]},"name":"deleted-index"}'

echo "✅ 初始化完成"
echo "📊 数据库信息:"
curl -s ${AUTH} ${COUCHDB_URL}/${DB_NAME} | python3 -m json.tool
```

### 4.5 Nginx 配置

#### 安装 Nginx

```bash
sudo apt install -y nginx
```

#### 配置文件 (/etc/nginx/sites-available/obsidian-sync)

```nginx
# 📌 HTTP -> HTTPS 重定向
server {
    listen 80;
    server_name sync.yourdomain.com;

    # Let's Encrypt 验证
    location /.well-known/acme-challenge/ {
        root /var/www/html;
    }

    # 其他请求重定向到 HTTPS
    location / {
        return 301 https://$server_name$request_uri;
    }
}

# 📌 HTTPS 配置
server {
    listen 443 ssl http2;
    server_name sync.yourdomain.com;

    # SSL 证书
    ssl_certificate /etc/letsencrypt/live/sync.yourdomain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/sync.yourdomain.com/privkey.pem;

    # SSL 安全配置
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-RSA-AES256-GCM-SHA384;
    ssl_prefer_server_ciphers off;
    ssl_session_cache shared:SSL:10m;
    ssl_session_timeout 1d;
    ssl_session_tickets off;

    # HSTS
    add_header Strict-Transport-Security "max-age=63072000" always;

    # 安全头
    add_header X-Frame-Options DENY always;
    add_header X-Content-Type-Options nosniff always;
    add_header X-XSS-Protection "1; mode=block" always;

    # 请求限制
    limit_req_zone $binary_remote_addr zone=obsidian:10m rate=10r/s;

    # CouchDB 代理
    location / {
        # 请求限制
        limit_req zone=obsidian burst=20 nodelay;

        # 代理设置
        proxy_pass http://127.0.0.1:5984;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # WebSocket 支持（LiveSync 需要）
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";

        # 超时设置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 300s;

        # 缓冲设置
        proxy_buffering off;
        proxy_request_buffering off;

        # 上传大小限制
        client_max_body_size 50M;
    }

    # 访问日志
    access_log /var/log/nginx/obsidian-sync-access.log;
    error_log /var/log/nginx/obsidian-sync-error.log;
}
```

#### 启用配置

```bash
# 创建软链接

# 删除默认配置
sudo rm -f /etc/nginx/sites-enabled/default
```

```bash
#!/bin/bash
# 📌 数据恢复脚本
```

### 7.2 监控脚本

```bash
#!/bin/bash
# 📌 简单监控脚本

set -e

LOG_FILE="/var/log/obsidian-monitor.log"
ALERT_EMAIL="your-email@example.com"

# 检查服务状态
check_services() {
  echo "[$(date '+%Y-%m-%d %H:%M:%S')] 检查服务状态..." >> ${LOG_FILE}

  # 检查 Docker
  if ! docker ps > /dev/null 2>&1; then
    echo "❌ Docker 服务异常" >> ${LOG_FILE}
    # 发送告警
    return 1
  fi

  # 检查 CouchDB
  if ! curl -s http://localhost:5984/_up > /dev/null 2>&1; then
    echo "❌ CouchDB 服务异常" >> ${LOG_FILE}
    # 发送告警
    return 1
  fi

  # 检查 Nginx
  if ! systemctl is-active --quiet nginx; then
    echo "❌ Nginx 服务异常" >> ${LOG_FILE}
    # 发送告警
    return 1
  fi

  echo "✅ 所有服务正常" >> ${LOG_FILE}
  return 0
}

# 检查资源使用
check_resources() {
  echo "[$(date '+%Y-%m-%d %H:%M:%S')] 检查资源使用..." >> ${LOG_FILE}

  # CPU 使用率
  CPU_USAGE=$(top -bn1 | grep "Cpu(s)" | awk '{print $2}' | cut -d'%' -f1)
  echo "CPU 使用率: ${CPU_USAGE}%" >> ${LOG_FILE}

  # 内存使用率
  MEMORY_USAGE=$(free | grep Mem | awk '{printf "%.2f", $3/$2 * 100.0}')
  echo "内存使用率: ${MEMORY_USAGE}%" >> ${LOG_FILE}

  # 磁盘使用率
  DISK_USAGE=$(df -h / | awk 'NR==2 {print $5}' | cut -d'%' -f1)
  echo "磁盘使用率: ${DISK_USAGE}%" >> ${LOG_FILE}

  # 告警阈值
  if (( $(echo "${CPU_USAGE} > 80" | bc -l) )); then
    echo "⚠️ CPU 使用率过高: ${CPU_USAGE}%" >> ${LOG_FILE}
  fi

  if (( $(echo "${MEMORY_USAGE} > 80" | bc -l) )); then
    echo "⚠️ 内存使用率过高: ${MEMORY_USAGE}%" >> ${LOG_FILE}
  fi

  if [ ${DISK_USAGE} -gt 80 ]; then
    echo "⚠️ 磁盘使用率过高: ${DISK_USAGE}%" >> ${LOG_FILE}
  fi
}

# 主函数
main() {
  check_services
  check_resources
}

main
```
