# 自建服务器 LiveSync 同步方案

> 📌 本文档详细说明如何使用 Obsidian LiveSync 插件 + 自建 CouchDB 服务器实现设备间实时同步。
> 参考方案：一位大佬推荐的"自建服务器配合Fast Note Sync"方案。

---

## 🌟 方案概述

### 核心优势

```
设备 A 编辑笔记
      │
      │ 实时同步（秒级）
      ▼
┌─────────────┐
│  CouchDB    │  ← 自建服务器
│  服务器     │
└─────────────┘
      │
      │ 实时同步（秒级）
      ▼
设备 B 即时看到更新
```

### 与 Git 方案对比

| 维度 | Git + GitHub | LiveSync + CouchDB |
|:---|:---|:---|
| 同步延迟 | 分钟级 | **秒级** ⚡ |
| 实时性 | ❌ 需手动操作 | ✅ 自动实时 |
| 冲突处理 | Git 标记 | 自动合并 |
| 版本历史 | ✅ 完整 | ✅ 可配置 |
| 离线支持 | ✅ | ✅ |
| 移动端 | ⚠️ 不便 | ✅ 良好 |
| 部署复杂度 | 低 | 中等 |
| 服务器成本 | 免费（GitHub） | 需自建服务器 |

## 🚀 部署步骤

### 第一步：准备服务器

#### 1.1 服务器要求

```bash
# 📌 最低配置
CPU: 1 核
内存: 1 GB
硬盘: 20 GB（根据笔记量调整）
系统: Ubuntu 20.04+ / CentOS 7+

# 📌 网络要求
- 公网 IP 或域名
- 开放端口：5984（CouchDB 默认端口）
- 建议配置 HTTPS（生产环境必须）
```

#### 1.2 安装 Docker（推荐）

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install -y docker.io docker-compose
sudo systemctl start docker
sudo systemctl enable docker

# 验证安装
docker --version
docker-compose --version
```

---

### 第二步：部署 CouchDB

#### 2.1 使用 Docker 部署

```bash
# 创建工作目录
mkdir -p ~/obsidian-couchdb
cd ~/obsidian-couchdb

# 创建 docker-compose.yml
cat > docker-compose.yml << 'EOF'
version: '3.8'

services:
  couchdb:
    image: couchdb:3
    container_name: obsidian-couchdb
    restart: unless-stopped
    ports:
      - "5984:5984"
    environment:
      - COUCHDB_USER=admin        # 📌 修改为你的用户名
      - COUCHDB_PASSWORD=your_password  # 📌 修改为强密码
    volumes:
      - ./data:/opt/couchdb/data
      - ./etc/local.ini:/opt/couchdb/etc/local.ini
    networks:
      - couchdb-net

networks:
  couchdb-net:
    driver: bridge
EOF

# 创建配置文件
mkdir -p etc
cat > etc/local.ini << 'EOF'
[couchdb]
single_node=true
max_document_size = 50000000

[chttpd]
require_valid_user = true
max_http_request_size = 4294967296
enable_cors = true

[chttpd_auth]
require_valid_user = true

[httpd]
WWW-Authenticate = Basic realm="couchdb"
bind_address = 0.0.0.0

[cors]
origins = app://obsidian.md, capacitor://localhost, http://localhost
credentials = true
headers = accept, authorization, content-type, origin, referer
methods = GET, PUT, POST, HEAD, DELETE
max_age = 3600
EOF

# 启动服务
docker-compose up -d

# 查看状态
docker-compose ps
docker-compose logs -f
```

#### 2.2 验证 CouchDB

```bash
# 测试连接
curl http://localhost:5984/

# 预期输出
{
  "couchdb": "Welcome",
  "version": "3.x.x",
  "features": [
    "access-ready",
    "partitioned",
    "pluggable-storage-engines",
    "reshard",
    "scheduler"
  ]
}

# 登录 Fauxton 管理界面
# 访问: http://你的服务器IP:5984/_utils
# 使用上面设置的用户名密码登录
```

#### 2.3 初始化数据库

```bash
# 创建数据库（在 Fauxton 界面或命令行）
# 📌 数据库名建议使用小写字母和下划线
curl -X PUT http://admin:password@localhost:5984/obsidian-vault
curl -X PUT http://admin:password@localhost:5984/obsidian-vault-config

# 如果需要远程访问，确保防火墙开放 5984 端口
sudo ufw allow 5984/tcp  # Ubuntu
# 或
sudo firewall-cmd --permanent --add-port=5984/tcp  # CentOS
sudo firewall-cmd --reload
```

### 第三步：配置 Obsidian LiveSync 插件

#### 3.1 安装插件

```
1. 打开 Obsidian
2. 设置 → 第三方插件 → 浏览
3. 搜索 "Self-hosted LiveSync" 或 "Obsidian LiveSync"
4. 安装并启用
```

#### 3.2 基础配置

```
设置 → Community plugins → Self-hosted LiveSync

# 📌 连接设置
Remote Database server: http://你的服务器IP:5984
Username: admin          # CouchDB 用户名
Password: your_password  # CouchDB 密码
Database name: obsidian-vault  # 数据库名

# 📌 测试连接
点击 "Test" 按钮验证连接
```

#### 3.3 同步策略配置

```yaml
# 🌟 推荐配置（实时同步模式）

# 同步模式
Sync Mode: LiveSync        # 实时同步

# 文件过滤
Ignore patterns:
  - .obsidian/workspace.json
  - .obsidian/graph.json
  - .git
  - node_modules

# 冲突处理
Conflict resolution: Newest wins  # 最新版本优先
# 或选择 "手动解决" 更安全

# 压缩设置
Enable compression: true   # 减少传输量

# 批量设置
Batch size: 50             # 批量处理文件数
Batch interval: 1000       # 批量间隔(ms)
```

## 🔧 高级配置

### 4.1 HTTPS 配置（生产环境必须）

```bash
# 使用 Nginx 反向代理 + Let's Encrypt

# 安装 Nginx
sudo apt install nginx

# 创建 Nginx 配置
sudo cat > /etc/nginx/sites-available/obsidian-sync << 'EOF'
server {
    listen 80;
    server_name sync.yourdomain.com;  # 📌 替换为你的域名

    location / {
        proxy_pass http://localhost:5984;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # WebSocket 支持（LiveSync 需要）
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
EOF

# 启用配置
sudo ln -s /etc/nginx/sites-available/obsidian-sync /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx

# 安装 Let's Encrypt 证书
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d sync.yourdomain.com
```

### 4.2 防火墙配置

```bash
# 📌 只允许 HTTPS 访问，关闭直接端口访问

# Ubuntu UFW
sudo ufw deny 5984/tcp       # 关闭直接端口访问
sudo ufw allow 443/tcp       # 开放 HTTPS
sudo ufw allow 80/tcp        # 开放 HTTP（用于证书验证）

# CentOS firewalld
sudo firewall-cmd --permanent --remove-port=5984/tcp
sudo firewall-cmd --permanent --add-service=https
sudo firewall-cmd --permanent --add-service=http
sudo firewall-cmd --reload
```

### 4.3 数据备份

```bash
# 创建备份脚本
cat > ~/backup-couchdb.sh << 'EOF'
#!/bin/bash
BACKUP_DIR=~/couchdb-backups
DATE=$(date +%Y%m%d_%H%M%S)
mkdir -p $BACKUP_DIR

# 备份数据
docker exec obsidian-couchdb couchdb-backup.sh > $BACKUP_DIR/backup_$DATE.json

# 保留最近 7 天备份
find $BACKUP_DIR -name "backup_*.json" -mtime +7 -delete

echo "Backup completed: backup_$DATE.json"
EOF

chmod +x ~/backup-couchdb.sh

# 添加定时任务（每天凌晨 3 点）
crontab -e
# 添加：0 3 * * * ~/backup-couchdb.sh
```

## 📱 多设备配置

### 5.1 PC 端配置

```
# 设备 A（主要设备）
设置 → Self-hosted LiveSync
- Remote Database server: https://sync.yourdomain.com
- Username: admin
- Password: your_password
- Database name: obsidian-vault
- Sync Mode: LiveSync

# 设备 B（次要设备）
配置相同，确保使用相同的数据库名
```

### 5.2 移动端配置

```
# iOS / Android
1. 安装 Obsidian 移动版
2. 安装 Self-hosted LiveSync 插件
3. 配置相同的服务器信息
4. 同步模式选择 "LiveSync" 或 "Periodic"

# 📌 移动端建议
- 使用 WiFi 时同步
- 设置较长的同步间隔节省电量
- 考虑使用 "Selective Sync" 只同步必要文件夹
```

## ⚠️ 常见问题

### Q1: 连接失败

```bash
# 检查项
1. 服务器是否运行
   docker-compose ps

2. 端口是否开放
   telnet 你的服务器IP 5984

3. 防火墙是否阻止
   sudo ufw status
   sudo iptables -L

4. CouchDB 日志
   docker-compose logs couchdb
```

### Q2: 同步冲突

```yaml
# 解决方案
1. 设置冲突处理策略
   - Newest wins: 自动选择最新版本
   - 手动解决: 更安全但需要人工干预

2. 使用插件的 "冲突视图" 查看和解决冲突

3. 定期备份，防止数据丢失
```

### Q3: 同步速度慢

```bash
# 优化方案
1. 启用压缩
2. 调整批量大小
3. 排除大文件（图片、附件）
4. 使用 CDN 加速（如果服务器在国外）
5. 升级服务器带宽
```

### Q4: 数据库膨胀

```bash
# 压缩数据库
curl -X POST http://admin:password@localhost:5984/obsidian-vault/_compact \
  -H "Content-Type: application/json"

# 定期执行压缩任务
```

## 📊 性能对比

| 场景 | Git + GitHub | LiveSync + CouchDB |
|:---|:---|:---|
| 单文件修改 | 需 commit + push | 自动秒级同步 |
| 多文件修改 | 批量 commit | 实时逐文件同步 |
| 离线编辑 | 本地 commit，上线后 push | 本地缓存，联网后自动同步 |
| 冲突发生 | Git 标记，手动解决 | 自动合并或提示 |
| 移动端体验 | 差 | 良好 |
| 服务器成本 | 免费 | ~$5/月（轻量云服务器） |
