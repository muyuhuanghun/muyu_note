# 七.LoRA 适配器加载

📌 LoRA（Low-Rank Adaptation）是一种高效的模型微调技术——用很小的适配器文件来调整大模型的行为，无需修改原始模型权重。

# 一.LoRA 原理简介

## 1.什么是 LoRA

```bash
# 📌 LoRA 核心概念

# 原始模型：几十 GB 的大模型
# LoRA 适配器：几十 MB 的小文件

# 🌟 工作原理：
# - 在模型的某些层插入小的"旁路"矩阵
# - 只训练这些旁路矩阵（参数量极少）
# - 推理时将旁路结果加到原始输出上

# 💡 优势：
# - 训练速度快（几小时 vs 几天）
# - 存储空间小（几十 MB vs 几十 GB）
# - 可以叠加多个 LoRA
# - 不修改原始模型
```

## 2.LoRA 文件格式

```bash
# 📌 常见 LoRA 格式

# HuggingFace 格式：
# adapter_model.safetensors
# adapter_config.json

# GGUF 格式（llama.cpp 使用）：
# adapter.gguf

# 🌟 转换方法：
# 使用 llama.cpp 的转换工具
python convert_lora_to_gguf.py \
    /path/to/huggingface/lora \
    --outfile adapter.gguf
```

# 二.加载 LoRA 适配器

## 1.基础加载命令

```bash
# 📌 加载单个 LoRA 适配器

# 语法：--lora <适配器路径> [缩放系数]

# 示例：加载 LoRA 并应用
./llama-cli -m base-model.gguf \
    --lora adapter.gguf \
    -ngl 99 \
    -c 8192

# 示例：指定缩放系数（0.0-1.0）
./llama-cli -m base-model.gguf \
    --lora adapter.gguf 0.8 \
    -ngl 99

# 🌟 缩放系数说明：
# 1.0 → 完全应用 LoRA（默认）
# 0.5 → 应用 50% 的 LoRA 效果
# 0.0 → 完全不应用（等同于原始模型）

# 💡 调整缩放系数可以控制 LoRA 的影响程度
```

## 2.Server 加载 LoRA

```bash
# 📌 llama-server 加载 LoRA

./llama-server -m base-model.gguf \
    --lora adapter.gguf \
    -ngl 99 \
    -c 8192 \
    --port 8080

# 🌟 API 调用方式与普通模型相同
curl http://localhost:8080/v1/chat/completions \
    -H "Content-Type: application/json" \
    -d '{
        "messages": [{"role": "user", "content": "你好"}],
        "temperature": 0.7
    }'
```

# 三.多 LoRA 管理

## 1.加载多个 LoRA

```bash
# 📌 同时加载多个 LoRA 适配器

# 语法：多次使用 --lora 参数
./llama-cli -m base-model.gguf \
    --lora adapter1.gguf 0.7 \
    --lora adapter2.gguf 0.3 \
    -ngl 99

# 🌟 应用场景：
# adapter1 → 代码生成 LoRA
# adapter2 → 中文优化 LoRA
# 两者叠加使用

# ⚠️ 注意：
# 多 LoRA 叠加可能产生意外效果
# 建议逐个测试后再组合
```

## 2.动态切换 LoRA（Server）

```bash
# 📌 在 Server 中动态切换 LoRA

# 启动时加载多个 LoRA
./llama-server -m base-model.gguf \
    --lora code-lora.gguf \
    --lora chinese-lora.gguf \
    -ngl 99

# API 请求时指定 LoRA
curl http://localhost:8080/v1/chat/completions \
    -H "Content-Type: application/json" \
    -d '{
        "messages": [{"role": "user", "content": "写一个排序算法"}],
        "lora": "code-lora.gguf"
    }'

# 💡 动态切换适合：
# 不同任务使用不同 LoRA
# A/B 测试不同 LoRA 效果
```

# 四.LoRA 转换与制作

## 1.从 HuggingFace 转换

```bash
# 📌 将 HuggingFace LoRA 转换为 GGUF

# Step 1: 克隆 llama.cpp
git clone https://github.com/ggml-org/llama.cpp.git
cd llama.cpp

# Step 2: 安装依赖
pip install -r requirements/requirements-convert_lora_to_gguf.txt

# Step 3: 转换
python convert_lora_to_gguf.py \
    /path/to/huggingface/lora \
    --base /path/to/base/model \
    --outfile adapter.gguf

# 🌟 参数说明：
# --base → 基础模型路径（用于计算缩放）
# --outfile → 输出 GGUF 文件路径

# 💡 常见 LoRA 来源：
# HuggingFace Hub
# 自己训练的 LoRA
# 社区分享的 LoRA
```

## 2.常用 LoRA 资源

# 五.LoRA 训练入门

## 1.训练工具选择

```bash
# 📌 LoRA 训练工具

# 推荐工具：
# 1. LLaMA-Factory → 最流行，GUI 界面
# 2. Unsloth → 速度快，显存省
# 3. Axolotl → 灵活，配置丰富

# 🌟 LLaMA-Factory 安装
git clone https://github.com/hiyouga/LLaMA-Factory.git
cd LLaMA-Factory
pip install -r requirements.txt

# 启动 GUI
llamafactory-cli webui
```

## 2.训练数据准备

```json
// 📌 训练数据格式（JSON）

// 对话格式
[
    {
        "instruction": "请解释什么是机器学习",
        "input": "",
        "output": "机器学习是人工智能的一个分支..."
    },
    {
        "instruction": "写一个 Python 函数",
        "input": "计算斐波那契数列",
        "output": "def fibonacci(n):\n    if n <= 1:\n        return n\n    return fibonacci(n-1) + fibonacci(n-2)"
    }
]

// 💡 数据准备建议：
// - 至少 100 条高质量数据
// - 指令清晰，回答准确
// - 覆盖目标任务的各种场景
```

## 3.训练参数配置

```bash
# 📌 LLaMA-Factory 训练参数

# 基础配置
model_name_or_path: /path/to/base/model
dataset: my_dataset
output_dir: ./output
lora_rank: 8
lora_alpha: 16
lora_target: all

# 训练参数
num_train_epochs: 3
per_device_train_batch_size: 4
gradient_accumulation_steps: 4
learning_rate: 2e-4
warmup_steps: 100

# 🌟 关键参数说明：
# lora_rank → LoRA 秩（越大越强，但越大越慢）
# lora_alpha → 缩放系数
# lora_target → 应用到哪些层

# 💡 建议：
# 初学者：lora_rank=8, lora_alpha=16
# 进阶：lora_rank=16, lora_alpha=32
```

# 七.LoRA 使用注意事项

```bash
# 📌 LoRA 使用最佳实践

# ✅ 推荐：
# 1. 使用与基础模型匹配的 LoRA
# 2. 先测试小数据集效果
# 3. 保存多个版本的 LoRA
# 4. 记录 LoRA 的训练参数

# ⚠️ 避免：
# 1. 不同架构模型的 LoRA 混用
# 2. LoRA 缩放系数过大（>1.0）
# 3. 训练数据质量差
# 4. 过拟合（训练轮数过多）

# 💡 调试技巧：
# - 调整缩放系数观察效果变化
# - 对比有无 LoRA 的输出差异
# - 在测试集上评估 LoRA 效果
```
