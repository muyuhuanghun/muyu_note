## 一、顺序表操作

顺序表是连续存储的线性结构，核心操作围绕**原地修改**展开。常见考法：删除满足条件的元素、去重、数据调整。三者共享同一个底层模式——双指针扫描。

```c
// 双指针通用模式：慢指针 j 记录保留位置，快指针 i 扫描原数组
int j = 0;
for (int i = 0; i <= L->last; i++) {
    if (满足保留条件) {
        L->elem[j++] = L->elem[i];
    }
}
L->last = j - 1;
```

**icoding 典型题**:
- 删除顺序表中值在 `[min, max]` 范围内的元素——条件为 `elem[i] < min || elem[i] > max`
- 有序顺序表删除重复元素——利用有序性，重复元素一定相邻，条件为 `elem[i] != elem[j]`
- 奇数移到前面、偶数移到后面——类快排 partition，左右指针相向扫描

## 二、链表操作

链表操作的核心是**指针的重新链接**。与顺序表不同，链表无法随机访问，但插入/删除只需修改指针，不需要移动元素。

常见考法：
- **倒数查找**：快慢指针法，快指针先走 k 步，然后同步走，快指针到尾时慢指针指向倒数第 k 个
- **范围删除**：prev + curr 双指针遍历，满足条件时 `prev->next = curr->next` 并释放
- **有序链表合并**：归并思想，哨兵结点简化头结点处理，逐一比较后尾插

## 三、真题精选

### 真题 160：合并顺序表

> 题目编号：160 | 来源：21级期末

解题思路:
- 双指针归并：i 扫描 LA，j 扫描 LB，k 指向 LC 写入位置
- 每次取较小者写入 LC，某一表耗尽后将剩余全部追加
- 时间 O(n+m)，空间 O(1)（LC 由调用者提供）

参考解答见: [[160 合并顺序表]]

### 真题 176：整除移除

> 题目编号：176 | 来源：22级期末

解题思路:
- 双指针原地筛选：慢指针 j 记录保留位置，快指针 i 扫描
- 条件：`elem[i] % f != 0` 时保留，否则跳过
- 遍历结束后 `L->len = j`
- 与顺序表删除范围、保留偶数是同一模式

参考解答见: [[176 整除移除]]

### 真题 177：共享结点

> 题目编号：177 | 来源：22级期末

解题思路:
- 先遍历两链表到尾部，比较尾结点地址判断是否共享
- 计算长度差 diff，长链表先走 diff 步（**求差对齐**）
- 两指针同步前进，首次相遇即为共享起始结点
- 从交汇点遍历到尾部计数

参考解答见: [[177 共享结点]]

### 真题 197：保留线性表中偶数

> 题目编号：197 | 来源：22级期末

解题思路:
- 双指针筛选，与 176 题完全同构
- 条件换为 `elem[i] % 2 == 0`，奇数跳过
- 遍历结束后 `L->len = j`

参考解答见: [[197 保留线性表中偶数]]

### 真题 201：合并有序数组

> 题目编号：201 | 来源：22级期末

解题思路:
- 与 160 题完全同构的双指针归并
- 区别仅在于使用裸指针 + 长度参数（而非顺序表结构体）
- 归并是**必考题型**，必须熟练到不需要思考

参考解答见: [[201 合并有序数组]]

## 解题套路总结

线性表题的三大核心模式：

1. **双指针**（快慢指针 / 左右指针）
   - 适用：顺序表删除、筛选、去重
   - 时间 O(n)，空间 O(1)，原地操作
   - 代表题：176、197、icoding 删除范围

2. **归并**
   - 适用：两个有序表/数组合并
   - 双指针逐一比较，耗尽后追加剩余
   - 代表题：160、201、icoding 链表合并

3. **求差 + 对齐**
   - 适用：链表交汇点、共享结点
   - 先求长度差，长链表先走差值步，然后同步走
   - 代表题：177
