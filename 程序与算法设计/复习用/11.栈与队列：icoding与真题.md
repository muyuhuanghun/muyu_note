## 一、栈的应用：后缀表达式计算

栈的核心特性是 **LIFO（后进先出）**，天然适合处理"需要回溯"的场景。后缀表达式计算是最经典的栈应用：数字入栈，遇运算符弹出两个操作数计算后入栈。

```c
// 后缀表达式求值的核心逻辑
// 输入: "3 4 5 * +"  （即 3 + 4 * 5）
while (还有token) {
    if (token是数字) push(token);
    else {  // token是运算符
        y = pop();  // 先弹出的是右操作数
        x = pop();
        push(x op y);
    }
}
```

后缀 vs 中缀：中缀需要处理优先级（运算符栈 + 输出队列），后缀直接栈计算，无需优先级。

## 二、队列：循环链表表示队列

队列的核心特性是 **FIFO（先进先出）**。循环链表队列的考点在于：只设尾指针时，头结点通过 `tail->next` 访问。

关键结构：
- 头结点作为哨兵，不存数据
- 判空条件：`(*LQ)->next == *LQ`（头结点指向自身）
- 入队：从头结点遍历找队尾，O(n)；若额外维护尾指针可 O(1)
- 出队：删除头结点的下一个结点，O(1)

## 三、真题精选

### 真题 178：反转字符串（递归转栈）

> 题目编号：178 | 来源：22级期末

解题思路:
- 递归版本中 `putchar(c)` 在递归调用之后，输出顺序与读入顺序相反
- 本质是 LIFO 行为，用显式栈替代隐式调用栈
- 两阶段：入栈阶段（读入字符全部 push）-> 出栈阶段（逐个 pop 输出）
- 递归的"回溯" = 栈的 LIFO

参考解答见: [[178 反转字符串]]

### 真题 113：循环链表表示队列

> 题目编号：113 | 来源：icoding 原题

解题思路:
- 初始化：分配头结点，`next` 指向自身
- 入队：从头结点遍历找队尾（`tail->next == 头结点` 的那个），新结点插入队尾之后
- 出队：删除头结点的下一个结点（队首元素），注意判空
- 只设尾指针时，入队需要 O(n) 遍历找队尾

参考解答见: [[113 循环链表表示队列]]

### 真题 120/198：非递归先序遍历

> 题目编号：120、198 | 来源：21级/22级期末 **高频**

解题思路:
- 用栈模拟先序遍历（根->左->右）
- 根结点入栈，循环：弹出 -> 访问 -> **先右后左入栈**
- 先右后左是关键：栈是 LIFO，右先入则左先出，保证左子树先被访问
- 120 题和 198 题本质相同，仅数据类型和栈接口不同

参考解答见: [[120 非递归先序遍历]] | [[198 非递归先序遍历]]

## 解题套路总结

栈和队列的三大考法：

1. **栈模拟递归**
   - 非递归先序/中序/后序遍历
   - 递归转非递归（反转字符串）
   - 核心理解：栈的 LIFO = 递归的回溯

2. **表达式求值**
   - 后缀表达式：数字入栈，遇运算符弹两个算
   - 注意顺序：先弹出的是右操作数

3. **队列实现**
   - 循环链表队列：带头结点，判空条件 `next == 自身`
   - 层次遍历本质是队列 + 二叉树（见树与二叉树专题）
