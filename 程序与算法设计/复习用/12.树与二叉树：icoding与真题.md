## 一、递归遍历与结点关系

二叉树的递归遍历是所有树操作的基础，一行代码即可实现：

```c
void preorder(BiTree root) {
    if (!root) return;
    visit(root);                   // 根
    preorder(root->left);          // 左
    preorder(root->right);         // 右
}
```

**LCA（最近公共祖先）** 是高频考点，递归思路：
- 当前结点是 p 或 q，返回当前结点
- p、q 分居左右子树，当前结点就是 LCA
- 都在同一侧，返回那一侧的结果

**树转二叉树**：孩子-兄弟表示法，左孩子 = 第一个孩子，右兄弟 = 下一个兄弟

**路径打印**：回溯 + 数组记录，到达叶子结点时打印路径

## 二、非递归遍历

非递归遍历的核心工具是**栈**，本质是用显式栈替代递归的隐式调用栈。

先序遍历（根->左->右）的非递归模板：
```
push(root)
while 栈非空:
    node = pop()
    visit(node)
    push(node.right)   // 右先入栈
    push(node.left)    // 左后入栈 → 左先被访问
```

中序遍历（左->根->右）的非递归模板：
```
curr = root
while curr 或 栈非空:
    一路向左压栈: while curr: push(curr); curr = curr.left
    curr = pop()
    visit(curr)
    curr = curr.right
```

## 三、层序遍历

层序遍历的核心工具是**队列**（BFS 广度优先），模板：

```
queue = [root]
while 队列非空:
    node = dequeue()
    visit(node)
    if node.left:  enqueue(node.left)
    if node.right: enqueue(node.right)
```

孩子-兄弟表示法的层序遍历：出队后，沿 `first`（第一个孩子）-> `sibling`（兄弟链）将所有孩子依次入队。

## 四、真题精选

### 真题 120/198：非递归先序遍历

> 题目编号：120、198 | 来源：21级/22级期末 **高频**

解题思路:
- 根结点入栈，循环弹出并访问
- **先右后左入栈**：栈的 LIFO 特性保证左子树先被访问
- 198 题是 120 题的 char 标签版本，栈接口略有不同，算法完全一样

参考解答见: [[120 非递归先序遍历]] | [[198 非递归先序遍历]]

### 真题 162/180：层序遍历

> 题目编号：162、180 | 来源：21级期末 **高频**

解题思路:
- 162 题：先建 BST（逐个插入），再用数组模拟队列做 BFS，结果写回原数组
- 180 题：孩子-兄弟表示法的层序遍历，出队后沿 first->sibling 链将所有孩子入队
- 层序遍历 = 队列，这是必须背下的模板

参考解答见: [[162 树的层序遍历]] | [[180 树的层序遍历]]

### 真题 179：镜像二叉树

> 题目编号：179 | 来源：22级期末

解题思路:
- 递归交换左右子树：`t->left = mirror(tree->right)`, `t->right = mirror(tree->left)`
- 注意区分：生成新镜像树（本题）vs 原地交换（swap）
- 递归终止条件：`if (!tree) return NULL`

参考解答见: [[179 镜像二叉树]]

### 真题 25-2：非递归先序遍历找双子结点

> 来源：24级期末第一批

解题思路:
- 非递归先序遍历的变形
- 访问条件从"所有结点"变为"左右孩子都存在的结点"
- 核心逻辑不变：弹出 -> 判断 `node->left && node->right` -> 先右后左入栈

## 解题套路总结

树与二叉树的五大考法：

1. **遍历**（必考）
   - 递归版本：一行代码，三种顺序的区别仅在 visit 的位置
   - 非递归版本：栈模拟，先序最简单（先右后左入栈）
   - 层序遍历：队列实现 BFS

2. **建树**
   - BST 逐个插入
   - 前序+中序重建：递归分治

3. **结点关系**
   - LCA：递归，p/q 分居左右时当前结点即答案
   - 路径打印：回溯 + 数组记录

4. **树的变换**
   - 镜像翻转：递归交换左右子树
   - 树转二叉树：孩子-兄弟表示法

5. **计数统计**
   - 叶子结点数：左右都空
   - 树的高度：max(左高, 右高) + 1
