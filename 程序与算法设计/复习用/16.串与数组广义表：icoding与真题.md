## 一、串的基本操作

串（string）是字符序列，核心操作围绕**逐字符遍历**展开。常见考法：比较、替换、匹配。

### 串比较

**icoding 题**: 实现字符串比较

```c
// 逐字符比较，返回差值
// 返回值：<0 表示 s1 < s2，0 表示相等，>0 表示 s1 > s2
int str_compare(char *s1, char *s2) {
    while (*s1 && *s2 && *s1 == *s2) {
        s1++;
        s2++;
    }
    return *s1 - *s2;
}
```

### 串替换

**icoding 题**: 在主串中将所有子串替换为新串

```c
// 暴力匹配 + 替换
void str_replace(char *main_str, char *pattern, char *replacement) {
    int mlen = strlen(main_str);
    int plen = strlen(pattern);
    int rlen = strlen(replacement);
    char result[1000] = {0};
    int ri = 0, mi = 0;

    while (mi < mlen) {
        if (strncmp(main_str + mi, pattern, plen) == 0) {
            for (int i = 0; i < rlen; i++)
                result[ri++] = replacement[i];
            mi += plen;                     // 跳过已匹配的子串
        } else {
            result[ri++] = main_str[mi++];  // 逐字符复制
        }
    }
    result[ri] = '\0';
    strcpy(main_str, result);
}
```

## 二、块链串

块链串是链式存储的改进版，每个结点存多个字符，减少指针开销。

**icoding 题**: 用块链存储字符串

```c
#define BLOCK_SIZE 4

typedef struct ChunkNode {
    char data[BLOCK_SIZE];  // 每个块存 BLOCK_SIZE 个字符
    int used;               // 实际存储的字符数
    struct ChunkNode *next;
} ChunkNode;

typedef struct {
    ChunkNode *head;
    int length;
} ChunkString;
```

块链串 vs 普通链串：普通链串每个结点存 1 个字符，指针占比大；块链串每个结点存多个字符，空间利用率更高。

## 三、十字链表（稀疏矩阵）

十字链表 = 行链表数组 + 列链表数组，每个非零元素同时挂在行链表和列链表上，支持高效的插入/删除。

**icoding 题**: 用十字链表存储稀疏矩阵

```c
typedef struct OLNode {
    int row, col;
    int value;
    struct OLNode *right;   // 同一行的下一个非零元素
    struct OLNode *down;    // 同一列的下一个非零元素
} OLNode;

typedef struct {
    OLNode *rhead[MAX];     // 行链表头数组
    OLNode *chead[MAX];     // 列链表头数组
    int rows, cols, nums;   // 行数、列数、非零元素个数
} CrossList;
```

十字链表 vs 三元组：

| 存储方式 | 插入/删除 | 空间 | 适用场景 |
|:---|:---:|:---:|:---|
| 三元组（顺序表） | O(n) 需移动 | 紧凑 | 静态稀疏矩阵运算 |
| 十字链表（链式） | O(1) | 有指针开销 | 频繁增删非零元素 |

## 四、广义表

广义表是递归定义的线性表：表头（第一个元素）+ 表尾（剩余元素组成的表）。

**关键概念**：
- **深度**：嵌套层数，`max(子表深度) + 1`，原子的深度为 0
- **长度**：顶层元素个数
- **表头**：可以是原子，也可以是子表
- **表尾**：一定是一个表（广义表）

示例：`A = (a, (b, c), d)`
- 长度 = 3（三个顶层元素）
- 表头 = `a`，表尾 = `((b, c), d)`
- 深度 = 2（`(b, c)` 嵌套了一层）

## 解题套路总结

串与数组广义表的三大考法：

1. **串操作**
   - 比较、替换、匹配，核心是逐字符遍历
   - KMP 算法可能手算 next 数组

2. **稀疏矩阵存储**
   - 三元组：行、列、值，按行优先排序，支持双指针归并（加法/乘法）
   - 十字链表：行链表 + 列链表，适合动态操作
   - 考试编程题偏向三元组，十字链表考概念

3. **广义表**
   - 递归定义，求深度用 max 子表深度 + 1
   - 求长度数顶层元素个数
   - 表头是元素，表尾是表
