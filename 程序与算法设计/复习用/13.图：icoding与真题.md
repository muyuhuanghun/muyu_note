## 一、存储结构

图的两种基本存储方式：

**邻接矩阵**：二维数组 `arcs[i][j]`，适合稠密图，O(1) 判断边是否存在
- 插入顶点：追加到 vertex 数组末尾，检查重复和容量
- 插入边：定位两个顶点下标，设置 `arcs[vi][wi] = 1`，无向图需对称设置

**邻接表**：顶点数组 + 边链表，适合稀疏图，节省空间
- 每个顶点维护一条出弧链表
- 头插法插入弧，O(1)

## 二、图的遍历

**DFS（深度优先搜索）**：递归/栈，沿着一条路走到底再回溯
```c
// 邻接矩阵上的 DFS
void DFS(Graph *G, int v) {
    visited[v] = true;
    visit(v);
    for (int w = 0; w < G->vexnum; w++)
        if (G->arcs[v][w] && !visited[w])
            DFS(G, w);
}
// 非连通图需遍历所有顶点，对每个未访问顶点调用 DFS
```

**BFS（广度优先搜索）**：队列，逐层扩展，层序遍历本质就是 BFS

## 三、真题精选

### 真题 127：邻接矩阵基本操作

> 题目编号：127 | 来源：icoding 原题

解题思路:
- 插入顶点：检查容量上限、检查重复、追加到数组末尾
- 插入边：调用 `locate_vertex` 定位下标、检查弧是否已存在、无向图需对称设置
- 结构体类型标志 `GraphType` 区分有向图和无向图

参考解答见: [[127 邻接矩阵]]

### 真题 161：关键路径

> 题目编号：161 | 来源：AOE 网经典题

解题思路:
- 正向求最早发生时间：`ve[j] = max{ve[i] + w(i,j)}`，按拓扑序计算
- 逆向求最迟发生时间：`vl[i] = min{vl[j] - w(i,j)}`，逆拓扑序计算
- 关键活动：`e(i,j) == l(i,j)` 的活动（即 `ve[i] == vl[j] - w(i,j)`）
- 关键路径 = 关键活动构成的从源点到汇点的路径

参考解答见: [[161 关键路径]]

### 真题 181：图的焊接（合并边）

> 题目编号：181 | 来源：22级期末

解题思路:
- 遍历 G2 的每个顶点，用 `locate_vertex` 在 G1 中找到对应顶点
- 遍历 G2 当前顶点的每条出弧，在 G1 中找到弧头顶点的下标
- 检查 G1 中是否已存在该弧（去重），不存在则用**头插法**插入
- 难点：通过字符标签在两个图之间建立映射关系

参考解答见: [[181 图的焊接]]

### 真题 200：判断欧拉通路

> 题目编号：200 | 来源：22级期末 **经典**

解题思路:
- 遍历邻接矩阵统计每个顶点的入度和出度
- 计算 `diff = indegree - outdegree`
- 判定条件：
  - 任何顶点 `|diff| > 1` -> 不存在
  - `diff != 0` 的顶点数为 0（欧拉回路）或 2（一进一出）-> 存在
  - 其他情况 -> 不存在

参考解答见: [[200 判断欧拉通路]]

## 四、手算必考

### Prim 最小生成树（从点出发）

1. 从任意顶点开始，加入集合 S
2. 找 S 到 V-S 的最小权值边
3. 将该边和对应顶点加入 S
4. 重复直到 S = V

适合稠密图，时间 O(n^2)

### Kruskal 最小生成树（从边出发）

1. 将所有边按权值从小到大排序
2. 依次选边，如果不成环则加入（用并查集判环）
3. 重复直到选了 n-1 条边

适合稀疏图，时间 O(E log E)

### 关键路径（AOE 网）

1. 正向 ve[]：从源点出发，`ve[j] = max{ve[i] + w(i,j)}`
2. 逆向 vl[]：从汇点出发，`vl[i] = min{vl[j] - w(i,j)}`
3. 关键活动：`ve[i] == vl[j] - w(i,j)`
4. 关键路径长度 = 汇点的 ve 值 = 工程最短工期

## 解题套路总结

图论的五大考法：

1. **存储结构**
   - 邻接矩阵：稠密图，O(1) 判边
   - 邻接表：稀疏图，节省空间
   - 插入操作需检查重复、无向图对称

2. **遍历**
   - DFS：递归/栈，深度优先
   - BFS：队列，广度优先
   - 非连通图需遍历所有顶点

3. **最短路径**
   - Dijkstra：单源最短路径，不含负权
   - Floyd：所有点对最短路径

4. **最小生成树**
   - Prim：从点出发，适合稠密图
   - Kruskal：从边出发，适合稀疏图

5. **拓扑排序 / 关键路径**
   - AOE 网：关键路径 = 最长路径 = 工程最短工期
   - 手算时画表求 ve[] 和 vl[] 最不容易出错
