## 一、手算必考题型

### 1. Prim / Kruskal 最小生成树

**Prim（从点出发）**：
1. 任选起点，加入集合 S
2. 找 S 到 V-S 的最小权边
3. 将边和对应顶点加入 S
4. 重复 n-1 次

**Kruskal（从边出发）**：
1. 所有边按权值排序
2. 从小到大选边，不成环就加入
3. 选够 n-1 条边停止

### 2. 关键路径（AOE 网）

1. 正向计算 `ve(j) = max{ve(i) + w(i,j)}` — 最早发生时间
2. 逆向计算 `vl(j) = min{vl(k) - w(j,k)}` — 最迟发生时间
3. `e(i) = ve(弧尾)` — 最早开始时间
4. `l(i) = vl(弧头) - w` — 最迟开始时间
5. `e(i) = l(i)` 的弧 -> 关键活动
6. 关键活动连成 -> 关键路径

24级期末真题答案示例：`{0, 3, 11, 18, 24}`

### 3. 邻接矩阵入度/出度计算

```c
// 入度：第 j 列的非零元素个数
int indegree(MatrixGraph *G, int v) {
    int count = 0;
    for (int i = 0; i < G->vexnum; i++)
        if (G->arcs[i][v] != 0) count++;
    return count;
}

// 出度：第 i 行的非零元素个数
int outdegree(MatrixGraph *G, int v) {
    int count = 0;
    for (int j = 0; j < G->vexnum; j++)
        if (G->arcs[v][j] != 0) count++;
    return count;
}
```

### 5. 非递归先序遍历

出现频率最高的编程题（21级、22级、24级三批均考）

```c
void preorder(BiTree root) {
    Stack S; init_stack(&S);
    push(&S, root);
    while (!is_empty(&S)) {
        BiTNode *node;
        pop(&S, &node);
        visit(node);
        if (node->right) push(&S, node->right);  // 右先入
        if (node->left) push(&S, node->left);    // 左后入 -> 左先出
    }
}
```

### 6. 顺序表操作

```c
// 插入：从后往前移
void seq_insert(SeqList *L, int pos, int val) {
    for (int i = L->last; i >= pos; i--)
        L->elem[i+1] = L->elem[i];
    L->elem[pos] = val;
    L->last++;
}

// 删除：从前往后覆盖
void seq_delete(SeqList *L, int pos) {
    for (int i = pos; i < L->last; i++)
        L->elem[i] = L->elem[i+1];
    L->last--;
}
```

### 7. 链表操作

```c
// 头插法建链表（结果是逆序的）
node* build_list_head(int arr[], int n) {
    node *head = NULL;
    for (int i = 0; i < n; i++) {
        node *new = malloc(sizeof(node));
        new->data = arr[i];
        new->next = head;
        head = new;
    }
    return head;
}

// 尾插法建链表（结果是正序的）
node* build_list_tail(int arr[], int n) {
    node dummy; node *tail = &dummy;
    for (int i = 0; i < n; i++) {
        node *new = malloc(sizeof(node));
        new->data = arr[i];
        new->next = NULL;
        tail->next = new;
        tail = new;
    }
    return dummy.next;
}
```

### 8. 哈希表操作

```c
// 线性探测法插入
void hash_insert_linear(int table[], int size, int key) {
    int idx = key % size;
    while (table[idx] != 0)
        idx = (idx + 1) % size;
    table[idx] = key;
}

// 拉链法插入
void hash_insert_chain(HashNode *table[], int size, int key) {
    int idx = key % size;
    HashNode *node = malloc(sizeof(HashNode));
    node->key = key;
    node->next = table[idx];
    table[idx] = node;  // 头插法
}
```

## 五、考试策略

程算 II 机考策略（2 小时 5 题）：

**时间分配**：
- 手算题（Prim/Kruskal/关键路径）：15-20 分钟
- 编程题：每题 20-25 分钟
- 留 10 分钟检查

**做题顺序**：
1. 先做手算题（稳拿分）
2. 再做编程题（从简单的开始）
3. 线性表/排序 -> 树遍历 -> 图 -> 其他

**编程题技巧**：
- 先写核心逻辑，再补边界检查
- 用注释说明思路（即使没写完也有步骤分）
- 善用辅助函数（swap、visit 等）

**高频考点**（按出现频率排序）：
- 非递归先序遍历
- 顺序表/链表操作
- 图的遍历/入度出度
- 哈希表操作
- 排序算法
