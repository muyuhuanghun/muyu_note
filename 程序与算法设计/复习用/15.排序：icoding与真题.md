## 一、堆操作

堆是完全二叉树的数组表示。大顶堆：父 >= 子；小顶堆：父 <= 子。数组下标从 1 开始时，结点 i 的左孩子 = 2i，右孩子 = 2i+1，父结点 = i/2。

### 向下调整（堆化）

删除堆顶后，将最后一个元素放到堆顶，再向下调整恢复堆性质。

```c
// 以 arr[k] 为根的子树调整为大顶堆，arr[0] 作暂存单元
void sift(int arr[], int k, int m) {
    arr[0] = arr[k];
    int j = 2 * k;              // j 指向左孩子

    while (j <= m) {
        // 选较大的孩子
        if (j < m && arr[j] < arr[j + 1])
            j++;                // 右孩子更大
        if (arr[0] >= arr[j])
            break;              // 根已经最大
        arr[k] = arr[j];        // 孩子上移
        k = j;
        j = 2 * k;
    }
    arr[k] = arr[0];            // 插入最终位置
}
```

### 建堆

从最后一个非叶子结点 n/2 开始，向前逐个调用 sift。

```c
void create_heap(int arr[], int n) {
    for (int i = n / 2; i > 0; i--)
        sift(arr, i, n);
}
```

### 向上调整（插入）

新元素放末尾，与父结点比较，若小于父则交换，直到满足堆性质。

```c
void heapify_up(int arr[], int i) {
    while (i > 0) {
        int parent = (i - 1) / 2;
        if (arr[i] < arr[parent]) {     // 最小堆：子 < 父就交换
            swap(&arr[i], &arr[parent]);
            i = parent;
        } else break;
    }
}
```

## 二、五种排序手写代码

### 1. 简单选择排序

每一轮从未排序部分选出最小元素，放到已排序部分末尾。

```c
void selection_sort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int min_idx = i;
        for (int j = i + 1; j < n; j++)
            if (arr[j] < arr[min_idx])
                min_idx = j;
        swap(&arr[i], &arr[min_idx]);
    }
}
```

### 2. 直接插入排序

类似打牌，每次把新牌插入到已排序的正确位置。

```c
void insertion_sort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];       // 后移
            j--;
        }
        arr[j + 1] = key;              // 插入到正确位置
    }
}
```

### 3. 快速排序

分治思想：选基准 -> 分区 -> 递归。partition 是核心。

```c
int partition(int arr[], int low, int high) {
    int pivot = arr[low];               // 选第一个做基准
    while (low < high) {
        while (low < high && arr[high] >= pivot)
            high--;
        swap(&arr[low], &arr[high]);
        while (low < high && arr[low] <= pivot)
            low++;
        swap(&arr[low], &arr[high]);
    }
    arr[low] = pivot;                   // 基准归位
    return low;
}

void quick_sort(int arr[], int low, int high) {
    if (low < high) {
        int pi = partition(arr, low, high);
        quick_sort(arr, low, pi - 1);
        quick_sort(arr, pi + 1, high);
    }
}
```

### 4. 堆排序

建大顶堆，每次将堆顶（最大值）交换到末尾，缩小堆范围后重新调整。

```c
void heap_sort(int arr[], int n) {
    // 建最大堆（从最后一个非叶子结点开始）
    for (int i = n / 2 - 1; i >= 0; i--)
        sift_max(arr, n, i);

    // 逐个取出堆顶放到末尾
    for (int i = n - 1; i > 0; i--) {
        swap(&arr[0], &arr[i]);         // 堆顶归位
        sift_max(arr, i, 0);            // 缩小范围，重新调整
    }
}
```

### 5. 归并排序

将数组一分为二，递归排序后合并。稳定排序中唯一 O(n log n)。

```c
void merge(int arr[], int left, int mid, int right) {
    int temp[right - left + 1];
    int i = left, j = mid + 1, k = 0;
    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j]) temp[k++] = arr[i++];
        else temp[k++] = arr[j++];
    }
    while (i <= mid) temp[k++] = arr[i++];
    while (j <= right) temp[k++] = arr[j++];
    for (k = 0; k < right - left + 1; k++)
        arr[left + k] = temp[k];
}

void merge_sort(int arr[], int left, int right) {
    if (left < right) {
        int mid = (left + right) / 2;
        merge_sort(arr, left, mid);
        merge_sort(arr, mid + 1, right);
        merge(arr, left, mid, right);
    }
}
```

## 三、核心排序对比表

| 算法 | 平均时间 | 最坏时间 | 空间 | 稳定性 | 适用场景 |
|:---|:---:|:---:|:---:|:---:|:---|
| 简单选择排序 | O(n^2) | O(n^2) | O(1) | 不稳定 | 小规模数据 |
| 直接插入排序 | O(n^2) | O(n^2) | O(1) | **稳定** | 几乎有序时 O(n) |
| 快速排序 | O(n log n) | O(n^2) | O(log n) | 不稳定 | 通用最优 |
| 堆排序 | O(n log n) | O(n log n) | O(1) | 不稳定 | 不怕最坏情况 |
| 归并排序 | O(n log n) | O(n log n) | O(n) | **稳定** | 需要稳定排序 |
| 计数排序 | O(n+m) | O(n+m) | O(m) | **稳定** | 非负整数，范围小 |

### 手算第一趟结果

| 排序算法 | 第一趟结果 | 说明 |

## 解题套路总结

排序的三大考法：

1. **手写排序代码**
   - 选择排序：双层循环，外层遍历位置，内层找最小值，交换
   - 插入排序：从第二个元素开始，与前面已排序部分比较后移，插入空位
   - 快排：partition 分区是核心，low/high 相向扫描
   - 堆排序：建堆 + 取堆顶 + 调整，三步走

2. **排序过程手算**
   - 给定数组，写出第一趟排序结果
   - 关键：判断用的是什么排序算法

3. **排序选择**
   - 小规模 -> 插入排序
   - 通用 -> 快排
   - 不允许最坏 -> 堆排序
   - 需要稳定 -> 归并排序
   - 非负整数且范围小 -> 计数排序
