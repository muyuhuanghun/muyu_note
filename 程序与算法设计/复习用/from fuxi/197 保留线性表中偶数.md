## 解题思路

- 与第 176 题（整除移除）采用**相同的双指针筛选**模式
- **慢指针 j**：指向下一个"偶数元素"应当写入的位置
- **快指针 i**：遍历整个数组，逐一检查每个元素
- 若 `elem[i]` 是偶数（`elem[i] % 2 == 0`），则将其复制到 `elem[j]` 并推进 j
- 若 `elem[i]` 是奇数，则跳过
- 遍历结束后更新 `L->len = j`

## 参考解答

```c
/*
 * keep_even - 在线性表中仅保留偶数元素
 *
 * 算法：双指针原地筛选（同 176 题模式）
 *   - i 是快指针，扫描整个数组
 *   - j 是慢指针，指向下一个保留元素的写入位置
 *   - 当 elem[i] 是偶数时，将其复制到 elem[j]，j 前进
 *   - 当 elem[i] 是奇数时，跳过（不复制）
 *   - 遍历结束后，j 即为保留元素的个数
 *
 * 时间复杂度：O(n)，只遍历一次
 * 空间复杂度：O(1)，原地操作
 *
 * @param L 指向线性表的指针，保证不为空表
 */
void keep_even(list *L) {
    int i;      /* 快指针：遍历整个数组 */
    int j = 0;  /* 慢指针：指向下一个偶数的写入位置，初始化为 0 */

    for (i = 0; i < L->len; i++) {          /* 遍历数组中的每一个元素 */
        if (L->elem[i] % 2 == 0) {          /* 当前元素是偶数 -> 保留 */
            L->elem[j] = L->elem[i];        /* 将偶数复制到慢指针位置 */
            j++;                             /* 慢指针前进，准备下一个写入位 */
        }
        /* 若 elem[i] 是奇数，直接跳过，不复制 */
    }

    L->len = j;  /* 更新线性表长度为保留元素（偶数）的个数 */
}
```
