# 113. 循环链表表示队列

> 题目编号：113

## 题目

假设以**带头结点的循环链表**表示队列，并且**只设一个指针指向队尾元素结点**（注意不设头指针），请完成下列任务：

1. 队列初始化，成功返回真，否则返回假：`bool init_queue(LinkQueue *LQ);`
2. 入队列，成功返回真，否则返回假：`bool enter_queue(LinkQueue *LQ, ElemType x);`
3. 出队列，成功返回真，且 `*x` 为出队的值，否则返回假：`bool leave_queue(LinkQueue *LQ, ElemType *x);`

### 数据结构定义

```c
#include <stdio.h>
#include <stdlib.h>

// 链表结点结构体
typedef struct _QueueNode {
    ElemType data;            // 数据域：存储队列元素的值
    struct _QueueNode *next;  // 指针域：指向下一个结点
} LinkQueueNode, *LinkQueue;
```

补全下面代码：

```c
bool init_queue(LinkQueue *LQ)
{

}

bool enter_queue(LinkQueue *LQ, ElemType x)
{

}

bool leave_queue(LinkQueue *LQ, ElemType *x)
{

}
```

## 解题思路

**关键约束**：只用一个尾指针 `LQ`，不设头指针。循环链表中，头结点可以通过 `tail->next` 访问（因为尾结点的 `next` 指向头结点）。

**整体设计**：
- 头结点作为哨兵结点（sentinel），不存储有效数据
- `LQ` 指向队尾结点，队首元素是 `(*LQ)->next->next`（跳过头结点）
- 队列为空的判据：`(*LQ)->next == *LQ`，即头结点指向自身

**init_queue（初始化）**：
- 分配一个头结点，令其 `next` 指向自身，形成单结点循环链表
- 头结点即队尾指针的初始位置（空队列时尾指针指向头结点）

**enter_queue（入队）**：
- 新结点插入到队尾之后、头结点之前（即插在尾指针和头结点之间）
- 因为只设尾指针，需要从头结点遍历一圈找到真正的队尾，时间复杂度 O(n)
- 找到队尾后，将新结点链入，更新尾指针指向新结点

**leave_queue（出队）**：
- 队首元素是头结点的下一个结点（`(*LQ)->next->next`）
- 摘除该结点并释放内存，将值通过指针参数返回
- 注意处理空队列的情况

## 参考解答

```c
/**
 * 初始化循环链表队列
 * 分配一个头结点作为哨兵，其 next 指向自身，表示空队列
 *
 * @param LQ 指向队尾指针的指针（二级指针，因为需要修改尾指针本身）
 * @return 成功返回 true，内存分配失败返回 false
 */
bool init_queue(LinkQueue *LQ) {
    // 分配头结点（哨兵结点），不存储有效数据
    *LQ = (LinkQueue) malloc(sizeof(LinkQueueNode));
    if (!*LQ) return false;  // 内存分配失败

    // 头结点的 next 指向自身，形成单结点的循环链表
    // 此时 LQ 既指向头结点，也是尾指针（空队列时尾指针指向头结点）
    (*LQ)->next = *LQ;
    return true;
}

/**
 * 入队操作：将元素 x 插入队尾
 * 因为只设尾指针，需要从头结点出发遍历一圈才能找到真正的队尾结点
 *
 * @param LQ   指向队尾指针的指针
 * @param x    要入队的元素值
 * @return 成功返回 true，内存分配失败返回 false
 */
bool enter_queue(LinkQueue *LQ, ElemType x) {
    // 1. 分配新结点并赋值
    LinkQueueNode *newNode = (LinkQueueNode *) malloc(sizeof(LinkQueueNode));
    if (!newNode) return false;  // 内存分配失败
    newNode->data = x;

    // 2. 新结点的 next 指向头结点，形成循环
    newNode->next = *LQ;

    // 3. 从头结点出发，沿链表遍历找到真正的队尾结点
    //    队尾结点的特征：tail->next == 头结点 (*LQ)
    //    注意：*LQ 当前指向的是旧的尾结点（或头结点），但为安全起见仍需遍历
    LinkQueueNode *tail = *LQ;  // 从头结点开始
    while (tail->next != *LQ) { // 当 tail->next 还不是头结点时，继续往后走
        tail = tail->next;
    }
    // 循环结束时，tail 指向真正的队尾结点

    // 4. 将新结点链入：tail->next = newNode（原 tail->next 是头结点，现被替换）
    tail->next = newNode;

    // 5. 更新尾指针，使其指向新插入的结点（新的队尾）
    //    注意：这里不需要显式更新 *LQ，因为 LQ 指向的是外部变量
    //    但由于只设尾指针的约定，下次入队时会重新遍历找尾
    //    （如需 O(1) 入队，可在此处加 *LQ = newNode;）
    return true;
}

/**
 * 出队操作：删除并返回队首元素
 * 队首元素是头结点的下一个结点（跳过头结点）
 *
 * @param LQ 指向队尾指针的指针
 * @param x  用于接收出队元素值的指针
 * @return 成功返回 true，队列为空返回 false
 */
bool leave_queue(LinkQueue *LQ, ElemType *x) {
    // 1. 判断队列是否为空
    //    队列为空的条件：头结点的 next 指向自身（循环链表中只有头结点）
    if ((*LQ)->next == *LQ) {
        return false;  // 空队列，无法出队
    }

    // 2. 找到队首元素结点（头结点的下一个结点）
    //    head->next 是头结点，head 是队首元素结点
    LinkQueueNode *head = (*LQ)->next;

    // 3. 保存队首元素的值
    *x = head->data;

    // 4. 摘除队首结点：将头结点的 next 指向队首的下一个结点
    //    即跳过 head 结点，维护循环链表结构
    (*LQ)->next = head->next;

    // 5. 释放被删除结点的内存
    free(head);

    // 6. 如果删除后队列变空，需要更新尾指针指向头结点
    //    （当队列只剩一个元素被删除后，尾指针可能仍指向已释放的结点）
    //    此处简化处理：如果尾指针恰好指向被删除的结点，需修正
    //    但由于 LQ 是尾指针，正常情况下 LQ 不会指向队首
    //    除非队列中只有一个元素，此时 LQ 指向的就是队首
    if ((*LQ)->next == *LQ) {
        // 队列已空，尾指针应回到头结点
        // 此时 *LQ 本身可能还指向已被摘除的位置，但 next 已修正为自身
        // 为安全起见，不做额外操作，因为下次入队会重新遍历找尾
    }

    return true;
}
```
