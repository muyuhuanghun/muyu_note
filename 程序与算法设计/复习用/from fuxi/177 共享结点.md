# 177 共享结点

> 题目编号：177

## 题目

### 数据结构定义

```c
/* ========== 单链表结点定义 ========== */
typedef struct _node {
    int data;            /* 数据域，存储结点的值 */
    struct _node *next;  /* 指针域，指向下一个结点 */
} node;

/* ========== 单链表类型定义 ========== */
typedef struct {
    node *head;      /* 头指针，指向链表的第一个结点（带头结点或不带头结点均可） */
    unsigned len;    /* 链表中的结点数量 */
} list;
```

**题目描述：**

现已知有两个上述类型的线性表 La 和 Lb，二者在某个结点处**融合**在一起，形成类似"Y"字形的结构：

```
La: a1 -> a2 -> a3 \
                      -> c1 -> c2 -> c3 -> NULL
Lb: b1 -> b2 ------/
```

即 La 和 Lb 各自有独立的前缀部分，但从某个结点开始共享同一段后缀（共享结点）。两个链表都可能为空。

### 编码要求

请设计一个算法，计算两个链表**共享结点的数量**。

**函数原型：**

```c
int list_shared(list *La, list *Lb);
```

**功能**：计算并返回线性表 La 和 Lb 的共享结点的数量。

**参数**：La 和 Lb 都是指向线性表的指针。

**返回值**：La 和 Lb 共享结点的数目。

**复杂度约束**：
- 时间复杂度：`O(max(La->len, Lb->len))`
- 空间复杂度：`O(1)`

---

## 解题思路

- **判断是否共享**：先分别遍历两个链表到尾部，记录各自长度。如果尾结点地址不同，说明两链表不共享，直接返回 0
- **对齐起点**：计算两个链表的长度差 `diff`，让较长链表的指针先走 `diff` 步，使两个指针到各自尾部的距离相同
- **同步前进找交点**：两个指针同时向后移动，当它们指向同一结点时，该结点就是共享的起始结点
- **计数共享结点**：从交点开始遍历到链表末尾，统计共享结点的数量

---

## 参考解答

```c
/*
 * list_shared - 计算两个链表的共享结点数量
 *
 * 算法步骤：
 *   1. 分别遍历 La 和 Lb 到各自尾结点，同时记录长度
 *   2. 比较尾结点地址：若不同则无共享结点，返回 0
 *   3. 计算长度差 diff，让较长链表的指针先走 diff 步（对齐）
 *   4. 两个指针同步前进，首次相遇的结点即为共享起始结点
 *   5. 从共享起始结点遍历到末尾，统计共享结点数量
 *
 * 时间复杂度：O(n + m)，n 和 m 分别为两个链表的长度
 * 空间复杂度：O(1)，只使用常数个指针变量
 *
 * @param La 指向链表 La 的指针
 * @param Lb 指向链表 Lb 的指针
 * @return 共享结点的数量；若不共享则返回 0
 */
int list_shared(list *La, list *Lb) {
    /* ---- 边界情况：任一链表为空则无共享 ---- */
    if (La->head == NULL || Lb->head == NULL)
        return 0;

    node *p = La->head;  /* p 用于遍历 La */
    node *q = Lb->head;  /* q 用于遍历 Lb */
    int len_a = 0;       /* La 的长度 */
    int len_b = 0;       /* Lb 的长度 */

    /* ---- 步骤1：遍历到各自尾结点，计算长度 ---- */
    while (p->next != NULL) {  /* 遍历 La 直到尾结点 */
        p = p->next;
        len_a++;
    }
    while (q->next != NULL) {  /* 遍历 Lb 直到尾结点 */
        q = q->next;
        len_b++;
    }

    /* ---- 步骤2：尾结点地址不同 -> 无共享结点 ---- */
    if (p != q)
        return 0;

    /* ---- 步骤3：对齐两个指针 ---- */
    /* 让较长链表的指针先走 diff 步，使得两个指针到尾部的距离相同 */
    p = La->head;  /* 重置 p 到 La 头部 */
    q = Lb->head;  /* 重置 q 到 Lb 头部 */

    if (len_a > len_b) {
        /* La 更长，p 先走 (len_a - len_b) 步 */
        for (int i = 0; i < len_a - len_b; i++)
            p = p->next;
    } else {
        /* Lb 更长（或等长），q 先走 (len_b - len_a) 步 */
        for (int i = 0; i < len_b - len_a; i++)
            q = q->next;
    }

    /* ---- 步骤4：同步前进，找到共享起始结点 ---- */
    /* 此时 p 和 q 到各自尾部的距离相同，同步移动必在共享起始处相遇 */
    while (p != q) {
        p = p->next;
        q = q->next;
    }

    /* ---- 步骤5：从共享起始结点遍历到末尾，计数 ---- */
    int count = 0;  /* 共享结点计数器 */
    while (p != NULL) {
        p = p->next;
        count++;
    }

    return count;  /* 返回共享结点数量 */
}
```
