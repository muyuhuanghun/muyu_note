# 哈希冲突（链址法）

> 题目编号：199

## 题目

创建一个使用链址法（chaining）解决键值冲突问题的 Hash 表。

### 数据结构定义

```c
/* 哈希表的结点结构体
 * key   : 存储的关键字值
 * next  : 指向同一桶中下一个结点的指针（链地址法的链表结构） */
typedef struct hashnode {
    int key;
    struct hashnode *next;
} hashnode;

/* main 函数，启动测试函数 */
int main() {
    extern int q3();   /* 已写好的测试函数，无需修改 */
    return q3();
}
```

### 函数原型

```c
/*
 * @brief   创建一个使用链址法解决键值冲突问题的 Hash 表
 *          如果散列时出现冲突，那么需要：
 *          1. 为新结点分配内存
 *          2. 将键值存入新结点的数据域
 *          3. 将新结点用头插法插入链表中
 *
 * @param   ht  : Hash 表。实际上是一个指针数组，每个指针是一个单链表的头指针。
 * @param   keys: 包含待散列的键值的数组
 * @param   n   : keys 数组的长度。注意：这不是 ht 的长度！ht 的长度为 P
 *
 * @return  void
 */
void hashing(hashnode *ht[], int *keys, int n);
```

## 解题思路

- **哈希函数**：`hashval = keys[i] % P`，其中 P 为哈希表的桶数（由外部定义），取模结果作为数组下标。
- **链址法原理**：哈希表的每个槽位维护一条单链表，所有映射到同一槽位的关键字都挂在这条链表上。
- **头插法**：当某个桶已有结点时，新结点插在链表头部（即桶的最前端），操作为：
  1. 将新结点的 `next` 指向当前桶的头结点；
  2. 将桶指针更新为新结点。
- **空桶处理**：若桶指针为 `NULL`，说明该桶尚无任何结点，直接将新结点赋给桶指针即可。
- **时间复杂度**：插入每个关键字为 O(1)，总时间复杂度为 O(n)。

## 参考解答

```c
/*
 * hashing - 使用链址法（头插法）将关键字数组散列到哈希表中
 *
 * @param ht  : 哈希表，类型为 hashnode* 数组，每个元素是一个链表的头指针
 * @param keys: 待散列的关键字数组
 * @param n   : keys 数组的长度
 *
 * 处理流程：
 *   遍历 keys 数组中的每个关键字：
 *     1. 分配新结点，填入 key 值
 *     2. 计算哈希值 hashval = keys[i] % P
 *     3. 若 ht[hashval] 为空，直接让桶指针指向新结点
 *     4. 若 ht[hashval] 非空，使用头插法将新结点插入链表头部
 */
void hashing(hashnode *ht[], int *keys, int n) {
    /* 遍历待散列的每一个关键字 */
    for (int i = 0; i < n; i++) {

        /* 第一步：为新结点分配内存，并初始化数据域和指针域 */
        hashnode *newnode = (hashnode *)malloc(sizeof(hashnode));
        newnode->key  = keys[i];   /* 填入关键字值 */
        newnode->next = NULL;      /* 初始化 next 指针为空 */

        /* 第二步：通过哈希函数计算该关键字应放入的桶下标 */
        int hashval = keys[i] % P;

        /* 第三步：根据桶是否为空，选择插入方式 */
        if (ht[hashval] == NULL) {
            /* 情况 A：桶为空 —— 新结点直接成为该桶的第一个结点 */
            ht[hashval] = newnode;
        } else {
            /* 情况 B：桶非空（发生冲突）—— 使用头插法
             * 1. 新结点的 next 指向原链表头结点
             * 2. 桶指针更新为新结点，使新结点成为新的链表头 */
            newnode->next = ht[hashval];
            ht[hashval] = newnode;
        }
    }
}
```
