# 树的层序遍历（孩子-兄弟表示法）

> 题目编号：180

## 题目

设有一棵树，其**层次遍历**顺序为：`ABFGCDHE`

该树的存储结构使用**孩子-兄弟表示法**：

```c
typedef struct csnode {
    char data;              // 结点的字符标签
    struct csnode *first;   // 指向结点的**第一个孩子**结点
    struct csnode *sibling; // 指向结点的**下一个兄弟**结点
} csnode, *cstree;
```

孩子-兄弟表示法的含义：
- `first` 指针指向该结点的最左边的孩子（第一个孩子）
- `sibling` 指针指向该结点右边的兄弟结点
- 通过 `first` 和 `sibling` 两个指针，可以将一棵普通树转化为"左孩子右兄弟"的二叉树形式

另有可用的**队列**操作接口：

```c
bool queue_enter(queue *Q, void *v);  // 数据 v 进队 Q，v 的类型是任意类型指针
void* queue_leave(queue *Q);          // 数据出队，返回值类型是任意类型指针
bool queue_empty(queue *Q);           // 测试队列 Q 是否为空，为空返回 true
```

再有访问树结点的函数：

`void visit(cstree node);` 其功能是输出结点 node 的字符标签。

## 任务描述

请设计一个算法，实现树的层次遍历。

算法函数原型：

`void layer(cstree root, queue *Q);`

功能：对树进行层次遍历。遍历到某个结点 node 时，调用 `visit(node)` 来访问该结点。
提示：如果是空树，则遍历没有输出。

参数：
- `root`：指向树根结点的指针
- `Q`：指向已初始化的队列的指针

返回值：无

## 解题思路

- 层序遍历的核心是**队列**（BFS 广度优先）
- 将根结点入队，循环执行：出队 -> 访问 -> 将该结点的**所有孩子**依次入队
- **孩子-兄弟表示法的入队方式**：
  1. 取出结点的 `first` 指针（第一个孩子）
  2. 入队该孩子，然后沿 `sibling` 指针链遍历，将所有兄弟依次入队
  3. 这样就实现了"同一层的所有孩子依次入队"的效果
- 循环终止条件：队列为空

## 参考解答

```c
/*
 * 层序遍历（孩子-兄弟表示法）
 * 核心思路：用队列实现 BFS
 *   1. 根结点入队
 *   2. 循环：出队 -> 访问 -> 将该结点的所有孩子依次入队
 *   3. 孩子-兄弟表示法中，通过 first 找到第一个孩子，再通过 sibling 遍历其余兄弟
 */
void layer(cstree root, queue *Q) {
    if (root) queue_enter(Q, (void *) root);  // 根结点入队（非空树时）

    csnode *node, *child;

    while (!queue_empty(Q)) {                 // 队列不为空时持续循环
        node = (csnode *) queue_leave(Q);     // 出队：取出队头结点
        visit(node);                          // 访问该结点

        // 将该结点的所有孩子依次入队
        child = node->first;                  // 取第一个孩子
        while (child) {                       // 沿 sibling 链遍历所有兄弟（即所有孩子）
            queue_enter(Q, (void *) child);   // 孩子入队
            child = child->sibling;           // 移动到下一个兄弟
        }
    }
}
```
