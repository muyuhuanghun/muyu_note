## 零、基础概念

### 数据结构定义

- **Data_Structure = (D, R)**：D 是数据元素集合，R 是 D 上关系的集合
- **逻辑结构**：线性结构 → 树形结构 → 图形结构（表是树的特例，树是图的特例）
- **存储结构**：顺序存储 | 链式存储 | 散列存储

| 存储方式 | 原理 | 优点 | 缺点 |
|---------|------|------|------|
| 顺序存储 | 相对位置表示逻辑关系 | 随机存取，无额外空间 | 插删需移动元素，静态分配 |
| 链式存储 | 指针表示逻辑关系 | 动态分配，插删 O(1) | 不可随机存取，存储密度 < 1 |
| 散列存储 | 关键字直接计算地址 | 查找 O(1) | 冲突处理复杂 |

**ADT 三元组**：(D, R, O) — 数据对象、结构关系、基本操作
**ADT 三大特征**：信息隐蔽、数据封装、使用与实现分离
**算法五大特性**：有穷性、确定性、可行性、输入、输出

### 时间复杂度

- 大 O 记号：T(n) = O(f(n))，取最高阶，忽略常数系数
- 常用阶（低→高）：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ)

```c
// 矩阵相乘示例 — 语句频度分析
for (i=0; i<n; i++)           // n+1
  for (j=0; j<n; j++) {       // n(n+1)
    c[i][j] = 0;              // n²
    for (k=0; k<n; k++)       // n²(n+1)
      c[i][j] += a[i][k]*b[k][j]; // n³
  }
// T(n) = 2n³ + 3n² + 2n + 1 → O(n³)
```

### 空间复杂度

```c
// 数组逆序 — 两种方案对比
// 方案1: 辅助数组 b[] → S(n) = O(n)
for (i=0; i<n; i++) b[i] = a[n-i-1];
for (i=0; i<n; i++) a[i] = b[i];

// 方案2: 原地交换 → S(n) = O(1)
for (i=0; i<n/2; i++) {
    t = a[i]; a[i] = a[n-i-1]; a[n-i-1] = t;
}
```

> ⚠️ 时间复杂度以**最坏情况**计算；时间和空间往往此消彼长，需综合考量。

## 一、线性表

### 1.1 核心操作模板

**顺序表插入**（从后往前移）：
```c
void seq_insert(SeqList *L, int pos, int val) {
    for (int i = L->last; i >= pos; i--)
        L->elem[i + 1] = L->elem[i];  // 后移一位
    L->elem[pos] = val;
    L->last++;
}
```

**顺序表删除**（从前往后覆盖）：
```c
void seq_delete(SeqList *L, int pos) {
    for (int i = pos; i < L->last; i++)
        L->elem[i] = L->elem[i + 1];  // 前移一位
    L->last--;
}
```

**链表头插法**（结果逆序）：
```c
node* build_list_head(int arr[], int n) {
    node *head = NULL;
    for (int i = 0; i < n; i++) {
        node *new = malloc(sizeof(node));
        new->data = arr[i];
        new->next = head;  // 新结点指向原链表头
        head = new;
    }
    return head;
}
```

**链表尾插法**（结果正序）：
```c
node* build_list_tail(int arr[], int n) {
    node dummy;  // 哨兵结点，简化头结点处理
    node *tail = &dummy;
    for (int i = 0; i < n; i++) {
        node *new = malloc(sizeof(node));
        new->data = arr[i];
        new->next = NULL;
        tail->next = new;
        tail = new;
    }
    return dummy.next;
}
```

### 1.4 补充：链表操作与横向对比

**单链表就地逆置**（头插法逆置）：
```c
void ReverseList(LinkList L) {
    Node *p = L->next, *q;
    L->next = NULL;           // 逆置表初始为空
    while (p != NULL) {
        q = p->next;          // 保存后继
        p->next = L->next;    // 头插法
        L->next = p;
        p = q;
    }
}
```

**循环链表尾指针合并 O(1)**：`RA->next = RB->next->next; RB->next = p;`

**双向链表操作**：
- 前插（4 步）：`s->prior = p->prior; p->prior->next = s; s->next = p; p->prior = s;`
- 删除（2 步 + free）：`p->prior->next = p->next; p->next->prior = p->prior; free(p);`

**横向对比**：

| 对比项 | 顺序表 | 单链表 | 双向链表 | 循环链表 |
|--------|--------|--------|---------|---------|
| 存储密度 | 1 (100%) | < 1 | < 1（更小） | < 1 |
| 随机存取 | ✅ O(1) | ❌ O(n) | ❌ O(n) | ❌ O(n) |
| 插删效率 | O(n) | O(1)* | O(1)* | O(1)* |
| 找前驱 | O(1) | ❌ 不可 | O(1) | ❌ 不可 |
| 空表判断 | last==-1 | L->next==NULL | 同左 | p->next==L |

*已知位置时

> ⚠️ 链表插入必须**先接后继再改前驱**，顺序反了会丢链；头插法建表结果是**逆序**的。

## 二、栈与队列

### 2.1 核心操作模板

**非递归先序遍历**（高频考题）：
```c
void preorder(BiTree root) {
    Stack S;
    init_stack(&S);
    push(&S, root);
    while (!is_empty(&S)) {
        BiTNode *node;
        pop(&S, &node);
        visit(node);
        // ⚠️ 先右后左入栈！栈是后进先出，左后入 = 左先出 = 先访问左子树
        if (node->right) push(&S, node->right);
        if (node->left) push(&S, node->left);
    }
}
```

**非递归中序遍历**：
```c
void inorder(BiTree root) {
    Stack S;
    init_stack(&S);
    BiTNode *curr = root;
    while (curr || !is_empty(&S)) {
        while (curr) {           // 一路向左，全部入栈
            push(&S, curr);
            curr = curr->left;
        }
        pop(&S, &curr);          // 弹出 → 访问
        visit(curr);
        curr = curr->right;      // 转向右子树
    }
}
```

2. **表达式求值** — 后缀表达式：数字入栈，遇运算符弹两个算
3. **队列实现** — 循环链表队列判空条件、层次遍历用队列

### 2.4 补充：两栈共享空间与带标志域队列

**两栈共享空间**：栈 1 从左增，栈 2 从右减，栈满条件 `top1 + 1 == top2`

**循环队列操作**：
```
入队：Q.rear = (Q.rear + 1) % MAXSIZE
出队：Q.front = (Q.front + 1) % MAXSIZE
判空：Q.front == Q.rear
判满：(Q.rear + 1) % MAXSIZE == Q.front  （牺牲一个空间）
队列长度：(Q.rear - Q.front + MAXSIZE) % MAXSIZE
```

**带标志域循环队列**（不牺牲空间）：
- 最近操作为插入 → flag=1；最近操作为删除 → flag=0
- 判空：`front==rear && flag==0`；判满：`front==rear && flag==1`

> ⚠️ 循环队列**牺牲一个空间**来区分队满和队空；中缀转后缀时**同级运算符也要弹出**（左结合）；表达式求值先弹出的是**右操作数**。

## 三、树与二叉树

### 3.1 核心操作模板

**层序遍历**（队列实现）：
```c
void level_order(BiTree root) {
    BiTNode *queue[100];
    int head = 0, tail = 0;
    queue[head++] = root;
    while (head > tail) {
        BiTNode *curr = queue[tail++];
        visit(curr);
        if (curr->left) queue[head++] = curr->left;
        if (curr->right) queue[head++] = curr->right;
    }
}
```

**BST 插入**：
```c
void bst_insert(node *root, int value) {
    if (value > root->data) {
        if (!root->right) {
            root->right = new_node(value);
        } else bst_insert(root->right, value);
    } else {
        if (!root->left) {
            root->left = new_node(value);
        } else bst_insert(root->left, value);
    }
}
```

### 3.4 补充：二叉树性质与哈夫曼树

**二叉树性质（必背）**：
1. 第 i 层最多 **2^(i-1)** 个结点
2. 深度为 k 的二叉树最多 **2^k - 1** 个结点
3. **n₀ = n₂ + 1**（叶子结点数 = 度为 2 的结点数 + 1）
4. **完全二叉树** n 个结点，深度为 **⌊log₂n⌋ + 1**
5. 完全二叉树中，结点 i 的左孩子 **2i**，右孩子 **2i+1**，父结点 **⌊i/2⌋**

**由遍历序列构造二叉树**：必须有**中序** + (前序或后序) 才能唯一确定。前序/后序确定根，中序确定左右子树。只有前序+后序**无法**唯一确定。

**哈夫曼树构造**：将 n 个权值作为 n 棵只有根结点的树，每次选权值**最小的两棵**合并，新根权值 = 两子之和，重复直到只剩一棵。WPL = Σ(wᵢ × lᵢ)。

手动推导示例（权值 {5, 29, 7, 8, 14, 23, 3, 11}）：
```
选 3,5→8; 选 7,8→15; 选 8,11→19; 选 14,15→29; 选 19,23→42; 选 29,29→58; 选 42,58→100
WPL = 23×2 + 11×3 + 14×3 + 5×4 + 7×4 + 29×2 + 3×4 + 8×4 = 271
```

> ⚠️ n₀ = n₂ + 1 是最常考性质；完全二叉树编号从 **1** 开始；哈夫曼编码中权值最小的两个要合并。

## 三·五、串

### KMP 算法

**核心思想**：利用已匹配信息，主串指针不回溯。next 数组手算：`next[1] = 0`，`next[j]` = 模式串 `T[1..j-1]` 中**最长相等前后缀长度 + 1**。

```c
// next 数组计算
void get_next(SString T, int next[]) {
    next[1] = 0;
    int i = 1, j = 0;
    while (i < T.length) {
        if (j == 0 || T.ch[i] == T.ch[j]) {
            i++; j++;
            next[i] = j;
        } else
            j = next[j];
    }
}

// KMP 匹配 — O(n+m)
int Index_KMP(SString S, SString T, int pos, int next[]) {
    int i = pos, j = 1;
    while (i <= S.length && j <= T.length) {
        if (j == 0 || S.ch[i] == T.ch[j]) { i++; j++; }
        else j = next[j];  // 不回溯 i
    }
    if (j > T.length) return i - T.length;
    return 0;
}
```

| j | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|
| T | a | b | a | a | b | c | a |
| next | 0 | 1 | 1 | 2 | 2 | 3 | 1 |

> ⚠️ next 数组下标从 **1** 开始；手算找的是**最长相等前后缀**；KMP 当 `j == 0` 时 i 和 j **都要++**。

## 四、图

### 4.1 核心操作模板

**邻接矩阵入度/出度**：
```c
int indegree(MatrixGraph *G, int v) {
    int count = 0;
    for (int i = 0; i < G->vexnum; i++)
        if (G->arcs[i][v] != 0) count++;  // 第 v 列非零元素个数
    return count;
}

int outdegree(MatrixGraph *G, int v) {
    int count = 0;
    for (int j = 0; j < G->vexnum; j++)
        if (G->arcs[v][j] != 0) count++;  // 第 v 行非零元素个数
    return count;
}
```

**DFS 遍历**：
```c
void DFS(MatrixGraph *G, int v, bool visited[]) {
    visited[v] = true;
    visit(G->vertex[v]);
    for (int w = 0; w < G->vexnum; w++)
        if (G->arcs[v][w] != 0 && !visited[w])
            DFS(G, w, visited);
}
```

**BFS 遍历**：
```c
void BFS(MatrixGraph *G, int v) {
    int queue[MAX], head = 0, tail = 0;
    bool visited[MAX] = {false};
    visited[v] = true;
    queue[head++] = v;
    while (head > tail) {
        int curr = queue[tail++];
        visit(G->vertex[curr]);
        for (int w = 0; w < G->vexnum; w++)
            if (G->arcs[curr][w] != 0 && !visited[w]) {
                visited[w] = true;
                queue[head++] = w;
            }
    }
}
```

### 4.3 手算必考

**Prim 最小生成树**：
1. 任选起点加入集合 S
2. 找 S 到 V-S 的最小权边
3. 将边和对应顶点加入 S
4. 重复 n-1 次

**Kruskal 最小生成树**：
1. 所有边按权值排序
2. 从小到大选边，不成环就加入
3. 选够 n-1 条边停止

**关键路径（AOE 网）**：
1. 正向：`ve(j) = max{ve(i) + w(i,j)}`（所有前驱取 max）
2. 逆向：`vl(j) = min{vl(k) - w(j,k)}`（所有后继取 min）
3. `e(i) = ve(弧尾)`，`l(i) = vl(弧头) - w`
4. `e(i) == l(i)` → 关键活动，连成关键路径

**拓扑排序**：条件为有向无环图 (DAG)。步骤：选入度为 0 的顶点输出，删除其所有出弧，重复。用途：判断有向图是否有环、确定工程可行性顺序。结果**不唯一**。

### 4.4 套路总结

图论五大考法：
1. **存储结构** — 邻接矩阵（稠密图）、邻接表（稀疏图）
2. **遍历** — DFS（递归/栈）、BFS（队列）
3. **最短路径** — Dijkstra（单源不含负权）、Floyd（所有点对）
4. **最小生成树** — Prim（从点出发）、Kruskal（从边出发）
5. **拓扑排序/关键路径** — AOE 网求最长路径

**横向对比**：

| 对比项 | Prim | Kruskal |
|--------|------|---------|
| 策略 | 加点 | 加边 |
| 时间 | O(n²) | O(e log e) |
| 适用 | 稠密图 | 稀疏图 |

| 对比项 | Dijkstra | Floyd |
|--------|----------|-------|
| 类型 | 单源 | 多源 |
| 时间 | O(n²) | O(n³) |
| 负权 | ❌ | ✅（无负环） |

> ⚠️ Dijkstra **不能处理负权边**；DFS/BFS 时间复杂度：邻接矩阵 O(n²)，邻接表 O(n+e)；连通图生成树有 **n-1 条边**。

## 五、查找与哈希

### 5.1 核心操作模板

**线性探测法插入**：
```c
void hash_insert_linear(int table[], int size, int key) {
    int idx = key % size;                  // 初始哈希位置
    while (table[idx] != 0)               // 冲突：线性探测
        idx = (idx + 1) % size;           // ⚠️ 取模实现循环
    table[idx] = key;
}
```

**拉链法插入**：
```c
void hash_insert_chain(HashNode *table[], int size, int key) {
    int idx = key % size;
    HashNode *node = malloc(sizeof(HashNode));
    node->key = key;
    node->next = table[idx];
    table[idx] = node;  // 头插法
}
```

### 5.2 真题

**真题 163：线性探测法**
- 解题思路：哈希函数 H(key)=key%13，冲突时 `key=(key+1)%SIZE` 循环探测。用 `calloc` 初始化（0 表示空位）
- 完整解答见 → [[163 线性探测法]]

**真题 199：哈希冲突（拉链法）**
- 解题思路：哈希函数 key%P，冲突时头插法插入链表。新结点的 `next` 指向原桶头，桶头更新为新结点
- 完整解答见 → [[199 哈希冲突]]

**真题 182：哈希排序（计数排序）**
- 解题思路：利用无重复值的特点，hash(K)=K。找最大值 m，建 m+1 大小的计数数组，值做下标计数，再按序收集
- 时间 O(n+m)，空间 O(m)，只适用于非负整数
- 完整解答见 → [[182 哈希排序]]

### 5.3 套路总结

查找四大考法：
1. **BST** — 左小右大，平均 O(log n)，最坏 O(n)
2. **AVL** — 平衡因子绝对值 ≤ 1，四种旋转 LL/RR/LR/RL
3. **哈希表** — 除留余数法 + 冲突处理（链地址/线性探测/二次探测）
4. **计数排序** — 值做下标，O(n+m)，非比较排序

### 5.4 补充：AVL 旋转与查找对比

**AVL 旋转条件**：

| 失衡类型 | 旋转方式 | 条件 |
|---------|---------|------|
| LL | 右旋 | BF > 1 且左子 BF ≥ 0 |
| RR | 左旋 | BF < -1 且右子 BF ≤ 0 |
| LR | 先左旋再右旋 | BF > 1 且左子 BF < 0 |
| RL | 先右旋再左旋 | BF < -1 且右子 BF > 0 |

**分块查找**：块间有序（第 i 块最大值 < 第 i+1 块最小值），块内无序。先在索引表中确定块（顺序或折半），再在块内顺序查找。

**查找方式横向对比**：

| 查找方式 | 时间 | 要求 | 适用 |
|---------|------|------|------|
| 顺序查找 | O(n) | 无 | 小表 |
| 折半查找 | O(log n) | 有序+顺序 | 静态表 |
| BST | O(log n) 平均 | 无 | 动态插入 |
| AVL | O(log n) | 平衡 | 频繁插入删除 |
| 哈希 | O(1) 平均 | 哈希函数 | 快速查找 |

> ⚠️ 折半查找**只能用于顺序存储**的有序表；BST 有序插入退化为 O(n)；AVL 的 LR 和 RL 是**双旋转**。

## 六、排序

### 6.1 算法对比

| 算法 | 平均 | 最坏 | 空间 | 稳定 |
|:---|:---:|:---:|:---:|:---:|
| 选择排序 | O(n^2) | O(n^2) | O(1) | 否 |
| 插入排序 | O(n^2) | O(n^2) | O(1) | 是 |
| 快速排序 | O(n log n) | O(n^2) | O(log n) | 否 |
| 堆排序 | O(n log n) | O(n log n) | O(1) | 否 |
| 归并排序 | O(n log n) | O(n log n) | O(n) | 是 |
| 计数排序 | O(n+m) | O(n+m) | O(m) | 是 |

### 6.2 手写代码模板

**简单选择排序** — 每次选最小交换到前面：
```c
void selection_sort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int min_idx = i;
        for (int j = i + 1; j < n; j++)
            if (arr[j] < arr[min_idx]) min_idx = j;
        swap(&arr[i], &arr[min_idx]);
    }
}
```

**直接插入排序** — 类似打牌，新牌插入已排序的正确位置：
```c
void insertion_sort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int key = arr[i], j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];  // 后移
            j--;
        }
        arr[j + 1] = key;  // 插入
    }
}
```

**快速排序** — 分治，选基准分区：
```c
int partition(int arr[], int low, int high) {
    int pivot = arr[high], i = low - 1;
    for (int j = low; j < high; j++)
        if (arr[j] <= pivot) swap(&arr[++i], &arr[j]);
    swap(&arr[i + 1], &arr[high]);
    return i + 1;
}
```

**堆排序** — 建堆 + 逐个取堆顶：
```c
void heap_sort(int arr[], int n) {
    for (int i = n / 2 - 1; i >= 0; i--)  // 建最大堆
        heapify_down_max(arr, n, i);
    for (int i = n - 1; i > 0; i--) {      // 逐个取堆顶
        swap(&arr[0], &arr[i]);
        heapify_down_max(arr, i, 0);
    }
}
```

### 6.3 手算第一趟结果

给定数组 `[49, 38, 65, 97, 76, 13, 27, 49]`：

| 排序算法 | 第一趟结果 | 说明 |
|:---|:---|:---|
| 直接插入 | `[38, 49, 65, 97, 76, 13, 27, 49]` | 38 插入到 49 前面 |
| 简单选择 | `[13, 38, 65, 97, 76, 49, 27, 49]` | 最小的 13 和第一个交换 |
| 快速排序 | `[27, 38, 13, 49, 76, 97, 65, 49]` | 以 49 为基准分区 |

**堆向上调整**（插入新元素到堆末尾后调用）：
```c
void heapify_up(int arr[], int i) {
    while (i > 0) {
        int parent = (i - 1) / 2;
        if (arr[i] < arr[parent]) {     // 小顶堆：子 < 父就交换
            swap(&arr[i], &arr[parent]);
            i = parent;
        } else break;
    }
}
```

### 防坑清单

- 顺序表 `last` 是最后一个元素下标，空表通常为 `-1`
- 链表插入先接后继，再改前驱；删除前先保存被删结点
- 循环队列判满常用 `(rear + 1) % MAX == front`，会牺牲一个空间
- 递归改非递归优先想栈；层序遍历优先想队列
- BST 中序遍历一定有序；有序插入会退化成单链表
- Dijkstra 不能处理负权边；Floyd 可以处理负权但不能有负环
- 快排最坏 O(n²)，堆排最坏仍是 O(n log n)，归并稳定但要 O(n) 空间
- 稳定排序只有：直接插入、折半插入、冒泡、归并、基数排序
- 建堆从 **n/2** 开始向下调整，不是从 n 开始
