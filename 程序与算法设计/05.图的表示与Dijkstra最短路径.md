## 二、数据建模

### 1. 邻接矩阵

```c
#define MAX_STN 9    // 站点数
#define INF 99999    // 无穷大（不可达）

static int G[MAX_STN][MAX_STN];  // 邻接矩阵

// 🌟 初始化：对角线为0，其余为INF
static void graph_init(void) {
    for(int i = 0; i < MAX_STN; i++)
        for(int j = 0; j < MAX_STN; j++)
            G[i][j] = (i == j) ? 0 : INF;

    // 根据边列表填充邻接矩阵
    for(int i = 0; i < edge_cnt; i++) {
        G[edge_list[i].u][edge_list[i].v] = edge_list[i].w;
        G[edge_list[i].v][edge_list[i].u] = edge_list[i].w;  // 无向图
    }
}
```

## 三、Dijkstra 最短路径算法

### 1. 核心思想

```
🌟 贪心策略：每次选距离起点最近的未访问节点，更新其邻居的距离

类比：你站在成都地图上，每次往"最近的未探索站点"走一步，
     并更新从这个站点出发能到达的所有站点的距离。
```

### 2. 算法步骤

```
初始化：
  dist[] = {0, INF, INF, ...}  // 起点距离为0，其余无穷
  done[] = {0, 0, 0, ...}      // 全部未访问
  prev[] = {-1, -1, ...}       // 前驱节点

循环 n 次：
  1. 选未访问节点中 dist 最小的 u
  2. 标记 u 已访问 (done[u] = 1)
  3. 对 u 的每个邻居 v：
     如果 dist[u] + G[u][v] < dist[v]：
       更新 dist[v] = dist[u] + G[u][v]
       记录 prev[v] = u

最终：通过 prev 数组从终点回溯到起点，得到最短路径
```

### 3. 实现代码

```c
static int dijkstra(int src, int dst, int path[], int *plen)
{
    int dist[MAX_STN], done[MAX_STN], prev[MAX_STN];
    int i, count, u, v, min_d;

    // 🚀 初始化
    for(i = 0; i < MAX_STN; i++) {
        dist[i] = INF;
        done[i] = 0;
        prev[i] = -1;
    }
    dist[src] = 0;  // 起点到自身的距离为0

    // 🌟 主循环：每次确定一个节点的最短距离
    for(count = 0; count < MAX_STN; count++)
    {
        // Step 1: 找未访问的距离最小节点
        u = -1;
        min_d = INF;
        for(i = 0; i < MAX_STN; i++)
        {
            if(!done[i] && dist[i] < min_d)
            {
                min_d = dist[i];
                u = i;
            }
        }

        // 没有可达节点 或 已到达终点 → 结束
        if(u == -1 || u == dst) break;

        done[u] = 1;  // 标记已访问

        // Step 2: 松弛 u 的所有邻居
        for(v = 0; v < MAX_STN; v++)
        {
            // ⚠️ 三个条件同时满足才能更新
            if(!done[v] &&                    // v 未访问
               G[u][v] < INF &&               // u 和 v 之间有边
               dist[u] + G[u][v] < dist[v])   // 通过 u 到 v 更近
            {
                dist[v] = dist[u] + G[u][v];  // 更新距离
                prev[v] = u;                   // 记录前驱
            }
        }
    }

    // 🌟 通过 prev 数组回溯构建路径
    if(dist[dst] >= INF) return INF;  // 不可达

    {
        int tmp[MAX_STN], len = 0;
        int cur = dst;
        while(cur != -1)  // 从终点回溯到起点
        {
            tmp[len++] = cur;
            cur = prev[cur];
        }
        // 反转得到 src → dst 的路径
        for(i = 0; i < len; i++)
            path[i] = tmp[len - 1 - i];
        *plen = len;
    }
    return dist[dst];
}
```

### 4. 复杂度分析

| 指标 | 复杂度 | 说明 |
|:---|:---:|:---|
| 时间 | O(V²) | V 为顶点数，每轮遍历找最小值 O(V) |
| 空间 | O(V) | dist, done, prev 数组 |

💡 **优化方向**：用最小堆维护未访问节点，时间复杂度可降到 O((V+E) log V)。对于稀疏图（边少）效果显著。

## 四、路径输出与换乘识别

```c
static void route_print(const char *start_uni, const char *end_uni,
                         int path[], int plen)
{
    int total = 0, last_line = -1;

    for(int i = 0; i < plen - 1; i++)
    {
        int u = path[i], v = path[i+1];
        int line_num = line_between(u, v);  // 查找边所属线路
        int w = G[u][v];
        total += w;

        // 🌟 换乘判断：线路变化时输出换乘提示
        if(line_num != last_line) {
            if(last_line == -1)
                printf("  乘坐%s\n", line_name[line_num]);
            else
                printf("  在 %s 换乘到%s\n", stn_name[u], line_name[line_num]);
            last_line = line_num;
        }
        printf("    %s --[%s, 约%d站]--> %s\n",
               stn_name[u], line_name[line_num], w, stn_name[v]);
    }
    printf("总估计站数权重：%d\n", total);
}
```

💡 换乘识别的关键：在路径中检查相邻两段边是否属于同一条线路。如果线路号 `line_num` 发生变化，说明需要换乘。

## 五、辅助函数

```c
// 判断是否为换乘站（属于 2 条及以上线路）
static int is_transfer(int s) {
    int count = 0;
    for(int i = 0; i < LINE_COUNT; i++)
        if(stn_mask[s] & (1 << i)) count++;
    return count > 1;
}

// 输出站点所属线路
static void print_station_lines(int s) {
    int first = 1;
    for(int i = 0; i < LINE_COUNT; i++)
        if(stn_mask[s] & (1 << i)) {
            if(!first) printf("/");
            printf("%s", line_name[i]);
            first = 0;
        }
}
```
