## 一、为什么需要泛型栈？

```
💡 问题：不同的数据结构都需要栈
- 二叉树非递归遍历 → 栈里存树节点指针 (BiTree)
- 表达式求值 → 栈里存数字 (int)
- 括号匹配 → 栈里存字符 (char)

难道每种场景都写一套栈？→ 泛型栈，一套代码适配所有类型
```

---

## 二、泛型实现方案

### 1. 类型抽象

```c
// 🌟 通过宏定义实现"编译期泛型"
#ifndef STACK_ELEM_TYPE
typedef int STACK_ELEM_TYPE;   // 默认元素类型为 int
#else
typedef STACK_ELEM_TYPE STACK_ELEM_TYPE;
#endif

// 使用时：在包含 stack.h 之前定义宏即可切换类型
// #define STACK_ELEM_TYPE BiTree   → 栈存树节点
// #define STACK_ELEM_TYPE double   → 栈存浮点数
```

### 2. 数据结构定义

```c
typedef struct {
    STACK_ELEM_TYPE *data;  // 动态数组
    size_t size;            // 当前元素个数
    size_t capacity;        // 数组容量
} Stack;
```

📌 用**动态数组**而非链表实现——连续内存访问更快（缓存友好），且支持随机访问。

## 三、核心操作

### 1. 初始化

```c
static inline int StackInit(Stack *s, size_t capacity)
{
    if(!s) return STACK_ERR;
    if(capacity == 0) capacity = STACK_INITIAL_CAPACITY;  // 默认 16

    s->data = (STACK_ELEM_TYPE*)malloc(sizeof(STACK_ELEM_TYPE) * capacity);
    if(!s->data) return STACK_ERR;  // 🌟 malloc 失败检查

    s->size = 0;
    s->capacity = capacity;
    return STACK_OK;
}
```

### 2. 动态扩容（核心亮点）

```c
static inline int StackEnsureCapacity(Stack *s, size_t min_capacity)
{
    if(!s) return STACK_ERR;
    if(s->capacity >= min_capacity) return STACK_OK;  // 容量足够，无需扩容

    // 🌟 容量翻倍策略：每次扩容到当前的 2 倍
    size_t newcap = s->capacity ? s->capacity * 2 : STACK_INITIAL_CAPACITY;
    while(newcap < min_capacity) newcap *= 2;  // 确保足够

    STACK_ELEM_TYPE *tmp = (STACK_ELEM_TYPE*)realloc(
        s->data, sizeof(STACK_ELEM_TYPE) * newcap
    );
    if(!tmp) return STACK_ERR;  // ⚠️ realloc 失败不修改原指针

    s->data = tmp;
    s->capacity = newcap;
    return STACK_OK;
}
```

💡 **为什么容量翻倍？** 摊还分析：如果每次只扩容 1 个，n 次 push 需要 O(n²) 次复制。翻倍策略下，n 次 push 的总复制次数为 O(n)，摊还 O(1)。

### 3. 入栈

```c
static inline int StackPush(Stack *s, STACK_ELEM_TYPE val)
{
    if(!s) return STACK_ERR;
    // 🌟 容量不足时自动扩容
    if(s->size >= s->capacity)
    {
        if(StackEnsureCapacity(s, s->size + 1) != STACK_OK)
            return STACK_ERR;
    }
    s->data[s->size++] = val;
    return STACK_OK;
}
```

### 4. 出栈

```c
static inline int StackPop(Stack *s, STACK_ELEM_TYPE *out)
{
    if(!s || s->size == 0) return STACK_ERR;  // 空栈检查
    s->size--;
    if(out) *out = s->data[s->size];  // 📌 通过指针返回弹出值
    return STACK_OK;
}
```

💡 `out` 参数可以为 NULL——如果调用者不关心弹出的值，只需 `StackPop(&s, NULL)`。

### 5. 查看栈顶

```c
static inline int StackTop(const Stack *s, STACK_ELEM_TYPE *out)
{
    if(!s || s->size == 0 || !out) return STACK_ERR;
    *out = s->data[s->size - 1];  // 不弹出，只读取
    return STACK_OK;
}
```

### 6. 清空与销毁

```c
static inline void StackClear(Stack *s)
{
    if(!s) return;
    s->size = 0;  // 📌 只重置计数，不释放内存（可复用）
}

static inline void StackDestroy(Stack *s)
{
    if(!s) return;
    free(s->data);       // 🌟 释放动态数组
    s->data = NULL;      // 防止悬空指针
    s->size = 0;
    s->capacity = 0;
}
```

### 7. O(1) 交换

```c
static inline void StackSwap(Stack *a, Stack *b)
{
    if(!a || !b) return;
    Stack tmp = *a;
    *a = *b;
    *b = tmp;
}
// 💡 直接交换结构体，O(1) 时间复杂度
```

## 四、使用示例

```c
// 场景1：默认 int 栈
Stack s;
StackInit(&s, 0);         // 默认容量 16
StackPush(&s, 42);
StackPush(&s, 99);
int val;
StackPop(&s, &val);       // val = 99
StackDestroy(&s);

// 场景2：树节点栈（在 treedata.h 中使用）
#define STACK_ELEM_TYPE BiTree
#include "stack.h"
// 现在 StackPush/Pop 操作的是 BiTree 类型
```

## 五、API 速查表

| 函数 | 功能 | 返回值 | 时间复杂度 |
|:---|:---|:---:|:---:|
| `StackInit(s, cap)` | 初始化栈 | OK/ERR | O(1) |
| `StackDestroy(s)` | 销毁栈，释放内存 | void | O(1) |
| `StackPush(s, val)` | 入栈 | OK/ERR | 摊还 O(1) |
| `StackPop(s, out)` | 出栈 | OK/ERR | O(1) |
| `StackTop(s, out)` | 查看栈顶 | OK/ERR | O(1) |
| `StackClear(s)` | 清空（不释放内存） | void | O(1) |
| `StackIsEmpty(s)` | 是否为空 | 1/0 | O(1) |
| `StackSize(s)` | 元素个数 | size_t | O(1) |
| `StackSwap(a, b)` | 交换两个栈 | void | O(1) |
