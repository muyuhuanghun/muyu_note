## 一、为什么需要稀疏矩阵？

```
💡 核心问题：矩阵中大部分元素为 0，普通二维数组浪费空间

一个 1000×1000 的矩阵，如果只有 100 个非零元素：
- 普通数组：1000 × 1000 × 4B = 4MB
- 三元组存储：100 × 12B = 1.2KB

节省了 99.97% 的空间！
```

📌 稀疏矩阵的核心思想：**只存储非零元素**，用三元组 `(行, 列, 值)` 表示每个非零元素。

---

## 二、数据结构定义

```c
// 🌟 三元组：一个非零元素的完整描述
typedef struct {
    int row, col;   // 行号、列号
    int data;       // 元素值
} triple;

// 稀疏矩阵：三元组数组 + 矩阵维度 + 非零元素个数
typedef struct {
    triple data[MaxSizex];  // 非零元素数组（按行优先、同行按列排序）
    int m, n, len;          // m 行 n 列，len 个非零元素
} tsmatrix;
```

📌 **关键约束**：三元组必须按 **行号升序，同行按列号升序** 排列——这是后续加法/乘法能用双指针归并的前提。

## 三、矩阵加法 — 双指针归并

### 1. 核心思路

```
两个已排序的三元组数组 A 和 B，归并为 C：

A: (0,1,5) (1,0,3) (2,2,7)
B: (0,1,2) (1,2,4) (2,2,1)
                 ↓ 归并
C: (0,1,7) (1,0,3) (1,2,4) (2,2,8)
         ↑ 5+2=7                ↑ 7+1=8
```

### 2. 四种情况处理

```c
while(i < A->len && j < B->len) {
    if(A[i].row == B[j].row) {           // 同一行
        if(A[i].col == B[j].col) {       // 同一列 → 值相加
            sum = A[i].data + B[j].data;
            if(sum != 0) 存入C;           // ⚠️ 和为0不存入
            i++; j++;
        } else if(A[i].col < B[j].col) { // A列更小 → 取A
            存入A[i]; i++;
        } else {                          // B列更小 → 取B
            存入B[j]; j++;
        }
    } else if(A[i].row < B[j].row) {     // A行更小 → 取A
        存入A[i]; i++;
    } else {                              // B行更小 → 取B
        存入B[j]; j++;
    }
}
// 别忘了：处理剩余元素（A或B没走完的部分）
while(i < A->len) 存入A[i++];
while(j < B->len) 存入B[j++];
```

### 3. 完整实现

```c
static tsmatrix * matrixadd(tsmatrix *A, tsmatrix *B)
{
    // 🚀 前置检查：维度必须匹配
    if(A->m != B->m || A->n != B->n) return NULL;

    tsmatrix *c = (tsmatrix*)malloc(sizeof(tsmatrix));
    if(c == NULL) return NULL;
    c->m = A->m; c->n = A->n; c->len = 0;

    int i = 0, j = 0;
    while(i < A->len && j < B->len)
    {
        if(A->data[i].row == B->data[j].row)
        {
            if(A->data[i].col == B->data[j].col)
            {
                int sum = A->data[i].data + B->data[j].data;
                if(sum != 0)  // ⚠️ 和为0不存入，保持稀疏性
                {
                    c->data[c->len].row = A->data[i].row;
                    c->data[c->len].col = A->data[i].col;
                    c->data[c->len].data = sum;
                    c->len++;
                }
                i++; j++;
            }
            else if(A->data[i].col < B->data[j].col)
            {
                c->data[c->len++] = A->data[i++];
            }
            else
            {
                c->data[c->len++] = B->data[j++];
            }
        }
        else if(A->data[i].row < B->data[j].row)
        {
            c->data[c->len++] = A->data[i++];
        }
        else
        {
            c->data[c->len++] = B->data[j++];
        }
    }
    // 处理剩余元素
    while(i < A->len) c->data[c->len++] = A->data[i++];
    while(j < B->len) c->data[c->len++] = B->data[j++];
    return c;
}
```

### 4. 复杂度分析

| 指标 | 复杂度 | 说明 |
|:---|:---:|:---|
| 时间 | O(A->len + B->len) | 双指针各走一遍，线性归并 |
| 空间 | O(A->len + B->len) | 最坏情况无抵消，全部非零 |

## 四、矩阵乘法 — 三重匹配

### 1. 核心思路

```
标准矩阵乘法：C[i][j] = Σ A[i][k] × B[k][j]

在三元组表示中：
对 A 的每个非零元素 (i, k, val_a)：
  → 找 B 中所有 (k, j, val_b)（即 B 的行号等于 A 的列号）
  → 累加 val_a × val_b 到 C 的 (i, j) 位置
```

### 2. 实现要点

```c
static tsmatrix* matrixmul(tsmatrix *A, tsmatrix *B)
{
    if(A->n != B->m) return NULL;  // 🚀 维度检查：A列数 = B行数

    tsmatrix *c = (tsmatrix*)malloc(sizeof(tsmatrix));
    c->m = A->m; c->n = B->n; c->len = 0;

    for(int i = 0; i < A->len; i++)        // 遍历A的每个非零元素
    {
        for(int j = 0; j < B->len; j++)    // 遍历B的每个非零元素
        {
            if(A->data[i].col == B->data[j].row)  // 🌟 关键匹配条件
            {
                int row = A->data[i].row;
                int col = B->data[j].col;
                int val = A->data[i].data * B->data[j].data;

                // 在结果C中查找是否已有 (row, col) 位置
                int k, pos = -1;
                for(k = 0; k < c->len; k++)
                {
                    if(c->data[k].row == row && c->data[k].col == col)
                    {
                        pos = k;
                        break;
                    }
                }

                if(pos != -1)  // 已有该位置 → 累加
                {
                    c->data[pos].data += val;
                    // ⚠️ 累加后如果变为0，需要删除该元素
                    if(c->data[pos].data == 0)
                    {
                        for(int t = pos; t < c->len-1; t++)
                            c->data[t] = c->data[t+1];
                        c->len--;
                    }
                }
                else if(val != 0)  // 新位置且非零 → 新增
                {
                    c->data[c->len].row = row;
                    c->data[c->len].col = col;
                    c->data[c->len].data = val;
                    c->len++;
                }
            }
        }
    }
    return c;
}
```

### 3. 复杂度分析

| 指标 | 复杂度 | 说明 |
|:---|:---:|:---|
| 时间 | O(A->len × B->len × c->len) | 三重循环，最坏情况较差 |
| 空间 | O(m × n) | 结果矩阵最坏情况 |

⚠️ **优化方向**：可以先转置 B，将 B 的元素按行号组织，用哈希表加速查找匹配元素，将复杂度降到 O(A->len × B->len)。

## 五、输出格式化

```c
// 🌟 按原始矩阵格式输出：遍历每个位置，在三元组中查找
for(int i = 0; i < result->m; i++) {
    for(int j = 0; j < result->n; j++) {
        int k;
        for(k = 0; k < result->len; k++) {
            if(result->data[k].row == i && result->data[k].col == j) {
                printf("%d ", result->data[k].data);
                break;
            }
        }
        if(k == result->len) printf("0 ");  // 未找到 → 输出0
    }
    printf("\n");
}
```

💡 这种输出方式的时间复杂度是 O(m×n×len)，如果需要频繁输出，可以先将三元组还原为普通二维数组。
