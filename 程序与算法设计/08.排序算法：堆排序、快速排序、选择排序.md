## 一、三种排序算法概览

```
💡 本代码实现了三种经典排序：

1. 简单选择排序 — 最直观，每次选最小
2. 快速排序    — 分治思想，平均最快
3. 堆排序      — 利用堆结构，稳定 O(n log n)
```

| 算法 | 平均时间 | 最坏时间 | 空间 | 稳定性 |
|:---|:---:|:---:|:---:|:---:|
| 简单选择排序 | O(n²) | O(n²) | O(1) | ❌ 不稳定 |
| 快速排序 | O(n log n) | O(n²) | O(log n) | ❌ 不稳定 |
| 堆排序 | O(n log n) | O(n log n) | O(1) | ❌ 不稳定 |

## 二、简单选择排序

### 1. 核心思想

```
🌟 每一轮从未排序部分选出最小元素，放到已排序部分的末尾

初始：[48, 62, 36, 77, 65, 14, 35, 99]
第1轮：找最小值 14 → 与第1个交换 → [14, 62, 36, 77, 65, 48, 35, 99]
第2轮：找最小值 35 → 与第2个交换 → [14, 35, 36, 77, 65, 48, 62, 99]
第3轮：找最小值 36 → 已在正确位置 → [14, 35, 36, 77, 65, 48, 62, 99]
...
```

### 2. 实现代码

```c
static void selection_sort(int a[], int n)
{
    for(int i = 0; i < n-1; i++)      // n-1 轮
    {
        int min_index = i;             // 假设当前位置最小
        for(int j = i+1; j < n; j++)  // 在后面找更小的
            if(a[j] < a[min_index])
                min_index = j;

        swap(&a[i], &a[min_index]);   // 🌟 最小值交换到前面
    }
}
```

### 3. 特点分析

- ✅ 实现最简单，容易理解
- ✅ 交换次数最少：最多 n-1 次交换
- ❌ 比较次数固定：n(n-1)/2，与数据无关
- ❌ 不稳定：相等元素的相对顺序可能改变

## 三、快速排序

### 1. 核心思想

```
🌟 分治策略：选一个基准（pivot），将数组分为两部分

   比 pivot 小的放左边，比 pivot 大的放右边
   然后对左右两部分递归排序

初始：[48, 62, 36, 77, 65, 14, 35, 99]
选 pivot = 48（第一个元素）

划分过程：
  [48, 62, 36, 77, 65, 14, 35, 99]
   ↑                              ↑
   low                            high

  high 从右找 < 48 的：找到 35
  [35, 62, 36, 77, 65, 14, 48, 99]  交换

  low 从左找 > 48 的：找到 62
  [35, 48, 36, 77, 65, 14, 62, 99]  交换

  high 从右找 < 48 的：找到 14
  [35, 14, 36, 77, 65, 48, 62, 99]  交换

  low 从左找 > 48 的：low == high，结束
  [35, 14, 36, 48, 65, 77, 62, 99]
              ↑ pivot 归位

递归：[35, 14, 36] [48] [65, 77, 62, 99]
```

### 2. 划分函数

```c
static int partition(int a[], int low, int high)
{
    int pivot = a[low];  // 📌 选第一个元素为基准

    while(low < high)
    {
        // 🌟 high 从右往左找第一个 < pivot 的元素
        while(low < high && a[high] >= pivot)
            high--;
        swap(&a[low], &a[high]);

        // 🌟 low 从左往右找第一个 > pivot 的元素
        while(low < high && a[low] <= pivot)
            low++;
        swap(&a[low], &a[high]);
    }

    a[low] = pivot;  // 📌 pivot 归位
    return low;       // 返回 pivot 的最终位置
}
```

⚠️ **注意**：`while(low < high && a[high] >= pivot)` 中 `>=` 不能写成 `>`，否则遇到与 pivot 相等的元素会死循环。

### 3. 递归排序

```c
static void quick_sort(int a[], int low, int high)
{
    if(low < high)
    {
        int pivot = partition(a, low, high);  // 划分
        quick_sort(a, low, pivot - 1);        // 递归左半部分
        quick_sort(a, pivot + 1, high);       // 递归右半部分
    }
}
```

### 4. 复杂度分析

| 情况 | 时间 | 说明 |
|:---|:---:|:---|
| 最好 | O(n log n) | 每次 pivot 恰好在中间 |
| 平均 | O(n log n) | 随机数据 |
| 最坏 | O(n²) | 数据已有序，pivot 总在一端 |

💡 **优化方向**：
- 三数取中法选 pivot（避免最坏情况）
- 小数组时切换为插入排序
- 尾递归优化减少栈深度

## 四、堆排序

### 1. 核心思想

```
🌟 利用完全二叉树（堆）的性质排序

大顶堆：每个节点 ≥ 其子节点（堆顶是最大值）
小顶堆：每个节点 ≤ 其子节点（堆顶是最小值）

数组表示完全二叉树（下标从 1 开始）：
  节点 i 的左孩子：2i
  节点 i 的右孩子：2i+1
  节点 i 的父节点：i/2

       a[1]
      /    \
   a[2]    a[3]
   / \     / \
 a[4] a[5] a[6] a[7]
```

### 2. 筛选调整（核心操作）

```c
// 🌟 以 a[k] 为根的子树调整为大顶堆
static void sift(int a[], int k, int m)
{
    a[0] = a[k];         // 暂存根节点（a[0] 是暂存单元）
    int j = 2 * k;       // j 指向左孩子

    while(j <= m)         // 还有孩子
    {
        // 📌 选较大的孩子
        if(j < m && a[j] < a[j+1])
            j++;          // 右孩子更大，j 指向右孩子

        if(a[0] >= a[j])
            break;        // 根已经最大，调整结束

        // 🌟 孩子上移，继续向下调整
        a[k] = a[j];
        k = j;
        j = 2 * k;
    }
    a[k] = a[0];  // 插入到最终位置
}
```

### 3. 建堆

```c
// 🌟 从最后一个非叶子节点开始，向前逐个筛选
static void create_heap(int a[], int n)
{
    for(int i = n/2; i > 0; i--)  // n/2 是最后一个非叶子节点
        sift(a, i, n);
}
```

💡 为什么要从 n/2 开始？因为叶子节点不需要调整（它们已经是"堆"），只有非叶子节点需要。

### 4. 堆排序主函数

```c
static void heap_sort(int a[], int n)
{
    create_heap(a, n);  // Step 1: 建大顶堆

    // 🌟 Step 2: 每次将堆顶（最大值）交换到末尾，再调整堆
    for(int i = n; i > 1; i--)
    {
        // 堆顶 a[1] 与 a[i] 交换 → 最大值归位
        int temp = a[1];
        a[1] = a[i];
        a[i] = temp;

        sift(a, 1, i-1);  // 对剩余元素重新调整为堆
    }
}
```

### 5. 图解过程

```
初始数组：[_, 48, 62, 36, 77, 65, 14, 35, 99]
          (a[0]空闲，数据从 a[1] 开始)

建堆后：  [_, 99, 77, 48, 62, 65, 14, 36, 35]
          堆顶 99 是最大值

第1轮：99 ↔ 35 → [_, 35, 77, 48, 62, 65, 14, 36, | 99]
       调整堆 →   [_, 77, 65, 48, 62, 35, 14, 36, | 99]

第2轮：77 ↔ 36 → [_, 36, 65, 48, 62, 35, 14, | 77, 99]
       调整堆 →   [_, 65, 62, 48, 36, 35, 14, | 77, 99]

...直到排序完成
```

### 6. 测试代码

```c
static int heap_nomal[] = {0, 48, 62, 36, 77, 65, 14, 35, 99};
//                        ↑ a[0] 空闲，数据从 a[1] 开始

int main()
{
    int n = sizeof(heap_nomal)/sizeof(heap_nomal[0]) - 1;
    heap_sort(heap_nomal, n);
    for(int i = 1; i <= n; i++)
        printf("%d ", heap_nomal[i]);
    // 输出：14 35 36 48 62 65 77 99
    return 0;
}
```

## 五、三种排序对比

```
📊 直观对比（对 [48, 62, 36, 77, 65, 14, 35, 99] 排序）：

选择排序：找最小 → 交换 → 找最小 → 交换 → ...（简单粗暴）
快速排序：划分 → 递归左边 → 递归右边（分治高效）
堆排序：  建堆 → 取堆顶 → 调整 → 取堆顶 → ...（稳定可控）
```

| 维度 | 选择排序 | 快速排序 | 堆排序 |
|:---|:---:|:---:|:---:|
| 平均时间 | O(n²) | **O(n log n)** | **O(n log n)** |
| 最坏时间 | O(n²) | O(n²) | **O(n log n)** |
| 额外空间 | O(1) | O(log n) | **O(1)** |
| 是否稳定 | ❌ | ❌ | ❌ |
| 适用场景 | 小规模数据 | 通用排序 | 需要稳定 O(n log n) |

💡 **面试高频问题**：
- 快速排序为什么平均最快？→ 分治 + 缓存友好 + 常数因子小
- 堆排序为什么最坏也是 O(n log n)？→ 完全二叉树高度始终为 log n
- 为什么三种都不稳定？→ 交换操作可能改变相等元素的相对位置

## 六、辅助函数

```c
static void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}
// 📌 三种排序共用的交换函数
```
