## 一、邻接矩阵 vs 邻接表

```
💡 两种图的存储方式，各有优劣：

邻接矩阵 G[][]：
  - 查边：O(1)，直接 G[u][v]
  - 空间：O(V²)，稀疏图浪费严重
  - 适用：边很多的稠密图

邻接表 vertices[] + ArcNode 链表：
  - 查边：O(度数)，需要遍历邻接链表
  - 空间：O(V+E)，只存实际存在的边
  - 适用：边较少的稀疏图
```

📌 上一篇的地铁图用邻接矩阵（站点少、边多），本篇的通用图用邻接表（顶点多、边少）。

## 二、邻接表数据结构

```c
// 🌟 边节点：链表中的一个结点，表示一条边
typedef struct ArcNode {
    int adjvex;                // 该边指向的顶点下标
    struct ArcNode *nextarc;   // 指向下一条边的指针
} ArcNode;

// 🌟 顶点节点：数组中的一个元素
typedef struct VNode {
    char data;                 // 顶点信息（如 'A', 'B'）
    ArcNode *firstarc;         // 指向第一条边
} VNode, AdjList[MAX_VERTEX];

// 图结构
typedef struct {
    AdjList vertices;          // 顶点数组
    int vexnum;                // 顶点数
    int arcnum;                // 边数
} ALGraph;
```

### 内存布局示意

```
vertices[] 数组：
  [0] data='A' → firstarc → (adjvex=1) → (adjvex=2) → NULL
  [1] data='B' → firstarc → (adjvex=0) → (adjvex=3) → NULL
  [2] data='C' → firstarc → (adjvex=0) → NULL
  [3] data='D' → firstarc → (adjvex=1) → NULL

表示的图：
  A --- B --- D
  |
  C
```

## 三、基本操作

### 1. 初始化

```c
void InitGraph(ALGraph *G) {
    G->vexnum = 0;
    G->arcnum = 0;
    for(int i = 0; i < MAX_VERTEX; i++)
        G->vertices[i].firstarc = NULL;
}
```

### 2. 添加顶点

```c
int AddVertex(ALGraph *G, char data) {
    if(G->vexnum >= MAX_VERTEX) return -1;
    G->vertices[G->vexnum].data = data;
    G->vertices[G->vexnum].firstarc = NULL;
    return G->vexnum++;  // 返回下标，然后计数+1
}
```

### 3. 添加有向边

```c
int AddEdge(ALGraph *G, int from, int to) {
    if(from < 0 || from >= G->vexnum || to < 0 || to >= G->vexnum)
        return -1;

    ArcNode *node = (ArcNode *)malloc(sizeof(ArcNode));
    if(!node) return -1;

    node->adjvex = to;
    node->nextarc = G->vertices[from].firstarc;  // 🌟 头插法
    G->vertices[from].firstarc = node;
    G->arcnum++;
    return 0;
}
```

💡 用**头插法**将新边插入链表头部，O(1) 时间。如果需要保持边的有序性，可以用尾插法。

### 4. 查找顶点

```c
int LocateVex(ALGraph G, char v) {
    for(int i = 0; i < G.vexnum; i++)
        if(G.vertices[i].data == v) return i;
    return -1;
}
```

## 四、深度优先搜索（DFS）

### 1. 核心思想

```
🌟 DFS = "一条路走到黑，走不通就回溯"

类比：走迷宫时，每次选择一条未走过的路一直走，
     走到死胡同就退回到上一个分岔口，换一条路继续。

实现方式：递归（隐式栈）或显式栈
```

### 2. 实现代码

```c
// DFS 核心：递归访问当前顶点的所有未访问邻接点
void DFS(ALGraph G, int v)
{
    ArcNode *p;

    printf("%c ", G.vertices[v].data);  // 访问当前顶点
    visited[v] = 1;                      // 标记已访问

    p = G.vertices[v].firstarc;          // 遍历所有邻接点
    while(p != NULL)
    {
        int w = p->adjvex;
        if(!visited[w])                  // 未访问则递归
            DFS(G, w);
        p = p->nextarc;                  // 下一个邻接点
    }
}
```

### 3. 遍历入口（处理非连通图）

```c
void DFSTraverse(ALGraph G)
{
    // 🚀 初始化访问数组
    for(int i = 0; i < G.vexnum; i++)
        visited[i] = 0;

    printf("DFS 遍历结果: ");
    // 🌟 外层循环：确保非连通图的所有顶点都被访问
    for(int i = 0; i < G.vexnum; i++)
    {
        if(!visited[i])      // 如果顶点 i 未被访问
            DFS(G, i);       // 以 i 为起点做一次 DFS
    }
    printf("\n");
}
```

⚠️ 为什么需要外层循环？如果图有多个连通分量（不连通的部分），单次 DFS 只能访问一个连通分量。

### 4. 复杂度

| 邻接表 | 邻接矩阵 |
|:---:|:---:|
| O(V + E) | O(V²) |

## 五、广度优先搜索（BFS）

### 1. 核心思想

```
🌟 BFS = "一层一层往外扩展"

类比：往池塘里扔一块石头，波纹从中心一圈一圈向外扩散。
     先访问所有距离为 1 的节点，再访问距离为 2 的，依此类推。

实现方式：队列（先进先出）
```

### 2. 实现代码

```c
void BFSTraverse(ALGraph G)
{
    int i, v;
    ArcNode *p;
    Queue Q;

    // 🚀 初始化
    for(i = 0; i < G.vexnum; i++)
        visited[i] = 0;
    InitQueue(&Q);

    printf("BFS 遍历结果: ");
    for(i = 0; i < G.vexnum; i++)  // 处理非连通图
    {
        if(!visited[i])
        {
            // 访问起点并入队
            printf("%c ", G.vertices[i].data);
            visited[i] = 1;
            EnQueue(&Q, i);

            while(!QueueEmpty(Q))
            {
                DeQueue(&Q, &v);           // 取出队头
                p = G.vertices[v].firstarc; // 遍历 v 的邻接点

                while(p != NULL)
                {
                    int w = p->adjvex;
                    if(!visited[w])
                    {
                        printf("%c ", G.vertices[w].data);
                        visited[w] = 1;
                        EnQueue(&Q, w);    // 入队，等待后续扩展
                    }
                    p = p->nextarc;
                }
            }
        }
    }
    printf("\n");
}
```

### 3. 辅助队列（循环队列）

```c
typedef struct {
    int data[MAX_VERTEX];
    int front, rear;
} Queue;

void InitQueue(Queue *Q) {
    Q->front = 0;
    Q->rear = 0;
}

int QueueEmpty(Queue Q) {
    return Q.front == Q.rear;  // 📌 front == rear 表示空
}

void EnQueue(Queue *Q, int e) {
    if((Q->rear + 1) % MAX_VERTEX == Q->front)  // ⚠️ 满判断
        return;
    Q->data[Q->rear] = e;
    Q->rear = (Q->rear + 1) % MAX_VERTEX;  // 循环
}

void DeQueue(Queue *Q, int *e) {
    if(Q->front == Q->rear) return;  // 空
    *e = Q->data[Q->front];
    Q->front = (Q->front + 1) % MAX_VERTEX;  // 循环
}
```

💡 循环队列的牺牲一个空间：`(rear+1) % capacity == front` 判满，这样可以区分"满"和"空"。

## 六、DFS vs BFS 对比

| 特性 | DFS | BFS |
|:---|:---|:---|
| 数据结构 | 栈（递归/显式） | 队列 |
| 搜索方式 | 深度优先，一条路走到底 | 广度优先，逐层扩展 |
| 最短路径 | ❌ 不保证 | ✅ 无权图中保证 |
| 空间复杂度 | O(V) | O(V) |
| 适用场景 | 连通性判断、拓扑排序、回溯 | 最短路径（无权）、层序遍历 |
