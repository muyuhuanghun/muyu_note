## 一、作业题 1：查找并删除子树

### 1. 问题描述

```
给定一棵二叉树和一个目标值，找到值等于目标值的节点，
删除以该节点为根的整棵子树。

示例：
        1
       / \
      2   3
     / \
    4   5

删除值为 2 的节点 → 结果只剩：
        1
         \
          3
```

### 2. 核心思路

```
🌟 递归查找 + 后序销毁

1. 递归遍历树，查找目标值
2. 找到后，调用 KillTree() 后序销毁子树
3. 将父节点中指向该子树的指针置为 NULL
```

### 3. 实现代码

```c
static void findandkill(BiTree *root, int target)
{
    // 📌 传入二级指针，因为需要修改指针本身的值
    if(root == NULL || *root == NULL)
        return;

    if((*root)->data == target)
    {
        *root = KillTree(*root);  // 🌟 销毁子树并置空指针
        return;
    }

    // 递归查找左右子树
    findandkill(&(*root)->left, target);
    findandkill(&(*root)->right, target);
}
```

### 4. 关键细节

💡 **为什么传 `BiTree *root`（二级指针）？**

```c
// ❌ 错误写法：传一级指针
void findandkill(BiTree root, int target) {
    if(root->data == target) {
        root = NULL;  // 只修改了局部变量，不影响调用者
    }
}

// ✅ 正确写法：传二级指针
void findandkill(BiTree *root, int target) {
    if((*root)->data == target) {
        *root = NULL;  // 修改了调用者的指针
    }
}
```

⚠️ C 语言是值传递。要修改指针本身，必须传指针的指针。

## 二、作业题 2：顺序存储二叉树求最近公共祖先（LCA）

### 1. 问题描述

```
💡 完全二叉树用数组存储，给定两个节点下标，求它们的最近公共祖先。

数组存储规则（下标从 1 开始）：
  节点 i 的父节点：i / 2
  节点 i 的左孩子：2i
  节点 i 的右孩子：2i + 1

示例：
  数组：[_, 1, 2, 3, 4, 5, 6, 7]
  对应树：
          1
         / \
        2   3
       / \ / \
      4  5 6  7

  LCA(4, 5) = 2
  LCA(4, 6) = 1
  LCA(2, 3) = 1
```

### 2. 核心算法

```
🌟 倍增法（简化版）：不断将较大下标除以 2，直到相等

LCA(4, 5):
  4 != 5, 4 < 5 → j = 5/2 = 2
  4 != 2, 4 > 2 → i = 4/2 = 2
  2 == 2 → 返回 2 ✓

LCA(4, 6):
  4 != 6, 4 < 6 → j = 6/2 = 3
  4 != 3, 4 > 3 → i = 4/2 = 2
  2 != 3, 2 < 3 → j = 3/2 = 1
  2 != 1, 2 > 1 → i = 2/2 = 1
  1 == 1 → 返回 1 ✓
```

### 3. 实现代码

```c
int LCAIndex(int i, int j)
{
    if(i <= 0 || j <= 0)
        return -1;  // 📌 下标非法

    while(i != j)
    {
        if(i > j)
            i = i / 2;  // i 向上移动
        else
            j = j / 2;  // j 向上移动
    }
    return i;  // 相遇点即为 LCA
}
```

💡 **为什么正确？** 在完全二叉树中，从任意节点向上走到根的路径是唯一的。两个节点的 LCA 就是它们向上路径的第一个交汇点。不断除以 2 就是向上走。

### 4. 边界检查

```c
// 🌟 完整的边界检查
if(i < 1 || i > n || j < 1 || j > n) {
    printf("下标越界。\n");
    return 0;
}
if(A[i] == 0 || A[j] == 0) {
    printf("i 或 j 对应空节点，不存在最近公共祖先。\n");
    return 0;
}

int ans = LCAIndex(i, j);
if(ans == -1 || ans > n || A[ans] == 0) {
    printf("不存在最近公共祖先。\n");
} else {
    printf("最近公共祖先节点下标为：%d\n", ans);
}
```

⚠️ **需要检查的边界**：
- 下标是否越界（< 1 或 > n）
- 对应位置是否为空节点（值为 0）
- LCA 结果是否有效（是否为空节点）
