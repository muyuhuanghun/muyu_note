# 量化交易入门课程体系 · 总览

## 🏷️ 文档元数据

- 定位：从零开始的量化交易 (Quantitative Trading) 入门课程体系
- 依据：全网调研权威教材与课程后整理，来源见 [[12.权威书单与课程索引]]
- 学习方式：代码驱动 —— 每章核心是可运行的 Python 代码，概念写在注释里

## 一、权威教材是怎么说的（调研结论）

全网（QuantStart、Reddit r/algotrading、知乎、掘金、CSDN 书单）反复被推荐的路线只有一条：

```
🌟 公认入门路线：
1. 《打开量化投资的黑箱》(Inside the Black Box, Rishi Narang) → 建立"量化是什么"的全景认知
2. 《Quantitative Trading》(Ernest Chan) → 学会像量化交易者一样思考，动手做第一个策略
3. 《Algorithmic Trading》(Ernest Chan) → 系统学动量 / 均值回归两大策略族 + Kelly 公式
4. 《Advances in Financial Machine Learning》(López de Prado) → 进阶，机器学习 + 防过拟合
5. 配套课程：MIT OCW 18.S096、Coursera Investment Management with Python、聚宽/掘金平台实战
```

⚠️ 共同警告：所有教材的作者都在第一章说同一句话——**回测赚钱 ≠ 实盘赚钱**。本课程体系把"回测陷阱"放在第 4 章提前讲，而不是最后。

## 三、学习路线（三阶段）

```
# ==========================================
# 🚀 阶段一：认知 + 工具（第 1-4 章，约 2-3 周）
#    目标：知道量化是什么，能拿到数据、算出收益率、跑通第一次回测
# ==========================================
# 🚀 阶段二：策略 + 理论（第 5-9 章，约 4-6 周）
#    目标：独立实现动量、均值回归、多因子三类策略，懂得仓位与成本
# ==========================================
# 🚀 阶段三：进阶 + 实盘（第 10-12 章，长期）
#    目标：机器学习方法、模拟盘验证、形成自己的研究流程
# ==========================================
```
