## 一、价格 → 收益率

```python
# ==========================================
# 📌 为什么用对数收益率 log return？
#    1. 可加性：多日收益 = 各日收益相加
#    2. 近似对称：涨跌可比
# ==========================================
import numpy as np
import pandas as pd

df = pd.read_parquet("600519.parquet")
price = df["close"]

simple_ret = price.pct_change().dropna()        # 简单收益率 (P_t - P_{t-1})/P_{t-1}
log_ret = np.log(price / price.shift(1)).dropna()  # 对数收益率 ln(P_t/P_{t-1})

# 📌 年化：A股一年约 244 个交易日，美股 252
ann_ret = log_ret.mean() * 244
ann_vol = log_ret.std() * np.sqrt(244)   # ⚠️ 波动率按 sqrt(时间) 缩放
print(f"年化收益: {ann_ret:.2%}, 年化波动: {ann_vol:.2%}")
```

## 二、绩效指标三件套

```python
# ==========================================
# 🌟 评估一个策略，先看这三个数
# ==========================================
def sharpe_ratio(ret, rf=0.02, periods=244):
    """夏普比率：每承担一单位波动，换来多少超额收益"""
    excess = ret.mean() * periods - rf
    return excess / (ret.std() * np.sqrt(periods))

def max_drawdown(price):
    """最大回撤：从历史最高点跌下来最惨的一次"""
    cummax = price.cummax()
    dd = price / cummax - 1
    return dd.min()

def calmar_ratio(ann_return, mdd):
    """Calmar = 年化收益 / |最大回撤|，回撤敏感型指标"""
    return ann_return / abs(mdd)

print(f"Sharpe: {sharpe_ratio(log_ret):.2f}")
print(f"MaxDD:  {max_drawdown(price):.2%}")
```

- 💡 经验基准：**日频策略 Sharpe ≥ 1 勉强可看，≥ 2 才值得上模拟盘**；扣除成本后通常再打对折
- ⚠️ Sharpe 高得离谱(>3 的日频策略) 大概率是回测有 bug 或过拟合，先查错别先高兴

## 三、收益率的统计性质

```python
# ==========================================
# 🌟 金融收益率的三大经验事实(18.S096 重点)
# ==========================================
from scipy import stats

# 1. 尖峰厚尾：极端涨跌比正态分布频繁得多
kurt = stats.kurtosis(log_ret)          # 正态为0，股票通常>3
print(f"超额峰度: {kurt:.1f}  → 别用正态假设算尾部风险")

# 2. 波动率聚集 (volatility clustering)：大波动跟着大波动
#    自相关检验：收益率本身几乎无自相关，但 |ret| 有强自相关
print("收益率自相关:  ", log_ret.autocorr(lag=1))
print("|收益率|自相关:", log_ret.abs().autocorr(lag=1))

# 3. 杠杆效应：下跌时波动率上升
#    简单验证：跌日 vs 涨日的次日波动
down = log_ret[log_ret < 0].index + pd.offsets.BDay(1)
up   = log_ret[log_ret > 0].index + pd.offsets.BDay(1)
print("跌后次日波动 > 涨后次日波动:",
      log_ret.reindex(down).abs().mean() > log_ret.reindex(up).abs().mean())
```

## 四、复习抓手

- 📌 对数收益率可加；波动率按 √t 年化；A股年化用 244 天
- 📌 Sharpe = 超额年化收益 / 年化波动；MaxDD = 价格/历史最高 - 1 的最小值
- 📌 收益率三大经验事实：尖峰厚尾、波动率聚集(可预测的是波动不是方向)、杠杆效应
