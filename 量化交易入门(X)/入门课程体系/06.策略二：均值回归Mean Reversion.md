# 06. 策略二：均值回归 Mean Reversion

## 🏷️ 文档元数据

- 依据：Ernest Chan《Algorithmic Trading》Ch3、Gatev et al. 配对交易、Avellaneda & Lee (2010)
- 核心假设：**价格偏离"锚"之后会弹回来**——和动量完全相反的赌注

## 一、什么是平稳性与协整

```python
# ==========================================
# 📌 两个关键统计概念(Chan 全书的地基)
# ==========================================
# 平稳性(stationary)：均值/方差不随时间变 → 才存在"会回归的均值"
# 协整(cointegration)：两个各自非平稳的价格序列，
#   它们的某个线性组合是平稳的 → 价差会回来，可以配对
#
# ⚠️ 相关性 ≠ 协整！两只同涨同跌的股票可能只是都被大盘推着走，
#    协整要求的是"价差本身"稳定
```

```python
# ==========================================
# 🌟 用 ADF 检验判断平稳性
# ==========================================
from statsmodels.tsa.stattools import adfuller, coint

# 1. 单只价格通常不平稳(有趋势)
adf_p = adfuller(price)[1]
print(f"价格 ADF p值: {adf_p:.3f}  (>0.05 → 不平稳,正常)")

# 2. 收益率通常平稳
print(f"收益率 ADF p值: {adfuller(price.pct_change().dropna())[1]:.4f}")

# 3. 配对协整检验：p<0.05 才算通过
score, pvalue, _ = coint(px_a, px_b)
print(f"协整 p值: {pvalue:.3f}")
```

## 二、配对交易完整流程

```python
# ==========================================
# 🌟 配对交易：做多便宜的 + 做空贵的，赌价差收敛
# ==========================================
import numpy as np

# Step1: 用 OLS 求对冲比率 hedge ratio
import statsmodels.api as sm
model = sm.OLS(px_a, sm.add_constant(px_b)).fit()
hedge = model.params.iloc[1]           # a = c + hedge * b

# Step2: 价差 spread，检验其平稳性
spread = px_a - hedge * px_b
assert adfuller(spread)[1] < 0.05      # ⚠️ 不平稳就别往下走

# Step3: 用滚动均值±N倍标准差做开平仓阈值(避免用全样本均值→未来函数)
mu = spread.rolling(60).mean()
sd = spread.rolling(60).std()
zscore = (spread - mu) / sd

# Step4: 信号：z < -2 做多价差(a多b空)，z 回到 0 平仓
position = pd.Series(np.nan, index=spread.index)
position[zscore < -2] = 1      # 开仓
position[zscore.abs() < 0.5] = 0   # 均值回归完成，平仓
position[zscore > 2] = -1      # 反向开仓
position = position.ffill().fillna(0)
# ⚠️ 别忘了 zscore 用的是 rolling(60)，天然不含未来信息
```

## 三、Bollinger 均值回归（单品种版）

```python
# 📌 单品种版：价格偏离均线2倍标准差时反向做
# ⚠️ 只适合震荡指数/ETF(如温和的指数)，个股有退市风险不适合裸抄底
ma20 = close.rolling(20).mean()
sd20 = close.rolling(20).std()
long_signal  = close < ma20 - 2 * sd20   # 超跌买
short_signal = close > ma20 + 2 * sd20   # 超涨做空(A股个股难做空，常退化为只做多)
```

## 四、⚠️ 均值回归的性格

- ⚠️ **高胜率、低盈亏比**：赚的是小钱，但偶尔一次"不再回归"(基本面变了、退市了)能把一年利润亏光——**必须设止损**
- ⚠️ 与动量互为镜像：震荡市里均值回归是印钞机，趋势市里是绞肉机
- 💡 进阶玩法：判断当前市场状态(regime)来决定用动量还是均值回归 → 见 [[05.策略一：动量Momentum]] 的投票机制

## 五、复习抓手

- 📌 协整 ≠ 相关性；配对交易前提是 spread 通过 ADF 检验
- 📌 阈值必须用滚动窗口算，全样本均值 = 未来函数
- ⚠️ 均值回归必须带止损，"均值"本身可能漂移
