## 一、Kelly 公式：最优仓位

```python
# ==========================================
# 📌 Kelly 公式：让长期复利增长最快仓位
#    f* = μ / σ²  (连续形式，μσ均为年化)
# ==========================================
mu = 0.12          # 年化期望收益(策略的)
sigma = 0.18       # 年化波动
f_star = mu / sigma**2
print(f"满Kelly仓位: {f_star:.1%}")   # 例：370% → 要上3.7倍杠杆?!
```

⚠️ **没人用满 Kelly**：

```python
# ==========================================
# ⚠️ 满Kelly的致命问题
# ==========================================
# 1. μ 和 σ 是估计值，μ 高估 50% → 杠杆放大 50% → 爆仓风险
# 2. Kelly 最优 = 回撤可以非常深(>50%很正常)
# 🌟 业界标准：半 Kelly (fractional Kelly, f/2 甚至 f/4)
half_kelly = f_star / 2
# 💡 代价是增长速度降为满Kelly的75%，换来回撤减半——超划算的交换
```

## 三、风险指标监控

```python
# ==========================================
# 📌 每天该看的仪表盘
# ==========================================
def risk_dashboard(returns, price):
    return {
        "Sharpe":      returns.mean() / returns.std() * np.sqrt(244),
        "Sortino":     returns.mean() / returns[returns < 0].std() * np.sqrt(244),
        "MaxDD":       (price / price.cummax() - 1).min(),
        "当前DD":      price.iloc[-1] / price.max() - 1,
        "VaR95(日)":   returns.quantile(0.05),      # 95%置信度下单日最大亏损
        "换手率":      None,  # 换手太高 = 成本吃掉收益，见第9章
    }

# ⚠️ 止损线建议：MaxDD 触发 -15%/-20% 强制减仓复盘，防"扛单变信仰"
```
