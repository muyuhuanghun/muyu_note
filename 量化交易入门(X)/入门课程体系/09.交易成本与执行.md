## 一、成本的构成

```python
# ==========================================
# 📌 每笔交易的真实成本 = 显性 + 隐性
# ==========================================
cost_model = {
    # --- 显性成本(看得见的账单) ---
    "佣金":     "A股约万2.5(可谈)，美股每股计费",
    "印花税":   "A股卖出单边 0.05%",
    # --- 隐性成本(看不见但更贵) ---
    "滑点slippage": "下单价 vs 成交价的差，流动性差时巨大",
    "冲击成本impact": "自己的单子把价格推走的部分，量越大越贵",
    "机会成本": "为了少付冲击成本慢慢下单，期间价格跑掉的部分",
}
# 💡 Barry Johnson 的经典框架：执行就是 冲击成本 与 机会成本 的权衡
#    下快 → 冲击大；下慢 → 机会成本大
```

## 二、A股成本实测口径

```python
# ==========================================
# 🌟 回测用成本参数(保守估计，宁高勿低)
# ==========================================
A_SHARE_COST = {
    "commission":  0.00025,   # 佣金(双边)
    "stamp_tax":   0.0005,    # 印花税(仅卖出)
    "slippage":    0.001,     # 滑点：按 0.1% 计，高频/小盘要更高
}

def round_trip_cost(is_short=False):
    buy  = A_SHARE_COST["commission"] + A_SHARE_COST["slippage"]
    sell = A_SHARE_COST["commission"] + A_SHARE_COST["stamp_tax"] + A_SHARE_COST["slippage"]
    return buy + sell   # 一买一卖约 0.25%

# 📌 成本敏感度检验(必做!)：
#    把 slippage 参数翻倍，策略 Sharpe 还剩多少？
#    若翻倍后归零 → 策略赚的就是"看起来便宜"的钱，实盘必死
```

## 三、换手率：成本的总阀门

```python
# ==========================================
# 📌 年换手率 = 一年内买卖的总市值 / 平均持仓市值
# ==========================================
turnover = signal.diff().abs().sum(axis=1).sum()   # 向量化算法见第4章
annual_turnover = turnover / 244

# 🌟 经验法则：策略年化超额收益必须 > 年换手率 × 单边成本
# 例：年换手 20 倍 × 0.25% 双边 = 5% 成本门槛
#    你的策略年化超额只有 4% → 成本直接吞掉，白干

# 💡 降低换手三板斧：
#    1. 降低调仓频率(日→周→月)
#    2. 加缓冲带：排名仍在 20%~40% 之间就不动(防边界反复换票)
#    3. 信号平滑：对信号做 EMA，减少毛刺
```

## 四、执行基础概念

```python
# ==========================================
# 🌟 常见订单类型(Johnson《DMA》核心)
# ==========================================
order_types = {
    "市价单 market":     "立即成交，吃掉流动性，冲击大",
    "限价单 limit":      "指定价格，提供流动性，可能不成交",
    "VWAP/TWAP算法":     "把大单拆散按成交量分布慢慢下，降低冲击",

# 💡 入门策略量级小(几十万以下)，冲击成本可忽略，市价/限价单即可
#    大资金执行是专门的研究方向(execution research)
```

## 五、复习抓手

- 📌 换手率 × 双边成本 = 成本门槛，超额收益必须跨过它
- 📌 必做压力测试：滑点翻倍，Sharpe 还活着吗？
