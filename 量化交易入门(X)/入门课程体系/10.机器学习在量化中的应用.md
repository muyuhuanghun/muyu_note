## 二、标签工程：三重障碍法 (Triple Barrier)

```python
# ==========================================
# 🌟 AFML 标志性方法：别再简单预测"明天涨跌"
#    给每个样本设三条障碍线，看先碰到哪条
# ==========================================
import numpy as np

def triple_barrier_label(price, upper=0.02, lower=-0.02, horizon=10):
    """
    每个时点：止盈线(+2%)、止损线(-2%)、时间到期(10天后)
    标签 = 先碰到哪条 → {1: 盈利, -1: 亏损, 0: 到期横盘}
    💡 好处：把"方向+幅度+时间"压缩成一个标签，
       且天然对齐了策略的止盈止损逻辑
    """
    labels = pd.Series(0, index=price.index, dtype=float)
    ret = price.pct_change()
    for i in range(len(price) - horizon):
        window = ret.iloc[i+1 : i+1+horizon]
        hit_tp = (window.cumsum() > upper).idxmax() if (window.cumsum() > upper).any() else None
        hit_sl = (window.cumsum() < lower).idxmax() if (window.cumsum() < lower).any() else None
        if hit_tp is not None and (hit_sl is None or hit_tp <= hit_sl):
            labels.iloc[i] = 1
        elif hit_sl is not None:
            labels.iloc[i] = -1
    return labels
```

