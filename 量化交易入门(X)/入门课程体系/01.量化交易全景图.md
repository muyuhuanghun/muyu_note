# 01. 量化交易全景图（Inside the Black Box）

## 🏷️ 文档元数据

- 依据：Rishi Narang《打开量化投资的黑箱》(Inside the Black Box) 第 1-4 章
- 目标：理解一个量化交易系统由哪几个模块组成，数据如何流动

## 一、本章导读

量化交易 = **用数学模型 + 程序代替人的主观判断做交易决策**。Narang 把整个系统比作"黑箱"，拆开看只有四大件：

```
数据 → Alpha 模型(预测) → 风险模型 → 组合构建 → 执行模型(下单)
                              ↑
                        成本模型贯穿始终
```

## 二、核心概念速记

```python
# ==========================================
# 🌟 量化系统的四大模块，用 Python 类比理解
# ==========================================

class QuantSystem:
    def __init__(self):
        self.data_engine = "数据引擎：清洗行情/财务/另类数据"
        self.alpha_model = "Alpha模型：预测哪个资产会涨(核心武器)"
        self.risk_model  = "风险模型：别把仓位搞太大，控制波动"
        self.portfolio   = "组合构建：把预测变成目标持仓"
        self.execution   = "执行模型：把目标持仓变成真实订单"
        self.cost_model  = "成本模型：每一笔交易都要付过路费"

    def daily_loop(self):
        # 📌 典型日频流程：每天收盘后跑一遍
        signals = self.alpha_model.predict()      # 1. 生成信号
        target  = self.portfolio.build(signals)   # 2. 目标持仓
        orders  = target - self.current_holdings  # 3. 差额 = 订单
        self.execution.send(orders)               # 4. 送进交易所
```

## 三、Alpha 模型的两大流派

```python
# ==========================================
# 🌟 理论驱动 vs 数据驱动
# ==========================================
theory_driven = {
    "思路": "先有经济学假设，再用数据验证",
    "例子": "动量效应：涨的会继续涨(Fama-French momentum)",
    "优点": "可解释、样本外更稳",
}

data_driven = {
    "思路": "先挖数据找规律，事后找解释",
    "例子": "机器学习直接拟合收益",
    "⚠️ 陷阱": "容易把噪音当规律(过拟合)",
}

# 💡 主流机构以理论驱动为主，ML 用于辅助(见第10章)
```

- **预测期限 (forecast horizon)**：高频(毫秒级) / 短线(天) / 中频(周-月) / 低频(季度)。入门从中频开始——数据便宜、成本不致命
- **投注结构**：单品种 VS 跨品种横截面 (cross-sectional)，入门推荐横截面多因子

## 四、复习抓手

- 📌 量化系统 = 数据 → Alpha → 风险 → 组合 → 执行，成本模型贯穿
- 📌 Alpha 模型回答"买什么"；组合构建回答"买多少"；执行回答"怎么买"
- ⚠️ 回测表现 ≠ 实盘表现，中间隔着一整套成本与执行问题(第 9 章)
