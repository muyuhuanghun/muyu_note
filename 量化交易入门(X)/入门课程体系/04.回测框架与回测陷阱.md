## 一、最简向量化回测（双均线示例）

```python
# ==========================================
# 🌟 向量化回测：不用循环，整列信号一次性计算
#    适合研究阶段的快速验证
# ==========================================
import numpy as np
import pandas as pd

df = pd.read_parquet("600519.parquet")
close = df["close"]

# 📌 信号：5日均线上穿20日均线做多，反之空仓
ma_fast = close.rolling(5).mean()
ma_slow = close.rolling(20).mean()
position = (ma_fast > ma_slow).astype(int)

# ⚠️ 关键一行：shift(1) —— 今天收盘才知道信号，明天才赚到钱
#    不 shift 就是 look-ahead bias，回测会凭空多出一大截收益
strat_ret = close.pct_change().shift(-1) * position.shift(1)
strat_ret = strat_ret.fillna(0)

# 📌 扣成本：A股佣金约 0.025%×2 + 印花税卖出 0.05%，留 0.1% 余量
cost = 0.001
turnover = position.diff().abs().fillna(0)
strat_ret -= turnover * cost

sharpe = strat_ret.mean() / strat_ret.std() * np.sqrt(244)
print(f"策略年化Sharpe: {sharpe:.2f}")
```

## 二、⚠️⚠️ 回测四大陷阱（全网教材口径一致）

```python
# ==========================================
# ⚠️ 陷阱1：Look-ahead bias 未来函数
# ==========================================
# 错误：用当天的收盘价决定当天仓位
position = (close > close.rolling(20).mean()).astype(int)  # 收盘才算得出!
# 正确：信号只能用 T 日及之前的信息，T+1 才成交
position = position.shift(1)

# ==========================================
# ⚠️ 陷阱2：Survivorship bias 幸存者偏差
# ==========================================
# 只用"现在还上市"的股票池回测 → 漏掉了退市的乐视们
# 解法：使用包含退市股票的点时(point-in-time)成分股数据

# ==========================================
# ⚠️ 陷阱3：Data snooping 数据窥探 / 多重检验
# ==========================================
# 把 100 组参数都回测一遍，挑 Sharpe 最高的那组 → 那是噪音的极值
# 解法：先定假设再验证；参数在合理区间内应该是一片"高原"而非孤峰

# ==========================================
# ⚠️ 陷阱4：Overfitting 过拟合
# ==========================================
# 参数太多、样本太少 → 拟合了噪音
# 解法：样本外(out-of-sample)测试 + walk-forward，见下
```
