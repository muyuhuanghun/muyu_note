## 二、获取数据（akshare，A 股免费数据首选）

```python
# ==========================================
# 🌟 akshare：免费 A 股日线，无需 token
# ==========================================
import akshare as ak
import pandas as pd

# 📌 拿贵州茅台日线(后复权：分红送股调整过，适合算收益率)
df = ak.stock_zh_a_hist(symbol="600519",
                        period="daily",
                        start_date="20180101",
                        end_date="20241231",
                        adjust="qfq")   # 前复权
df = df.rename(columns={"日期": "date", "开盘": "open", "收盘": "close",
                        "最高": "high", "最低": "low", "成交量": "volume"})
df["date"] = pd.to_datetime(df["date"])
df = df.set_index("date")
print(df.tail())
```

## 三、数据存储与质量检查

```python
# ==========================================
# 📌 数据是量化的地基，脏数据 = 全盘皆输
# ==========================================
def quality_check(df):
    # 1. 缺失值：停牌/数据源缺口
    print("缺失值:\n", df.isna().sum())
    # 2. 异常值：价格突变(可能是复权没做好)
    ret = df["close"].pct_change()
    print("单日涨跌幅超过±20%的天数:", (ret.abs() > 0.2).sum())
    # 3. 重复索引：数据源重复抓取
    print("重复日期:", df.index.duplicated().sum())
    # 4. 交易日历对齐：A股和美股节假日不同
    print("日期是否单调递增:", df.index.is_monotonic_increasing)

quality_check(df)

# 💡 本地存 parquet，比 csv 快 10 倍且保留 dtype
df.to_parquet("600519.parquet")
```

## 四、⚠️ 数据的三坑

- ⚠️ **复权方式**：算收益率必须用复权价；`qfq` 前复权会随新分红变化，长期研究建议用后复权 + 自己管理基准日
- ⚠️ **幸存者偏差**：免费接口常常只给"还活着"的股票，退市股不在样本里(详见第 4 章)
- ⚠️ **财务数据的时间戳**：财报公布日 ≠ 报告期末，用错就是 look-ahead bias
