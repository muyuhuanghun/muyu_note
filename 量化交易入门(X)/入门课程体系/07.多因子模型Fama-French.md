```python
# ==========================================
# 📌 一句话：因子 = 解释股票收益差异的共同原因
# ==========================================
# Fama-French 六因子(Robeco 口径)：
#   Market     市场因子    - 大盘本身涨跌
#   Size       规模因子SMB - 小盘长期跑赢大盘
#   Value      价值因子HML - 低估值(高B/M)跑赢高估值
#   Momentum   动量因子    - 过去赢家跑赢输家(12-1，见第5章)
#   Profitability 盈利因子 - 高ROE跑赢低ROE
#   Investment 投资因子    - 保守投资(低资本开支)跑赢激进扩张
```

## 二、亲手跑一次因子回归

```python
# ==========================================
# 🌟 检验：某股票/某策略的超额收益，是 alpha 还是因子暴露？
# ==========================================
import pandas as pd
import statsmodels.api as sm

# factors: DataFrame，含 Mkt-RF / SMB / HML / Mom(可从 FF 官网或 akshare 获取)
# rf: 无风险利率日序列；ret: 你的策略日收益
excess = ret - rf

model = sm.OLS(excess,
               sm.add_constant(factors[["Mkt-RF", "SMB", "HML", "Mom"]])
              ).fit(cov_type="HAC", cov_kwds={"maxlags": 5})  # HAC 处理自相关
print(model.summary())

alpha = model.params["const"]
# 📌 判读：
#   alpha 显著>0 且 t>2        → 策略真有超额能力
#   alpha≈0，beta_loadings 显著 → 只是"把因子暴露卖给你"，收不到管理费的被动暴露
```

## 三、自建一个简单因子（横截面）

```python
# ==========================================
# 🌟 自己造因子的标准流程
# ==========================================
# Step1 构造信号：例如 "低波动因子"
vol20 = close.pct_change().rolling(20).std()
factor = -vol20          # 波动越低分越高

# Step2 分层回测(quantile backtest)：按因子分5组，看各组收益是否单调
q = factor.rank(axis=1, pct=True)
group = pd.qcut(q.stack(), 5, labels=False).unstack()
# 💡 因子有效的标志：Q1→Q5 组合年化收益单调递增/递减
#    多头组(Q1) - 空头组(Q5) 的收益差 = 因子收益

# Step3 IC 分析：因子值与下期收益的相关性
ic = factor.corrwith(ret.shift(-1), axis=1)   # 每日截面 IC
print(f"IC均值: {ic.mean():.3f}, ICIR: {ic.mean()/ic.std():.2f}")
# 📌 经验：|IC|>0.03 且 ICIR>0.5 值得继续研究
```

## 四、⚠️ 因子投资的坑

- ⚠️ **因子拥挤**：所有人都买低波动股，因子收益会被吃掉(2018 年后低波因子表现疲软)
- ⚠️ **小样本显著性**：用 20 年数据检验一个因子，5% 显著水平下随机也能"发现"一个假因子——多重检验问题又来了
- ⚠️ **因子择时极难**：连学术大牛都做不好，入门别碰，做全天候暴露即可
