# 05. 策略一：动量 Momentum

## 🏷️ 文档元数据

- 依据：Ernest Chan《Algorithmic Trading》Ch2、Jegadeesh & Titman (1993)、Moskowitz et al. 时间序列动量
- 核心假设：**过去涨的，未来一段时间倾向于继续涨**——"强者恒强"

## 一、两种动量

```python
# ==========================================
# 📌 横截面动量 vs 时间序列动量
# ==========================================
# 横截面(cross-sectional)：在股票池里，买过去N天涨最多的，卖涨最少的
#   → 赚的是"相对排名"的钱，市场涨跌无所谓
# 时间序列(time-series)：每个资产自己跟自己的过去比
#   → 涨过均线/历史高点才做多，赚的是"绝对方向"的钱
```

## 二、横截面动量（每月调仓版）

```python
# ==========================================
# 🌟 经典 12-1 动量：过去12个月、剔除最近1个月的收益排名
#    (剔除最近1个月是因为短期存在反转效应)
# ==========================================
import pandas as pd
import numpy as np

# close: DataFrame(index=日期, columns=多只股票) —— 来自第2章的数据管道
mom_12_1 = close.shift(21) / close.shift(252) - 1   # 12个月前→1个月前

# 📌 每月第一个交易日调仓：做多排名前20%
rank = mom_12_1.rank(axis=1, pct=True)      # 横截面百分位
signal = (rank > 0.8).astype(int)
signal = signal.div(signal.sum(axis=1), axis=0).fillna(0)  # 等权归一

# ⚠️ 月度调仓：只在月末最后一天更新信号，其余日期沿用
month_end = ~close.index.to_period("M").duplicated()
signal = signal.where(month_end).ffill()

# 计算组合收益(记得 shift + 成本，见第4章)
ret = close.pct_change()
port_ret = (signal.shift(1) * ret).sum(axis=1) - signal.diff().abs().sum(axis=1).shift(1) * 0.001
sharpe = port_ret.mean() / port_ret.std() * np.sqrt(244)
```

## 三、时间序列动量（双均线 / 突破）

```python
# ==========================================
# 🌟 趋势跟随最简形态(已在第4章写过完整回测)
#    更稳健的版本：多周期均线投票
# ==========================================
signals = pd.DataFrame(index=close.index)
for n in [20, 60, 120]:
    signals[f"ma{n}"] = (close > close.rolling(n).mean()).astype(int)
vote = signals.sum(axis=1)
position = (vote >= 2).astype(int)    # 3个周期里≥2个看多才做多
# 💡 多信号投票比单均线更平滑，减少被震荡市反复打脸
```

## 四、⚠️ 动量策略的性格

- ⚠️ **左侧亏损，右侧爆发**：动量策略赚大钱靠少数大趋势，震荡市会持续小亏——心理上最难扛的是"明明回撤了还在持仓"
- ⚠️ **动量崩溃 (momentum crash)**：市场 V 型反转时(如 2009 年 3 月)，动量策略会重仓追在山顶
- 💡 改进方向：用波动率倒数加权（低波动多配）、加入趋势过滤（大盘跌时不做多个股）

## 五、复习抓手

- 📌 12-1 动量 = shift(21)/shift(252) - 1，剔除最近一月防短期反转
- 📌 横截面赚相对钱、时间序列赚绝对钱
- ⚠️ 动量的收益分布：胜率低、盈亏比高，靠趋势行情养着
