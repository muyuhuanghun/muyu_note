
前往park.edu → 右上角 → “申请帕克大学” →在“新生”标题下“创建账户” 。

第一步——创建您的帐户

填写：

姓名、您的个人邮箱、随机生成的美国电话号码、密码
地点 =在线
复选框 =以上均不适用
→ 提交。

第二步——开始申请

在“申请”标题下，您会看到“开始申请”选项。点击它。

请仅填写红色下划线的必填项：

场地	价值
军队	不
国籍	美国公民
学生类型	本科生
地点	在线及校园中心
程序类型	证书← 请勿更改此项
程序	任何
学期开始	秋季或夏季
→ 保存并提交。

步骤 3 — 个人信息 + 地址信息

场地	价值
国家	我们
地址	您生成的美国地址
邮件寄送方式同上	是的
社会安全号码	您生成的社会安全号码
公民身份（再次）	我们
性别	任何
→ 保存并提交。

第四步——高中信息

CEEB代码：搜索您的虚拟城市 → 选择任意一所列出的学校
以下所有问题请选择“否” ：毕业、在读、获得证书等。
→ 保存并提交。

第五步——为你的教育筹集资金

检查：私人贷款+现金支付
所有选项均选择“否” ：联邦雇员、军队雇员、受雇人员
→ 保存并提交（此处无需填写其他任何内容）。

步骤 6 — 背景 + 父母

请选择“否”回答以下所有问题：家长曾就读于帕克学校、任何人曾就读于帕克学校、重罪。
→ 保存并提交。

步骤 7 — 最终提交

勾选“我同意”复选框 → 保存并提交
点击“提交申请”按钮
提交后——请留意您的个人邮箱，您会收到两条消息：

电子邮件	定时	它包含什么
电子邮件 1	即时（分钟）	学生证确认——您的新公园ID号码
电子邮件 2	2-6小时	学生门户网站已准备就绪，并附有临时密码
:高电压: 请保存这两封邮件。它们是您的注册证明——您在领取 GitHub、SheerID 福利等时需要上传



第二封邮件到达后：

1. 登录学生门户网站
→ my.park.edu — 使用您的学生 ID 号和电子邮件中的临时密码 2.

2. 更改密码
→ 如有需要，请访问myaccount.microsoft.com重置密码

3. 直接访问您的 .edu 邮箱
→ gmail.park.edu — 输入您的学生 ID 号和密码
→ 您的邮箱地址是：（[StudentIDnumber]@park.edu例如 P1234567@park.edu）

4. 将您的帕克大学邮箱添加到 Gmail 或任何邮件客户端
→ 它基于 Google Workspace 运行，使用方式与普通 Gmail 帐户相同
→ 转发到您的主邮箱，或直接登录 gmail.park.edu

:高电压: 请至少登录一次以激活账户，然后才能领取任何权益。
