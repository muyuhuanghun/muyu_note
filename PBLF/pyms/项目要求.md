# 实验指导 - 基于 Python 的可视化云服务综合设计实验

## 1. 实验系列

* Python DevOps & PBLF

## 2. 实验目的

* 熟练掌握 Python Sanic 框架的基本运用；
* 理解并能运用基本的 Python Sanic 服务设计思想和方法；
* 能够运用数据处理相关 Python 库对爬虫合法爬取的数据做数据分析、清洗与可视化。

## 3. 实验要求

* 查阅学习 Python Sanic 的官方文档，进一步深入理解基于 Sanic 构建 Web 服务基本模式；
* 利用爬取的豆瓣影评数据，独立搭建 Python Sanic 云服务，通过 CSV 存储数据，并应用情感分析模型分析数据；
* 学习可视化 Python 库，并将其应用与 Python Sanic 云服务，实现数据可视化 Web 服务展示。

## 4. 实验原理

* 参见前期验证性实验。

## 5. 实验环境

* Python 3.8 +、Sanic、Requests、Matplotlib Pyplot
* Ubuntu 22.04 LTS

## 6. 实验步骤

### 6.1 数据清洗

清洗爬取的豆瓣影评数据，筛选目标数据后输出 JSON 文件，示例格式如下：

```json
{
  "movie_id": "",            // 电影ID
  "movie_title": "",         // 电影标题
  "movie_rating": xx,        // 豆瓣评分
  "comment_list": [{         // 评论
    "comment_cid": "",       // 评论ID
    "comment_content": "",   // 评论内容
    "comment_rating": xx,    // 几星
    "comment_timestamp": xx  // 时间戳
  }]
}

```

### 6.2 数据存储

实现 Python 将 JSON 格式转换成 CSV 的接口，将影评数据规范存储到 CSV 中，易于读取和排查。

### 6.3 运用情感模型分析数据

运用 Senta 情感模型对读取出来的电影评论进行情感分析，得到评论的情感分布信息，供可视化页面显示。

### 6.4 实验自主扩展

模仿前期验证性实验，至少实现可视化数据文件的下载，并在此基础上，尝试进行可视化 Web 页面展示。
