# 一.正确的网络连接

GitHub的网络认证极其严格，且后续的学生认证阶段会根据你的网络ip定位进行验证，所以为了稳定且稳妥的网络连接，请尽量避免使用科学上网，因此这里提供一种无需科学上网[[VPN BASE SET]]，基于steam++加速器的GitHub稳定连接方式

- 1.Microsoft Store中搜索并下载watt toolkit
	![[Pasted image 20260513194820.png]]
	
- 2.打开应用并选择到网络加速界面，勾选GitHub，查看连通性测试，待网络稳定后即可稳定访问GitHub
